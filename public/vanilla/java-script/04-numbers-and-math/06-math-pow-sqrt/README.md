# 📌 Що вивчаємо

У JavaScript для роботи зі степенями та квадратними коренями найчастіше використовуються:

- `Math.pow()`
- оператор `**`
- `Math.sqrt()`

Наприклад:

    Math.pow(2, 3); // 8

    2 ** 3;        // 8

    Math.sqrt(25); // 5

---

# 🔢 Math.pow()

`Math.pow()` підносить число до заданого степеня.

    Math.pow(base, exponent)

де:

- `base` — основа;
- `exponent` — показник степеня.

Наприклад:

    Math.pow(2, 3); // 8

Математично:

    2³ = 2 × 2 × 2 = 8

Ще приклади:

    Math.pow(5, 2); // 25
    Math.pow(3, 3); // 27
    Math.pow(10, 2); // 100

---

# ⚡ Оператор `**`

Сучасний JavaScript має оператор піднесення до степеня:

    **

Наприклад:

    2 ** 3; // 8

    5 ** 2; // 25

    3 ** 3; // 27

Це більш компактний і зазвичай більш зручний запис.

---

# 🔄 Math.pow() vs `**`

Обидва варіанти виконують одну операцію:

    Math.pow(2, 4); // 16

    2 ** 4; // 16

У сучасному JavaScript частіше використовують:

    const result = 2 ** 4;

замість:

    const result = Math.pow(2, 4);

### Порівняння

| Варіант | Результат | Коментар |
|---|---:|---|
| `Math.pow(2, 3)` | `8` | старіший функціональний запис |
| `2 ** 3` | `8` | сучасний оператор |
| `Math.pow(5, 2)` | `25` | зрозуміло |
| `5 ** 2` | `25` | коротше |

### Практичне правило

Для нового коду зазвичай достатньо:

    const square = number ** 2;

    const cube = number ** 3;

---

# ² Піднесення до квадрату

Квадрат числа — це число, помножене саме на себе.

    5² = 5 × 5 = 25

У JavaScript:

    const number = 5;

    const square = number ** 2;

    console.log(square); // 25

Або:

    const square = Math.pow(number, 2);

### Практичні приклади

    const width = 10;
    const area = width ** 2;

    console.log(area); // 100

---

# ³ Піднесення до кубу

Куб числа:

    3³ = 3 × 3 × 3 = 27

У JavaScript:

    const number = 3;

    const cube = number ** 3;

    console.log(cube); // 27

Або:

    const cube = Math.pow(number, 3);

---

# 0️⃣ Степінь з нульовим показником

Для будь-якого ненульового числа:

    number ** 0 === 1

Наприклад:

    5 ** 0; // 1
    100 ** 0; // 1
    (-7) ** 0; // 1

Так само:

    Math.pow(5, 0); // 1

### Виняток

Для `0 ** 0` JavaScript повертає:

    0 ** 0; // 1

У JavaScript це результат операції, хоча в математичному контексті `0⁰` може розглядатися окремо.

Для звичайної практики JavaScript достатньо пам'ятати:

    5 ** 0; // 1

---

# ➖ Від'ємний показник степеня

Від'ємний степінь означає обернене число.

Математично:

    2⁻³ = 1 / 2³ = 1 / 8 = 0.125

У JavaScript:

    2 ** -3; // 0.125

Ще:

    10 ** -2; // 0.01

    5 ** -1; // 0.2

Через `Math.pow()`:

    Math.pow(2, -3); // 0.125

### Загальна формула

    number ** -n === 1 / (number ** n)

---

# 🔢 Дробовий показник степеня

Показник степеня може бути дробовим.

Наприклад:

    9 ** 0.5; // 3

Тому що:

    9^(1/2) = √9 = 3

Аналогічно:

    27 ** (1 / 3); // 3

Тому що:

    27^(1/3) = ∛27 = 3

### Важливо

Дробовий показник дозволяє отримувати корені:

    number ** (1 / 2) // квадратний корінь

    number ** (1 / 3) // кубічний корінь

---

# √ Math.sqrt()

`Math.sqrt()` повертає квадратний корінь числа.

    Math.sqrt(number)

Наприклад:

    Math.sqrt(25); // 5

    Math.sqrt(9); // 3

    Math.sqrt(16); // 4

Математично:

    √25 = 5

    √9 = 3

    √16 = 4

---

# 🧮 Квадратний корінь через `**`

Квадратний корінь можна отримати за допомогою степеня `0.5`:

    25 ** 0.5; // 5

    9 ** 0.5; // 3

Або більш математично:

    25 ** (1 / 2); // 5

Тобто:

    Math.sqrt(25);

і

    25 ** 0.5;

дають однаковий результат.

---

# 🔄 Math.sqrt() vs `** 0.5`

| Варіант | Результат | Коментар |
|---|---:|---|
| `Math.sqrt(25)` | `5` | явно означає квадратний корінь |
| `25 ** 0.5` | `5` | корінь через степінь |
| `25 ** (1 / 2)` | `5` | математично наочний варіант |

Для звичайного квадратного кореня краще використовувати:

    Math.sqrt(number)

Тому що назва методу одразу пояснює, що відбувається:

    const root = Math.sqrt(number);

---

# ⚠️ Особливість оператора `**` і від'ємних чисел

У виразах з від'ємною основою потрібно використовувати дужки.

Правильно:

    (-2) ** 2; // 4

    (-2) ** 3; // -8

Без дужок:

    -2 ** 2;

JavaScript не дозволяє такий запис через особливості синтаксису оператора `**`.

Потрібно написати:

    (-2) ** 2;

### Чому це важливо?

Математично:

    (-2)² = 4

    (-2)³ = -8

А мінус перед результатом — це вже інша операція:

    -(2 ** 2); // -4

Тому:

    (-2) ** 2; // 4

    -(2 ** 2); // -4

---

# ♾️ Поведінка з NaN та Infinity

Степеневі операції працюють і зі спеціальними числовими значеннями.

### NaN

    Math.pow(NaN, 2); // NaN

    NaN ** 2; // NaN

    Math.sqrt(NaN); // NaN

### Infinity

    Math.pow(Infinity, 2); // Infinity

    Infinity ** 2; // Infinity

    Math.sqrt(Infinity); // Infinity

### Негативна нескінченність

    Math.sqrt(-Infinity); // NaN

---

# ❌ Від'ємні числа та корінь

У JavaScript квадратний корінь від'ємного числа повертає `NaN`.

    Math.sqrt(-1); // NaN

    Math.sqrt(-25); // NaN

Це тому, що в множині дійсних чисел немає числа, квадрат якого дорівнює `-1`.

Перевірка:

    Number.isNaN(Math.sqrt(-1)); // true

### Важливо

Якщо користувач вводить число, перед `Math.sqrt()` може знадобитися перевірка:

    const number = -25;

    if (number >= 0) {
        console.log(Math.sqrt(number));
    } else {
        console.log("Cannot calculate square root");
    }

## 5. Перевірка квадратного числа

Можна перевірити, чи є число повним квадратом:

    const number = 49;

    const root = Math.sqrt(number);

    const isPerfectSquare = Number.isInteger(root);

    console.log(isPerfectSquare); // true

Наприклад:

    Math.sqrt(49); // 7
    Number.isInteger(7); // true

А для:

    const number = 50;

    const root = Math.sqrt(number);

    const isPerfectSquare = Number.isInteger(root);

    console.log(isPerfectSquare); // false

# 📐 Теорема Піфагора

Формула:

    c = √(a² + b²)

У JavaScript:

    const a = 3;
    const b = 4;

    const c = Math.sqrt(a ** 2 + b ** 2);

    console.log(c); // 5

Це дуже хороший практичний приклад одночасного використання:

- `**`
- `Math.sqrt()`
- арифметичних операторів.

# ⬜ Площа та сторона квадрата

Якщо відома площа квадрата, сторону можна знайти через квадратний корінь:

    side = √area

Наприклад:

    const area = 64;

    const side = Math.sqrt(area);

    console.log(side); // 8

Зворотна операція:

    const side = 8;

    const area = side ** 2;

    console.log(area); // 64

Отже:

    side ** 2 → area

    Math.sqrt(area) → side

---

# 📏 Відстань між точками

Відстань між двома точками на площині:

    distance = √((x₂ - x₁)² + (y₂ - y₁)²)

JavaScript:

    const x1 = 1;
    const y1 = 2;

    const x2 = 4;
    const y2 = 6;

    const dx = x2 - x1;
    const dy = y2 - y1;

    const distance = Math.sqrt(dx ** 2 + dy ** 2);

    console.log(distance); // 5

Це вже близько до реальних задач програмування:

- координати;
- графіка;
- карти;
- ігри;
- геометрія;
- обробка даних.

# 📈 Степеневе зростання

Степені часто використовуються у формулах зростання.

Наприклад:

    const value = 100;
    const growth = 1.1;
    const years = 3;

    const result = value * growth ** years;

    console.log(result); // 133.1

Тут:

    growth ** years

означає:

    1.1³

# 🧮 Степінь з дробом

Наприклад, квадратний корінь:

    const number = 81;

    const root = number ** (1 / 2);

    console.log(root); // 9

Кубічний корінь:

    const number = 27;

    const root = number ** (1 / 3);

    console.log(root); // 3

Але для квадратного кореня в реальному коді краще:

    const root = Math.sqrt(number);

# 🧠 `Math.pow()` — коли все ще зустрічається

У сучасному коді оператор `**` часто є зручнішим:

    const result = 2 ** 10;

Але `Math.pow()` потрібно розуміти, тому що він:

- зустрічається у старому коді;
- використовується у навчальних матеріалах;
- може зустрічатися в існуючих проєктах;
- є частиною стандартного `Math API`.

Тому знати потрібно обидва варіанти.

---

# ⚠️ Типові помилки

## ❌ Помилка 1. Плутати `^` та `**`

У JavaScript:

    2 ** 3; // 8

А `^` — це не степінь.

    2 ^ 3; // 1

`^` — побітовий XOR.

### Запам'ятати

    ** → степінь

    ^ → bitwise XOR

---

## ❌ Помилка 2. Забувати дужки для від'ємної основи

Правильно:

    (-3) ** 2; // 9

Не потрібно намагатися писати:

    -3 ** 2

---

## ❌ Помилка 3. Плутати квадрат і квадратний корінь

Квадрат:

    number ** 2

Квадратний корінь:

    Math.sqrt(number)

Наприклад:

    9 ** 2; // 81

    Math.sqrt(9); // 3

---

## ❌ Помилка 4. Використовувати `Math.sqrt()` для від'ємного числа

    Math.sqrt(-9); // NaN

Якщо від'ємні значення можливі, перевіряйте їх:

    if (number >= 0) {
        const result = Math.sqrt(number);
    }

---

## ❌ Помилка 5. Забувати про пріоритет операторів

Наприклад:

    2 + 3 ** 2; // 11

Спочатку:

    3 ** 2 // 9

Потім:

    2 + 9 // 11

Якщо потрібен інший порядок — використовуйте дужки:

    (2 + 3) ** 2; // 25

---

# 📊 Порядок операцій

У складних математичних виразах дужки роблять код зрозумілішим.

Наприклад:

    const result = Math.sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2);

Замість спроб запам'ятати весь пріоритет операторів можна використовувати дужки там, де вони покращують читабельність.

# 💼 Питання на співбесіді

### 1. Як піднести число до степеня?

    2 ** 3;

або:

    Math.pow(2, 3);

---

### 2. Що робить `Math.sqrt()`?

Повертає квадратний корінь числа.

    Math.sqrt(25); // 5

---

### 3. Чим `**` відрізняється від `^`?

`**` — піднесення до степеня.

`^` — побітовий XOR.

    2 ** 3; // 8

    2 ^ 3; // 1

---

### 4. Як знайти квадрат числа?

    const square = number ** 2;

---

### 5. Як знайти куб числа?

    const cube = number ** 3;

---

### 6. Як знайти квадратний корінь без `Math.sqrt()`?

    const root = number ** 0.5;

або:

    const root = number ** (1 / 2);

---

### 7. Що поверне `Math.sqrt(-1)`?

    Math.sqrt(-1); // NaN

---

### 8. Як перевірити, чи є число повним квадратом?

Наприклад:

    const number = 81;

    const root = Math.sqrt(number);

    const result = Number.isInteger(root);

    console.log(result); // true

---

### 9. Що буде з `(-2) ** 2`?

    (-2) ** 2; // 4

---

### 10. Чому потрібні дужки навколо `-2`?

Тому що оператор експоненти `**` має спеціальні синтаксичні правила щодо унарного мінуса.

Потрібно:

    (-2) ** 2

А вираз:

    -2 ** 2

не є допустимим записом у JavaScript.

# 🧠 Головне правило

> `**` — піднести число до степеня.

> `Math.pow()` — альтернативний функціональний запис піднесення до степеня.

> `Math.sqrt()` — знайти квадратний корінь.

Для сучасного JavaScript запам'ятай насамперед:

    number ** exponent

    Math.sqrt(number)

А для практичних задач особливо важливо вміти комбінувати їх:

    const distance = Math.sqrt(dx ** 2 + dy ** 2);

Саме такі комбінації перетворюють окремі математичні операції на реальні алгоритми.

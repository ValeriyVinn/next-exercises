### 1. Етап: Синхронне виконання (Рядок за рядком)

1. **`console.log("Початок програми")`** потрапляє в **Call Stack**.
   - *Консоль:* Виводиться `"Початок програми"`.
   - Функція видаляється з **Call Stack**.

2. **`fetchUserData(42, callback)`** викликається і потрапляє в **Call Stack**.

3. Всередині цієї функції виконується **`console.log("[1] Запит даних...")`** (заходить в **Call Stack** і одразу виходить).
   - *Консоль:* Виводиться `"[1] Запит даних для користувача з ID: 42..."`.

4. Наступний рядок всередині функції — **`setTimeout(..., 5000)`**. Він потрапляє в **Call Stack**.
   - Рушій JavaScript бачить, що це асинхронна операція оточення, тому він **передає таймер на 5 секунд у Web APIs**.
   - Сама функція `setTimeout` моментально видаляється з **Call Stack**. Вона не чекає 5 секунд у стеку.

5. Функція `fetchUserData` завершує своє виконання і видаляється з **Call Stack**.

6. **`console.log("Кінець програми...")`** потрапляє в **Call Stack**.
   - *Консоль:* Виводиться `"Кінець програми (код продовжує виконуватися далі)"`.
   - Функція видаляється з **Call Stack**.

*Стан на цей момент:* **Call Stack** повністю порожній. Програма продовжує жити у фоні, оскільки у **Web APIs** цокає 5-секундний таймер. 

---

### 2. Етап: Очікування та перенесення в чергу (Web APIs -> Task Queue)

1. Поки виконувався або міг виконуватися інший синхронний код, у фоні (в **Web APIs**) минає **5000 мс**.
2. Як тільки таймер закінчився, **Web APIs** бере анонімний колбек (колбек `setTimeout`) і переміщує його в **Task Queue (Macrotask Queue)**.
3. **Event Loop** постійно перевіряє стан системи: *"Чи порожній Call Stack? Так. Чи є щось у Microtask Queue? Ні. Чи є щось у Task Queue? Так, колбек від таймера"*.
4. **Event Loop** бере цей колбек з **Task Queue** і проштовхує його в порожній **Call Stack** для виконання.

---

### 3. Етап: Виконання асинхронного колбеку (Call Stack)

1. Колбек починає виконуватися в **Call Stack**. Створюється локальний об'єкт `user`.
2. Викликається **`console.log("[2] Дані успішно отримані...")`**, потрапляє в стек.
   - *Консоль:* Виводиться `"[2] Дані успішно отримані від сервера!"`.
   - Видаляється зі стеку.
3. Наступним у колбеку викликається **`callback(user)`** (це функція, яку ви передали при виклику `fetchUserData`). Вона додається в **Call Stack** поверх поточного колбеку.
4. Всередині функції `callback` викликається **`console.log("[3] Колбек спрацював...", data)`**. Заходить у стек.
   - *Консоль:* Виводиться `"[3] Колбек спрацював. Отримані дані: { id: 42, name: 'Valeriy', role: 'Developer' }"`.
   - Видаляється зі стеку.
5. Функція `callback` завершується і видаляється з **Call Stack**.
6. Анонімний колбек таймера `setTimeout` повністю завершується і також видаляється з **Call Stack**.

*Фінал:* Програма повністю закінчила роботу, **Call Stack** та всі черги знову порожні.

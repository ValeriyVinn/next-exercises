# CSS `clamp()`, `min()` і `max()` — адаптивні розміри та гнучкі обмеження

CSS-функції `clamp()`, `min()` і `max()` дозволяють обчислювати значення CSS на основі кількох варіантів або обмежувати їх мінімальними й максимальними межами.

Вони особливо корисні для адаптивного дизайну, коли розміри тексту, відступи, ширина контейнерів та інші параметри повинні гнучко змінюватися залежно від доступного простору.

Замість великої кількості медіазапитів можна описувати поведінку безпосередньо у значенні CSS-властивості.

## 1. Навіщо потрібні `clamp()`, `min()` і `max()`

Традиційний адаптивний підхід часто використовує медіазапити.

    h1 {
        font-size: 24px;
    }

    @media (min-width: 768px) {
        h1 {
            font-size: 32px;
        }
    }

    @media (min-width: 1200px) {
        h1 {
            font-size: 40px;
        }
    }

Такий код працює, але розмір змінюється стрибками в заданих точках.

За допомогою `clamp()` можна створити плавну зміну розміру:

    h1 {
        font-size: clamp(24px, 4vw, 40px);
    }

Тепер розмір шрифту залежить від ширини вікна, але не стає меншим за `24px` і більшим за `40px`.

### Основні можливості

- `min()` — вибирає найменше з переданих значень.
- `max()` — вибирає найбільше з переданих значень.
- `clamp()` — обмежує значення мінімальною та максимальною межами.
- Функції можуть використовувати відносні одиниці: `%`, `vw`, `rem`, `em` тощо.
- Функції можна поєднувати з `calc()` і CSS Custom Properties.
- Їх можна застосовувати до ширини, відступів, розмірів шрифтів та інших властивостей, де відповідні значення допустимі.

## 2. Функція `min()`

`min()` повертає найменше з двох або більше значень.

### Синтаксис

    width: min(значення1, значення2, ...);

Приклад:

    .container {
        width: min(100%, 1200px);
    }

Якщо доступна ширина становить менше ніж `1200px`, контейнер може займати всю доступну ширину. Якщо доступний простір більший, ширина контейнера не перевищуватиме `1200px`.

### Приклад із різними одиницями

    .box {
        width: min(80vw, 600px);
    }

Браузер порівнює:

- `80vw` — 80% ширини вікна браузера.
- `600px` — фіксовану максимальну ширину.

Для ширини вікна `1000px`:

- `80vw` дорівнює `800px`.
- `min(800px, 600px)` дорівнює `600px`.

Для ширини вікна `500px`:

- `80vw` дорівнює `400px`.
- `min(400px, 600px)` дорівнює `400px`.

Отже, ширина елемента змінюється залежно від доступного простору.

### Центрування контейнера

    .container {
        width: min(100% - 32px, 1200px);
        margin-inline: auto;
    }

Це поширений патерн для адаптивних контейнерів.

- Контейнер має відступи від країв на вузьких екранах.
- Максимальна ширина становить `1200px`.
- `margin-inline: auto` центрує контейнер по горизонталі в звичайному горизонтальному режимі письма.

Тут `100% - 32px` без `calc()` не є допустимим арифметичним виразом. Правильний запис:

    .container {
        width: min(calc(100% - 32px), 1200px);
        margin-inline: auto;
    }

Або можна використати `calc()` у першому аргументі.

### `min()` для відступів

    .section {
        padding-inline: min(5vw, 48px);
    }

Відступи збільшуються на широких екранах, але не перевищують `48px`.

### `min()` для розміру заголовка

    h1 {
        font-size: min(8vw, 48px);
    }

Розмір залежить від ширини вікна, але не перевищує `48px`.

Важливо: `min()` сам по собі не встановлює нижню межу. Якщо потрібно гарантувати мінімальний розмір, розглянь `max()` або `clamp()`.

## 3. Функція `max()`

`max()` повертає найбільше з двох або більше значень.

### Синтаксис

    width: max(значення1, значення2, ...);

Приклад:

    .box {
        width: max(50%, 300px);
    }

Ширина елемента буде не меншою за `300px`, якщо значення `50%` менше за цю величину.

Водночас потрібно враховувати розмір батьківського контейнера: ширина `300px` може виявитися завеликою для дуже вузького екрана.

### `max()` для відступів

    .section {
        padding: max(24px, 4vw);
    }

Відступ становитиме щонайменше `24px`, але збільшуватиметься на ширших екранах, коли `4vw` стане більшим.

### `max()` для ширини

    .content {
        width: max(70%, 320px);
    }

Елемент намагатиметься займати щонайменше `320px` або `70%` ширини батьківського контейнера — залежно від того, яке значення більше.

Це не завжди найкращий вибір для мобільних пристроїв: мінімальна ширина може перевищити доступний простір.

Якщо потрібен розмір, який ніколи не перевищує доступну ширину, варто розглянути `min()` або `clamp()`.

## 4. Функція `clamp()`

`clamp()` задає мінімальне, бажане та максимальне значення.

### Синтаксис

    clamp(мінімум, бажане-значення, максимум)

Приклад:

    h1 {
        font-size: clamp(24px, 4vw, 48px);
    }

Параметри:

- `24px` — мінімальний розмір.
- `4vw` — бажаний, гнучкий розмір.
- `48px` — максимальний розмір.

Браузер обчислює результат і обмежує його встановленими межами.

Концептуально результат відповідає найбільшому з мінімального значення та бажаного, обмеженого максимальним значенням:

    clamp(мінімум, бажане, максимум)
    = max(мінімум, min(бажане, максимум))

### Як працює `clamp()`

Приклад:

    .title {
        font-size: clamp(24px, 4vw, 48px);
    }

| Ширина вікна | `4vw` | Результат |
|---|---:|---:|
| 400px | 16px | 24px |
| 800px | 32px | 32px |
| 1200px | 48px | 48px |
| 1600px | 64px | 48px |

Коли бажане значення менше за мінімум, застосовується мінімум.

Коли бажане значення перебуває між межами, застосовується воно.

Коли бажане значення перевищує максимум, застосовується максимум.

### Основне правило

    font-size: clamp(мінімум, бажане-значення, максимум);

Мінімум і максимум не повинні обов'язково бути пікселями. Можна використовувати `rem`, `em`, `vw` та інші сумісні одиниці.

## 5. Порівняння `min()`, `max()` і `clamp()`

| Функція | Що повертає | Типове завдання |
|---|---|---|
| `min()` | Найменше значення | Обмежити максимальну ширину |
| `max()` | Найбільше значення | Забезпечити мінімальний розмір |
| `clamp()` | Значення між заданими межами | Плавно масштабувати розмір |

### Одна властивість — три різні підходи

    .box-min {
        width: min(80vw, 600px);
    }

    .box-max {
        width: max(80vw, 600px);
    }

    .box-clamp {
        width: clamp(300px, 80vw, 600px);
    }

- `.box-min`: ширина не перевищує `600px`.
- `.box-max`: ширина не менша за `600px`.
- `.box-clamp`: ширина змінюється в межах `300px`–`600px`.

Останній приклад може створити горизонтальне переповнення, якщо доступна ширина менша за `300px`. Мінімальна межа завжди має відповідати реальним потребам макета.

## 6. Відносні одиниці у функціях

Щоб правильно використовувати `min()`, `max()` і `clamp()`, потрібно розуміти CSS-одиниці.

### `px`

Піксель CSS — абсолютніша щодо макета одиниця, ніж відносні одиниці на кшталт `vw`.

    .title {
        font-size: clamp(24px, 4vw, 48px);
    }

### `rem`

`rem` залежить від розміру шрифту кореневого елемента.

    html {
        font-size: 16px;
    }

    h1 {
        font-size: clamp(1.5rem, 4vw, 3rem);
    }

За базового розміру `16px`:

- `1.5rem` дорівнює `24px`.
- `3rem` дорівнює `48px`.

Якщо користувач змінює базовий розмір шрифту, значення в `rem` теж змінюються.

### `em`

`em` зазвичай залежить від розміру шрифту відповідного контексту. Для властивості `font-size` воно обчислюється від розміру шрифту батьківського елемента.

    .card {
        font-size: 1rem;
    }

    .card__title {
        font-size: clamp(1.2em, 1.5em, 2em);
    }

`em` може бути корисним для масштабування елементів відносно типографіки компонента.

### `vw`

`vw` дорівнює 1% ширини вікна перегляду.

    h1 {
        font-size: clamp(24px, 5vw, 56px);
    }

Якщо ширина вікна `1000px`, то `5vw` дорівнює `50px`.

### `vh`, `dvh` та інші одиниці висоти

`vh` базується на висоті вікна перегляду. На мобільних пристроях динамічні панелі браузера можуть впливати на фактичний видимий простір.

`dvh` відповідає динамічній висоті вікна перегляду.

    .hero {
        min-height: max(400px, 70dvh);
    }

Тут секція має висоту щонайменше `400px` або `70dvh` — залежно від того, яке значення більше.

Не варто застосовувати одиниці висоти вікна автоматично до всіх секцій: для звичайного контенту часто краще дозволити висоті визначатися самим вмістом.

## 7. Адаптивна типографіка через `clamp()`

Одна з найпоширеніших практик — плавна зміна розміру тексту.

    h1 {
        font-size: clamp(2rem, 1.2rem + 3vw, 4rem);
    }

    h2 {
        font-size: clamp(1.5rem, 1.1rem + 1.5vw, 2.5rem);
    }

    p {
        font-size: clamp(1rem, 0.95rem + 0.2vw, 1.125rem);
    }

Переваги:

- Заголовки поступово масштабуються.
- Не потрібно створювати медіазапит для кожного проміжного розміру.
- Мінімум захищає від надто дрібного тексту.
- Максимум запобігає надмірному збільшенню.

### Чому бажане значення може містити `calc()`?

У виразі:

    font-size: clamp(2rem, 1.2rem + 3vw, 4rem);

бажаний розмір складається з базового значення `1.2rem` і гнучкої частини `3vw`.

Це дозволяє контролювати не лише нахил масштабування, а й базовий розмір.

### Приклад адаптивної шкали заголовків

    :root {
        --font-size-h1: clamp(2rem, 1.2rem + 3vw, 4rem);
        --font-size-h2: clamp(1.5rem, 1.1rem + 1.5vw, 2.5rem);
        --font-size-h3: clamp(1.25rem, 1.1rem + 0.8vw, 1.75rem);
        --font-size-body: clamp(1rem, 0.95rem + 0.2vw, 1.125rem);
    }

    h1 {
        font-size: var(--font-size-h1);
    }

    h2 {
        font-size: var(--font-size-h2);
    }

    h3 {
        font-size: var(--font-size-h3);
    }

    body {
        font-size: var(--font-size-body);
    }

Таку шкалу можна поєднувати з CSS Custom Properties із попередньої теми.

### Важливо для доступності

Не встановлюй надто малий мінімальний розмір тексту лише заради дизайну. Перевіряй:

- читабельність на мобільних пристроях;
- масштабування сторінки;
- збільшення тексту користувачем;
- достатній міжрядковий інтервал;
- відсутність обрізання довгих заголовків.

## 8. Адаптивні відступи

`clamp()` добре підходить для відступів між секціями, картками й елементами інтерфейсу.

    .section {
        padding-block: clamp(32px, 6vw, 96px);
    }

На вузьких екранах відступ буде близьким до `32px`, на широких поступово збільшуватиметься, але не перевищить `96px`.

### Відступи всередині картки

    .card {
        padding: clamp(16px, 3vw, 32px);
    }

### Відстань між елементами

    .grid {
        display: grid;
        gap: clamp(16px, 2vw, 32px);
    }

### Відступи сторінки

    :root {
        --page-gutter: clamp(16px, 4vw, 48px);
    }

    .container {
        padding-inline: var(--page-gutter);
    }

Так можна створити єдину адаптивну систему відступів для всього сайту.

## 9. Контейнери з `min()` і `max()`

Контейнери часто мають дві вимоги:

1. Не виходити за межі доступної ширини.
2. Не ставати надто широкими на великих екранах.

Для цього зручно використовувати `min()`.

    .container {
        width: min(calc(100% - 32px), 1200px);
        margin-inline: auto;
    }

На вузькому екрані ширина контейнера становить доступну ширину мінус `32px`. На широкому екрані вона обмежується `1200px`.

### Центрування без фіксованої ширини

    .container {
        width: min(90%, 1200px);
        margin-inline: auto;
    }

Контейнер займає 90% ширини батьківського блока, але не стає ширшим за `1200px`.

### Мінімальна ширина

    .sidebar {
        width: max(240px, 20vw);
    }

Це гарантує ширину щонайменше `240px`, але на вузьких екранах може призвести до переповнення.

Для адаптивного компонування краще часто використовувати Grid:

    .layout {
        display: grid;
        grid-template-columns: minmax(0, 1fr);
        gap: 24px;
    }

    @media (min-width: 800px) {
        .layout {
            grid-template-columns: minmax(220px, 280px) minmax(0, 1fr);
        }
    }

`minmax()` — окрема CSS-функція для Grid. Не плутай її з `min()` і `max()`.

## 10. Картки й сітки

Функції мінімальних і максимальних значень корисні в адаптивних сітках.

    .cards {
        display: grid;
        grid-template-columns: repeat(
            auto-fit,
            minmax(min(100%, 260px), 1fr)
        );
        gap: clamp(16px, 2vw, 32px);
    }

Цей приклад поєднує кілька можливостей:

- `repeat()` повторює структуру колонок.
- `auto-fit` дозволяє розмістити доступну кількість колонок.
- `minmax()` задає мінімальний і максимальний розмір треку Grid.
- `min(100%, 260px)` не дозволяє мінімальній ширині колонки перевищити ширину її доступного контейнера.
- `clamp()` адаптує відстань між картками.

### Альтернативний варіант

    .cards {
        display: grid;
        grid-template-columns: repeat(
            auto-fit,
            minmax(min(100%, 18rem), 1fr)
        );
        gap: 1.5rem;
    }

Використання `rem` дозволяє прив'язати мінімальний розмір картки до базового розміру шрифту.

## 11. Зображення та медіаконтент

`min()`, `max()` і `clamp()` можна використовувати для керування розмірами зображень.

    .article-image {
        width: min(100%, 900px);
        height: auto;
        display: block;
        margin-inline: auto;
    }

Зображення не перевищуватиме ширину контейнера або `900px`.

### Обмеження висоти

    .hero-image {
        width: 100%;
        height: clamp(240px, 45vw, 560px);
        object-fit: cover;
    }

Висота зображення змінюється залежно від ширини вікна, але обмежена заданими межами.

`object-fit: cover` заповнює задану область, зберігаючи пропорції зображення, але може обрізати частину зображення.

### Адаптивне співвідношення сторін

Для звичайних зображень часто краще використовувати:

    .article-image {
        width: 100%;
        height: auto;
    }

Якщо потрібне стабільне співвідношення сторін, можна застосувати `aspect-ratio`:

    .thumbnail {
        width: 100%;
        aspect-ratio: 16 / 9;
        object-fit: cover;
    }

Не потрібно використовувати `clamp()` там, де простіша властивість краще вирішує завдання.

## 12. Поєднання з CSS Custom Properties

Функції особливо зручні разом із користувацькими властивостями.

    :root {
        --container-max: 1200px;
        --page-gutter: clamp(16px, 4vw, 48px);

        --font-size-heading: clamp(2rem, 1.2rem + 3vw, 4rem);

        --section-space: clamp(40px, 7vw, 100px);
        --card-space: clamp(16px, 3vw, 32px);
    }

    .container {
        width: min(100%, var(--container-max));
        padding-inline: var(--page-gutter);
        margin-inline: auto;
    }

    .hero {
        padding-block: var(--section-space);
    }

    .hero__title {
        font-size: var(--font-size-heading);
    }

    .card {
        padding: var(--card-space);
    }

### Чому це зручно?

- Усі ключові параметри зібрані в одному місці.
- Можна змінити масштаб дизайну без переписування компонентів.
- Значення простіше узгоджувати з дизайн-системою.
- Змінні можна перевизначати для тем або окремих компонентів.

## 13. Поєднання з `calc()`

`calc()` виконує арифметичні обчислення в CSS.

    .container {
        width: calc(100% - 32px);
    }

Його можна вкладати в `min()`, `max()` і `clamp()`.

### `min()` із `calc()`

    .container {
        width: min(calc(100% - 32px), 1200px);
    }

### `max()` із `calc()`

    .section {
        padding-block: max(24px, calc(2vw + 8px));
    }

### `clamp()` із `calc()`

    h1 {
        font-size: clamp(24px, calc(16px + 3vw), 48px);
    }

Усередині `calc()` можна поєднувати сумісні величини. Під час додавання або віднімання одиниці мають бути сумісними за правилами CSS.

Не потрібно писати `calc()` для простих обчислень, які CSS може виконати безпосередньо, наприклад `min(100% - 2rem, 70rem)` у сучасному CSS допускає математичні вирази без окремого `calc()` у відповідному синтаксисі, але `calc()` залишається зрозумілим і широко впізнаваним способом оформлення арифметики.

## 14. Чи можна повністю замінити медіазапити?

Ні. `clamp()`, `min()` і `max()` розв'язують завдання обчислення значень, але не замінюють усі можливості медіазапитів.

### Коли вистачає функцій

    h1 {
        font-size: clamp(2rem, 5vw, 4rem);
    }

Розмір заголовка змінюється плавно.

### Коли потрібен медіазапит

    .layout {
        display: grid;
        grid-template-columns: 1fr;
    }

    @media (min-width: 800px) {
        .layout {
            grid-template-columns: 280px minmax(0, 1fr);
        }
    }

Тут змінюється сама структура макета, а не лише одне числове значення.

### Можна використовувати обидва підходи

    .layout {
        display: grid;
        grid-template-columns: 1fr;
        gap: clamp(16px, 3vw, 32px);
    }

    @media (min-width: 800px) {
        .layout {
            grid-template-columns: minmax(220px, 280px) minmax(0, 1fr);
        }
    }

У цьому прикладі медіазапит змінює структуру колонок, а `clamp()` плавно регулює відстань між ними.

## 15. Типові помилки

### Помилка 1. Переплутати порядок параметрів `clamp()`

Неправильно:

    h1 {
        font-size: clamp(48px, 4vw, 24px);
    }

Перший параметр має бути мінімумом, а третій — максимумом.

Правильно:

    h1 {
        font-size: clamp(24px, 4vw, 48px);
    }

Якщо нижня межа більша за верхню, результат не відповідатиме очікуваному обмеженню. Тому завжди задавай логічний порядок меж.

### Помилка 2. Вважати `min()` мінімальною межею

    .box {
        width: min(90%, 600px);
    }

Це обмежує ширину зверху, але не гарантує мінімальної ширини.

Якщо потрібна нижня межа:

    .box {
        width: max(300px, 90%);
    }

Проте перевір, чи не призведе це до переповнення на малих екранах.

### Помилка 3. Використовувати надто велике значення `vw`

    h1 {
        font-size: 10vw;
    }

На широкому екрані заголовок може стати надто великим, а на вузькому — надто дрібним.

Краще:

    h1 {
        font-size: clamp(2rem, 5vw, 4rem);
    }

### Помилка 4. Забути про вузькі екрани

    .container {
        width: max(400px, 90%);
    }

На екрані завширшки `320px` контейнер може бути ширшим за доступний простір.

Якщо потрібен адаптивний контейнер:

    .container {
        width: min(calc(100% - 24px), 1200px);
        margin-inline: auto;
    }

### Помилка 5. Вважати, що `clamp()` автоматично робить сайт адаптивним

    .card {
        width: clamp(300px, 50vw, 700px);
    }

Навіть із `clamp()` картка може не поміщатися в батьківський контейнер.

Адаптивність залежить не лише від функцій, а й від структури макета, вмісту та доступного простору.

### Помилка 6. Надмірно використовувати `vw` для тексту

Якщо розмір шрифту залежить лише від ширини вікна, на деяких екранах він може бути незручним для читання.

Краще поєднувати гнучку частину з `rem` і встановлювати межі:

    body {
        font-size: clamp(1rem, 0.95rem + 0.2vw, 1.125rem);
    }

### Помилка 7. Ігнорувати доступність

Мінімальний розмір тексту має залишатися читабельним, а максимальний не повинен порушувати композицію.

Перевіряй сторінку зі збільшеним текстом і масштабуванням браузера.

### Помилка 8. Застосовувати складні функції там, де вони не потрібні

Якщо елемент завжди має бути шириною `300px`, звичайного значення достатньо:

    .icon {
        width: 300px;
    }

Не потрібно писати `clamp(300px, 300px, 300px)` без практичної причини.

## 16. Практичні рекомендації

1. Використовуй `clamp()` для плавного масштабування заголовків, відступів і проміжків.
2. Використовуй `min()` для обмеження максимальної ширини контейнерів.
3. Використовуй `max()`, коли потрібно забезпечити мінімальне значення.
4. Перевіряй, чи не спричиняють мінімальні межі горизонтальне переповнення.
5. Поєднуй `rem` і гнучкі одиниці для адаптивної типографіки.
6. Не покладайся лише на `vw` для всіх текстових розмірів.
7. Використовуй медіазапити, коли потрібно змінити структуру макета.
8. Поєднуй функції з CSS Custom Properties для централізованого керування значеннями.
9. Перевіряй поведінку на дуже вузьких і дуже широких екранах.
10. Враховуй довгі слова, великі кнопки, довгі заголовки й інший контент, що може спричинити переповнення.
11. Не забувай про доступність і збільшення тексту.
12. Обирай найпростіший інструмент, який розв'язує конкретне завдання.

### Що демонструє приклад?

- `clamp()` створює адаптивні розміри заголовків і відступів.
- `min()` обмежує ширину контейнера.
- `minmax()` і `auto-fit` допомагають створювати адаптивну сітку карток.
- `min(100%, 240px)` дозволяє зменшити мінімальний розмір треку на вузьких контейнерах.
- CSS Custom Properties централізують параметри дизайну.
- `min-width: 0` допомагає Grid-елементам стискатися відповідно до доступного простору.
- `overflow-wrap: break-word` допомагає запобігти переповненню через довгі слова.

## 21. Головне, що потрібно запам'ятати

1. `min()` вибирає найменше значення з переданих.
2. `max()` вибирає найбільше значення з переданих.
3. `clamp()` задає мінімальну межу, бажане значення та максимальну межу.
4. `clamp()` особливо корисний для адаптивної типографіки й відступів.
5. `min()` часто використовують для обмеження ширини контейнерів.
6. `max()` корисний, коли потрібно забезпечити мінімальний розмір.
7. Відносні одиниці, як-от `vw` і `rem`, допомагають створювати гнучкі значення.
8. `calc()` можна поєднувати з `min()`, `max()` і `clamp()`.
9. CSS Custom Properties дозволяють централізовано керувати межами та гнучкими значеннями.
10. Ці функції не замінюють медіазапити в усіх випадках.
11. Мінімальні межі можуть створювати переповнення, якщо вони більші за доступний простір.
12. Адаптивність потрібно перевіряти на різних ширинах вікна, а також зі збільшеним текстом.

**Основна ідея:** `min()`, `max()` і `clamp()` допомагають створювати гнучкі CSS-значення з контрольованими межами. Використовуй їх для адаптивної типографіки, відступів, контейнерів і компонентів, а медіазапити залишай для ситуацій, коли потрібно змінювати структуру макета.

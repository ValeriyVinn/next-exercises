# Modern CSS Color Functions — сучасні функції кольорів у CSS

Сучасні CSS-функції кольорів дозволяють створювати, змінювати, змішувати та порівнювати кольори за допомогою різних колірних моделей.

Окрім традиційних форматів `hex`, `rgb()` і `hsl()`, сучасний CSS підтримує `hwb()`, `lab()`, `lch()`, `oklab()`, `oklch()`, `color()`, `color-mix()` та інші можливості.

Ці інструменти допомагають створювати палітри, керувати прозорістю, будувати теми оформлення, отримувати відтінки основного кольору та налаштовувати кольори з урахуванням людського сприйняття.

## 1. Навіщо потрібні сучасні функції кольорів

Традиційні кольори CSS можна задавати різними способами.

    .box-hex {
        background-color: #2563eb;
    }

    .box-rgb {
        background-color: rgb(37 99 235);
    }

    .box-hsl {
        background-color: hsl(221 83% 53%);
    }

Усі три записи представляють приблизно той самий синій колір.

Проте різні колірні моделі зручні для різних завдань.

Наприклад, у HSL можна змінити світлість, не задаючи заново червоний, зелений і синій компоненти:

    .button {
        background-color: hsl(221 83% 53%);
    }

    .button:hover {
        background-color: hsl(221 83% 43%);
    }

Сучасні функції розширюють ці можливості: вони дають змогу працювати з кольорами в моделях, які краще відповідають людському сприйняттю, змішувати кольори й отримувати плавні переходи між ними.

### Основні завдання

- Задавати кольори різними способами.
- Керувати відтінком, насиченістю та світлістю.
- Змінювати прозорість.
- Змішувати два або більше кольорів.
- Створювати палітри на основі одного кольору.
- Отримувати більш передбачувані градієнти.
- Працювати з широкими колірними просторами.
- Будувати світлі й темні теми.
- Створювати кольорові варіанти компонентів.
- Покращувати контроль над контрастом і візуальною узгодженістю.

## 2. Основні способи запису кольорів у CSS

Перед вивченням сучасних функцій потрібно розуміти базові формати кольорів.

### Ключові слова

    .box {
        color: white;
        background-color: tomato;
    }

CSS має набір іменованих кольорів: `red`, `blue`, `green`, `tomato`, `rebeccapurple` та багато інших.

Перевага — простота запису. Недолік — обмежений вибір конкретних значень.

### HEX

HEX — шістнадцятковий запис компонентів кольору.

    .box {
        color: #ffffff;
        background-color: #2563eb;
    }

Формат `#RRGGBB` містить значення червоного, зеленого й синього компонентів.

Також доступні скорочені записи:

    .box {
        color: #fff;
        background-color: #26e;
    }

Трицифровий запис розгортається до шестизначного: `#26e` відповідає `#2266ee`.

HEX із альфа-каналом:

    .overlay {
        background-color: #00000080;
    }

Останні дві шістнадцяткові цифри задають прозорість. `80` — приблизно половина непрозорості.

### RGB

RGB описує колір через червоний, зелений і синій компоненти.

    .box {
        color: rgb(255 255 255);
        background-color: rgb(37 99 235);
    }

Прозорість можна задати четвертим компонентом:

    .overlay {
        background-color: rgb(0 0 0 / 50%);
    }

Сучасний синтаксис використовує пробіли між компонентами та `/` перед альфа-каналом.

### HSL

HSL складається з трьох компонентів:

- `H` — Hue, відтінок.
- `S` — Saturation, насиченість.
- `L` — Lightness, світлість.

    .box {
        background-color: hsl(221 83% 53%);
    }

Відтінок зазвичай задають у градусах колірного кола, а насиченість і світлість — у відсотках.

Прозорість:

    .overlay {
        background-color: hsl(221 83% 53% / 50%);
    }

HSL зручний для ручного створення варіантів кольору, хоча рівні зміни світлості в HSL не завжди відповідають рівним змінам сприйманої світлості.

## 3. Сучасний синтаксис RGB і HSL

У сучасному CSS можна використовувати пробіли між компонентами замість ком.

    .box {
        color: rgb(255 0 0);
        background-color: hsl(0 100% 50%);
    }

Старий синтаксис також широко використовується:

    .box {
        color: rgb(255, 0, 0);
        background-color: hsl(0, 100%, 50%);
    }

Обидва варіанти є валідними.

### Альфа-канал

Альфа-канал визначає непрозорість кольору.

    .box {
        background-color: rgb(0 0 0 / 25%);
    }

    .box:hover {
        background-color: rgb(0 0 0 / 50%);
    }

Чим менше значення альфа-каналу, тим прозоріший колір.

- `100%` — повністю непрозорий.
- `50%` — напівпрозорий.
- `0%` — повністю прозорий.

У сучасному синтаксисі також можна використовувати числа від `0` до `1`.

    .box {
        background-color: rgb(0 0 0 / 0.5);
    }

Важливо: прозорість кольору та властивість `opacity` — не одне й те саме.

    .card {
        background-color: rgb(0 0 0 / 50%);
    }

У цьому прикладі напівпрозорим є фон, але текст усередині картки залишається непрозорим.

    .card {
        opacity: 0.5;
    }

Тут прозорими стають і фон, і текст, і всі інші нащадки елемента.

## 4. Функція `hwb()`

`hwb()` — колірна функція, яка використовує відтінок, білизну та чорність.

Назва походить від:

- `H` — Hue, відтінок.
- `W` — Whiteness, білизна.
- `B` — Blackness, чорність.

Синтаксис:

    color: hwb(відтінок білизна чорність);

Приклад:

    .box {
        background-color: hwb(221 10% 8%);
    }

Це синій відтінок із доданими частками білого й чорного.

### Приклади

    .color-1 {
        background-color: hwb(0 0% 0%);
    }

    .color-2 {
        background-color: hwb(0 50% 0%);
    }

    .color-3 {
        background-color: hwb(0 0% 50%);
    }

У цих прикладах:

- перший колір — чистий червоний відтінок;
- другий додає білизну;
- третій додає чорність.

Якщо сума білизни та чорності становить 100% або більше, колірні компоненти нормалізуються, тому результат не змінюється так, як можна було б очікувати від простого додавання.

### Коли використовувати `hwb()`

- Коли зручно працювати з відтінком і домішками білого або чорного.
- Коли потрібно швидко отримати світліші чи темніші варіанти кольору.
- Коли палітру простіше описати через білизну та чорність.

`hwb()` не є універсально кращим за HSL. Обирай модель, яка зручніша для конкретного завдання.

## 5. Колірна модель CIELAB: `lab()`

`lab()` задає кольори в моделі CIELAB.

Вона використовує:

- `L` — світлість.
- `a` — вісь від зеленого до червоного.
- `b` — вісь від синього до жовтого.

Синтаксис:

    color: lab(L a b);

Приклад:

    .box {
        background-color: lab(60% 20 40);
    }

На відміну від RGB, компоненти `a` і `b` описують напрямки колірних відмінностей, а не інтенсивність основних світлових компонентів.

### Світлість у `lab()`

Перший компонент `L` задає світлість у відсотках.

    .light {
        background-color: lab(85% 20 40);
    }

    .medium {
        background-color: lab(60% 20 40);
    }

    .dark {
        background-color: lab(35% 20 40);
    }

У цих прикладах інші компоненти однакові, тому основна задумана зміна стосується світлості.

### Для чого потрібна модель LAB

- Для роботи з кольорами на основі людського сприйняття.
- Для створення палітр із контрольованою світлістю.
- Для розуміння колірних відмінностей.
- Для побудови кольорових переходів у більш перцептивно орієнтованому просторі.

Важливо: CIELAB — не лінійна RGB-модель. Значення LAB не можна напряму трактувати як компоненти червоного, зеленого та синього кольорів.

## 6. Колірна модель LCH: `lch()`

`lch()` — циліндричне представлення простору CIELAB.

Вона використовує:

- `L` — світлість.
- `C` — Chroma, інтенсивність кольору.
- `H` — Hue, відтінок.

Синтаксис:

    color: lch(світлість інтенсивність відтінок);

Приклад:

    .box {
        background-color: lch(60% 50 250);
    }

### Основні компоненти

**Світлість (`L`)**

Визначає, наскільки світлим або темним сприймається колір.

**Інтенсивність (`C`)**

Відображає насиченість кольору в моделі LCH. Вона не тотожна відсотковій насиченості HSL.

**Відтінок (`H`)**

Задає напрямок на колірному колі, зазвичай у градусах.

### Створення палітри зі спільною світлістю

    .color-red {
        background-color: lch(60% 50 30);
    }

    .color-green {
        background-color: lch(60% 50 140);
    }

    .color-blue {
        background-color: lch(60% 50 250);
    }

Тут світлість та інтенсивність однакові, а відтінок змінюється.

Проте результат не обов'язково матиме однакову сприйману яскравість у всіх кольорів, оскільки сприйняття залежить і від відтінку, і від можливостей колірного простору.

### Коли використовувати `lch()`

- Для створення палітр із контрольованою світлістю.
- Для зміни відтінку без переходу до RGB-компонентів.
- Для генерації варіантів кольорів.
- Для експериментів із колірними переходами.

## 7. Колірна модель Oklab: `oklab()`

`oklab()` — колірна модель, розроблена для більш перцептивно рівномірного представлення кольорів.

Вона використовує:

- `L` — світлість.
- `a` — вісь зелений–червоний.
- `b` — вісь синій–жовтий.

Синтаксис:

    color: oklab(L a b);

Приклад:

    .box {
        background-color: oklab(65% 0.05 0.12);
    }

На відміну від `lab()`, координати `a` і `b` у Oklab зазвичай мають менший числовий масштаб.

### Приклади зі зміною світлості

    .light {
        background-color: oklab(90% 0.05 0.12);
    }

    .medium {
        background-color: oklab(65% 0.05 0.12);
    }

    .dark {
        background-color: oklab(40% 0.05 0.12);
    }

За інших однакових компонентів світлість змінюється від світлішого до темнішого значення.

### Чим Oklab відрізняється від Lab?

Обидві моделі створені для опису кольорів з урахуванням людського сприйняття, але мають різні математичні основи.

Oklab часто зручний для сучасних CSS-палітр і плавних колірних переходів. Це не означає, що він завжди дає ідеально однакові візуальні зміни за будь-яких умов.

## 8. Колірна модель OkLCH: `oklch()`

`oklch()` — циліндричне представлення простору Oklab.

Вона використовує:

- `L` — світлість.
- `C` — інтенсивність кольору.
- `H` — відтінок.

Синтаксис:

    color: oklch(світлість інтенсивність відтінок);

Приклад:

    .box {
        background-color: oklch(65% 0.18 250);
    }

### Чому `oklch()` корисна для дизайн-систем

У багатьох випадках зручніше мислити так:

- зберегти відтінок;
- змінити світлість;
- контролювати інтенсивність кольору.

Наприклад:

    :root {
        --blue-light: oklch(90% 0.08 250);
        --blue-medium: oklch(65% 0.18 250);
        --blue-dark: oklch(40% 0.12 250);
    }

    .notice {
        background-color: var(--blue-light);
        color: var(--blue-dark);
        border: 1px solid var(--blue-medium);
    }

Зверни увагу: інтенсивність `C` у цих прикладах також змінюється. Це може бути корисно, оскільки максимально допустима інтенсивність залежить від світлості й відтінку.

### Переваги `oklch()`

- Зручне керування світлістю.
- Інтуїтивне керування відтінком.
- Можливість створювати узгоджені палітри.
- Корисна для колірних переходів.
- Підходить для системних токенів кольорів.

### Обмеження

Не кожне поєднання `L`, `C` і `H` відповідає кольору, який можна точно відобразити в стандартному sRGB-просторі.

Якщо колір виходить за межі доступного простору, браузер може виконувати відображення кольору в доступний діапазон. Це може змінювати очікуваний результат.

## 9. Порівняння HSL, Lab, LCH, Oklab і Oklch

| Модель | Компоненти | Основна перевага |
|---|---|---|
| HSL | Відтінок, насиченість, світлість | Простий ручний вибір кольору |
| HWB | Відтінок, білизна, чорність | Зручне змішування з білим і чорним |
| Lab | Світлість, осі `a` і `b` | Перцептивно орієнтований простір |
| LCH | Світлість, інтенсивність, відтінок | Зручне керування відтінком і світлістю |
| Oklab | Світлість, осі `a` і `b` | Сучасна перцептивна модель |
| Oklch | Світлість, інтенсивність, відтінок | Зручна модель для палітр і варіантів кольору |

### Яку модель вибрати?

- Для простих традиційних стилів підійдуть HEX, RGB або HSL.
- Для інтуїтивної роботи з білим і чорним можна використовувати HWB.
- Для палітр зі зміною світлості та відтінку варто розглянути LCH або Oklch.
- Для перцептивно орієнтованих переходів можна використовувати Lab або Oklab.
- Для системи кольорових токенів обирай модель, яка забезпечує потрібну передбачуваність і підтримується цільовими браузерами.

Жодна модель не є найкращою для всіх завдань.

## 10. Функція `color()`

`color()` дозволяє задавати колір у визначеному колірному просторі.

Синтаксис:

    color(колірний-простір компонент1 компонент2 компонент3);

Наприклад, у просторі sRGB:

    .box {
        background-color: color(srgb 0.2 0.4 0.9);
    }

У цьому записі компоненти RGB задані числами в діапазоні від `0` до `1`.

### Приклад із Display P3

    .wide-color {
        background-color: color(display-p3 0.2 0.7 0.9);
    }

`display-p3` — ширший колірний простір, ніж стандартний sRGB, у якому деякі кольори можуть мати більшу насиченість.

Фактичне відображення залежить від підтримки браузером, дисплея та його колірних можливостей.

### Коли використовувати `color()`

- Коли потрібен доступ до певного колірного простору.
- Для роботи з Display P3 та іншими підтримуваними просторами.
- Для проєктів із широкою палітрою кольорів.
- Коли колірний простір є частиною вимог до дизайну.

Для звичайного сайту з типовими кольорами часто достатньо HEX, RGB, HSL або Oklch.

## 11. Функція `color-mix()`

`color-mix()` змішує два кольори в заданому колірному просторі.

Це одна з найкорисніших сучасних функцій для створення палітр.

Синтаксис:

    color-mix(in колірний-простір, колір1, колір2);

Приклад:

    .box {
        background-color: color-mix(in srgb, red, blue);
    }

За відсутності явно заданих часток кольори зазвичай беруть участь у суміші порівну.

### Змішування з білим

    .button {
        background-color: color-mix(in srgb, royalblue 70%, white);
    }

Цей приклад створює світліший варіант синього, змішуючи його з білим.

### Змішування з чорним

    .button:hover {
        background-color: color-mix(in srgb, royalblue 80%, black);
    }

Це створює темніший варіант синього.

### Створення палітри з одним основним кольором

    :root {
        --color-primary: oklch(60% 0.18 250);

        --color-primary-light: color-mix(
            in oklch,
            var(--color-primary),
            white 35%
        );

        --color-primary-dark: color-mix(
            in oklch,
            var(--color-primary),
            black 25%
        );
    }

Тепер можна використовувати базовий колір і два його варіанти.

    .button {
        background-color: var(--color-primary);
    }

    .button:hover {
        background-color: var(--color-primary-dark);
    }

    .notice {
        background-color: var(--color-primary-light);
    }

### Чому важливо вказувати колірний простір?

Колірний простір визначає спосіб змішування.

    .srgb {
        background-color: color-mix(in srgb, red, blue);
    }

    .oklab {
        background-color: color-mix(in oklab, red, blue);
    }

Результати можуть відрізнятися, оскільки змішування виконується в різних моделях.

`oklab` часто дає більш перцептивно рівномірні переходи, але конкретний вибір залежить від бажаного ефекту.

### Змішування з прозорістю

    .overlay {
        background-color: color-mix(
            in srgb,
            black 40%,
            transparent
        );
    }

Такий запис створює напівпрозорий чорний колір.

Для простого керування прозорістю часто зрозуміліше використовувати безпосередньо:

    .overlay {
        background-color: rgb(0 0 0 / 40%);
    }

Обирай той спосіб, який найкраще виражає задум.

## 12. Керування частками в `color-mix()`

Частки визначають, скільки кожного кольору бере участь у суміші.

    .mix-1 {
        background-color: color-mix(in oklch, royalblue 90%, white);
    }

    .mix-2 {
        background-color: color-mix(in oklch, royalblue 70%, white);
    }

    .mix-3 {
        background-color: color-mix(in oklch, royalblue 50%, white);
    }

    .mix-4 {
        background-color: color-mix(in oklch, royalblue 30%, white);
    }

Що менша частка синього і більша частка білого, то світлішим зазвичай стає результат.

### Сума часток

Якщо вказано дві частки, наприклад `70%` і `30%`, вони утворюють повну суміш.

Якщо частки в сумі менші за 100%, CSS нормалізує співвідношення кольорів і може застосувати додаткове масштабування альфа-каналу відповідно до неповної суми.

Наприклад:

    .mix {
        background-color: color-mix(
            in srgb,
            red 30%,
            blue 30%
        );
    }

Не слід сприймати цей приклад як еквівалент суміші з двома частками по 50% за непрозорістю: неповна сума впливає і на прозорість результату.

Для передбачуваних непрозорих палітр зручніше задавати частки, що в сумі становлять 100%.

## 13. Прозорість у сучасних колірних функціях

Більшість сучасних функцій кольорів підтримують альфа-канал через `/`.

Приклади:

    .box-rgb {
        background-color: rgb(37 99 235 / 50%);
    }

    .box-hsl {
        background-color: hsl(221 83% 53% / 50%);
    }

    .box-hwb {
        background-color: hwb(221 10% 8% / 50%);
    }

    .box-lab {
        background-color: lab(60% 20 40 / 50%);
    }

    .box-lch {
        background-color: lch(60% 50 250 / 50%);
    }

    .box-oklab {
        background-color: oklab(65% 0.05 0.12 / 50%);
    }

    .box-oklch {
        background-color: oklch(65% 0.18 250 / 50%);
    }

Для `color()` також можна задавати альфа-канал:

    .box {
        background-color: color(srgb 0.2 0.4 0.9 / 50%);
    }

Альфа-канал особливо корисний для:

- накладок на зображення;
- напівпрозорих фонів;
- тіней;
- декоративних елементів;
- кольорів рамок;
- станів наведення та натискання.

## 14. Створення палітри кольорів

Сучасні колірні функції можна використовувати для побудови системної палітри.

    :root {
        --color-primary: oklch(60% 0.18 250);

        --color-primary-100: color-mix(
            in oklch,
            var(--color-primary) 10%,
            white
        );

        --color-primary-200: color-mix(
            in oklch,
            var(--color-primary) 25%,
            white
        );

        --color-primary-300: color-mix(
            in oklch,
            var(--color-primary) 45%,
            white
        );

        --color-primary-700: color-mix(
            in oklch,
            var(--color-primary) 75%,
            black
        );

        --color-primary-900: color-mix(
            in oklch,
            var(--color-primary) 45%,
            black
        );
    }

Використання:

    .button {
        color: white;
        background-color: var(--color-primary);
    }

    .button:hover {
        background-color: var(--color-primary-700);
    }

    .badge {
        color: var(--color-primary-900);
        background-color: var(--color-primary-100);
    }

Цей підхід зменшує кількість вручну підібраних значень.

Однак змішування кольорів не завжди автоматично створює якісну дизайнерську палітру. Для складної дизайн-системи варто перевіряти контраст, насиченість і візуальну узгодженість кожного варіанта.

## 15. Сучасні функції кольорів і дизайн-токени

Дизайн-токени — це іменовані значення, які описують рішення дизайн-системи.

Наприклад:

    :root {
        --color-brand: oklch(60% 0.18 250);

        --color-brand-hover: color-mix(
            in oklch,
            var(--color-brand),
            black 15%
        );

        --color-brand-soft: color-mix(
            in oklch,
            var(--color-brand),
            white 85%
        );

        --color-text: oklch(25% 0.02 250);
        --color-background: oklch(99% 0.005 250);
        --color-border: oklch(85% 0.015 250);
    }

    body {
        color: var(--color-text);
        background-color: var(--color-background);
    }

    .button {
        background-color: var(--color-brand);
        color: white;
    }

    .button:hover {
        background-color: var(--color-brand-hover);
    }

    .notice {
        background-color: var(--color-brand-soft);
        border: 1px solid var(--color-border);
    }

### Чому це корисно?

- Брендовий колір визначено в одному місці.
- Похідні кольори можуть залежати від основного.
- Компоненти використовують зрозумілі назви токенів.
- Палітру простіше підтримувати.
- Можна централізовано змінити дизайн.

У великих проєктах також корисно розділяти базові кольори та семантичні токени.

Наприклад, `--blue-600` описує конкретний колір палітри, а `--color-button-primary` — його призначення в інтерфейсі.

## 16. Світла й темна теми

Сучасні колірні функції можна комбінувати з CSS Custom Properties та атрибутами теми.

    :root {
        color-scheme: light;

        --color-text: oklch(25% 0.02 250);
        --color-background: oklch(99% 0.005 250);
        --color-surface: oklch(96% 0.01 250);
        --color-border: oklch(85% 0.015 250);
        --color-primary: oklch(55% 0.2 250);
    }

    [data-theme="dark"] {
        color-scheme: dark;

        --color-text: oklch(95% 0.01 250);
        --color-background: oklch(18% 0.02 250);
        --color-surface: oklch(24% 0.025 250);
        --color-border: oklch(38% 0.025 250);
        --color-primary: oklch(75% 0.14 250);
    }

    body {
        color: var(--color-text);
        background-color: var(--color-background);
    }

    .card {
        background-color: var(--color-surface);
        border: 1px solid var(--color-border);
    }

    .button {
        color: white;
        background-color: var(--color-primary);
    }

Перемикання атрибута `data-theme` змінює палітру.

### Чому не можна просто інвертувати всі кольори?

Темна тема потребує дизайнерського контролю:

- основний текст має бути читабельним;
- поверхні повинні відрізнятися одна від одної;
- рамки не мають бути надто яскравими;
- акцентні кольори можуть потребувати іншої світлості;
- кольори тексту на кнопках мають залишатися контрастними.

Автоматичне перетворення світлої палітри на темну не завжди забезпечує хороший результат.

## 17. Функція `light-dark()`

`light-dark()` дозволяє задати два кольори: один для світлової схеми, інший — для темної.

    :root {
        color-scheme: light dark;
    }

    body {
        color: light-dark(#1f2937, #f9fafb);
        background-color: light-dark(#ffffff, #111827);
    }

Браузер вибирає відповідний колір залежно від активної схеми кольорів.

### Приклад для компонентів

    :root {
        color-scheme: light dark;
    }

    .card {
        color: light-dark(#1f2937, #f9fafb);
        background-color: light-dark(#f3f4f6, #1f2937);
        border-color: light-dark(#d1d5db, #374151);
    }

`light-dark()` може спростити стилі, коли достатньо автоматичного вибору між двома схемами.

### Важливо

`light-dark()` враховує властивість `color-scheme`. Щоб явно оголосити доступність обох схем, зазвичай використовують:

    :root {
        color-scheme: light dark;
    }

Якщо потрібно примусово перемикати тему кнопкою або зберігати окремий вибір користувача, може бути зручнішим підхід із `[data-theme]`.

## 18. Відносні кольори: Relative Color Syntax

Відносний синтаксис кольорів дозволяє взяти наявний колір і побудувати новий на основі його компонентів.

Це корисно для створення похідних кольорів без ручного повторного підбору всіх значень.

### Приклад із HSL

    :root {
        --color-primary: hsl(221 83% 53%);
    }

    .button-hover {
        background-color: hsl(from var(--color-primary) h s calc(l - 10));
    }

У цьому прикладі браузер бере колір із `--color-primary`, отримує його компоненти HSL і зменшує світлість.

У відносному синтаксисі компоненти залежать від вихідного кольору. Їх можна використовувати без змін або обчислювати через `calc()`.

### Приклад із RGB

    :root {
        --color-primary: rgb(37 99 235);
    }

    .button-soft {
        background-color: rgb(
            from var(--color-primary)
            r
            g
            b
            / 20%
        );
    }

Цей приклад використовує компоненти вихідного кольору й задає альфа-канал `20%`.

### Приклад із Oklch

    :root {
        --color-primary: oklch(60% 0.18 250);
    }

    .button-hover {
        background-color: oklch(
            from var(--color-primary)
            calc(l - 0.08)
            c
            h
        );
    }

Тут світлість зменшується, а інтенсивність і відтінок беруться з вихідного кольору.

### Коли використовувати відносні кольори

- Для автоматичного створення станів наведення.
- Для створення світліших і темніших варіантів.
- Для керування альфа-каналом на основі вихідного кольору.
- Для генерації компонентних палітр.
- Для зменшення дублювання колірних значень.

Відносний синтаксис має специфічні правила для компонентів та їхніх діапазонів. Перед використанням у проєкті перевір підтримку цільовими браузерами.

## 19. Градієнти із сучасними колірними моделями

Градієнти можуть використовувати кольори з різних колірних моделей.

    .gradient {
        background: linear-gradient(
            90deg,
            oklch(65% 0.2 250),
            oklch(70% 0.18 320)
        );
    }

Вибір колірного простору впливає на те, як браузер інтерполює проміжні кольори.

### Вказування простору інтерполяції

    .gradient {
        background: linear-gradient(
            in oklch,
            oklch(65% 0.2 250),
            oklch(70% 0.18 320)
        );
    }

Цей запис задає інтерполяцію градієнта в Oklch.

### Порівняння різних просторів

    .gradient-srgb {
        background: linear-gradient(
            in srgb,
            red,
            blue
        );
    }

    .gradient-oklab {
        background: linear-gradient(
            in oklab,
            red,
            blue
        );
    }

    .gradient-oklch {
        background: linear-gradient(
            in oklch,
            red,
            blue
        );
    }

Градієнти можуть мати помітно різний вигляд залежно від обраного простору.

### Коли це корисно?

- Для брендових градієнтів.
- Для фонових декоративних ефектів.
- Для плавних переходів між відтінками.
- Для керування характером переходу між кольорами.

Oklab та Oklch можуть забезпечувати більш перцептивно узгоджені переходи, але кінцевий вигляд усе одно потрібно перевіряти в реальному інтерфейсі.

## 20. Широкі колірні простори та sRGB

Більшість традиційних вебкольорів використовує sRGB.

Це добре підтримуваний простір, який підходить для великої кількості звичайних інтерфейсів.

Проте сучасні дисплеї можуть підтримувати ширші колірні простори, наприклад Display P3.

    .standard-color {
        background-color: rgb(0 200 120);
    }

    .wide-color {
        background-color: color(display-p3 0 0.85 0.45);
    }

Другий колір задається в Display P3, а не в sRGB.

### Що потрібно враховувати?

- Не всі дисплеї можуть показувати однакову гаму кольорів.
- Браузери можуть по-різному відображати кольори залежно від пристрою та підтримки.
- Значення з ширшого простору не обов'язково будуть яскравішими за будь-яких умов.
- Потрібно тестувати палітру на цільових пристроях.
- Для більшості навчальних проєктів достатньо почати з sRGB, а потім вивчати ширші простори.

## 21. Контрастність і доступність

Сучасні функції дозволяють гнучко створювати кольори, але не гарантують автоматичної доступності.

Наприклад:

    .button {
        color: white;
        background-color: oklch(70% 0.2 250);
    }

Навіть якщо колір виглядає привабливо, білий текст може мати недостатній контраст.

### Що перевіряти

- Контраст тексту відносно фону.
- Контраст інтерактивних елементів.
- Видимість стану фокуса.
- Читабельність у світлій і темній темах.
- Відмінність між кольорами статусів: успіх, помилка, попередження.
- Читабельність тексту на градієнтах і зображеннях.

### Не покладайся лише на колір

Для повідомлень про помилки використовуй не лише червоний колір, а й текстове пояснення або відповідний значок.

    .error-message {
        color: #b91c1c;
    }

    .error-message::before {
        content: "Помилка: ";
        font-weight: 700;
    }

Колір має доповнювати зміст, а не бути єдиним способом передавання важливої інформації.

### Корисні інструменти

Для перевірки контрастності можна використовувати:

- вбудовані інструменти доступності браузера;
- перевірку контрастності у DevTools;
- спеціалізовані онлайн-інструменти для WCAG;
- перевірку інтерфейсу з різними налаштуваннями дисплея.

## 22. Підтримка браузерами та сумісність

Сучасні функції кольорів не мають однакового рівня підтримки в усіх браузерах і версіях.

Особливо уважно перевіряй:

- `oklch()` та `oklab()`;
- `color-mix()`;
- `light-dark()`;
- відносний синтаксис кольорів;
- широкий колірний простір через `color(display-p3 ...)`;
- інтерполяцію градієнтів у заданому колірному просторі.

### Прогресивне покращення

Для критично важливих кольорів можна задати традиційний варіант, а потім перевизначити його в `@supports`.

    .button {
        background-color: #2563eb;
    }

    @supports (background-color: oklch(60% 0.18 250)) {
        .button {
            background-color: oklch(60% 0.18 250);
        }
    }

Браузер, який підтримує `oklch()`, застосує сучасний колір. Якщо підтримки немає, залишиться попереднє значення.

### Для `color-mix()`

    .button {
        background-color: #1d4ed8;
    }

    @supports (background-color: color-mix(in oklch, blue, white)) {
        .button {
            background-color: color-mix(
                in oklch,
                #2563eb 80%,
                black
            );
        }
    }

Це дає змогу використовувати сучасні можливості без втрати базового оформлення в браузерах, які їх не підтримують.

Важливо: перевіряй конкретні функції й синтаксис, які використовуєш. Підтримка однієї сучасної функції не означає підтримки всіх інших.

## 23. Типові помилки

### Помилка 1. Вважати HSL і HSB однаковими

HSL та HSV/HSB — різні моделі кольору.

HSL використовує світлість, а HSV/HSB — яскравість у власному визначенні. Їхні значення не можна напряму вважати взаємозамінними.

### Помилка 2. Плутати насиченість HSL та інтенсивність LCH

У HSL насиченість задається у відсотках.

У LCH та Oklch інтенсивність кольору позначається `C`, але вона має інший зміст і діапазон.

Неправильно очікувати, що `50%` у HSL відповідає певному фіксованому значенню `C` у Oklch.

### Помилка 3. Змішувати кольори без урахування колірного простору

    .gradient {
        background: linear-gradient(red, blue);
    }

Якщо важливий конкретний характер переходу, можна явно вказати простір інтерполяції.

    .gradient {
        background: linear-gradient(in oklab, red, blue);
    }

### Помилка 4. Вважати, що `color-mix()` автоматично створює гарну палітру

Змішування кольорів може дати несподіваний результат для конкретного дизайну.

Перевіряй:

- світлість;
- інтенсивність;
- контраст;
- читабельність;
- зовнішній вигляд на різних фонах.

### Помилка 5. Вважати `opacity` і альфа-канал кольору однаковими

    .card {
        background-color: rgb(0 0 0 / 40%);
    }

Прозорий лише фон.

    .card {
        opacity: 0.4;
    }

Прозорими стають усі частини елемента разом із нащадками.

### Помилка 6. Використовувати широкий колірний простір без перевірки

Колір Display P3 може не відображатися однаково на всіх пристроях.

Для критичних елементів інтерфейсу перевіряй поведінку на цільових дисплеях і передбачай базовий варіант.

### Помилка 7. Забувати про доступність

Красивий акцентний колір не обов'язково забезпечує достатній контраст із білим або чорним текстом.

Перевіряй контрастність окремо для кожної комбінації кольорів.

### Помилка 8. Надмірно ускладнювати звичайні кольори

Якщо для невеликого навчального проєкту достатньо `#2563eb`, не потрібно використовувати складну систему перетворень без конкретної причини.

Сучасні функції варто застосовувати там, де вони реально поліпшують гнучкість або керування кольорами.

## 24. Практичні рекомендації

1. Почни з розуміння HEX, RGB та HSL.
2. Вивчи HWB, Lab, LCH, Oklab і Oklch поступово.
3. Використовуй `color-mix()` для створення похідних кольорів.
4. Розглядай Oklch, коли потрібне зручне керування світлістю, інтенсивністю та відтінком.
5. Використовуй `color()` для роботи з конкретними колірними просторами.
6. Застосовуй `light-dark()` для простих сценаріїв автоматичного вибору кольорів.
7. Вивчай відносний синтаксис кольорів для побудови динамічних варіантів.
8. Перевіряй підтримку браузерами.
9. Для важливих компонентів використовуй запасні значення.
10. Перевіряй контрастність тексту та фону.
11. Не покладайся лише на колір для передавання важливої інформації.
12. Документуй кольорові токени в дизайн-системі.
13. Тестуй палітри в реальних компонентах, а не лише на окремих кольорових квадратах.
14. Не ускладнюй CSS, якщо традиційні формати вже розв'язують завдання.

### Що демонструє приклад?

- `oklch()` задає основний колір.
- `color-mix()` генерує світлий і темний варіанти.
- CSS Custom Properties зберігають кольори як токени.
- Компоненти використовують повторно визначені кольори.
- `@supports` забезпечує запасну палітру для браузерів без підтримки `oklch()`.
- Grid і Flexbox створюють адаптивний макет палітри та кнопок.

## 29. Головне, що потрібно запам'ятати

1. HEX, RGB і HSL — базові формати, з яких варто починати.
2. HWB дозволяє працювати з відтінком, білизною та чорністю.
3. Lab і Oklab — колірні моделі, орієнтовані на людське сприйняття.
4. LCH та Oklch представляють колір через світлість, інтенсивність і відтінок.
5. `color()` дозволяє задавати кольори в певному колірному просторі.
6. `color-mix()` змішує кольори, а результат залежить від вибраного простору.
7. Відносний синтаксис дозволяє створювати нові кольори на основі наявних.
8. `light-dark()` допомагає вибирати кольори залежно від активної схеми.
9. Сучасні колірні функції корисні для дизайн-токенів, тем і градієнтів.
10. Підтримку сучасного синтаксису варто перевіряти для цільових браузерів.
11. Широкі колірні простори можуть відображатися по-різному на різних пристроях.
12. Контрастність і доступність потрібно перевіряти незалежно від способу задання кольору.

**Основна ідея:** сучасні CSS-функції кольорів дають більше контролю над палітрами, змішуванням, світлістю та колірними переходами. Найважливіше — розуміти призначення різних моделей і використовувати їх там, де вони роблять дизайн послідовнішим, гнучкішим і зручнішим для підтримки.

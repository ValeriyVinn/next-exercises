# 05. Border Radius

## 1. Що таке Border Radius?

**Border Radius (радіус заокруглення)** — це властивість CSS, яка визначає, наскільки заокругленими будуть кути елемента.

Для створення заокруглених кутів використовується властивість `border-radius`.

Приклад:

    .card {
      border-radius: 12px;
    }

У цьому прикладі всі чотири кути картки заокруглені на 12px.

Без заокруглення:

    .card {
      border: 1px solid #d1d5db;
      border-radius: 0;
    }

Із заокругленням:

    .card {
      border: 1px solid #d1d5db;
      border-radius: 12px;
    }

**Головна ідея:** Border Radius допомагає визначати форму компонентів і створювати послідовний візуальний стиль інтерфейсу.

У дизайн-системі радіуси зазвичай не вибирають довільно для кожного елемента. Замість цього створюють узгоджену шкалу значень і повторно використовують її через токени.

---

## 2. Навіщо потрібні Border Radius Tokens?

**Border Radius Tokens** — це іменовані змінні, які зберігають значення радіусів заокруглення в дизайн-системі.

Вони допомагають:

✔ підтримувати однаковий стиль компонентів;
✔ уникати випадкових значень радіусів;
✔ повторно використовувати значення в різних елементах;
✔ швидко змінювати форму компонентів;
✔ створювати візуальну ієрархію;
✔ підтримувати цілісність дизайн-системи;
✔ спрощувати розробку нових компонентів;
✔ централізовано змінювати зовнішній вигляд інтерфейсу.

### Без токенів

    .button {
      border-radius: 8px;
    }

    .input {
      border-radius: 7px;
    }

    .card {
      border-radius: 13px;
    }

    .modal {
      border-radius: 15px;
    }

Такі відмінності можуть бути виправданими, але якщо вони виникли випадково, інтерфейс виглядатиме непослідовно.

### Із токенами

    :root {
      --radius-sm: 4px;
      --radius-md: 8px;
      --radius-lg: 12px;
      --radius-xl: 16px;
    }

    .button {
      border-radius: var(--radius-md);
    }

    .input {
      border-radius: var(--radius-md);
    }

    .card {
      border-radius: var(--radius-lg);
    }

    .modal {
      border-radius: var(--radius-xl);
    }

Тепер радіуси належать до спільної системи значень.

**Що запам'ятати:** Border Radius Tokens перетворюють окремі значення `border-radius` на узгоджену шкалу, яку можна повторно використовувати в усьому проєкті.

---

## 3. Основні поняття

### 3.1. Border Radius — радіус заокруглення

`border-radius` визначає форму кутів елемента.

    .box {
      border-radius: 16px;
    }

Можна використовувати різні одиниці вимірювання:

    border-radius: 8px;
    border-radius: 0.5rem;
    border-radius: 50%;

Найчастіше в дизайн-системах використовують `px`, `rem` або відсотки — залежно від призначення компонента.

### 3.2. Radius Scale — шкала радіусів

**Radius Scale** — це набір узгоджених значень радіусів, які використовуються в інтерфейсі.

Наприклад:

    --radius-none: 0;
    --radius-xs: 2px;
    --radius-sm: 4px;
    --radius-md: 8px;
    --radius-lg: 12px;
    --radius-xl: 16px;
    --radius-2xl: 24px;
    --radius-full: 9999px;

Це лише приклад. Не обов'язково використовувати всі значення в кожному проєкті.

### 3.3. Radius Token — токен радіуса

**Radius Token** — це іменована змінна, яка зберігає конкретне значення радіуса.

    :root {
      --radius-card: 12px;
      --radius-button: 8px;
      --radius-input: 8px;
    }

Токен дозволяє змінити радіус централізовано.

### 3.4. Corner Radius — радіус кута

У CSS можна задавати радіус усіх кутів одночасно або налаштовувати кожен кут окремо.

    .box {
      border-radius: 12px;
    }

    .box-special {
      border-top-left-radius: 16px;
      border-top-right-radius: 16px;
      border-bottom-right-radius: 0;
      border-bottom-left-radius: 0;
    }

Це корисно для карток, модальних вікон і панелей, де заокруглюються лише певні кути.

---

## 4. Radius Scale — шкала радіусів

Шкала радіусів допомагає створити спільні правила оформлення кутів.

Приклад:

    :root {
      --radius-none: 0;
      --radius-xs: 2px;
      --radius-sm: 4px;
      --radius-md: 8px;
      --radius-lg: 12px;
      --radius-xl: 16px;
      --radius-2xl: 24px;
      --radius-full: 9999px;
    }

### Як використовувати значення?

| Токен | Приклад значення | Можливе застосування |
|---|---:|---|
| `--radius-none` | `0` | Квадратні кути |
| `--radius-xs` | `2px` | Ледь помітне заокруглення |
| `--radius-sm` | `4px` | Невеликі елементи |
| `--radius-md` | `8px` | Кнопки та поля форм |
| `--radius-lg` | `12px` | Картки |
| `--radius-xl` | `16px` | Великі картки та панелі |
| `--radius-2xl` | `24px` | Великі контейнери |
| `--radius-full` | `9999px` | Пілюлі та круглі елементи |

Це не універсальний стандарт. Значення залежать від стилю продукту, його компонентів і загальної дизайн-системи.

**Важливо:** більший радіус не завжди означає кращий дизайн. Радіус повинен відповідати розміру, формі та призначенню елемента.

---

## 5. Primitive Tokens і Semantic Tokens

Як і кольори та типографіка, радіуси можна організувати через два рівні токенів.

### 5.1. Primitive Tokens — базові токени

Primitive Tokens зберігають конкретні значення радіусів.

Вони відповідають на запитання:

«Яке значення радіуса доступне в системі?»

Приклад:

    :root {
      --radius-0: 0;
      --radius-2: 2px;
      --radius-4: 4px;
      --radius-8: 8px;
      --radius-12: 12px;
      --radius-16: 16px;
      --radius-24: 24px;
      --radius-pill: 9999px;
    }

Це базова шкала значень.

### 5.2. Semantic Tokens — семантичні токени

Semantic Tokens описують призначення радіуса в інтерфейсі.

Вони відповідають на запитання:

«Який радіус повинен використовувати цей компонент?»

Приклад:

    :root {
      --radius-button: var(--radius-8);
      --radius-input: var(--radius-8);
      --radius-card: var(--radius-12);
      --radius-dialog: var(--radius-16);
      --radius-chip: var(--radius-pill);
    }

Тепер компоненти використовують зрозумілі назви.

### 5.3. У чому різниця?

| Primitive Token | Semantic Token |
|---|---|
| `--radius-8` | `--radius-button` |
| `--radius-12` | `--radius-card` |
| `--radius-16` | `--radius-dialog` |
| Зберігає конкретне значення | Визначає призначення |
| Формує шкалу | Пов'язує шкалу з компонентами |

**Що запам'ятати:**

Primitive Token — конкретне значення радіуса.

Semantic Token — радіус, призначений для певної ролі або компонента.

Для невеликого навчального проєкту достатньо однієї шкали. У великій дизайн-системі окремий семантичний рівень допомагає змінювати оформлення компонентів без редагування кожного CSS-класу.

---

## 6. Border Radius для різних компонентів

Різні компоненти можуть використовувати різні радіуси.

### 6.1. Buttons — кнопки

    :root {
      --radius-button: 8px;
    }

    .button {
      border-radius: var(--radius-button);
    }

Невеликий або середній радіус часто підходить для кнопок із прямокутною формою.

Для повністю заокруглених кнопок можна використати окремий токен.

    :root {
      --radius-button-pill: 9999px;
    }

    .button--pill {
      border-radius: var(--radius-button-pill);
    }

### 6.2. Inputs — поля введення

    :root {
      --radius-input: 8px;
    }

    .input {
      border-radius: var(--radius-input);
    }

Поля введення та кнопки часто мають однаковий радіус, щоб виглядати як частини однієї системи.

### 6.3. Cards — картки

    :root {
      --radius-card: 12px;
    }

    .card {
      border-radius: var(--radius-card);
      overflow: hidden;
    }

Картки можуть мати більший радіус, ніж невеликі елементи керування.

`overflow: hidden` часто використовують, коли зображення або внутрішній вміст повинні обрізатися за заокругленими кутами контейнера.

Але застосовувати його потрібно обережно: він також може обрізати тіні, підказки та інший вміст, який виходить за межі картки.

### 6.4. Modals — модальні вікна

    :root {
      --radius-dialog: 16px;
    }

    .dialog {
      border-radius: var(--radius-dialog);
    }

Для великих контейнерів може використовуватися більший радіус, якщо це відповідає стилю продукту.

### 6.5. Avatars — аватари

    :root {
      --radius-avatar: 50%;
    }

    .avatar {
      width: 48px;
      aspect-ratio: 1;
      border-radius: var(--radius-avatar);
      object-fit: cover;
    }

Значення `50%` створює круглу форму за умови квадратного контейнера.

Якщо контейнер не квадратний, результат буде еліпсом.

### 6.6. Badges і Chips

    :root {
      --radius-badge: 6px;
      --radius-chip: 9999px;
    }

    .badge {
      border-radius: var(--radius-badge);
    }

    .chip {
      border-radius: var(--radius-chip);
    }

Badge може мати невелике заокруглення, а chip — форму пілюлі.

Це залежить від дизайну компонентів.

---

## 7. Основні способи використання border-radius

CSS підтримує кілька способів задавати радіуси.

### 7.1. Однаковий радіус для всіх кутів

    .box {
      border-radius: 12px;
    }

Усі чотири кути мають однакове заокруглення.

### 7.2. Два значення

    .box {
      border-radius: 8px 16px;
    }

Перше значення застосовується до верхнього лівого та нижнього правого кутів.

Друге — до верхнього правого та нижнього лівого кутів.

### 7.3. Чотири значення

    .box {
      border-radius: 4px 8px 12px 16px;
    }

Порядок значень:

1. Верхній лівий кут.
2. Верхній правий кут.
3. Нижній правий кут.
4. Нижній лівий кут.

### 7.4. Окремі властивості

    .box {
      border-top-left-radius: 16px;
      border-top-right-radius: 16px;
      border-bottom-right-radius: 0;
      border-bottom-left-radius: 0;
    }

Цей варіант зручний, коли потрібно налаштувати кожен кут окремо.

### 7.5. Горизонтальний і вертикальний радіуси

CSS дозволяє задавати різні горизонтальні й вертикальні радіуси через `/`.

    .box {
      border-radius: 24px / 12px;
    }

У цьому випадку горизонтальний радіус дорівнює 24px, а вертикальний — 12px для відповідних кутів.

Такий синтаксис корисний для створення еліптичних заокруглень, але в більшості звичайних компонентів достатньо простих значень.

---

## 8. Border Radius і форма елемента

Радіус впливає на загальне візуальне сприйняття компонента.

### 8.1. Квадратні кути

    .box {
      border-radius: 0;
    }

Можуть використовуватися в строгих, геометричних або редакційних інтерфейсах.

### 8.2. Невелике заокруглення

    .box {
      border-radius: 4px;
    }

Зберігає прямокутну форму, але робить кути менш гострими.

### 8.3. Помірне заокруглення

    .box {
      border-radius: 12px;
    }

Часто підходить для карток, панелей і кнопок.

### 8.4. Велике заокруглення

    .box {
      border-radius: 24px;
    }

Може використовуватися для великих карток, модальних вікон або виразних контейнерів.

### 8.5. Повне заокруглення

    .box {
      border-radius: 9999px;
    }

Створює форму пілюлі, якщо висота елемента значно менша за заданий радіус.

Для квадратного елемента також можна використати:

    .circle {
      width: 64px;
      aspect-ratio: 1;
      border-radius: 50%;
    }

**Що запам'ятати:** радіус — це не лише декоративна властивість. Він допомагає формувати характер інтерфейсу та підтримувати узгодженість компонентів.

---

## 9. CSS Custom Properties для Border Radius Tokens

У CSS токени радіусів найчастіше створюють через Custom Properties.

### 9.1. Оголошення токенів

    :root {
      --radius-none: 0;
      --radius-sm: 4px;
      --radius-md: 8px;
      --radius-lg: 12px;
      --radius-xl: 16px;
      --radius-full: 9999px;
    }

### 9.2. Використання через var()

    .button {
      border-radius: var(--radius-md);
    }

    .card {
      border-radius: var(--radius-lg);
    }

    .dialog {
      border-radius: var(--radius-xl);
    }

### 9.3. Резервне значення

Якщо потрібно передбачити значення на випадок відсутності токена, можна використати резервне значення `var()`.

    .button {
      border-radius: var(--radius-button, 8px);
    }

Проте в добре організованій дизайн-системі необхідні токени зазвичай оголошують централізовано.

### 9.4. Перевизначення токена

CSS-змінні можна перевизначати для окремої секції.

    :root {
      --radius-card: 12px;
    }

    .compact-layout {
      --radius-card: 6px;
    }

    .card {
      border-radius: var(--radius-card);
    }

Картки всередині `.compact-layout` використовуватимуть радіус 6px, якщо змінна не перевизначена ближче до елемента.

Це дозволяє створювати локальні варіанти оформлення без дублювання всіх стилів.

## 10. Primitive Tokens і Semantic Tokens на практиці

Розглянемо більш організовану систему.

### Крок 1. Створюємо базову шкалу

    :root {
      /* Primitive radius tokens */
      --radius-0: 0;
      --radius-2: 2px;
      --radius-4: 4px;
      --radius-8: 8px;
      --radius-12: 12px;
      --radius-16: 16px;
      --radius-24: 24px;
      --radius-pill: 9999px;
    }

### Крок 2. Створюємо семантичні токени

    :root {
      /* Semantic radius tokens */
      --radius-button: var(--radius-8);
      --radius-input: var(--radius-8);
      --radius-card: var(--radius-12);
      --radius-dialog: var(--radius-16);
      --radius-badge: var(--radius-4);
      --radius-chip: var(--radius-pill);
    }

### Крок 3. Використовуємо їх у компонентах

    .button {
      border-radius: var(--radius-button);
    }

    .input {
      border-radius: var(--radius-input);
    }

    .card {
      border-radius: var(--radius-card);
    }

    .dialog {
      border-radius: var(--radius-dialog);
    }

    .badge {
      border-radius: var(--radius-badge);
    }

    .chip {
      border-radius: var(--radius-chip);
    }

### Крок 4. Змінюємо систему централізовано

Наприклад, потрібно зробити всі кнопки менш заокругленими.

Було:

    --radius-button: var(--radius-8);

Стає:

    --radius-button: var(--radius-4);

Компонент `.button` не потрібно переписувати. Він продовжує використовувати той самий семантичний токен.

**Важливо:** семантичні токени особливо корисні, коли дизайн-система має багато компонентів або кілька візуальних варіантів.

---

## 11. Border Radius і візуальна ієрархія

Радіуси можуть допомагати розрізняти компоненти за їхньою роллю та розміром.

Наприклад:

    :root {
      --radius-control: 8px;
      --radius-card: 12px;
      --radius-container: 20px;
    }

    .button,
    .input {
      border-radius: var(--radius-control);
    }

    .card {
      border-radius: var(--radius-card);
    }

    .page-panel {
      border-radius: var(--radius-container);
    }

У такій системі великі контейнери можуть мати виразніше заокруглення, а невеликі елементи керування — стриманіше.

Однак це не універсальне правило.

У деяких дизайн-системах усі компоненти мають однаковий радіус. В інших радіуси залежать від стилю бренду або типу компонента.

**Головне:** радіуси повинні створювати зрозумілу систему, а не випадковий набір форм.

---

## 12. Border Radius і вкладені компоненти

Іноді один заокруглений контейнер містить інші елементи.

Наприклад, картка має зовнішній радіус, а зображення всередині повинно повторювати форму верхніх кутів.

    .card {
      border-radius: 16px;
      overflow: hidden;
    }

    .card__image {
      display: block;
      width: 100%;
      height: auto;
    }

`overflow: hidden` обрізає зображення за межами картки.

Але якщо всередині картки є меню, підказка або тінь, вони також можуть бути обрізані.

У такому випадку можна заокруглити лише саме зображення:

    .card {
      border-radius: 16px;
    }

    .card__image {
      display: block;
      width: 100%;
      height: auto;
      border-top-left-radius: inherit;
      border-top-right-radius: inherit;
    }

Властивість `inherit` бере значення радіуса від батьківського елемента.

Проте такий підхід потрібно перевіряти, якщо радіуси батьківського елемента змінюються або якщо вкладений елемент має інші розміри.

### Коли використовувати overflow: hidden?

Використовуй його, коли потрібно обрізати внутрішній вміст за межами контейнера.

Не додавай його автоматично до кожного заокругленого елемента.

---

## 13. Border Radius і доступність

Border Radius переважно впливає на візуальне оформлення, але під час роботи з компонентами потрібно пам'ятати про доступність.

### 13.1. Радіус не замінює видимий фокус

Неправильно вважати, що заокруглена кнопка автоматично має зрозумілий стан фокусу.

Краще:

    .button {
      border-radius: var(--radius-button);
    }

    .button:focus-visible {
      outline: 2px solid #2563eb;
      outline-offset: 3px;
    }

Користувач клавіатури повинен бачити, який елемент зараз у фокусі.

### 13.2. Не зменшуй область взаємодії заради форми

Кнопка може бути круглою або мати форму пілюлі, але її клікабельна область повинна залишатися зручною.

    .icon-button {
      width: 44px;
      height: 44px;
      border-radius: 50%;
    }

Це приклад квадратної кнопки з круглою формою.

Сам радіус не визначає доступність області взаємодії. Важливі фактичні розміри, відстань до інших елементів та відповідні вимоги доступності.

### 13.3. Не покладайся лише на форму

Заокруглення саме по собі не пояснює призначення елемента.

Кнопка повинна мати зрозумілий текст або доступну назву, а її стани мають бути достатньо помітними.

## 14. Типові помилки

### Помилка 1. Довільні значення в кожному компоненті

    .button {
      border-radius: 7px;
    }

    .input {
      border-radius: 9px;
    }

    .card {
      border-radius: 13px;
    }

Проблема: інтерфейс може виглядати непослідовно.

Рішення: створи шкалу радіусів і використовуй спільні токени.

### Помилка 2. Занадто багато значень

    --radius-5: 5px;
    --radius-7: 7px;
    --radius-9: 9px;
    --radius-11: 11px;
    --radius-13: 13px;
    --radius-15: 15px;

Проблема: розробнику важко зрозуміти, який радіус обрати.

Рішення: починай із невеликої шкали та додавай значення лише за потреби.

### Помилка 3. Один радіус для всіх випадків без аналізу

    :root {
      --radius-all: 12px;
    }

Проблема: великі картки, поля введення, аватари та пілюлі мають різні геометричні потреби.

Рішення: визнач, чи потрібні компонентам різні ролі радіусів. Водночас не створюй додаткові токени без реальної потреби.

### Помилка 4. Занадто великі радіуси

Проблема: якщо кожен компонент має дуже заокруглені кути, інтерфейс може виглядати перевантаженим або не відповідати характеру продукту.

Рішення: узгоджуй радіуси з розміром елементів і загальним стилем.

### Помилка 5. Неправильне використання 50%

    .avatar {
      width: 80px;
      height: 48px;
      border-radius: 50%;
    }

Проблема: елемент стане еліптичним, а не круглим.

Рішення: для кола використовуй однакові ширину й висоту.

    .avatar {
      width: 48px;
      height: 48px;
      border-radius: 50%;
    }

### Помилка 6. Непотрібний overflow: hidden

Проблема: можуть обрізатися тіні, меню, підказки та інші елементи, які виходять за межі контейнера.

Рішення: використовуй `overflow: hidden` лише тоді, коли справді потрібно обрізати внутрішній вміст.

### Помилка 7. Використання лише числових назв

    --radius-8: 8px;
    --radius-12: 12px;

Це зручно для базової шкали, але не пояснює призначення радіуса.

Рішення: за потреби створи семантичні токени.

    --radius-button: var(--radius-8);
    --radius-card: var(--radius-12);

### Помилка 8. Непослідовні назви

    --button-rounding: 8px;
    --card-radius: 12px;
    --input-corner: 8px;

Проблема: назви побудовані за різними правилами.

Рішення: вибери єдину схему, наприклад `--radius-button`, `--radius-card`, `--radius-input`.

## 16. Практичний алгоритм створення Border Radius Tokens

### Крок 1. Проаналізуй компоненти

Визнач, які елементи використовуються в проєкті:

- кнопки;
- поля введення;
- картки;
- модальні вікна;
- бейджі;
- аватари;
- пілюлі;
- великі контейнери.

### Крок 2. Створи невелику шкалу

Наприклад:

    --radius-none: 0;
    --radius-sm: 4px;
    --radius-md: 8px;
    --radius-lg: 12px;
    --radius-xl: 16px;
    --radius-full: 9999px;

### Крок 3. Визнач призначення значень

Виріши, які радіуси будуть використовуватися для невеликих елементів, карток і великих контейнерів.

### Крок 4. За потреби додай семантичні токени

    --radius-button: var(--radius-md);
    --radius-input: var(--radius-md);
    --radius-card: var(--radius-lg);
    --radius-dialog: var(--radius-xl);

### Крок 5. Застосуй токени в CSS

Не дублюй числові значення без потреби.

### Крок 6. Перевір реальні компоненти

Переконайся, що радіуси відповідають розміру елементів та загальному стилю.

### Крок 7. Перевір вкладені елементи

Якщо картка містить зображення, меню або тіні, переконайся, що вони не обрізаються неправильно.

### Крок 8. Перевір фокус і взаємодію

Заокруглення не повинно приховувати індикатори фокусу або заважати взаємодії з компонентом.

### Крок 9. Документуй правила

Опиши, які токени використовуються для основних компонентів і коли допускаються винятки.

## 19. Коротка шпаргалка

### Основні поняття

    Border Radius
    Радіус заокруглення кутів елемента.

    Radius Scale
    Узгоджений набір значень радіусів.

    Primitive Token
    Токен конкретного значення радіуса.

    Semantic Token
    Токен радіуса, призначений для певної ролі або компонента.

### Основна CSS-властивість

    border-radius: 12px;

Заокруглює всі чотири кути.

### Окремі кути

    border-top-left-radius: 12px;
    border-top-right-radius: 12px;
    border-bottom-right-radius: 12px;
    border-bottom-left-radius: 12px;

### Приклад токенів

    :root {
      --radius-none: 0;
      --radius-sm: 4px;
      --radius-md: 8px;
      --radius-lg: 12px;
      --radius-xl: 16px;
      --radius-full: 9999px;

      --radius-button: var(--radius-md);
      --radius-card: var(--radius-lg);
      --radius-dialog: var(--radius-xl);
    }

### Використання

    .button {
      border-radius: var(--radius-button);
    }

    .card {
      border-radius: var(--radius-card);
    }

    .dialog {
      border-radius: var(--radius-dialog);
    }

### Три головні правила

1. **Використовуй узгоджену шкалу радіусів замість випадкових значень.**
2. **Використовуй семантичні токени для компонентів, якщо це допомагає керувати системою.**
3. **Вибирай радіуси відповідно до форми, розміру та призначення елементів.**

## 21. Підсумок

**Border Radius Tokens — це система іменованих значень заокруглення, яка допомагає підтримувати послідовну форму компонентів у всьому інтерфейсі.**

Найважливіше запам'ятати:

- `border-radius` визначає заокруглення кутів.
- Radius Scale задає набір узгоджених значень.
- Primitive Tokens зберігають конкретні радіуси.
- Semantic Tokens пов'язують радіуси з ролями компонентів.
- CSS Custom Properties дозволяють централізовано керувати радіусами.
- Різні компоненти можуть використовувати різні значення.
- Не потрібно створювати багато токенів без реальної потреби.
- `border-radius: 50%` допомагає створювати круглі елементи за умови квадратного контейнера.
- `overflow: hidden` варто використовувати лише тоді, коли потрібно обрізати внутрішній вміст.
- Заокруглення має підтримувати загальний стиль і не заважати доступності.

**Практична мета:** навчитися створювати невелику шкалу радіусів і застосовувати її через CSS-токени, щоб усі компоненти інтерфейсу мали послідовне та кероване оформлення.

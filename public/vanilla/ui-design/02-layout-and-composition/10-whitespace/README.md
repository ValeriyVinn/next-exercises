# 10. Whitespace — Негативний простір у UI-дизайні

## 1. Що таке Whitespace

**Whitespace (негативний простір, порожній простір)** — це простір між елементами інтерфейсу та навколо них, який не зайнятий основним візуальним контентом.

Whitespace може бути білим, сірим, чорним або будь-якого іншого кольору. Назва не означає, що простір обов'язково має бути білим.

Наприклад, у картці курсу простором Whitespace є:

- Відстань між заголовком і описом.
- Простір між текстом і кнопкою.
- Внутрішні відступи від країв картки.
- Відстань між сусідніми картками.
- Вільна область навколо заголовка секції.

Whitespace — це не просто відсутність контенту. Це активний інструмент дизайну, який допомагає керувати увагою, читабельністю та сприйняттям структури.

### Приклад

Перевантажений інтерфейс:

    ┌─────────────────────────────────────────┐
    │Dashboard Overview Revenue Users Orders  │
    │Revenue $12,450 Users 1,250 Orders 340   │
    │Recent activity User A User B User C     │
    │Performance chart                       │
    └─────────────────────────────────────────┘

Інтерфейс із продуманим Whitespace:

    ┌─────────────────────────────────────────┐
    │                                         │
    │  Dashboard                              │
    │  Overview of your activity              │
    │                                         │
    │  ┌──────────┐ ┌──────────┐ ┌──────────┐ │
    │  │ Revenue  │ │  Users   │ │  Orders  │ │
    │  │ $12,450  │ │  1,250   │ │   340    │ │
    │  └──────────┘ └──────────┘ └──────────┘ │
    │                                         │
    │  Recent activity                        │
    │                                         │
    └─────────────────────────────────────────┘

У другому варіанті вільний простір допомагає розділити заголовок, показники та наступну секцію.

---

## 2. Навіщо потрібен Whitespace

Продуманий негативний простір допомагає:

- Покращувати читабельність тексту.
- Розділяти інформацію на логічні групи.
- Створювати візуальну ієрархію.
- Привертати увагу до важливих елементів.
- Зменшувати відчуття перевантаженості.
- Підкреслювати значущість заголовків і кнопок.
- Покращувати сприйняття композиції.
- Робити інтерфейс візуально охайним.
- Підтримувати зрозумілу структуру сторінки.
- Створювати відчуття простору, легкості або преміальності.

### Основна ідея

**Whitespace допомагає користувачеві зрозуміти, що важливо, що пов'язано між собою і де починається новий змістовий блок.**

Важливо: більше вільного простору не завжди означає кращий дизайн. Кількість Whitespace має відповідати призначенню інтерфейсу, кількості інформації та контексту використання.

---

## 3. Whitespace і Negative Space

Терміни `Whitespace` і `Negative Space` часто використовують як синоніми.

У графічному дизайні Negative Space особливо підкреслює простір навколо об'єктів і між ними, тоді як Whitespace часто використовують у контексті типографіки, вебдизайну та інтерфейсів.

У UI-дизайні обидва терміни описують простір, який допомагає організовувати контент.

### Приклади

- Простір навколо логотипа.
- Відстань між абзацами.
- Відступи всередині кнопки.
- Вільна область навколо головного заголовка.
- Проміжки між елементами навігації.
- Відстані між колонками таблиці.
- Простір між картками в сітці.

Whitespace може бути як великим і помітним, так і маленьким — наприклад, між літерами або рядками тексту.

---

## 4. Основні види Whitespace

У практиці UI-дизайну корисно розрізняти кілька типів простору.

### 4.1. Micro Whitespace — мікропростір

Невеликі проміжки всередині тексту та компонентів.

Приклади:

- Між літерами.
- Між словами.
- Між рядками тексту.
- Між іконкою та текстом кнопки.
- Між підписом і полем введення.
- Між пунктами короткого списку.

CSS-приклади:

    .button {
      display: inline-flex;
      align-items: center;
      gap: 8px;
      padding: 10px 16px;
    }

    .paragraph {
      line-height: 1.6;
    }

    .heading {
      letter-spacing: -0.02em;
    }

Мікропростір впливає на локальну читабельність і зручність взаємодії з компонентами.

### 4.2. Macro Whitespace — макропростір

Великі проміжки між секціями, блоками та областями сторінки.

Приклади:

- Відстань між Hero-секцією та наступним блоком.
- Простір навколо основного заголовка.
- Відстань між групами карток.
- Вільна область навколо центрального зображення.
- Відстань між основним контентом і футером.

CSS-приклад:

    .page-section {
      padding-block: 64px;
    }

    .section-header {
      margin-bottom: 32px;
    }

Макропростір визначає загальний ритм сторінки та допомагає сприймати її як систему секцій.

### 4.3. Internal Whitespace — внутрішній простір

Простір усередині компонента або контейнера.

Наприклад, внутрішній простір картки між її краями та текстом.

    .card {
      padding: 24px;
    }

Внутрішній простір не дає контенту прилипати до меж компонента.

### 4.4. External Whitespace — зовнішній простір

Простір навколо компонента, який відокремлює його від інших елементів.

    .card {
      margin-bottom: 24px;
    }

Або за допомогою контейнера:

    .card-list {
      display: flex;
      flex-direction: column;
      gap: 24px;
    }

Для Flexbox і Grid `gap` часто є зручнішим способом визначити відстані між сусідніми елементами.

### 4.5. Active Whitespace — простір, який підсилює композицію

Це простір, який свідомо залишають навколо важливого елемента, щоб зробити його помітнішим.

Наприклад, головний заголовок може мати достатньо вільного простору навколо себе, щоб користувач сприймав його як основний елемент першого екрана.

### 4.6. Passive Whitespace — простір між звичайними елементами

Це простір, який виникає природно в процесі компонування тексту, списків, карток та інших елементів.

Він також важливий: навіть якщо простір не має спеціального декоративного призначення, він допомагає структурувати контент.

---

## 5. Whitespace і візуальна ієрархія

Візуальна ієрархія (Visual Hierarchy) визначає порядок, у якому користувач помічає елементи.

Whitespace — один із засобів створення цієї ієрархії.

Наприклад:

    Our courses

    Learn practical skills with structured lessons.

    [Course 1]    [Course 2]    [Course 3]

Якщо заголовок і опис розташовані близько, вони сприймаються як одна група.

Якщо після опису є більший відступ, користувач розуміє, що далі починається окремий блок із курсами.

### Інструменти візуальної ієрархії

- Розмір шрифту.
- Насиченість шрифту.
- Колір і контраст.
- Розташування.
- Вирівнювання.
- Відстані.
- Розмір елементів.
- Форма та межі.

Whitespace не замінює ці інструменти, а працює разом із ними.

### Практичне правило

Якщо всі елементи мають однаковий розмір, колір і приблизно однакову відстань один від одного, інтерфейс може виглядати пласким.

Змінюючи відстані між групами, ти створюєш зрозуміліші рівні структури.

---

## 6. Whitespace і Proximity

Proximity — принцип близькості, за яким елементи, розташовані близько, сприймаються як пов'язані.

Whitespace — це простір, за допомогою якого можна реалізувати цей принцип.

Наприклад, у формі:

    Email
    [________________]

    Password
    [________________]
    Forgot password?

    [Sign in]

Тут:

- Підпис і поле мають невеликий проміжок.
- Повідомлення `Forgot password?` розташоване ближче до поля пароля, ніж до інших полів, якщо воно стосується саме пароля.
- Відстань між групами полів більша.
- Кнопка відокремлена від полів, але залишається частиною форми.

### Правило групування

**Відстань усередині логічної групи зазвичай менша за відстань між окремими групами.**

Наприклад:

    .form-field {
      display: flex;
      flex-direction: column;
      gap: 8px;
    }

    .form {
      display: flex;
      flex-direction: column;
      gap: 24px;
    }

У цьому прикладі `8px` — внутрішня відстань між елементами одного поля, а `24px` — відстань між групами полів.

Це орієнтир, а не універсальне правило для кожного інтерфейсу.

---

## 7. Whitespace і типографіка

Типографіка — одна з основних сфер застосування Whitespace.

Навіть правильно підібраний шрифт може бути важким для читання, якщо текст занадто щільний або неправильно розділений на абзаци.

### 7.1. Line Height — міжрядковий інтервал

`line-height` визначає висоту рядка тексту.

    body {
      line-height: 1.5;
    }

    h1 {
      line-height: 1.1;
    }

Для основного тексту часто використовують більший міжрядковий інтервал, ніж для великих заголовків.

Конкретні значення залежать від шрифту, розміру тексту, довжини рядка та стилю інтерфейсу.

### 7.2. Paragraph Spacing — відстань між абзацами

Абзаци потрібно візуально відокремлювати, щоб текст не сприймався як суцільна стіна.

    .article p {
      margin: 0 0 1rem;
    }

Використовуй відступи між абзацами, а не порожні HTML-елементи для створення простору.

### 7.3. Letter Spacing — міжлітерний інтервал

`letter-spacing` змінює відстань між літерами.

    .eyebrow {
      letter-spacing: 0.08em;
      text-transform: uppercase;
    }

Невеликий додатний інтервал може бути доречним для коротких написів великими літерами.

Надмірний інтервал може погіршити читання, особливо в довгому тексті.

### 7.4. Text Width — ширина текстового блоку

Довгі рядки важче відстежувати поглядом.

    .article-content {
      max-width: 68ch;
    }

Одиниця `ch` приблизно відповідає ширині символу `0` у вибраному шрифті. Вона зручна для обмеження ширини тексту, але не гарантує однакової кількості символів у кожному рядку.

### Практичні правила

- Не стискай довгі абзаци до надто малої висоти рядка.
- Розділяй довгий текст на логічні абзаци.
- Використовуй заголовки для структурування матеріалу.
- Контролюй ширину текстового блоку.
- Перевіряй читабельність на реальному пристрої.
- Не створюй відступи великою кількістю пробілів або порожніх рядків у HTML.

## 8. Whitespace і сітка (Grid)

Grid допомагає розміщувати елементи в рядках і колонках, а Whitespace визначає відстані між ними та навколо них.

### Приклад сітки карток

    .card-grid {
      display: grid;
      grid-template-columns: repeat(3, minmax(0, 1fr));
      gap: 24px;
    }

У цьому прикладі `gap: 24px` задає однакові проміжки між рядками та колонками.

За потреби їх можна налаштувати окремо:

    .card-grid {
      display: grid;
      grid-template-columns: repeat(3, minmax(0, 1fr));
      column-gap: 24px;
      row-gap: 32px;
    }

Тут горизонтальні й вертикальні проміжки мають різні значення.

### Контейнер і зовнішні поля

Whitespace існує не лише між картками. Важливий також простір між контентом і краями вікна браузера.

    .container {
      width: min(100% - 32px, 1200px);
      margin-inline: auto;
    }

Цей контейнер:

- Залишає мінімальний простір по краях на вузьких екранах.
- Обмежує максимальну ширину контенту.
- Центрує основний блок на широких екранах.

### Типова помилка

Створювати сітку з великими проміжками між картками, але залишати текст або картки надто близько до країв сторінки.

Внутрішні та зовнішні відступи мають працювати як єдина система.

---

## 9. Whitespace у різних частинах інтерфейсу

### 9.1. Header

У шапці сайту Whitespace допомагає розділяти:

- Логотип.
- Основну навігацію.
- Додаткові посилання.
- Кнопки входу або реєстрації.

Приклад:

    .navbar {
      display: flex;
      align-items: center;
      justify-content: space-between;
      gap: 24px;
      padding: 16px 24px;
    }

    .navbar__links {
      display: flex;
      align-items: center;
      gap: 20px;
    }

`gap` між посиланнями організовує навігацію, а `padding` створює простір навколо всієї шапки.

### 9.2. Hero Section

Hero — верхня презентаційна секція сторінки, яка часто містить головний заголовок, опис, кнопку та зображення.

Whitespace може підкреслювати головне повідомлення та робити композицію виразнішою.

    .hero {
      padding-block: 96px;
    }

    .hero__content {
      max-width: 640px;
    }

    .hero__title {
      margin: 0 0 24px;
    }

    .hero__description {
      margin: 0 0 32px;
      max-width: 60ch;
    }

Значення відступів залежать від композиції. На мобільних екранах їх часто потрібно адаптувати.

### 9.3. Cards

Внутрішній Whitespace робить картку зручною для читання.

    .card {
      padding: 24px;
      border-radius: 12px;
    }

    .card__content {
      display: flex;
      flex-direction: column;
      gap: 12px;
    }

Не варто додавати однаково великі відступи між усіма елементами, якщо вони мають різні функції.

### 9.4. Forms

У формах Whitespace допомагає розділяти поля та пов'язану з ними допоміжну інформацію.

    .form {
      display: flex;
      flex-direction: column;
      gap: 24px;
    }

    .form-field {
      display: flex;
      flex-direction: column;
      gap: 8px;
    }

    .form-field__hint {
      margin: 0;
      font-size: 0.875rem;
    }

Підпис, поле, підказка й помилка мають бути візуально пов'язані.

### 9.5. Buttons

Кнопці потрібен внутрішній простір, щоб текст не прилипав до країв і щоб її було зручно натискати.

    .button {
      display: inline-flex;
      align-items: center;
      justify-content: center;
      gap: 8px;
      min-height: 44px;
      padding: 10px 16px;
    }

`padding` впливає на внутрішній простір кнопки. `gap` контролює відстань між іконкою та текстом.

### 9.6. Dashboard

У Dashboard Whitespace допомагає розділити:

- Заголовок сторінки.
- Фільтри.
- Картки показників.
- Таблиці.
- Графіки.
- Додаткові панелі.

Для насичених даними інтерфейсів важливо не прибирати всі відступи заради розміщення більшої кількості інформації.

### 9.7. Footer

Футер може містити кілька логічних груп посилань, інформацію про компанію та юридичні сторінки.

    .footer {
      padding-block: 48px;
    }

    .footer__grid {
      display: grid;
      grid-template-columns: repeat(3, minmax(0, 1fr));
      gap: 32px;
    }

Whitespace допомагає відокремити футер від основного контенту й організувати його внутрішню структуру.

## 10. Whitespace і responsive design

На різних розмірах екрана простір потрібно адаптувати до доступної ширини та сценарію використання.

На великому екрані достатньо місця для широких полів, кількох колонок і значних проміжків між секціями.

На мобільному екрані простору менше, тому відступи можуть бути компактнішими. Однак надмірне зменшення відступів робить інтерфейс перевантаженим.

### Приклад

    .section {
      padding-block: 80px;
    }

    .card-grid {
      display: grid;
      grid-template-columns: repeat(3, minmax(0, 1fr));
      gap: 24px;
    }

    @media (max-width: 768px) {
      .section {
        padding-block: 56px;
      }

      .card-grid {
        grid-template-columns: repeat(2, minmax(0, 1fr));
        gap: 16px;
      }
    }

    @media (max-width: 480px) {
      .section {
        padding-block: 40px;
      }

      .card-grid {
        grid-template-columns: 1fr;
        gap: 20px;
      }
    }

У цьому прикладі:

- Великі секції мають більше вертикального простору на широкому екрані.
- На планшеті відступи зменшуються.
- На мобільному картки переходять в одну колонку.
- Відстань між картками адаптується до нового компонування.

Це приклад, а не обов'язкова схема для кожного проєкту.

### Важливо

Responsive design — це не лише зменшення всіх відступів.

Потрібно враховувати:

- Довжину тексту.
- Кількість колонок.
- Розмір кнопок.
- Зручність натискання.
- Внутрішні відступи компонентів.
- Пріоритети контенту.
- Перенесення елементів на нові рядки.

---

## 11. Whitespace і accessibility

Негативний простір може покращувати доступність, якщо він сприяє читабельності та зручній взаємодії.

### Основні рекомендації

1. Забезпечуй достатній простір між інтерактивними елементами.
2. Не розташовуй кнопки та посилання настільки близько, щоб їх було легко натиснути помилково.
3. Використовуй комфортний міжрядковий інтервал.
4. Не створюй надто довгі рядки тексту.
5. Зберігай зрозуміле групування підписів, полів і повідомлень.
6. Перевіряй інтерфейс зі збільшеним масштабом.
7. Не використовуй Whitespace як єдиний спосіб передавання важливої інформації.

### Приклад групи кнопок

    .actions {
      display: flex;
      flex-wrap: wrap;
      gap: 12px;
    }

    .actions button {
      min-height: 44px;
      padding: 10px 16px;
    }

Відступи зменшують ризик випадкового натискання сусідньої кнопки.

Проте самі розміри й відстані потрібно перевіряти відповідно до вимог доступності, типу пристрою та контексту взаємодії. Візуальний проміжок не замінює належного розміру інтерактивної області.

---

## 12. Whitespace і композиція

Композиція — це організація елементів у межах сторінки або компонента.

Whitespace впливає на:

- Баланс.
- Візуальний ритм.
- Напрямок руху погляду.
- Фокус уваги.
- Відчуття щільності.
- Сприйняття пропорцій.

### 12.1. Balance — баланс

Вільний простір допомагає врівноважувати композицію.

Наприклад, великий заголовок з одного боку Hero-секції може врівноважуватися зображенням з іншого боку.

### 12.2. Rhythm — ритм

Послідовне використання відступів створює ритм сторінки.

Наприклад, якщо всі секції мають узгоджені вертикальні відступи, сторінка виглядає системною.

### 12.3. Focus — фокус

Якщо навколо кнопки або заголовка є достатньо простору, вони можуть привертати більше уваги.

Однак фокус залежить також від розміру, кольору, контрасту та розташування.

### 12.4. Density — щільність

Щільність показує, скільки візуальної інформації розміщено в певній області.

Інтерфейс із великою кількістю щільно розташованих даних може бути доречним у професійній таблиці або фінансовому Dashboard.

Для презентаційної сторінки або лендингу більший Whitespace часто допомагає створити спокійніше візуальне враження.

**Важливо:** не існує єдиної правильної кількості Whitespace для всіх продуктів. Потрібно враховувати контекст, користувачів і завдання сторінки.

---

## 13. Whitespace і колір фону

Whitespace не обов'язково має бути білим.

Він може бути:

- Білим.
- Світло-сірим.
- Темним.
- Кольоровим.
- Текстурованим.
- Частиною градієнтного фону.

Наприклад, темний інтерфейс також може мати багато вільного простору.

    .page {
      color: #f9fafb;
      background: #111827;
    }

    .section {
      padding-block: 64px;
    }

Тут вільний простір утворюється не білим кольором, а темною областю навколо контенту.

### Що потрібно пам'ятати

Whitespace — це не конкретний колір.

Це простір, який допомагає організовувати контент.

Фон, контраст і декоративні елементи можуть впливати на сприйняття цього простору, але не змінюють його основного призначення.

## 15. Типові помилки у використанні Whitespace

### Помилка 1. Надто мало вільного простору

Усі елементи розташовані близько один до одного, і користувачеві складно визначити структуру.

**Рішення:** збільшуй відстані між логічними групами та перевіряй ієрархію.

### Помилка 2. Надто багато вільного простору

Контент стає розрідженим, а пов'язані елементи можуть виглядати так, ніби вони не належать до однієї групи.

**Рішення:** зменшуй відстань між пов'язаними елементами, але зберігай простір між незалежними блоками.

### Помилка 3. Однакові відступи на всіх рівнях

Відстань між заголовком і підзаголовком може бути такою самою, як між двома великими секціями.

**Рішення:** використовуй кілька рівнів spacing, відповідних структурі контенту.

### Помилка 4. Випадкові значення CSS

Наприклад:

    margin-top: 17px;
    padding: 23px;
    gap: 19px;
    margin-bottom: 37px;

Такі значення можуть бути обґрунтованими, але якщо вони з'являються випадково, дизайн стає складнішим для підтримки.

**Рішення:** створи узгоджену spacing system.

### Помилка 5. Використання порожніх елементів для відступів

Не варто додавати порожні `div`, щоб створювати простір між секціями.

Поганий підхід:

    <div class="empty-space"></div>

Краще:

    <section class="section">
      <h2>Our courses</h2>
    </section>

    <section class="section section--next">
      <h2>Our instructors</h2>
    </section>

    .section {
      padding-block: 64px;
    }

Відступи мають бути частиною стилів компонента або системи компонування, а не зайвими порожніми елементами в HTML.

### Помилка 6. Надмірне використання `<br>`

`<br>` призначений для перенесення рядка всередині тексту, коли таке перенесення має змістове значення.

Не використовуй його для створення вертикальних відступів.

Для відстаней між блоками застосовуй `margin`, `padding`, `gap` або інші відповідні CSS-засоби.

### Помилка 7. Відсутність системи відступів

Якщо кожна картка та секція має власні випадкові значення, сторінка може виглядати непослідовно.

**Рішення:** визнач набір spacing-токенів і застосовуй їх системно.

### Помилка 8. Ігнорування мобільних екранів

Відступи, які добре працюють на Desktop, можуть забирати надто багато місця на мобільному.

**Рішення:** перевіряй композицію на різних ширинах, а не просто зменшуй усі значення автоматично.

### Помилка 9. Спроба виправити структурну проблему лише відступами

Якщо контент розташований у неправильному порядку або групи сформовані нелогічно, зміна `margin` не розв'яже проблему повністю.

**Рішення:** спочатку визнач правильну інформаційну архітектуру, потім налаштовуй простір.

## 16. Spacing System — система відступів

Spacing system — це набір узгоджених значень, які використовуються для створення простору між елементами та навколо них.

Система допомагає підтримувати послідовність у всьому продукті.

### Приклад шкали

| Токен | Значення | Приклад застосування |
|---|---:|---|
| `space-1` | 4px | Дуже малі проміжки |
| `space-2` | 8px | Підпис і поле |
| `space-3` | 12px | Відстань усередині групи |
| `space-4` | 16px | Внутрішній простір компонента |
| `space-6` | 24px | Між компонентами |
| `space-8` | 32px | Між більшими групами |
| `space-12` | 48px | Між секціями |
| `space-16` | 64px | Великі вертикальні відступи |
| `space-20` | 80px | Просторі секції або Hero |

Це приклад шкали, а не обов'язковий стандарт. Ти можеш вибрати іншу систему залежно від проєкту.

### CSS Custom Properties

    :root {
      --space-1: 4px;
      --space-2: 8px;
      --space-3: 12px;
      --space-4: 16px;
      --space-6: 24px;
      --space-8: 32px;
      --space-12: 48px;
      --space-16: 64px;
      --space-20: 80px;
    }

### Використання

    .card {
      padding: var(--space-6);
    }

    .card__content {
      display: flex;
      flex-direction: column;
      gap: var(--space-3);
    }

    .section {
      padding-block: var(--space-16);
    }

    .section__header {
      margin-bottom: var(--space-8);
    }

### Переваги

- Послідовний дизайн.
- Легше змінювати відступи глобально.
- Менше випадкових значень.
- Простішa підтримка CSS.
- Зручніша робота з компонентами.
- Легше передавати дизайн між дизайнерами й розробниками.

## 17. Whitespace у дизайн-системі

У дизайн-системі відступи мають не лише конкретні значення, а й зрозуміле призначення.

Наприклад:

    :root {
      --space-inline-tight: 4px;
      --space-inline-normal: 8px;
      --space-group-tight: 12px;
      --space-group-normal: 16px;
      --space-component: 24px;
      --space-section: 48px;
      --space-section-large: 64px;
    }

Такі назви можуть бути зручнішими для великих проєктів, оскільки описують не тільки величину, а й роль відступу.

### Приклад компонента

    .form-field {
      display: flex;
      flex-direction: column;
      gap: var(--space-inline-normal);
    }

    .form {
      display: flex;
      flex-direction: column;
      gap: var(--space-component);
    }

    .page-section {
      padding-block: var(--space-section);
    }

### Що потрібно узгодити в команді

- Які значення spacing доступні.
- Які токени застосовуються всередині компонентів.
- Які токени використовуються між компонентами.
- Як задаються відступи секцій.
- Як відступи змінюються на різних екранах.
- Які винятки дозволені й чому.

Дизайн-система не повинна забороняти будь-які винятки, але допомагає уникати безсистемного стилювання.

## 18. Як перевіряти Whitespace у готовому дизайні

Використовуй послідовний алгоритм.

### Крок 1. Визнач структуру

Знайди:

- Головний заголовок.
- Підзаголовок.
- Основний контент.
- Логічні групи.
- Межі між секціями.
- Основні та другорядні дії.

### Крок 2. Перевір мікропростір

Подивися на:

- Міжрядкові інтервали.
- Відстані між підписами й полями.
- Проміжки між іконками та текстом.
- Внутрішні відступи кнопок.
- Відстані між абзацами.

### Крок 3. Перевір макропростір

Подивися на:

- Відстані між секціями.
- Простір навколо Hero.
- Відступи від країв контейнера.
- Проміжки між групами карток.
- Відстань між основним контентом і футером.

### Крок 4. Перевір ієрархію

Запитай себе:

- Що користувач помітить першим?
- Які елементи сприймаються як група?
- Чи зрозуміло, де починається наступна секція?
- Чи не конкурують другорядні елементи з основними?

### Крок 5. Тимчасово прибери декор

Подивися на сторінку без тіней, зайвих рамок і декоративних кольорів.

Якщо структура залишається зрозумілою завдяки відступам, це добрий знак.

### Крок 6. Перевір різні ширини

Перевір Desktop, Tablet і Mobile.

Зверни увагу на перенесення тексту, кількість колонок і відстані між елементами.

### Крок 7. Перевір на реальних даних

Довші назви, помилки у формах, великі числа й додаткові кнопки можуть змінити компонування.

Whitespace має працювати не лише з ідеальним демонстраційним контентом.

## 19. Whitespace у різних типах продуктів

### Landing Page

Великі відступи можуть допомагати підкреслювати основні повідомлення, презентаційні зображення та ключові дії.

### E-commerce

Whitespace допомагає організувати зображення товарів, назви, ціни, рейтинги та кнопки покупки.

### Освітня платформа

Простір відокремлює категорії курсів, опис навчання, інформацію про викладачів і блоки із завданнями.

### Медичний застосунок

Чітке групування й достатній простір допомагають відрізняти показники, підписи, пояснення та рекомендації.

### Фінансовий Dashboard

Відступи допомагають розділяти числові показники, графіки, таблиці та фільтри, не втрачаючи інформаційної щільності.

### Адміністративна панель

Потрібно балансувати простір і щільність даних. Надто великі відступи можуть ускладнювати перегляд великих таблиць.

### Мобільний застосунок

Простір має забезпечувати зрозуміле групування, читабельність і зручність натискання.

### Портфоліо або презентаційний сайт

Whitespace може створювати виразну композицію та підкреслювати роботи, зображення й типографіку.

## 20. Питання для співбесіди

### Junior

**1. Що таке Whitespace?**

Це вільний простір між елементами інтерфейсу та навколо них, який допомагає організовувати контент.

**2. Чи обов'язково Whitespace має бути білим?**

Ні. Він може мати будь-який колір. Назва є історичним терміном.

**3. Яка різниця між Micro Whitespace і Macro Whitespace?**

Micro Whitespace — невеликі проміжки всередині тексту та компонентів. Macro Whitespace — великі відстані між секціями й основними блоками.

**4. Які CSS-властивості використовують для створення Whitespace?**

`margin`, `padding`, `gap`, `row-gap`, `column-gap`, а також `line-height` для міжрядкового інтервалу.

**5. Чому Whitespace важливий?**

Він покращує читабельність, допомагає групувати елементи й створює зрозумілу візуальну ієрархію.

### Middle

**6. Як Whitespace пов'язаний із Proximity?**

Whitespace створює відстані, які допомагають показати, які елементи пов'язані між собою, а які належать до різних груп.

**7. Чи завжди більше Whitespace означає кращий дизайн?**

Ні. Надмірний простір може порушувати групування, збільшувати довжину сторінки та зменшувати інформаційну щільність.

**8. Як Whitespace впливає на типографіку?**

Він впливає на міжрядкові інтервали, відстані між абзацами, ширину текстового блоку та читабельність.

**9. Як підтримувати послідовність відступів?**

Створити spacing system, визначити CSS-токени й використовувати їх у компонентах і секціях.

**10. Як адаптувати Whitespace для мобільного екрана?**

Перевірити компонування, зменшити або змінити відступи за потреби та зберегти зрозуміле групування й зручність взаємодії.

### Senior

**11. Як визначити правильну кількість Whitespace?**

Оцінювати її в контексті інформаційної ієрархії, щільності контенту, завдань користувача та тестування реального інтерфейсу.

**12. Як Whitespace впливає на складні Dashboard?**

Він допомагає розділяти інформаційні блоки, але має бути збалансований із потребою ефективно показувати велику кількість даних.

**13. Як відрізнити проблему Whitespace від проблеми інформаційної архітектури?**

Якщо контент логічно структурований, але візуально погано читається, проблема може бути у відступах. Якщо сам порядок і групування інформації неправильні, потрібно переглянути інформаційну архітектуру.

**14. Яка роль Whitespace у дизайн-системі?**

Він створює послідовні правила відстаней між елементами, компонентами та секціями в межах продукту.

- Непослідовні значення spacing.
- Непотрібні порожні блоки.

## 23. Коротка шпаргалка

| Поняття | Що запам'ятати |
|---|---|
| Whitespace | Вільний простір між елементами та навколо них |
| Negative Space | Інша назва негативного простору |
| Micro Whitespace | Невеликі проміжки всередині тексту й компонентів |
| Macro Whitespace | Великі відстані між блоками та секціями |
| Internal Whitespace | Простір усередині компонента |
| External Whitespace | Простір навколо компонента |
| `margin` | Зовнішній простір навколо елемента |
| `padding` | Внутрішній простір елемента |
| `gap` | Відстань між елементами Flexbox або Grid |
| `line-height` | Висота рядка тексту |
| `letter-spacing` | Відстань між літерами |
| Spacing System | Узгоджений набір значень відступів |
| Visual Hierarchy | Порядок візуальної важливості |
| Proximity | Групування пов'язаних елементів через близькість |
| Density | Кількість візуальної інформації в певній області |
| Responsive Whitespace | Адаптація простору до розміру екрана |

### Головні правила

1. Whitespace — це повноцінний інструмент дизайну, а не порожнє місце.
2. Пов'язані елементи зазвичай розташовують ближче один до одного.
3. Відстані між великими групами зазвичай більші, ніж усередині груп.
4. Використовуй `gap` для відстаней між елементами Flexbox і Grid.
5. Використовуй `padding` для внутрішнього простору компонентів.
6. Використовуй `margin` для зовнішніх відстаней, коли це відповідає структурі.
7. Створюй spacing system замість випадкових значень.
8. Адаптуй відступи для різних екранів.
9. Не плутай надмірний простір із хорошим дизайном.
10. Перевіряй Whitespace на реальному контенті.

## 24. Що потрібно запам'ятати

**Whitespace — це простір, який допомагає організувати інформацію та керувати увагою користувача.**

Він працює разом із типографікою, кольором, вирівнюванням, Proximity та візуальною ієрархією.

Під час створення інтерфейсу став собі п'ять запитань:

1. Чи достатньо простору навколо важливих елементів?
2. Чи зрозуміло, які елементи належать до однієї групи?
3. Чи відокремлені різні секції?
4. Чи комфортно читати текст?
5. Чи зберігається зрозуміла структура на мобільному екрані?

Якщо відповіді позитивні, Whitespace працює на користь інтерфейсу.

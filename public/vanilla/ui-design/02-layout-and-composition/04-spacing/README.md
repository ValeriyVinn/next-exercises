# Spacing — Відступи та простір в UI-дизайні

> **Spacing (відступи та проміжки)** — це принцип UI-дизайну, який визначає відстані між елементами, навколо них і всередині компонентів.
>
> Правильно організований простір допомагає створювати візуальну ієрархію, групувати пов'язані елементи, покращувати читабельність і робити інтерфейс зручним для користування.

---

## 1. Для чого потрібен Spacing?

Spacing допомагає:

- відокремлювати один елемент від іншого;
- об'єднувати пов'язані елементи у візуальні групи;
- створювати ієрархію між заголовками, текстом і діями;
- полегшувати сканування сторінки;
- робити інтерфейс охайним і передбачуваним;
- забезпечувати однакові відступи в повторюваних компонентах;
- адаптувати інтерфейс до різних розмірів екрана;
- покращувати зручність натискання інтерактивних елементів.

Наприклад, якщо заголовок розташований близько до свого опису, а наступна секція відокремлена більшим проміжком, користувач краще розуміє, які елементи належать один до одного.

    Без продуманої системи відступів:

    Заголовок


    Опис тексту

    [Кнопка]


    Наступний блок


    Інший заголовок

    З продуманою системою відступів:

    Заголовок
    Опис тексту
    [Кнопка]


    Наступний блок
    Інший заголовок

Важливо не просто додавати більше або менше простору, а створювати зрозумілу систему відстаней.

---

## 2. Основні поняття

### 2.1. Spacing

**Spacing** — загальна система відстаней між елементами та навколо них.

Вона охоплює:

- відстані між текстовими елементами;
- проміжки між кнопками;
- внутрішні відступи карток;
- відступи між секціями сторінки;
- відступи від країв екрана;
- проміжки між колонками;
- відстані між пунктами навігації.

### 2.2. Margin

**Margin (зовнішній відступ)** — простір за межами елемента, який відокремлює його від сусідніх елементів.

У CSS:

    .card {
        margin-bottom: 2rem;
    }

Це додає нижній зовнішній відступ елементу `.card`.

У сучасному компонуванні відстань між елементами часто зручніше задавати через `gap`, але `margin` залишається корисним для окремих випадків.

### 2.3. Padding

**Padding (внутрішній відступ)** — простір між вмістом елемента та його внутрішніми межами.

У CSS:

    .card {
        padding: 1.5rem;
    }

Це створює внутрішній простір навколо вмісту картки.

Padding особливо важливий для:

- карток;
- кнопок;
- полів форм;
- модальних вікон;
- навігаційних панелей;
- контейнерів із текстом.

### 2.4. Gap

**Gap** — відстань між елементами всередині Flexbox- або Grid-контейнера.

    .actions {
        display: flex;
        gap: 1rem;
    }

`gap` створює проміжок між сусідніми елементами без необхідності задавати зовнішні відступи кожному з них.

Це зручно для:

- груп кнопок;
- навігації;
- списків карток;
- форм;
- сіток;
- горизонтальних і вертикальних груп елементів.

### 2.5. Whitespace

**Whitespace (негативний простір)** — вільний простір навколо елементів і між ними.

Він не обов'язково має бути білим: це може бути простір будь-якого кольору фону.

Whitespace допомагає:

- зменшувати візуальний шум;
- виділяти важливі елементи;
- групувати контент;
- створювати відчуття простору;
- покращувати читабельність.

### 2.6. Spacing scale

**Spacing scale (шкала відступів)** — набір узгоджених значень, які повторно використовуються в інтерфейсі.

Наприклад:

    4px
    8px
    12px
    16px
    24px
    32px
    48px
    64px

Завдяки шкалі відступів інтерфейс стає послідовним, а рішення щодо відстаней — передбачуваними.

---

## 3. Чим відрізняються Margin, Padding і Gap?

Це три важливі інструменти, які вирішують різні задачі.

| Властивість | Що визначає | Типове використання |
|---|---|---|
| `margin` | Зовнішній простір навколо елемента | Відстань між окремими блоками |
| `padding` | Внутрішній простір елемента | Відстань від меж картки до її вмісту |
| `gap` | Відстань між елементами в контейнері | Проміжки між кнопками, картками або полями |

### Приклад

    .card {
        padding: 1.5rem;
    }

    .card-list {
        display: flex;
        flex-direction: column;
        gap: 1rem;
    }

    .section {
        margin-block: 3rem;
    }

Тут:

- `padding` створює простір усередині картки;
- `gap` визначає відстань між картками;
- `margin-block` відокремлює секцію від сусіднього контенту по вертикалі.

**Практичне правило:**

- простір усередині компонента — зазвичай `padding`;
- простір між елементами одного компонування — часто `gap`;
- зовнішнє розташування окремого елемента — за потреби `margin`.

Це не жорсткі обмеження, а корисна початкова схема.

## 4. Принцип близькості (Proximity)

**Proximity (близькість)** — принцип дизайну, за яким елементи, що належать один до одного, розташовуються ближче, ніж елементи різних груп.

Наприклад:

    Назва курсу
    Короткий опис курсу
    [Переглянути курс]


    Наступний курс
    Опис наступного курсу
    [Переглянути курс]

Відстань між назвою та описом має бути меншою, ніж відстань між двома окремими картками курсів.

### 4.1. Близькість формує групи

У формі:

    Електронна пошта
    [_____________________]
    Введіть адресу електронної пошти.

    Пароль
    [_____________________]
    Мінімум 8 символів.

Підпис, поле та допоміжний текст повинні виглядати як одна група.

Між різними полями варто залишати достатньо простору, щоб їх було легко розрізняти.

### 4.2. Близькість важливіша за декоративні лінії

Не завжди потрібно використовувати межі, рамки або кольорові фони, щоб розділити групи.

Часто достатньо правильно підібраних відступів.

### 4.3. Як перевірити близькість?

Запитай себе:

- Які елементи належать до однієї групи?
- Які елементи потрібно сприймати разом?
- Де починається нова група?
- Чи відстані допомагають зрозуміти структуру?
- Чи можна прибрати зайві лінії та декоративні роздільники, залишивши достатньо простору?

## 5. Візуальна ієрархія через відступи

Spacing допомагає показати важливість елементів без додаткових кольорів або декоративних ефектів.

### 5.1. Малий, середній і великий простір

Умовно можна виділити три рівні:

- **Small spacing** — відстані між тісно пов'язаними елементами.
- **Medium spacing** — відстані між елементами однієї групи або компонента.
- **Large spacing** — відстані між великими блоками та секціями.

Наприклад:

    Заголовок секції

    Невеликий опис секції


    [Кнопка]  [Другорядна кнопка]


    Наступна секція

Тут відстань між заголовком та описом може бути невеликою, між описом і діями — більшою, а між секціями — ще більшою.

### 5.2. Не всі відстані мають бути однаковими

Якщо всі елементи мають однакові відступи, структура може виглядати одноманітно.

Наприклад, відстань між заголовком і його описом не обов'язково має дорівнювати відстані між двома секціями сторінки.

**Spacing має відображати структуру контенту.**

### 5.3. Контраст відстаней

Для зрозумілої композиції важливо, щоб різниця між відстанями була помітною, коли вона має структурне значення.

Наприклад:

- 8px — між іконкою та текстом;
- 16px — між елементами однієї групи;
- 32px — між групами;
- 64px — між великими секціями.

Це лише приклад. Реальні значення залежать від масштабу інтерфейсу, типографіки та призначення компонента.

## 6. Spacing scale — система відступів

### 6.1. Навіщо потрібна шкала?

Без спільної шкали дизайн часто накопичує випадкові значення:

    13px
    17px
    21px
    29px
    37px

Іноді такі значення потрібні для точного налаштування, але якщо їх багато без системи, інтерфейс стає складніше підтримувати.

Шкала допомагає:

- стандартизувати відстані;
- швидше компонувати макети;
- повторно використовувати значення;
- підтримувати дизайн-систему;
- узгоджувати роботу дизайнера та розробника;
- спрощувати глобальні зміни стилів.

### 6.2. Приклад шкали на основі 4px

    4px   — дуже малий проміжок
    8px   — малий проміжок
    12px  — невеликий проміжок
    16px  — базовий проміжок
    24px  — середній проміжок
    32px  — великий проміжок
    48px  — дуже великий проміжок
    64px  — простір між великими блоками
    96px  — простір для великих секцій

Це приклад системи, а не обов'язковий стандарт.

Деякі дизайн-системи використовують шкалу, побудовану навколо 4px, інші — навколо 8px або комбінують кілька принципів.

### 6.3. Чому використовують крок 4px?

Крок 4px дає змогу створювати достатньо гнучку шкалу, зберігаючи узгодженість.

Наприклад:

    4px → 8px → 12px → 16px → 24px → 32px

Це полегшує узгодження внутрішніх відступів, проміжків між компонентами та відстаней між секціями.

### 6.4. Приклад CSS-токенів

    :root {
        --space-1: 0.25rem;
        --space-2: 0.5rem;
        --space-3: 0.75rem;
        --space-4: 1rem;
        --space-6: 1.5rem;
        --space-8: 2rem;
        --space-12: 3rem;
        --space-16: 4rem;
    }

Якщо базовий розмір `1rem` дорівнює 16px, значення будуть такими:

| Токен | Значення в rem | За бази 16px |
|---|---:|---:|
| `--space-1` | 0.25rem | 4px |
| `--space-2` | 0.5rem | 8px |
| `--space-3` | 0.75rem | 12px |
| `--space-4` | 1rem | 16px |
| `--space-6` | 1.5rem | 24px |
| `--space-8` | 2rem | 32px |
| `--space-12` | 3rem | 48px |
| `--space-16` | 4rem | 64px |

У коді:

    .card {
        padding: var(--space-6);
    }

    .card-list {
        display: grid;
        gap: var(--space-4);
    }

    .section {
        padding-block: var(--space-12);
    }

### 6.5. Чи потрібно використовувати всі значення?

Ні.

Для невеликого застосунку достатньо невеликої, добре продуманої шкали.

Краще мати кілька значень, які системно використовуються, ніж десятки майже однакових значень без чіткого призначення.

## 7. Внутрішні відступи компонентів (Padding)

Padding визначає, скільки простору залишається між вмістом компонента та його межами.

### 7.1. Padding у картці

    .card {
        padding: 1.5rem;
        border: 1px solid #ddd;
        border-radius: 0.75rem;
    }

Внутрішній відступ:

- не дає тексту прилипати до країв;
- покращує читабельність;
- допомагає структурувати вміст;
- створює візуальний баланс.

### 7.2. Padding у кнопці

    .button {
        padding: 0.75rem 1rem;
    }

У скороченому записі:

    padding: 0.75rem 1rem;

Перше значення задає вертикальні відступи, друге — горизонтальні.

Для кнопок важливо враховувати не лише візуальний вигляд, а й розмір інтерактивної області.

### 7.3. Padding у формі

    .form-panel {
        padding: 2rem;
    }

Для великих панелей форми може бути потрібен більший внутрішній простір, ніж для компактних елементів керування.

На мобільних екранах внутрішні відступи іноді зменшують, щоб залишити більше місця для корисного вмісту.

### 7.4. Різні значення для різних сторін

CSS дозволяє задавати відступи окремо:

    .card {
        padding-top: 1rem;
        padding-right: 1.5rem;
        padding-bottom: 1.5rem;
        padding-left: 1.5rem;
    }

Або скорочено:

    .card {
        padding: 1rem 1.5rem 1.5rem;
    }

Три значення означають:

1. верхній відступ;
2. горизонтальні відступи;
3. нижній відступ.

Чотири значення задають відступи за годинниковою стрілкою:

    .card {
        padding: 1rem 1.5rem 2rem 1.25rem;
    }

Порядок:

    top → right → bottom → left

Для підтримки різних напрямків письма можна використовувати логічні властивості:

    .card {
        padding-block: 1rem 2rem;
        padding-inline: 1.5rem;
    }

- `padding-block` задає відступи на початку та в кінці блочного напрямку;
- `padding-inline` задає відступи на початку та в кінці рядкового напрямку.

У типовому горизонтальному письмі це відповідає верхньому/нижньому та лівому/правому напрямкам.

## 8. Зовнішні відступи (Margin)

Margin задає простір за межами елемента.

### 8.1. Відстань між секціями

    .section {
        margin-bottom: 3rem;
    }

Це відокремлює секцію від наступного контенту.

Для сторінок із великими блоками часто зручніше задавати відступи через `padding` батьківських секцій або використовувати системне компонування з `gap`.

### 8.2. Центрування контейнера

    .container {
        max-width: 72rem;
        margin-inline: auto;
    }

`margin-inline: auto` дозволяє автоматично розподілити вільний простір з обох боків контейнера, коли його ширина обмежена.

### 8.3. Margin collapse

У звичайному блочному потоці вертикальні зовнішні відступи деяких сусідніх блоків можуть об'єднуватися. Це називається **margin collapsing**.

Наприклад:

    .title {
        margin-bottom: 24px;
    }

    .description {
        margin-top: 16px;
    }

У звичайному вертикальному потоці між цими елементами відстань може становити 24px, а не 40px.

Це залежить від конкретних умов CSS-компонування.

У Flexbox і Grid відступи не згортаються за цим правилом. Для контрольованих проміжків між елементами часто зручніше використовувати `gap`.

### 8.4. Коли Margin доречний?

Margin корисний, коли потрібно:

- відокремити блок від сусіднього контенту;
- задати зовнішнє положення окремого елемента;
- центрувати контейнер;
- керувати простором у звичайному потоці документа.

Не потрібно автоматично задавати `margin` кожному дочірньому елементу, якщо відстані можна централізовано керувати через батьківський контейнер.

## 9. Gap — проміжки між елементами

`gap` часто є одним із найзручніших інструментів для побудови системного компонування.

### 9.1. Gap у Flexbox

    .button-group {
        display: flex;
        gap: 1rem;
    }

Відстань між кнопками визначається одним правилом.

### 9.2. Gap у вертикальному списку

    .form {
        display: flex;
        flex-direction: column;
        gap: 1.25rem;
    }

Поля форми отримують однакову відстань одне від одного.

### 9.3. Gap у Grid

    .card-grid {
        display: grid;
        grid-template-columns: repeat(3, minmax(0, 1fr));
        gap: 1.5rem;
    }

У цьому випадку `gap` задає проміжки між рядками та колонками.

### 9.4. Різні проміжки по горизонталі та вертикалі

    .card-grid {
        display: grid;
        grid-template-columns: repeat(3, minmax(0, 1fr));
        column-gap: 2rem;
        row-gap: 1.5rem;
    }

- `column-gap` — проміжок між колонками;
- `row-gap` — проміжок між рядками.

Можна також записати:

    .card-grid {
        gap: 1.5rem 2rem;
    }

Порядок значень:

    row-gap column-gap

### 9.5. Gap чи Margin?

| Ситуація | Часто зручніше |
|---|---|
| Відстань між кнопками в групі | `gap` |
| Відстань між картками в Grid | `gap` |
| Відстань між полями Flexbox-форми | `gap` |
| Відступ конкретного елемента від інших частин сторінки | `margin` |
| Внутрішній простір картки | `padding` |

Вибір залежить від структури компонента. Головна перевага `gap` — він задає відстані на рівні контейнера, а не окремих дітей.

## 10. Відступи в типографіці

Spacing має велике значення для читабельності тексту.

### 10.1. Відстань між заголовком та абзацом

Заголовок і його опис мають сприйматися як пов'язана група.

    .section-title {
        margin-bottom: 0.75rem;
    }

    .section-description {
        margin-top: 0;
    }

### 10.2. Відстань між абзацами

Абзаци повинні бути достатньо відокремленими, щоб читач міг розрізняти думки, але не настільки, щоб текст втрачав цілісність.

    .article p {
        margin-block: 0 1rem;
    }

### 10.3. Line-height — це не Spacing між компонентами

**Line-height** визначає висоту рядка тексту. Він впливає на вертикальний простір між рядками, але не замінює відступи між окремими блоками.

    .article-text {
        line-height: 1.6;
    }

Тут `line-height` задає комфортну висоту рядка, а `margin-block` може визначати відстань між абзацами.

### 10.4. Відстань між літерами

`letter-spacing` керує проміжком між символами.

    .eyebrow {
        letter-spacing: 0.08em;
    }

Це типографічна властивість, а не заміна загальній системі простору між елементами.

### 10.5. Рекомендації

- не притискай заголовок до опису;
- не розривай візуально пов'язані рядки;
- зберігай зрозумілу відстань між абзацами;
- враховуй довжину тексту;
- перевіряй читабельність на мобільних пристроях;
- не використовуй однакові відступи для всіх текстових блоків без урахування їхньої ролі.

## 11. Spacing у картках

Картка — хороший приклад того, як внутрішні та зовнішні відступи працюють разом.

    ┌────────────────────────────┐
    │                            │
    │  [Зображення]              │
    │                            │
    │  Назва матеріалу           │
    │                            │
    │  Короткий опис матеріалу   │
    │  у кількох рядках.         │
    │                            │
    │  [Докладніше]              │
    │                            │
    └────────────────────────────┘

У картці потрібно визначити:

- відстань між краями картки та її вмістом;
- відстань між зображенням і заголовком;
- відстань між заголовком і описом;
- відстань між описом і кнопкою;
- проміжок між сусідніми картками.

### Приклад CSS

    .card-grid {
        display: grid;
        grid-template-columns: repeat(3, minmax(0, 1fr));
        gap: 1.5rem;
    }

    .card {
        display: flex;
        flex-direction: column;
        padding: 1.5rem;
        gap: 1rem;
        border: 1px solid #ddd;
        border-radius: 0.75rem;
    }

    .card__title,
    .card__description {
        margin: 0;
    }

    .card__button {
        align-self: flex-start;
        margin-top: auto;
    }

`gap` задає відстань між дочірніми елементами картки.

`padding` визначає простір від вмісту до меж картки.

`margin-top: auto` може розташувати кнопку ближче до нижньої частини картки, якщо доступна висота це дозволяє.

---

## 12. Spacing у формах

Форми потребують послідовних відступів, оскільки користувачі повинні швидко розпізнавати поля, підписи та повідомлення.

### Приклад структури

    Електронна пошта
    [________________________]
    Введіть адресу електронної пошти.

    Пароль
    [________________________]
    Використовуйте щонайменше 8 символів.

    [Створити обліковий запис]

### Приклад CSS

    .form {
        display: flex;
        flex-direction: column;
        gap: 1.25rem;
    }

    .form-field {
        display: flex;
        flex-direction: column;
        gap: 0.5rem;
    }

    .form-field__label {
        font-weight: 600;
    }

    .form-field__hint {
        margin: 0;
        font-size: 0.875rem;
    }

    .form__actions {
        display: flex;
        flex-wrap: wrap;
        gap: 0.75rem;
    }

У цьому прикладі:

- `gap` у `.form` задає відстань між полями;
- `gap` у `.form-field` задає відстань між підписом, полем і допоміжним текстом;
- `gap` у `.form__actions` задає проміжок між кнопками.

**Важливо:** помилки валідації також потребують продуманих відступів. Вони мають бути візуально пов'язані з полем, якого стосуються.

---

## 13. Spacing у навігації

Навігація повинна залишатися читабельною та зручною для взаємодії.

    [Логотип]    Головна    Курси    Про нас    [Увійти]

Важливо розрізняти:

- відстань між пунктами меню;
- внутрішні відступи інтерактивної області кожного пункту;
- відстань між логотипом і меню;
- відстань між меню та кнопкою дії.

### Приклад CSS

    .navigation {
        display: flex;
        align-items: center;
        gap: 1.5rem;
    }

    .navigation__links {
        display: flex;
        align-items: center;
        gap: 1rem;
    }

    .navigation__link {
        display: inline-flex;
        align-items: center;
        padding: 0.5rem 0.25rem;
    }

Тут зовнішні проміжки між групами та внутрішні відступи посилань мають різні функції.

На мобільних пристроях навігація може перебудовуватися, тому відступи слід перевіряти після переходу до іншого компонування.

## 14. Spacing і розміри інтерактивних елементів

Spacing впливає не лише на зовнішній вигляд, а й на зручність взаємодії.

### 14.1. Внутрішні відступи кнопки

    .button {
        display: inline-flex;
        align-items: center;
        justify-content: center;
        min-height: 2.75rem;
        padding: 0.75rem 1rem;
    }

Padding допомагає створити достатній простір навколо тексту кнопки.

### 14.2. Відстань між кнопками

    .button-group {
        display: flex;
        flex-wrap: wrap;
        gap: 0.75rem;
    }

Достатній проміжок зменшує ризик випадкового натискання сусідньої кнопки.

### 14.3. Розмір цілі натискання

**Touch target** — область, яку користувач може натиснути пальцем або активувати іншим способом.

Важливо:

- інтерактивні елементи мають бути достатнього розміру;
- сусідні цілі не повинні бути надто близько одна до одної;
- іконка може бути маленькою візуально, але її інтерактивна область має бути більшою;
- потрібно враховувати вимоги доступності та платформні рекомендації.

Збільшення відстані між кнопками саме по собі не завжди робить інтерфейс доступним: потрібно перевіряти і розмір кожної цілі, і проміжки між ними.

## 15. Spacing у layout: контейнери, колонки та секції

### 15.1. Відступи сторінки

На широкому екрані основний контент зазвичай має максимальну ширину та відступи від країв.

    .container {
        width: min(calc(100% - 2rem), 72rem);
        margin-inline: auto;
    }

Цей підхід дозволяє:

- зберігати горизонтальні відступи;
- не розтягувати контент на всю ширину великого монітора;
- центрувати основну область;
- використовувати єдине правило для різних секцій.

### 15.2. Відстань між секціями

    .section {
        padding-block: 4rem;
    }

Внутрішній вертикальний простір секції може допомогти відокремити її від сусідніх блоків.

Інший підхід — керувати відстанню між секціями на рівні батьківського компонента:

    .page-sections {
        display: flex;
        flex-direction: column;
        gap: 4rem;
    }

Не потрібно одночасно задавати великі відступи на секціях і такий самий `gap` без чіткої причини. Інакше відстані можуть стати надмірними.

### 15.3. Відстань між колонками

    .two-column-layout {
        display: grid;
        grid-template-columns: minmax(0, 1fr) minmax(0, 1fr);
        gap: 2rem;
    }

`gap` створює відстань між двома колонками.

### 15.4. Відступи між картками

    .cards {
        display: grid;
        grid-template-columns: repeat(3, minmax(0, 1fr));
        gap: 1.5rem;
    }

Відстань між картками має бути достатньою, щоб вони сприймалися як окремі компоненти, але не настільки великою, щоб втрачався зв'язок між ними.

## 16. Responsive spacing

**Responsive spacing** — адаптація відступів відповідно до доступного простору та розміру екрана.

Відступи, які добре працюють на десктопі, можуть бути завеликими на мобільному пристрої.

### 16.1. Desktop

На широких екранах часто доречні:

- більші відступи між секціями;
- ширші поля навколо контейнерів;
- більші проміжки між колонками;
- більше вільного простору навколо ключових блоків.

### 16.2. Mobile

На вузьких екранах часто потрібні:

- менші відступи від країв;
- менші проміжки між великими секціями;
- вертикальне компонування замість горизонтального;
- збереження достатнього простору всередині кнопок і полів;
- відсутність горизонтального переповнення.

Не потрібно зменшувати всі відступи однаково. Внутрішні відступи кнопок можуть залишатися достатніми, навіть якщо відстань між секціями зменшується.

### 16.3. Приклад із медіазапитом

    .page-section {
        padding-block: 4rem;
    }

    .page-container {
        width: min(calc(100% - 3rem), 72rem);
        margin-inline: auto;
    }

    .card-grid {
        display: grid;
        grid-template-columns: repeat(3, minmax(0, 1fr));
        gap: 1.5rem;
    }

    @media (max-width: 48rem) {
        .page-section {
            padding-block: 3rem;
        }

        .page-container {
            width: min(calc(100% - 2rem), 72rem);
        }

        .card-grid {
            grid-template-columns: repeat(2, minmax(0, 1fr));
            gap: 1rem;
        }
    }

    @media (max-width: 36rem) {
        .page-section {
            padding-block: 2rem;
        }

        .card-grid {
            grid-template-columns: 1fr;
        }
    }

У цьому прикладі:

- вертикальні відступи секцій зменшуються на менших екранах;
- горизонтальні відступи контейнера адаптуються;
- проміжки між картками стають меншими;
- сітка поступово переходить до однієї колонки.

Значення медіазапитів потрібно обирати відповідно до контенту, а не лише за назвами пристроїв.

### 16.4. Fluid spacing через `clamp()`

CSS-функція `clamp()` дозволяє задати мінімальне, гнучке та максимальне значення.

    .hero {
        padding-block: clamp(2rem, 5vw, 5rem);
    }

Це означає:

- відступ не буде меншим за `2rem`;
- проміжне значення залежатиме від ширини viewport;
- відступ не перевищить `5rem`.

Fluid spacing допомагає плавно адаптувати відступи без великої кількості медіазапитів.

Однак не всі відступи повинні змінюватися плавно. Для деяких компонентів фіксовані значення шкали можуть бути зрозумілішими та передбачуванішими.

---

## 17. Логічні CSS-властивості для відступів

Для сучасних інтерфейсів корисно використовувати логічні властивості замість жорстко заданих фізичних напрямків.

### Фізичні властивості

    .card {
        margin-left: 1rem;
        padding-right: 1.5rem;
    }

Вони завжди прив'язані до фізичних лівого та правого боків.

### Логічні властивості

    .card {
        margin-inline-start: 1rem;
        padding-inline-end: 1.5rem;
    }

Вони залежать від напрямку письма.

Інші корисні властивості:

    margin-inline
    margin-block
    padding-inline
    padding-block
    inset-inline
    inset-block

Переваги:

- підтримка LTR- і RTL-інтерфейсів;
- узгодженість із напрямком письма;
- менша залежність стилів від фізичних сторін екрана;
- простіша підтримка локалізованих застосунків.

Для звичайного LTR-інтерфейсу фізичні властивості теж можуть бути доречними, але логічні властивості часто забезпечують більшу гнучкість.

## 18. Spacing у дизайн-системі

У дизайн-системі відступи повинні бути передбачуваними та повторно використовуваними.

### 18.1. Токени відступів

Токени — це іменовані значення, які можна використовувати в різних компонентах.

    :root {
        --space-1: 0.25rem;
        --space-2: 0.5rem;
        --space-3: 0.75rem;
        --space-4: 1rem;
        --space-6: 1.5rem;
        --space-8: 2rem;
        --space-12: 3rem;
        --space-16: 4rem;
    }

### 18.2. Використання токенів

    .card {
        padding: var(--space-6);
    }

    .card-list {
        display: grid;
        gap: var(--space-4);
    }

    .section {
        padding-block: var(--space-12);
    }

    .button-group {
        display: flex;
        gap: var(--space-2);
    }

Замість випадкових значень компоненти використовують узгоджену шкалу.

### 18.3. Семантичні токени

За потреби можна створити токени, які описують не числове значення, а його призначення.

    :root {
        --spacing-inline-icon: 0.5rem;
        --spacing-field-group: 1.25rem;
        --spacing-card-padding: 1.5rem;
        --spacing-section: 4rem;
    }

Перевага — назва пояснює, для чого використовується значення.

Недолік — якщо семантичних токенів надто багато, система стає складнішою. Тому для навчального проєкту часто достатньо базової шкали.

### 18.4. Не кожен відступ має бути токеном

Іноді невелике індивідуальне значення потрібне для конкретного компонента або оптичного коригування.

Важливо не створювати винятки без причини, але й не змушувати всі елементи використовувати однаковий відступ, якщо це шкодить композиції.

4. `gap` задає відстань між дочірніми елементами.
5. Сітка має окремий проміжок між картками.
6. На мобільних пристроях кількість колонок і частина відступів змінюються.
7. Внутрішні відступи картки не залежать від зовнішнього проміжку між картками.

## 20. Типові помилки у Spacing

### Помилка 1. Випадкові значення відступів

    .title {
        margin-bottom: 17px;
    }

    .description {
        margin-bottom: 23px;
    }

    .button {
        margin-top: 19px;
    }

Такі значення можуть бути виправданими в окремих ситуаціях, але велика кількість випадкових відступів ускладнює підтримку інтерфейсу.

**Краще:** використовувати узгоджену шкалу й пояснювані правила.

### Помилка 2. Занадто малі внутрішні відступи

Якщо текст розташований надто близько до меж картки, інтерфейс виглядає перевантаженим.

**Краще:** залишати достатній внутрішній простір, особливо в картках, панелях і модальних вікнах.

### Помилка 3. Однакові відстані між усіма елементами

Якщо відстань між заголовком та його описом дорівнює відстані між двома великими секціями, ієрархія може стати нечіткою.

**Краще:** підбирати відступи відповідно до структури контенту.

### Помилка 4. Надмірна кількість порожнього простору

Whitespace важливий, але надмірні відстані можуть ускладнити пошук інформації та змусити користувача зайвий раз прокручувати сторінку.

**Краще:** зберігати баланс між простором, щільністю контенту та призначенням інтерфейсу.

### Помилка 5. Занадто малі відстані між інтерактивними елементами

Кнопки, посилання та іконки можуть бути важкими для натискання, якщо вони розташовані надто близько.

**Краще:** враховувати розмір цілі натискання та проміжки між сусідніми цілями.

### Помилка 6. Використання Margin для всіх дочірніх елементів

Кожен елемент має власні відступи, через що важко зрозуміти загальну структуру.

**Краще:** розглянути `gap` на рівні контейнера.

### Помилка 7. Padding і Gap використовуються без системи

Компонент має великий внутрішній відступ, великий `gap` і додаткові зовнішні відступи на кожному дочірньому елементі. У результаті композиція стає надмірно розрідженою.

**Краще:** окремо визначати внутрішній простір компонента, проміжки між його елементами та відстань до сусідніх компонентів.

### Помилка 8. Відступи не адаптуються до мобільного екрана

Великі десктопні відступи можуть забирати надто багато місця на вузькому екрані.

**Краще:** перевіряти адаптивність і змінювати відступи там, де це покращує композицію.

### Помилка 9. Використання `margin-top` як універсального інструмента

Постійне додавання `margin-top` може приховувати проблему в структурі компонування.

**Краще:** спочатку перевірити, чи доречні тут `gap`, `padding`, Grid або Flexbox.

### Помилка 10. Відступи не враховують довжину контенту

Довгі заголовки, помилки форм, локалізовані написи та різна кількість тексту можуть змінити висоту компонентів.

**Краще:** перевіряти макет на реальному контенті, а не лише на коротких демонстраційних текстах.

## 21. Як перевіряти Spacing у готовому UI

Під час перевірки сторінки постав собі такі запитання:

- Чи є послідовна шкала відступів?
- Чи мають пов'язані елементи менші проміжки, ніж різні групи?
- Чи достатньо внутрішнього простору в картках?
- Чи узгоджені відступи між полями форми?
- Чи не надто близько розташовані кнопки?
- Чи однакові відступи в однотипних компонентах?
- Чи не накопичуються `margin`, `padding` і `gap` без потреби?
- Чи зручно читати текст?
- Чи не займають відступи забагато місця на мобільному екрані?
- Чи правильно працює компонування з довгим контентом?
- Чи можна змінити відступи в одному місці через токени?
- Чи допомагає простір розрізняти групи інформації?

### Практичний метод аудиту

1. Знайди всі основні відстані на сторінці.
2. Визнач, які відстані повторюються.
3. Згрупуй їх за призначенням.
4. Порівняй їх зі шкалою відступів.
5. Прибери зайві або суперечливі значення.
6. Перевір внутрішні відступи карток, кнопок і форм.
7. Перевір відстані між великими секціями.
8. Переглянь сторінку на мобільному екрані.
9. Перевір довгі тексти та повідомлення про помилки.
10. Переконайся, що система відступів покращує структуру, а не створює зайвий простір.

## 22. Запитання для співбесіди

### Junior

**1. Що таке spacing у UI-дизайні?**

Це система відстаней між елементами та навколо них, яка допомагає структурувати контент і покращувати читабельність.

**2. Чим відрізняються `margin` і `padding`?**

`Margin` створює зовнішній відступ навколо елемента, а `padding` — внутрішній простір між його вмістом і межами.

**3. Що таке `gap`?**

Це властивість Flexbox і Grid, яка задає відстань між елементами контейнера.

**4. Що таке spacing scale?**

Це набір узгоджених значень відступів, які повторно використовуються в інтерфейсі.

**5. Чому важливо використовувати послідовні відступи?**

Вони допомагають створювати єдину візуальну систему, покращують читабельність і спрощують підтримку дизайну.

**6. Що таке whitespace?**

Це вільний простір навколо елементів і між ними, який допомагає створювати візуальну ієрархію.

### Middle

**7. Коли краще використовувати `gap`, а не `margin`?**

Коли потрібно задати системні проміжки між дочірніми елементами Flexbox або Grid-контейнера.

**8. Що таке margin collapsing?**

Це поведінка CSS, за якої певні вертикальні зовнішні відступи в звичайному блочному потоці об'єднуються.

**9. Як spacing впливає на візуальну ієрархію?**

Різні відстані допомагають показати, які елементи належать до однієї групи, а які є окремими блоками.

**10. Що таке responsive spacing?**

Це адаптація відступів до доступного простору та розміру екрана.

**11. Для чого потрібні CSS spacing tokens?**

Вони дозволяють централізовано керувати відступами й підтримувати послідовність між компонентами.

### Поглиблені питання

**12. Чому однакові відступи між усіма елементами не завжди є хорошим рішенням?**

Тому що відстані повинні відображати структуру контенту. Заголовок і його опис зазвичай мають бути ближчими, ніж дві незалежні секції.

**13. Як відступи впливають на доступність?**

Вони можуть покращувати розрізнення груп, читабельність і зручність натискання елементів. Проте spacing сам по собі не гарантує доступності — потрібно враховувати розміри цілей, контраст, клавіатурну навігацію та інші вимоги.

**14. Коли варто використовувати `clamp()` для відступів?**

Коли потрібне плавне масштабування простору між мінімальним і максимальним значеннями.

**15. Чим логічні властивості відступів відрізняються від фізичних?**

Логічні властивості залежать від напрямку письма та працюють із початком і кінцем рядкового або блочного напрямку. Фізичні властивості прив'язані до конкретних сторін — лівої, правої, верхньої та нижньої.

## 24. Мінішпаргалка

| Задача | Що використовувати |
|---|---|
| Внутрішній простір картки | `padding` |
| Зовнішній відступ окремого блока | `margin` |
| Проміжки між flex-елементами | `gap` |
| Проміжки між grid-елементами | `gap` |
| Різні проміжки між рядками й колонками | `row-gap`, `column-gap` |
| Узгоджені відстані в дизайн-системі | CSS spacing tokens |
| Плавна адаптація відступів | `clamp()` |
| Відступи з урахуванням напрямку письма | `margin-inline`, `padding-inline`, `margin-block`, `padding-block` |
| Відстань між заголовком та описом | Узгоджений малий або середній проміжок |
| Відстань між великими секціями | Більший вертикальний проміжок |
| Простір між кнопками | `gap` |
| Простір усередині кнопки | `padding` |
| Відстань між полями форми | `gap` у контейнері форми |
| Адаптація відступів на мобільному | Медіазапити або fluid spacing |

### Головне запам'ятати

1. Spacing — це не просто порожній простір, а інструмент структурування інтерфейсу.
2. Пов'язані елементи зазвичай розташовують ближче один до одного, ніж незалежні групи.
3. `padding` відповідає за внутрішній простір, `margin` — за зовнішній, `gap` — за проміжки між елементами контейнера.
4. Шкала відступів допомагає підтримувати візуальну послідовність.
5. Відстані мають відображати структуру контенту, а не бути однаковими всюди.
6. Whitespace допомагає виділяти важливі елементи й зменшувати візуальний шум.
7. Відступи впливають на читабельність, зручність користування та доступність.
8. На мобільних пристроях потрібно перевіряти баланс між вільним простором і доступною шириною.
9. CSS-токени спрощують підтримку системи відступів.
10. Хороший spacing робить інтерфейс зрозумілішим, а не просто просторішим.

## 25. Практичні завдання

### Завдання 1. Створи власну spacing scale

Визнач набір значень для свого UI-проєкту.

Наприклад:

    4px
    8px
    12px
    16px
    24px
    32px
    48px
    64px

Створи CSS-токени та використовуй їх у кількох компонентах.

### Завдання 2. Картка курсу

Створи картку з:

- категорією;
- заголовком;
- описом;
- кнопкою.

Налаштуй:

- внутрішні відступи;
- відстані між елементами;
- відстань між сусідніми картками;
- відступи від меж сторінки.

### Завдання 3. Форма реєстрації

Створи форму з трьома полями.

Перевір:

- відстань між підписом і полем;
- відстань між полем і допоміжним текстом;
- проміжки між різними полями;
- відступ до кнопки;
- поведінку повідомлень про помилки.

### Завдання 4. Адаптивна сторінка

Створи сторінку з трьома секціями та сіткою карток.

Зроби так, щоб:

- секції мали узгоджені вертикальні відступи;
- контейнер мав горизонтальні відступи;
- картки мали однакові внутрішні відступи;
- проміжки між картками адаптувалися;
- на мобільному екрані контент не виглядав стиснутим.

### Завдання 5. Аудит spacing

Вибери одну сторінку свого проєкту й знайди:

- випадкові значення відступів;
- надто малі внутрішні відступи;
- надмірні проміжки;
- неузгоджені відстані між схожими елементами;
- місця, де `gap` може спростити код;
- місця, де варто використовувати CSS-токени.

Виправ щонайменше п'ять проблем і порівняй результат до та після змін.

## 26. Підсумок

**Spacing — це система простору, яка допомагає організувати контент, сформувати візуальну ієрархію та зробити інтерфейс зручним для користувача.**

Під час проєктування UI:

- починай із визначення груп елементів;
- використовуй близькість для позначення зв'язків;
- відокремлюй внутрішні відступи від зовнішніх;
- застосовуй `gap` для системних проміжків у Flexbox і Grid;
- використовуй spacing scale та CSS-токени;
- адаптуй відступи до розміру екрана;
- враховуй реальний контент і розміри інтерактивних елементів;
- перевіряй, чи допомагає простір краще розуміти структуру сторінки.

Хороший spacing не привертає зайвої уваги. Він допомагає користувачеві природно переходити від одного елемента до іншого, розуміти зв'язки між блоками та зосереджуватися на важливому.

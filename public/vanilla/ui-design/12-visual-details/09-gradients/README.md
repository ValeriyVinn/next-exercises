# 09. Gradients — Градієнти в UI-дизайні

Градієнт (Gradient) — це плавний перехід між двома або більше кольорами. У UI-дизайні градієнти використовують для створення глибини, візуального акценту, декоративних фонів, об'єму та емоційного настрою інтерфейсу.

Градієнти можуть бути ледь помітними або насиченими, лінійними або радіальними, статичними або анімованими. Вони застосовуються у фонах сторінок, кнопках, картках, ілюстраціях, обкладинках, графіках і декоративних елементах.

**Головний принцип:** градієнт повинен підтримувати візуальну ієрархію та читабельність інтерфейсу, а не створювати зайвий візуальний шум.

---

## 1. Основи градієнтів

✔ Градієнт — це плавний перехід між кольорами.

✔ Може складатися з двох або більше кольорів.

✔ Може змінюватися за напрямком, формою та інтенсивністю.

✔ Допомагає створювати візуальну глибину.

✔ Може бути фоном, декоративним елементом або частиною компонента.

✔ Повинен відповідати палітрі та стилю дизайн-системи.

### 1.1. Для чого використовують градієнти

- **Фон** — додають глибину великій поверхні.
- **Акцент** — привертають увагу до важливого елемента.
- **Об'єм** — створюють враження освітлення та простору.
- **Брендинг** — допомагають формувати впізнаваний стиль.
- **Декорування** — роблять композицію цікавішою.
- **Візуальне групування** — допомагають відокремлювати секції.
- **Візуалізація даних** — показують інтенсивність або зміну значень.
- **Ілюстрації** — додають колірні переходи та глибину графіці.

### 1.2. Градієнт і суцільний колір

Суцільний колір (Solid Color) має однакове значення в усій області.

Градієнт поступово змінює колір у певному напрямку або відносно центральної точки.

| Властивість | Суцільний колір | Градієнт |
|---|---|---|
| Простота | Дуже простий | Залежить від кількості кольорів і переходів |
| Візуальна увага | Часто стримана | Може бути виразнішою |
| Передавання глибини | Обмежене | Може імітувати освітлення |
| Читабельність тексту | Зазвичай простіше контролювати | Потрібно перевіряти на всій площі |
| Використання | Фони, кнопки, поверхні | Акценти, декоративні фони, ілюстрації |

Градієнт не є автоматично кращим за суцільний колір. Часто однотонний фон краще підходить для інтерфейсів, у яких важливі простота, читабельність і мінімум відволікальних елементів.

## 2. Основні типи градієнтів

### 2.1. Лінійний градієнт (Linear Gradient)

Лінійний градієнт змінює кольори вздовж прямої лінії.

Приклад:

    background: linear-gradient(to right, #356ae6, #8b5cf6);

У цьому прикладі перехід відбувається зліва направо.

Лінійні градієнти використовують для:

- фонів hero-секцій;
- кнопок;
- декоративних смуг;
- банерів;
- карток;
- заголовків;
- підкреслень і акцентів.

### 2.2. Радіальний градієнт (Radial Gradient)

Радіальний градієнт поширюється від центральної точки або області назовні.

Приклад:

    background: radial-gradient(circle, #dbeafe, #356ae6);

Радіальний градієнт може імітувати світіння, локальне освітлення або м'яку кольорову пляму.

Використовується для:

- декоративних фонів;
- світлових акцентів;
- hero-блоків;
- фонових плям за ілюстраціями;
- м'якого підсвічування карток.

### 2.3. Конічний градієнт (Conic Gradient)

Конічний градієнт переходить між кольорами навколо центральної точки, ніби кольори обертаються навколо неї.

Приклад:

    background: conic-gradient(
      #356ae6,
      #8b5cf6,
      #ec4899,
      #356ae6
    );

Використовується для:

- декоративних кругів;
- діаграм;
- індикаторів;
- кольорових кілець;
- абстрактної графіки.

Для інтерфейсів конічний градієнт потрібно використовувати обережно: він може нагадувати діаграму навіть тоді, коли не передає реальних даних.

### 2.4. Багатокольоровий градієнт

Такий градієнт використовує три або більше кольорів.

Приклад:

    background: linear-gradient(
      120deg,
      #2563eb,
      #7c3aed,
      #db2777
    );

Він може бути виразним брендовим елементом, але надмірна кількість кольорів часто ускладнює композицію.

### 2.5. Прозорий градієнт

Прозорий градієнт поступово змінює прозорість кольору.

Приклад:

    background: linear-gradient(
      to bottom,
      rgba(15, 23, 42, 0),
      rgba(15, 23, 42, 0.8)
    );

Такий прийом часто використовують поверх фотографій, щоб текст залишався читабельним.

### 2.6. Градієнт із кількох шарів

Можна поєднувати декілька градієнтів в одному CSS-властивості.

Приклад:

    background:
      radial-gradient(
        circle at 20% 20%,
        rgba(96, 165, 250, 0.35),
        transparent 45%
      ),
      radial-gradient(
        circle at 80% 70%,
        rgba(167, 139, 250, 0.3),
        transparent 40%
      ),
      #0f172a;

Цей підхід дає змогу створювати складні декоративні фони без окремих графічних файлів.

## 3. Синтаксис градієнтів у CSS

Градієнти в CSS використовуються як значення властивостей, що приймають зображення, наприклад `background-image`.

### 3.1. Лінійний градієнт

Загальна форма:

    background: linear-gradient(direction, color-stop-1, color-stop-2);

Приклад:

    .gradient-box {
      background: linear-gradient(
        to right,
        #2563eb,
        #9333ea
      );
    }

Основні частини:

- `linear-gradient()` — функція лінійного градієнта;
- `to right` — напрямок;
- `#2563eb` — перший колір;
- `#9333ea` — другий колір.

### 3.2. Напрямок словами

Можна використовувати такі напрямки:

    background: linear-gradient(to right, #2563eb, #9333ea);
    background: linear-gradient(to left, #2563eb, #9333ea);
    background: linear-gradient(to bottom, #2563eb, #9333ea);
    background: linear-gradient(to top, #2563eb, #9333ea);

Також можна використовувати діагональні напрямки:

    background: linear-gradient(to bottom right, #2563eb, #9333ea);
    background: linear-gradient(to top left, #2563eb, #9333ea);

### 3.3. Напрямок у градусах

Градієнт можна задати через кут.

    background: linear-gradient(90deg, #2563eb, #9333ea);

Типові кути:

- `0deg` — напрямок знизу вгору;
- `90deg` — напрямок зліва направо;
- `180deg` — напрямок згори вниз;
- `270deg` — напрямок справа наліво.

Важливо: у CSS кут `0deg` спрямований угору, а не вправо.

### 3.4. Радіальний градієнт

    background: radial-gradient(
      circle at center,
      #bfdbfe,
      #2563eb
    );

Тут:

- `circle` визначає круглу форму;
- `at center` задає розташування центральної точки;
- кольори визначають перехід.

### 3.5. Конічний градієнт

    background: conic-gradient(
      from 0deg at center,
      #2563eb,
      #9333ea,
      #ec4899,
      #2563eb
    );

`from 0deg` задає початковий кут, а `at center` — положення центральної точки.

## 4. Color Stops — контрольні точки кольору

Color stop — це колір, який займає певне положення в градієнті.

За допомогою контрольних точок можна змінювати розподіл кольорів і характер переходу.

### 4.1. Два кольори

    background: linear-gradient(
      to right,
      #2563eb,
      #9333ea
    );

Браузер автоматично розподіляє перехід між двома кольорами.

### 4.2. Три кольори

    background: linear-gradient(
      to right,
      #2563eb,
      #7c3aed,
      #db2777
    );

Три кольори дають змогу створити складніший перехід.

### 4.3. Позиції кольорів у відсотках

    background: linear-gradient(
      to right,
      #2563eb 0%,
      #7c3aed 40%,
      #db2777 100%
    );

Відсотки визначають позиції кольорів уздовж градієнта.

Наприклад, `40%` означає, що відповідна контрольна точка розташована на 40% довжини градієнтної лінії.

### 4.4. Різкий перехід

Якщо потрібно створити чітку межу між кольорами, можна використати однакові або дуже близькі позиції контрольних точок.

    background: linear-gradient(
      to right,
      #2563eb 0%,
      #2563eb 50%,
      #9333ea 50%,
      #9333ea 100%
    );

Це створює різкий перехід між синьою та фіолетовою половинами.

Такий прийом більше нагадує двоколірне розділення, ніж плавний градієнт.

### 4.5. Кілька контрольних точок одного кольору

Можна зробити один колір домінантним, змістивши інші точки.

    background: linear-gradient(
      110deg,
      #1d4ed8 0%,
      #2563eb 65%,
      #7c3aed 100%
    );

У цьому прикладі синій займає більшу частину градієнта.

## 5. Вибір кольорів для градієнта

Градієнт починається не з CSS, а з вибору кольорів.

### 5.1. Аналогічні кольори

Аналогічні кольори розташовані поруч на колірному колі.

Приклад:

- синій;
- блакитний;
- бірюзовий.

Такі поєднання часто створюють спокійний і природний перехід.

    background: linear-gradient(
      120deg,
      #1d4ed8,
      #0ea5e9,
      #2dd4bf
    );

### 5.2. Близькі відтінки одного кольору

Градієнт можна створити на основі одного кольору та його світліших або темніших відтінків.

    background: linear-gradient(
      135deg,
      #1e40af,
      #3b82f6,
      #93c5fd
    );

Це допомагає зберегти стриманий стиль.

### 5.3. Контрастні кольори

Контрастні кольори створюють виразний акцент.

    background: linear-gradient(
      120deg,
      #2563eb,
      #ec4899
    );

Такі градієнти добре підходять для промоблоків, але можуть перевантажувати інтерфейс, якщо використовувати їх усюди.

### 5.4. Нейтральні градієнти

Градієнт не обов'язково повинен бути яскравим.

    background: linear-gradient(
      135deg,
      #f8fafc,
      #e2e8f0
    );

Нейтральні градієнти можуть додавати глибину фону, не привертаючи надмірної уваги.

### 5.5. Правила вибору палітри

✔ Починай із кольорів дизайн-системи.

✔ Визнач, яку емоцію або функцію повинен підтримувати градієнт.

✔ Не використовуй багато насичених кольорів без чіткої причини.

✔ Перевіряй перехід між кольорами на реальному розмірі компонента.

✔ Переконайся, що градієнт не конфліктує з фотографіями, іконками й текстом.

✔ Перевіряй вигляд градієнта на різних екранах.

## 6. Градієнти та візуальна ієрархія

Градієнт може посилювати або порушувати візуальну ієрархію.

### 6.1. Градієнт як акцент

Якщо головна кнопка має градієнт, а інші елементи нейтральні, кнопка може привертати більше уваги.

Проте важливо, щоб це була справді основна дія.

### 6.2. Градієнт як фон

Великий градієнтний фон може підтримувати загальну композицію, не стаючи головним елементом.

Для цього використовуй:

- помірну насиченість;
- близькі кольори;
- м'які переходи;
- достатній контраст тексту;
- просту композицію поверхні.

### 6.3. Не конкуруй із контентом

Якщо фон уже містить яскравий перехід, не обов'язково додавати градієнтні кнопки, текст і декоративні фігури одночасно.

**Правило:** визнач один головний візуальний акцент і підпорядкуй йому решту елементів.

---

## 7. Градієнти для тексту

Градієнтний текст може бути декоративним акцентом для заголовків або коротких написів.

### 7.1. Приклад градієнтного тексту

    .gradient-text {
      background: linear-gradient(
        90deg,
        #2563eb,
        #9333ea
      );

      background-clip: text;
      -webkit-background-clip: text;
      color: transparent;
    }

Тут фон обрізається за формою тексту, а сам текст стає прозорим, щоб показати градієнт.

### 7.2. Коли використовувати

Градієнтний текст доречний для:

- короткого hero-заголовка;
- ключового слова;
- назви продукту;
- промоакценту;
- декоративного заголовка.

### 7.3. Чого уникати

Не варто використовувати градієнт для всього тексту на сторінці.

Особливо обережно застосовуй його для:

- довгих абзаців;
- дрібного тексту;
- навігації;
- повідомлень про помилки;
- інструкцій;
- юридичних текстів.

Градієнтний текст може мати недостатній контраст на окремих ділянках. Перевіряй читабельність у всьому діапазоні кольорів.

---

## 8. Градієнти для кнопок

Градієнт може використовуватися як фон основної кнопки.

### 8.1. Приклад кнопки

    .button-primary {
      display: inline-flex;
      align-items: center;
      justify-content: center;
      min-height: 2.75rem;
      padding: 0.75rem 1.25rem;
      border: none;
      border-radius: 0.5rem;

      background: linear-gradient(
        110deg,
        #2563eb,
        #7c3aed
      );

      color: #ffffff;
      font: inherit;
      font-weight: 600;
      cursor: pointer;
    }

    .button-primary:hover {
      filter: brightness(1.08);
    }

    .button-primary:focus-visible {
      outline: 3px solid #93c5fd;
      outline-offset: 3px;
    }

### 8.2. Стани кнопки

Кнопка повинна залишатися зрозумілою у різних станах:

- default;
- hover;
- focus;
- active;
- disabled;
- loading.

Не покладайся лише на зміну кольору для передачі стану. Враховуй текст, форму, доступність і поведінку компонента.

### 8.3. Градієнт чи суцільний колір

Градієнт доречний, коли він є частиною візуальної мови продукту.

Суцільний колір часто кращий, якщо потрібна стримана, передбачувана кнопка або інтерфейс має багато важливих дій.

---

## 9. Градієнти у фонових секціях

Градієнти особливо корисні для великих декоративних поверхонь.

### 9.1. Hero-фон

    .hero {
      padding: 5rem 1.5rem;
      background: linear-gradient(
        135deg,
        #eff6ff,
        #f5f3ff
      );
    }

Такий фон створює м'який перехід між двома світлими кольорами.

### 9.2. Темний фон із кольоровим світінням

    .hero-dark {
      color: #f8fafc;
      background:
        radial-gradient(
          circle at 15% 20%,
          rgba(59, 130, 246, 0.3),
          transparent 35%
        ),
        radial-gradient(
          circle at 85% 70%,
          rgba(139, 92, 246, 0.25),
          transparent 40%
        ),
        #0f172a;
    }

Такий підхід створює кольорові акценти без додавання окремих зображень.

### 9.3. Фон для картки

    .feature-card {
      padding: 1.5rem;
      border: 1px solid #dbeafe;
      border-radius: 1rem;
      background: linear-gradient(
        145deg,
        #ffffff,
        #eff6ff
      );
    }

Використовуй легкий градієнт, якщо він допомагає відокремити картку від сторінки.

### 9.4. Градієнт поверх фотографії

    .photo-card {
      position: relative;
      overflow: hidden;
      border-radius: 1rem;
    }

    .photo-card img {
      display: block;
      width: 100%;
      height: 24rem;
      object-fit: cover;
    }

    .photo-card::after {
      content: "";
      position: absolute;
      inset: 0;
      background: linear-gradient(
        to top,
        rgba(15, 23, 42, 0.85),
        transparent 65%
      );
      pointer-events: none;
    }

Градієнтний шар може покращувати читабельність тексту поверх фотографії. Сам текст потрібно розміщувати окремо, наприклад у позиціонованому контейнері над зображенням.

## 10. Градієнти для карток та компонентів

Градієнти можуть використовуватися не лише як великі фони.

### 10.1. Акцентна смуга

    .notice-card {
      position: relative;
      padding: 1.5rem;
      border-radius: 0.75rem;
      background: #ffffff;
      border: 1px solid #e2e8f0;
    }

    .notice-card::before {
      content: "";
      position: absolute;
      inset: 0 auto 0 0;
      width: 0.3rem;
      border-radius: 0.75rem 0 0 0.75rem;
      background: linear-gradient(
        to bottom,
        #2563eb,
        #9333ea
      );
    }

Цей прийом додає кольоровий акцент, не перетворюючи весь компонент на яскраву поверхню.

### 10.2. Градієнтна рамка

Для простої градієнтної рамки можна використати два фони.

    .gradient-border {
      padding: 1.5rem;
      border: 2px solid transparent;
      border-radius: 1rem;

      background:
        linear-gradient(#ffffff, #ffffff) padding-box,
        linear-gradient(120deg, #2563eb, #9333ea) border-box;
    }

Перший фон покриває внутрішню частину, а другий формує градієнтну рамку.

### 10.3. Декоративне світіння

    .glow-card {
      position: relative;
      isolation: isolate;
      padding: 2rem;
      border-radius: 1rem;
      background: #0f172a;
      color: #f8fafc;
    }

    .glow-card::before {
      content: "";
      position: absolute;
      z-index: -1;
      inset: -1rem;
      border-radius: inherit;
      background: linear-gradient(
        135deg,
        #2563eb,
        #9333ea
      );
      filter: blur(2rem);
      opacity: 0.35;
    }

Світіння потрібно перевіряти на різних фонах і розмірах екрана. Надмірне розмиття може створювати візуальний шум.

## 11. Градієнти та глибина

Градієнти можуть створювати ілюзію освітлення й об'єму.

### 11.1. Імітація освітлення

Світліші ділянки можуть створювати враження, що поверхня освітлена з певного боку.

Темніші ділянки можуть формувати відчуття глибини.

Проте градієнт сам по собі не є справжньою тінню. Для об'ємного компонента часто потрібно поєднувати:

- колір;
- градієнт;
- межу;
- тінь;
- розташування;
- контраст із фоном.

### 11.2. Градієнти в декоративних формах

Можна використовувати градієнти для кіл, хвиль та інших геометричних елементів.

    .decorative-circle {
      width: 12rem;
      aspect-ratio: 1;
      border-radius: 50%;
      background: radial-gradient(
        circle at 30% 30%,
        #93c5fd,
        #6366f1 55%,
        #312e81
      );
    }

Такі форми можуть підтримувати hero-композицію або ілюстрацію.

### 11.3. Не плутай глибину з надмірною декоративністю

Якщо кожна картка має власний градієнт, тінь, світіння й рамку, інтерфейс може виглядати перевантаженим.

Вибирай ті ефекти, які допомагають зрозуміти структуру інтерфейсу.

## 12. Градієнти для іконок та ілюстрацій

Градієнти можуть використовуватися всередині векторної графіки.

### 12.1. SVG із градієнтом

У SVG можна визначити градієнт у секції `defs`, а потім застосувати його до фігури.

    <svg
      viewBox="0 0 120 120"
      role="img"
      aria-labelledby="gradient-icon-title"
      xmlns="http://www.w3.org/2000/svg"
    >
      <title id="gradient-icon-title">Кольорове коло</title>

      <defs>
        <linearGradient id="circle-gradient" x1="0" y1="0" x2="1" y2="1">
          <stop offset="0%" stop-color="#60a5fa" />
          <stop offset="100%" stop-color="#7c3aed" />
        </linearGradient>
      </defs>

      <circle
        cx="60"
        cy="60"
        r="48"
        fill="url(#circle-gradient)"
      />
    </svg>

### 12.2. Де використовувати

- брендова графіка;
- декоративні іконки;
- обкладинки;
- ілюстрації;
- логотипи, якщо це відповідає правилам бренду.

### 12.3. Коли краще уникати

Градієнт може бути зайвим для невеликих функціональних іконок, особливо якщо набір іконок повинен залишатися стриманим і однорідним.

У межах однієї бібліотеки іконок потрібно дотримуватися спільного стилю.

## 13. Градієнти та доступність

Градієнти можуть ускладнювати читання тексту та розрізнення елементів.

### 13.1. Контраст тексту

Текст поверх градієнта повинен залишатися читабельним на всіх ділянках, які займає текст.

Не достатньо перевірити лише найсвітліший або найтемніший колір.

Якщо фон переходить від світлого до темного, білий текст може бути читабельним лише на частині градієнта.

Можливі рішення:

- змінити палітру;
- перемістити текст у стабільнішу за кольором область;
- додати однотонну поверхню під текст;
- використати прозорий затемнювальний шар;
- збільшити розмір і вагу шрифту, якщо це доречно.

Збільшення розміру не компенсує будь-який недостатній контраст, тому перевірка залишається необхідною.

### 13.2. Не передавай значення лише кольором

Якщо градієнт показує статус, прогрес або інтенсивність даних, додай інші засоби передавання інформації:

- підписи;
- числові значення;
- текстові повідомлення;
- зрозумілі позначення;
- доступні альтернативи для візуалізації.

### 13.3. Градієнтні фони й текстові блоки

Для довгого тексту краще використовувати однорідний або майже однорідний фон.

Градієнт доречніший для великих декоративних областей, коротких заголовків і компонентів із контрольованим контрастом.

### 13.4. Режими високого контрасту

Якщо інтерфейс повинен підтримувати режими високого контрасту, не покладайся лише на декоративні градієнти для розрізнення компонентів.

Перевіряй, чи залишаються видимими межі, фокусні індикатори, кнопки та текст.

## 14. Градієнти в дизайн-системі

Якщо градієнти використовуються в кількох компонентах, варто визначити спільні правила.

### 14.1. Що потрібно стандартизувати

- основні кольорові пари;
- напрямки;
- типи градієнтів;
- правила використання;
- допустимі компоненти;
- контраст тексту;
- стани кнопок;
- варіанти для світлої та темної тем;
- правила анімації;
- обмеження на декоративні ефекти.

### 14.2. CSS-змінні

    :root {
      --gradient-primary: linear-gradient(
        110deg,
        #2563eb,
        #7c3aed
      );

      --gradient-soft: linear-gradient(
        135deg,
        #eff6ff,
        #f5f3ff
      );

      --gradient-dark: linear-gradient(
        135deg,
        #0f172a,
        #312e81
      );
    }

    .button-primary {
      background: var(--gradient-primary);
    }

    .hero {
      background: var(--gradient-soft);
    }

    .hero-dark {
      background: var(--gradient-dark);
    }

Перевага змінних полягає в тому, що градієнти можна змінювати централізовано.

### 14.3. Семантичні назви

Називай змінні за їхнім призначенням, а не лише за кольорами.

Наприклад:

- `--gradient-primary`;
- `--gradient-hero`;
- `--gradient-surface`;
- `--gradient-decorative`;
- `--gradient-brand`.

Такі назви зрозуміліші, ніж `--blue-purple-gradient-1`, якщо призначення ефекту важливіше за його конкретні кольори.

### 14.4. Світла й темна теми

    :root {
      --gradient-hero: linear-gradient(
        135deg,
        #eff6ff,
        #f5f3ff
      );
    }

    [data-theme="dark"] {
      --gradient-hero: linear-gradient(
        135deg,
        #0f172a,
        #1e1b4b
      );
    }

    .hero {
      background: var(--gradient-hero);
    }

Це лише приклад. У реальному проєкті назва атрибута теми повинна відповідати реалізації перемикання тем.

## 15. Анімація градієнтів

Анімований градієнт змінює напрямок, положення або кольори з часом.

### 15.1. Приклад анімованого фону

    .animated-gradient {
      background: linear-gradient(
        120deg,
        #2563eb,
        #7c3aed,
        #db2777
      );
      background-size: 200% 200%;
      animation: gradient-shift 8s ease infinite;
    }

    @keyframes gradient-shift {
      0% {
        background-position: 0% 50%;
      }

      50% {
        background-position: 100% 50%;
      }

      100% {
        background-position: 0% 50%;
      }
    }

Цей приклад змінює позицію збільшеного фону, створюючи плавний рух кольорів.

### 15.2. Коли анімація доречна

- у промоблоках;
- у декоративних елементах;
- у візуально виразних брендових секціях;
- у спеціальних станах, де рух має зрозумілу мету.

### 15.3. Коли анімація недоречна

- у кожному компоненті сторінки;
- за довгими текстовими блоками;
- поруч із важливими кнопками, якщо рух відволікає;
- у постійно видимих областях без потреби;
- у ситуаціях, коли рух може спричиняти дискомфорт.

### 15.4. Зменшення руху

    @media (prefers-reduced-motion: reduce) {
      .animated-gradient {
        animation: none;
        background-position: 50% 50%;
      }
    }

Це допомагає враховувати системне налаштування зменшення руху.

## 16. Градієнти та продуктивність

CSS-градієнти не потребують окремого файлу зображення, але складні ефекти все одно можуть мати вартість для рендерингу.

### 16.1. На що звертати увагу

- кількість шарів;
- площа градієнтних поверхонь;
- використання `filter: blur()`;
- постійна анімація;
- кількість елементів з ефектами;
- поведінка на мобільних пристроях.

### 16.2. Не створюй зайві шари

Кілька великих градієнтів із сильним розмиттям можуть бути важчими для відображення, ніж один простий фон.

Починай із найпростішого рішення та додавай складність лише за потреби.

### 16.3. Використання растрового зображення замість CSS

Для простого переходу кольорів CSS зазвичай зручніший за окреме зображення.

Для складної художньої графіки, текстур або спеціально створених композицій може бути доцільнішим оптимізований графічний файл.

Вибирай спосіб відповідно до завдання, а не за правилом «CSS завжди кращий».

## 17. Типові помилки

### Помилка 1. Надто багато кольорів

Градієнт містить багато яскравих кольорів, які не утворюють узгодженої палітри.

**Рішення:** починай із двох близьких кольорів і додавай інші лише за потреби.

### Помилка 2. Надто сильний контраст без мети

Різкий перехід привертає більше уваги, ніж основний контент.

**Рішення:** зменш насиченість або використай м'якший перехід.

### Помилка 3. Текст погано читається

Один колір градієнта забезпечує контраст, а інший — ні.

**Рішення:** перевіряй усю область під текстом і, за потреби, додавай однотонну поверхню.

### Помилка 4. Градієнт на кожному компоненті

Кнопки, картки, поля та фони одночасно мають різні переходи кольорів.

**Рішення:** визнач кілька дозволених варіантів і використовуй їх послідовно.

### Помилка 5. Градієнт не відповідає бренду

Колірні переходи створюють інший настрій, ніж решта дизайну.

**Рішення:** починай із палітри бренду та перевіряй ефект у контексті всього інтерфейсу.

### Помилка 6. Невдалий напрямок

Перехід створює небажаний акцент або візуально порушує композицію.

**Рішення:** спробуй кілька напрямків і перевір, як вони взаємодіють із текстом та ілюстраціями.

### Помилка 7. Надмірне світіння

Розмиті кольорові плями перекривають інші елементи.

**Рішення:** зменш розмиття та прозорість або прибери зайві шари.

### Помилка 8. Анімація відволікає

Постійний рух перетягує увагу на декоративний фон.

**Рішення:** вимкни анімацію або зроби її коротшою та менш помітною.

### Помилка 9. Градієнт використовується замість зрозумілої структури

Колірні переходи намагаються замінити межі, підписи або логічне групування.

**Рішення:** спочатку побудуй правильну структуру, а потім використовуй градієнт як додатковий засіб.

### Помилка 10. Немає перевірки темної теми

Світлий градієнт стає надто яскравим або погано поєднується з темними поверхнями.

**Рішення:** перевіряй палітру в кожній підтримуваній темі.

## 18. Найкращі практики

✔ Починай із мети, а не з декоративного ефекту.

✔ Використовуй градієнти як частину дизайн-системи.

✔ Обмежуй кількість кольорів.

✔ Підбирай напрямок відповідно до композиції.

✔ Використовуй близькі кольори для стриманих фонів.

✔ Застосовуй виразні градієнти для чітко визначених акцентів.

✔ Перевіряй читабельність тексту на всіх ділянках фону.

✔ Не використовуй градієнт як єдиний спосіб передавання стану.

✔ Враховуй темну тему.

✔ Використовуй CSS-змінні для повторюваних градієнтів.

✔ Не додавай анімацію без функціональної або візуальної причини.

✔ Враховуй `prefers-reduced-motion`.

✔ Не перевантажуй інтерфейс світінням, тінями та багатошаровими фонами.

✔ Перевіряй ефект на реальному розмірі екрана.

✔ Порівнюй градієнт із простим суцільним кольором: іноді простіший варіант працює краще.

## 19. Мініпроєкт: бібліотека градієнтів

Мета — створити невелику бібліотеку градієнтів для освітнього вебсайту.

### Завдання

Створи п'ять варіантів:

1. `gradient-primary` — для основної кнопки.
2. `gradient-hero` — для головної секції.
3. `gradient-soft` — для світлої картки.
4. `gradient-dark` — для темної секції.
5. `gradient-decorative` — для декоративних елементів.

### Крок 1. Визнач палітру

Обери основні кольори бренду.

Наприклад:

- синій — `#2563eb`;
- фіолетовий — `#7c3aed`;
- світло-блакитний — `#eff6ff`;
- темно-синій — `#0f172a`.

Це лише приклад палітри. Для власного проєкту вибери кольори, які відповідають його стилю.

### Крок 2. Створи CSS-змінні

    :root {
      --gradient-primary: linear-gradient(
        110deg,
        #2563eb,
        #7c3aed
      );

      --gradient-hero: linear-gradient(
        135deg,
        #eff6ff,
        #f5f3ff
      );

      --gradient-soft: linear-gradient(
        145deg,
        #ffffff,
        #eff6ff
      );

      --gradient-dark: linear-gradient(
        135deg,
        #0f172a,
        #312e81
      );

      --gradient-decorative: radial-gradient(
        circle at 30% 30%,
        #93c5fd,
        #6366f1,
        #312e81
      );
    }

### Крок 3. Створи демонстраційні компоненти

Застосуй градієнти до:

- кнопки;
- hero-секції;
- картки;
- темного блоку;
- декоративного кола.

### Крок 4. Порівняй варіанти

Для кожного компонента перевір:

- градієнтний фон;
- суцільний колір;
- контраст тексту;
- візуальну ієрархію;
- узгодженість із сусідніми елементами.

### Крок 5. Перевір адаптивність

Переглянь сторінку на вузькому та широкому екранах.

Переконайся, що градієнти не створюють зайвого шуму та не погіршують читабельність.

### Результат

Ти отримаєш невелику бібліотеку градієнтів, яку можна повторно використовувати в різних компонентах сайту.

- [ ] Ефект перевірено на мобільному екрані.
- [ ] Порівняно градієнт із варіантом на суцільному кольорі.

## 21. Що потрібно запам'ятати

1. **Градієнт — це інструмент, а не самоціль.** Він повинен підтримувати зміст і композицію.
2. **Існують різні типи градієнтів.** Лінійний, радіальний і конічний градієнти мають різні властивості.
3. **Кольори повинні бути узгодженими.** Палітра впливає на настрій і цілісність інтерфейсу.
4. **Color stops контролюють перехід.** Позиції кольорів дозволяють керувати розподілом кольорових областей.
5. **Контраст має вирішальне значення.** Текст повинен залишатися читабельним на всьому фоні.
6. **Градієнт може створювати глибину.** Але не замінює автоматично тіні, межі та правильну композицію.
7. **CSS-змінні спрощують підтримку.** Повторювані градієнти краще централізувати.
8. **Анімація потребує обережності.** Вона повинна мати мету та враховувати налаштування зменшення руху.
9. **Не кожен компонент потребує градієнта.** Суцільний колір часто забезпечує кращу читабельність.
10. **Перевіряй результат у контексті.** Градієнт, який добре виглядає окремо, може не працювати в реальному інтерфейсі.

10. Перевірити результати на мобільному екрані та в темній темі.

## 24. Коротка шпаргалка

| Поняття | Що запам'ятати |
|---|---|
| Gradient | Плавний перехід між кольорами |
| Linear gradient | Перехід уздовж прямої лінії |
| Radial gradient | Перехід від центральної точки або області |
| Conic gradient | Перехід кольорів навколо центральної точки |
| Color stop | Колір і його позиція в градієнті |
| Gradient direction | Напрямок переходу |
| Transparent gradient | Градієнт із поступовою зміною прозорості |
| Multi-layer gradient | Поєднання кількох градієнтних шарів |
| Gradient text | Текст із градієнтним заповненням |
| Gradient border | Рамка з переходом між кольорами |
| Gradient overlay | Градієнтний шар поверх зображення |
| Visual hierarchy | Порядок сприйняття елементів |
| Contrast | Різниця між кольорами, необхідна для розрізнення елементів |
| CSS custom property | Змінна CSS для повторного використання значень |
| `linear-gradient()` | CSS-функція лінійного градієнта |
| `radial-gradient()` | CSS-функція радіального градієнта |
| `conic-gradient()` | CSS-функція конічного градієнта |
| `background-clip: text` | Дозволяє обрізати фон за формою тексту |
| `prefers-reduced-motion` | Медіазапит для врахування налаштування зменшення руху |

**Головна думка:** хороший градієнт підтримує композицію, підкреслює важливі елементи та узгоджується з палітрою продукту. Якщо він погіршує читабельність або відволікає від змісту, краще спростити його або використати суцільний колір.

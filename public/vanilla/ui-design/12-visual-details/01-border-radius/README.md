# 01. Border Radius

Border radius (заокруглення кутів) — це візуальна властивість інтерфейсу, яка визначає, наскільки заокругленими будуть кути елемента.

У UI design border radius використовується для оформлення:

- buttons;
- cards;
- input fields;
- images;
- modals;
- dialogs;
- badges;
- chips;
- avatars;
- navigation elements;
- containers;
- panels.

Border radius впливає на візуальний стиль інтерфейсу, сприйняття компонентів, їхню виразність і загальну узгодженість дизайну.

Основні поняття:

    border radius
    corner radius
    rounded corners
    border-radius scale
    radius tokens
    consistent radius
    nested radius
    circular elements
    pill shape
    design consistency

У CSS заокруглення кутів задається властивістю:

    border-radius

Наприклад:

    .card {
        border-radius: 12px;
    }

Це означає, що кути картки будуть заокруглені радіусом 12px.

## Що потрібно пам'ятати

• Border radius визначає заокруглення кутів елемента.

• У CSS використовується властивість `border-radius`.

• Малий радіус створює легке заокруглення.

• Великий радіус створює м'якший, округліший вигляд.

• Значення `border-radius: 0` означає відсутність заокруглення.

• Значення `border-radius: 50%` може створювати коло, якщо елемент квадратний.

• Для створення pill-shaped кнопок часто використовують дуже великий радіус, наприклад `999px`.

• Border radius має відповідати загальному візуальному стилю продукту.

• Картки, кнопки, поля введення та модальні вікна повинні використовувати узгоджені значення радіуса.

• Не обов'язково використовувати однаковий радіус для всіх компонентів.

• Великі компоненти часто мають більший радіус, ніж невеликі компоненти, але це дизайнерське рішення, а не суворе правило.

• Радіус зовнішнього контейнера та внутрішніх елементів потрібно узгоджувати.

• `border-radius` не успадковується автоматично від батьківського елемента.

• Заокруглення кутів саме по собі не гарантує, що вміст буде обрізаний за формою контейнера. Для цього може знадобитися `overflow: hidden`.

• Надмірне заокруглення може зробити інтерфейс візуально перевантаженим або невідповідним до характеру продукту.

• Найкращий підхід — визначити невелику систему значень радіуса та використовувати її послідовно.

---

# Border Radius

Border radius — це параметр форми елемента, який визначає геометрію його кутів.

Наприклад, прямокутна картка може мати:

    border-radius: 0;

або:

    border-radius: 8px;

або:

    border-radius: 16px;

або:

    border-radius: 24px;

Чим більше значення радіуса, тим сильніше заокруглюються кути.

Однак візуальний результат залежить також від ширини, висоти та форми самого елемента.

---

# Corner Radius

Corner radius — радіус окремого кута елемента.

У CSS можна задавати радіус для всіх кутів одночасно або для кожного кута окремо.

Наприклад:

    .card {
        border-radius: 12px;
    }

Усі чотири кути матимуть однакове заокруглення.

Або:

    .card {
        border-top-left-radius: 16px;
        border-top-right-radius: 16px;
        border-bottom-right-radius: 4px;
        border-bottom-left-radius: 4px;
    }

Верхні кути будуть сильніше заокруглені, ніж нижні.

У UI design окремі радіуси використовують, коли цього потребує композиція або візуальна концепція.

Для більшості звичайних компонентів однаковий радіус є простішим і передбачуванішим рішенням.

---

# Border Radius у CSS

Основна властивість:

    border-radius

Синтаксис:

    border-radius: value;

Наприклад:

    .button {
        border-radius: 8px;
    }

    .input {
        border-radius: 6px;
    }

    .card {
        border-radius: 16px;
    }

Значення можна задавати в різних одиницях, зокрема:

    px
    rem
    %

Для навчальних прикладів і дизайн-систем часто зручно використовувати `px` або `rem`.

---

# Radius 0

`border-radius: 0` прибирає заокруглення.

    .card {
        border-radius: 0;
    }

Такий стиль створює прямі кути.

Його використовують у дизайнах, де важливі:

- геометричність;
- строгість;
- технічний характер;
- мінімалізм;
- прямокутні композиції.

Приклади інтерфейсів:

    technical dashboards
    data tables
    editorial layouts
    brutalist interfaces
    industrial applications

Прямі кути не є застарілим рішенням. Вони можуть бути свідомою частиною дизайн-системи.

---

# Small Radius

Small radius — невелике заокруглення кутів.

Наприклад:

    .button {
        border-radius: 4px;
    }

    .input {
        border-radius: 4px;
    }

    .card {
        border-radius: 6px;
    }

Невеликий радіус зберігає прямокутну форму, але робить її трохи м'якшою.

Його можна використовувати для:

- компактних кнопок;
- полів введення;
- невеликих карток;
- таблиць;
- технічних інтерфейсів;
- щільних інформаційних панелей.

Важливо: наведені значення — приклади, а не універсальний стандарт.

---

# Medium Radius

Medium radius — помірне заокруглення.

Наприклад:

    .button {
        border-radius: 8px;
    }

    .input {
        border-radius: 8px;
    }

    .card {
        border-radius: 12px;
    }

Помірний радіус створює баланс між прямокутною геометрією та м'якістю форми.

Його часто використовують у:

    SaaS applications
    educational platforms
    healthcare interfaces
    admin dashboards
    productivity tools
    web applications

Такий підхід може бути зручним для універсальної дизайн-системи, але конкретні значення залежать від стилю продукту.

---

# Large Radius

Large radius — велике заокруглення кутів.

Наприклад:

    .card {
        border-radius: 20px;
    }

    .modal {
        border-radius: 24px;
    }

Великі радіуси створюють більш м'який і виразний вигляд.

Їх можна використовувати для:

- великих карток;
- модальних вікон;
- промоблоків;
- великих зображень;
- мобільних інтерфейсів;
- окремих композиційних контейнерів.

Важливо не збільшувати радіус автоматично для кожного компонента.

Великі заокруглення повинні відповідати візуальній концепції та масштабу елемента.

---

# Sharp vs Rounded Corners

Sharp corners — прямі кути без заокруглення або з мінімальним радіусом.

Rounded corners — заокруглені кути.

Порівняння:

    Sharp corners
        → строгість
        → геометричність
        → прямокутні форми

    Rounded corners
        → м'якші форми
        → плавні контури
        → більш округлий візуальний стиль

Це загальні візуальні асоціації, а не суворі правила сприйняття.

Обидва підходи можуть бути професійними та ефективними.

Головне — щоб вони відповідали продукту та використовувалися послідовно.

---

# Radius Scale

Radius scale — це набір узгоджених значень радіуса, які використовуються в дизайн-системі.

Наприклад:

    radius-none: 0px;
    radius-sm: 4px;
    radius-md: 8px;
    radius-lg: 12px;
    radius-xl: 16px;
    radius-2xl: 24px;
    radius-full: 999px;

Це приклад умовної шкали.

У реальному проєкті можна використовувати менше або більше значень.

Головна мета radius scale — не допустити випадкового використання десятків майже однакових радіусів.

Наприклад, замість:

    5px
    7px
    9px
    11px
    13px
    15px

можна визначити кілька стандартних значень:

    4px
    8px
    12px
    16px

Так простіше підтримувати узгодженість компонентів.

---

# Radius Tokens

Radius tokens — дизайн-токени, які зберігають стандартні значення радіуса.

У дизайн-системі токени дають змогу використовувати однакові значення в різних компонентах.

Наприклад, у CSS:

    :root {
        --radius-none: 0;
        --radius-sm: 4px;
        --radius-md: 8px;
        --radius-lg: 12px;
        --radius-xl: 16px;
        --radius-2xl: 24px;
        --radius-full: 999px;
    }

Використання:

    .button {
        border-radius: var(--radius-md);
    }

    .input {
        border-radius: var(--radius-md);
    }

    .card {
        border-radius: var(--radius-lg);
    }

    .modal {
        border-radius: var(--radius-2xl);
    }

Переваги:

- єдина система значень;
- простіша підтримка стилів;
- швидка зміна дизайну;
- менше випадкових відмінностей;
- зручне масштабування проєкту.

У дизайн-інструментах, наприклад Figma, аналогічну роль можуть виконувати variables або design tokens.

---

# Consistent Radius

Consistent radius — послідовне використання радіусів у межах інтерфейсу.

Наприклад, якщо всі основні поля введення використовують радіус 8px, не варто без причини створювати інші поля з радіусом 5px, 11px або 13px.

Неузгоджений підхід:

    .input-a {
        border-radius: 6px;
    }

    .input-b {
        border-radius: 11px;
    }

    .input-c {
        border-radius: 9px;
    }

Узгоджений підхід:

    .input {
        border-radius: var(--radius-md);
    }

Послідовність не означає, що кожен елемент повинен мати однаковий радіус.

Кнопки, картки, поля введення та модальні вікна можуть використовувати різні токени.

Важливо, щоб ці відмінності були навмисними.

---

# Border Radius для Buttons

Кнопки можуть мати різні форми залежно від характеру продукту.

## Прямокутна кнопка

    .button {
        border-radius: 0;
    }

Підходить для строгих геометричних інтерфейсів.

## Злегка заокруглена кнопка

    .button {
        border-radius: 4px;
    }

Створює стриманий вигляд.

## Кнопка з помірним заокругленням

    .button {
        border-radius: 8px;
    }

Поширений варіант для вебзастосунків.

## Повністю округла кнопка

    .button {
        border-radius: 999px;
    }

Створює pill shape.

При виборі радіуса потрібно враховувати:

- висоту кнопки;
- ширину кнопки;
- розмір тексту;
- внутрішні відступи;
- стиль інших компонентів;
- загальну візуальну концепцію.

Не потрібно використовувати pill shape для всіх кнопок лише тому, що такий стиль популярний.

---

# Border Radius для Input Fields

Поля введення повинні відповідати формі інших інтерактивних компонентів.

Наприклад:

    .input {
        width: 100%;
        padding: 12px 16px;
        border: 1px solid #cbd5e1;
        border-radius: 8px;
    }

Якщо кнопки та поля введення мають однаковий радіус, інтерфейс може виглядати більш узгодженим.

Однак допустимо використовувати різні значення, якщо вони є частиною дизайн-системи.

Важливо не плутати форму компонента з його станом.

Наприклад, focus state може змінювати колір рамки або додавати outline, не змінюючи радіус.

---

# Border Radius для Cards

Card — контейнер, який групує пов'язаний контент.

Наприклад:

    .card {
        padding: 24px;
        border: 1px solid #e2e8f0;
        border-radius: 16px;
    }

Радіус картки повинен узгоджуватися з:

- її розміром;
- внутрішніми компонентами;
- стилем сторінки;
- сусідніми картками;
- іншими контейнерами.

Невеликі картки в щільному інтерфейсі можуть використовувати менший радіус.

Великі промокартки можуть мати більший радіус.

Це не означає, що всі великі картки обов'язково повинні бути більш заокругленими.

---

# Border Radius для Images

Заокруглення зображень може використовуватися для:

- фотографій;
- прев'ю статей;
- обкладинок;
- ілюстрацій;
- галерей;
- аватарів;
- зображень у картках товарів.

Наприклад:

    .article-image {
        width: 100%;
        height: auto;
        border-radius: 12px;
    }

Радіус зображення може збігатися з радіусом картки або бути трохи меншим.

Вибір залежить від композиції.

Якщо зображення розташоване всередині картки, важливо перевірити, чи не створює його радіус випадкові проміжки або подвійне заокруглення.

---

# Border Radius для Avatars

Avatar — елемент, який представляє користувача або іншу сутність.

Аватари можуть мати:

- квадратну форму;
- злегка заокруглену форму;
- круглу форму.

Наприклад, квадратний аватар:

    .avatar {
        width: 48px;
        height: 48px;
        border-radius: 8px;
        object-fit: cover;
    }

Круглий аватар:

    .avatar {
        width: 48px;
        height: 48px;
        border-radius: 50%;
        object-fit: cover;
    }

Якщо ширина та висота однакові, `border-radius: 50%` створює круглу форму.

Якщо розміри різні, результатом буде еліпс.

Форма аватара повинна бути узгодженою в різних частинах застосунку.

---

# Circular Elements

Circular element — елемент круглої форми.

Для створення кола зазвичай використовують однакову ширину та висоту разом із `border-radius: 50%`.

Наприклад:

    .avatar {
        width: 64px;
        height: 64px;
        border-radius: 50%;
    }

Коло можна використовувати для:

- аватарів;
- декоративних індикаторів;
- круглих кнопок;
- елементів статусу;
- окремих графічних маркерів.

Для круглих кнопок і контролів також необхідно перевіряти доступність, розмір інтерактивної області та зрозумілість призначення.

---

# Pill Shape

Pill shape — форма з дуже заокругленими кінцями, схожа на капсулу.

Наприклад:

    .badge {
        display: inline-flex;
        align-items: center;
        padding: 4px 12px;
        border-radius: 999px;
    }

Pill shape часто використовують для:

- badges;
- chips;
- tags;
- labels;
- filter controls;
- деяких кнопок;
- елементів вибору.

Велике значення радіуса не обов'язково потрібно точно розраховувати від ширини компонента.

Значення `999px` часто використовують як простий спосіб отримати дуже заокруглені кінці.

---

# Asymmetric Radius

Asymmetric radius — асиметричне заокруглення, коли різні кути мають різні значення.

Наприклад:

    .card {
        border-radius: 24px 24px 8px 8px;
    }

Порядок значень:

    top-left
    top-right
    bottom-right
    bottom-left

Інший приклад:

    .card {
        border-top-left-radius: 24px;
        border-top-right-radius: 8px;
        border-bottom-right-radius: 24px;
        border-bottom-left-radius: 8px;
    }

Асиметричні радіуси можуть створювати:

- нестандартну форму;
- акцент на певній частині композиції;
- декоративний характер;
- відмінність між компонентами.

Використовувати їх потрібно обережно.

Якщо асиметрія не підтримує композицію або не має чіткої причини, вона може виглядати випадковою.

---

# Nested Radius

Nested radius — узгодження радіусів вкладених елементів.

Наприклад, картка містить внутрішній блок або зображення.

    .card {
        padding: 16px;
        border-radius: 20px;
    }

    .card__image {
        border-radius: 12px;
    }

Внутрішній елемент має менший радіус, ніж зовнішній контейнер.

Це один із можливих підходів, але не універсальне правило.

Важливо враховувати відстань між зовнішнім краєм і внутрішнім елементом.

Наприклад, якщо внутрішній блок розташований безпосередньо біля краю картки, невдале поєднання радіусів може створити помітні геометричні розриви.

Тому потрібно перевіряти:

- зовнішній радіус;
- внутрішній радіус;
- padding;
- розташування внутрішнього елемента;
- clipping;
- візуальну безперервність кутів.

---

# Radius і Padding

Padding — внутрішній відступ елемента.

Радіус та внутрішній відступ часто потрібно розглядати разом.

Наприклад:

    .card {
        padding: 24px;
        border-radius: 16px;
    }

Якщо картка має великий радіус, але текст розташований занадто близько до кута, композиція може виглядати незбалансованою.

Для карток і контейнерів потрібно перевіряти, чи має вміст достатньо простору біля заокруглених кутів.

Однак немає універсальної формули, яка визначає правильне співвідношення між padding і radius.

Воно залежить від розмірів елемента, вмісту та дизайну.

---

# Radius і Overflow

Властивість `border-radius` заокруглює форму самого елемента, але не гарантує автоматичного обрізання всього його вмісту по заокругленому контуру.

Наприклад:

    .card {
        border-radius: 16px;
    }

Якщо всередині картки розташоване велике зображення, воно може виходити за межі потрібного візуального контуру.

Для обрізання вмісту можна використати:

    .card {
        border-radius: 16px;
        overflow: hidden;
    }

Це особливо корисно для карток із зображеннями, кольоровими фонами або внутрішніми декоративними елементами.

Важливо пам'ятати, що `overflow: hidden` також може обрізати інший вміст, який виходить за межі контейнера, наприклад:

- тіні дочірніх елементів;
- декоративні елементи;
- меню;
- tooltip;
- інші елементи, які виступають за межі контейнера.

Тому використовувати `overflow: hidden` потрібно з урахуванням поведінки всіх дочірніх компонентів.

---

# Radius і Visual Hierarchy

Visual hierarchy — візуальна ієрархія, яка допомагає користувачу розуміти важливість і взаємозв'язок елементів.

Радіус може бути одним із засобів візуального розрізнення компонентів.

Наприклад:

    Primary action
        → radius-md

    Card
        → radius-lg

    Modal
        → radius-xl

Це лише умовний приклад.

Не варто використовувати радіус як єдиний спосіб показати важливість компонента.

Для візуальної ієрархії також використовуються:

- розмір;
- контраст;
- колір;
- позиціонування;
- відступи;
- типографіка;
- тіні;
- щільність композиції.

Радіус повинен доповнювати ці засоби, а не замінювати їх.

---

# Radius і Brand Identity

Brand identity — візуальна ідентичність бренду.

Форма компонентів може бути частиною впізнаваного стилю продукту.

Наприклад:

    sharp corners
        → геометричний стиль

    subtle rounding
        → стриманий сучасний стиль

    highly rounded shapes
        → м'який, округлий стиль

Це загальні дизайнерські асоціації, а не універсальні характеристики брендів.

Під час створення дизайн-системи потрібно визначити:

- загальний характер форми;
- базовий радіус;
- допустимі відхилення;
- радіуси для окремих типів компонентів;
- правила використання pill shape;
- правила використання круглих елементів.

Головне — підтримувати цілісний характер інтерфейсу.

---

# Radius у Light і Dark Themes

Border radius зазвичай залишається однаковим у світлій і темній темах.

Наприклад:

    .card {
        border-radius: var(--radius-lg);
    }

Змінювати радіус між темами потрібно лише тоді, коли це є свідомою частиною дизайн-рішення.

У більшості випадків light theme і dark theme використовують однакову геометрію компонентів, але різні кольори, межі та інші візуальні властивості.

---

# Responsive Radius

Responsive radius — використання радіусів з урахуванням розміру екрана або компонента.

Наприклад:

    .card {
        border-radius: 12px;
    }

    @media (min-width: 768px) {
        .card {
            border-radius: 16px;
        }
    }

Це може бути доречно, якщо дизайн справді передбачає різну форму картки на різних екранах.

Однак не потрібно автоматично збільшувати радіуси на desktop або зменшувати їх на mobile.

Рішення залежить від:

- загального стилю;
- розміру компонента;
- доступного простору;
- співвідношення елементів;
- поведінки композиції на різних екранах.

Responsive design повинен зберігати цілісність дизайн-системи.

---

# Radius у Design Systems

У дизайн-системі радіуси потрібно визначати централізовано.

Наприклад:

    Radius tokens

    none  → 0px
    sm    → 4px
    md    → 8px
    lg    → 12px
    xl    → 16px
    2xl   → 24px
    full  → 999px

Далі можна визначити умовні правила:

    Buttons
        → radius-md

    Inputs
        → radius-md

    Cards
        → radius-lg

    Modals
        → radius-xl

    Badges
        → radius-full

Ці правила не є обов'язковим стандартом. Це приклад того, як можна побудувати узгоджену систему.

У реальному продукті кожне рішення потрібно перевірити на відповідність його компонентам і візуальному стилю.

---

# Border Radius і Figma

У Figma радіус заокруглення налаштовується у властивостях вибраного елемента.

Під час роботи з радіусами потрібно вміти:

- задавати однаковий радіус для всіх кутів;
- задавати радіус окремо для кожного кута;
- копіювати стиль між компонентами;
- використовувати variables або дизайн-токени, якщо це підтримується обраною структурою файлу;
- підтримувати однакові значення в повторюваних компонентах;
- перевіряти результат на різних розмірах екрана.

Важливо не просто налаштовувати радіус візуально, а й розуміти, до якої системи значень належить це значення.

---

# Border Radius і Component Variants

Один компонент може мати кілька варіантів оформлення.

Наприклад, кнопка:

    Button
        ├── Primary
        ├── Secondary
        ├── Tertiary
        └── Destructive

Варіанти кнопки можуть відрізнятися кольором, рамкою та іншими стилями, але зберігати однаковий радіус.

Наприклад:

    .button {
        border-radius: var(--radius-md);
    }

    .button--primary {
        background: #2563eb;
    }

    .button--secondary {
        background: #ffffff;
    }

    .button--destructive {
        background: #dc2626;
    }

Якщо всі варіанти належать до одного сімейства компонентів, однаковий радіус часто допомагає підтримувати їхню візуальну цілісність.

Відмінності у формі варто додавати лише тоді, коли для них є обґрунтована причина.

---

# Типові помилки

## 1. Використовувати випадкові значення

Неузгоджений підхід:

    .button {
        border-radius: 7px;
    }

    .input {
        border-radius: 11px;
    }

    .card {
        border-radius: 17px;
    }

Такі значення не обов'язково неправильні, але якщо вони не належать до визначеної шкали, підтримувати дизайн буде складніше.

Краще визначити radius tokens.

---

## 2. Надмірно заокруглювати всі елементи

Наприклад:

    .button {
        border-radius: 40px;
    }

    .input {
        border-radius: 40px;
    }

    .card {
        border-radius: 40px;
    }

Це може бути свідомим стилем, але не завжди відповідає продукту.

Не потрібно використовувати максимальне заокруглення для кожного компонента.

---

## 3. Змішувати несумісні стилі

Наприклад, більшість компонентів мають прямі кути, а одна випадкова картка — дуже великий радіус.

Якщо така відмінність не має композиційного обґрунтування, вона може порушувати цілісність інтерфейсу.

---

## 4. Використовувати однаковий радіус без урахування масштабу

Маленька кнопка та велика промокартка не обов'язково повинні мати однакову форму.

Використання однакового значення може бути правильним рішенням, якщо цього вимагає дизайн-система, але масштаб елементів варто перевіряти в контексті.

---

## 5. Забувати про внутрішні відступи

Великий радіус у поєднанні з малим padding може створити незбалансований вигляд.

Потрібно оцінювати радіус разом із розташуванням тексту, зображень та інших елементів.

---

## 6. Забувати про overflow

Наприклад:

    .card {
        border-radius: 16px;
    }

Заокруглення контейнера не завжди означає, що дочірнє зображення буде обрізане по його контуру.

За потреби:

    .card {
        border-radius: 16px;
        overflow: hidden;
    }

Однак потрібно перевірити, чи не обрізає це тіні або інші елементи, які мають виходити за межі контейнера.

---

## 7. Плутати radius і border

`border-radius` визначає форму кутів.

`border` визначає рамку елемента.

Наприклад:

    .card {
        border: 1px solid #d1d5db;
        border-radius: 12px;
    }

Тут:

    border
        → рамка

    border-radius
        → заокруглення кутів

Це різні властивості, які можуть використовуватися разом.

---

## 8. Вважати, що радіус успадковується

Наприклад:

    .card {
        border-radius: 16px;
    }

    .card__image {
        border-radius: inherit;
    }

У другому правилі радіус явно успадковується через значення `inherit`.

Але без цього запису дочірній елемент не успадковує `border-radius` автоматично.

---

## 9. Використовувати `border-radius: 50%` без перевірки розмірів

Наприклад:

    .avatar {
        width: 80px;
        height: 48px;
        border-radius: 50%;
    }

Результатом буде еліпс, а не коло.

Для кола ширина та висота повинні бути однаковими.

---

## 10. Використовувати pill shape для кожного компонента

Pill shape може бути доречним для badges, chips або окремих кнопок.

Проте надмірне використання цієї форми може зробити інтерфейс одноманітним або невідповідним до його призначення.

---

# Практичні приклади

## Приклад 1 — Button

    .button {
        padding: 10px 16px;
        border: none;
        border-radius: 8px;
        background: #2563eb;
        color: #ffffff;
        cursor: pointer;
    }

Тут кнопка має помірно заокруглені кути.

---

## Приклад 2 — Input

    .input {
        width: 100%;
        padding: 12px;
        border: 1px solid #cbd5e1;
        border-radius: 8px;
    }

Поле введення використовує той самий радіус, що й кнопка.

---

## Приклад 3 — Card

    .card {
        padding: 24px;
        border: 1px solid #e2e8f0;
        border-radius: 16px;
        background: #ffffff;
    }

Картка має більший радіус, ніж кнопка та поле введення.

---

## Приклад 4 — Avatar

    .avatar {
        width: 64px;
        height: 64px;
        border-radius: 50%;
        object-fit: cover;
    }

Квадратне зображення перетворюється на коло.

---

## Приклад 5 — Badge

    .badge {
        display: inline-flex;
        align-items: center;
        padding: 4px 12px;
        border-radius: 999px;
        background: #dcfce7;
        color: #166534;
    }

Badge має форму капсули.

---

## Приклад 6 — Modal

    .modal {
        width: min(480px, calc(100% - 32px));
        padding: 24px;
        border-radius: 20px;
        background: #ffffff;
    }

Великий радіус допомагає відокремити модальне вікно від інших елементів інтерфейсу.

---

## Приклад 7 — Image inside Card

    .card {
        overflow: hidden;
        border-radius: 16px;
    }

    .card__image {
        display: block;
        width: 100%;
        height: auto;
    }

Контейнер обрізає вміст за своєю формою.

---

## Приклад 8 — Radius Tokens

    :root {
        --radius-none: 0;
        --radius-sm: 4px;
        --radius-md: 8px;
        --radius-lg: 12px;
        --radius-xl: 16px;
        --radius-2xl: 24px;
        --radius-full: 999px;
    }

Використання:

    .button {
        border-radius: var(--radius-md);
    }

    .card {
        border-radius: var(--radius-xl);
    }

    .badge {
        border-radius: var(--radius-full);
    }

---

## Приклад 9 — Окремі кути

    .card {
        border-top-left-radius: 20px;
        border-top-right-radius: 20px;
        border-bottom-right-radius: 8px;
        border-bottom-left-radius: 8px;
    }

Верхня частина картки має сильніше заокруглення.

---

## Приклад 10 — Radius Scale у компонентній системі

    :root {
        --radius-control: 8px;
        --radius-card: 12px;
        --radius-dialog: 20px;
        --radius-pill: 999px;
    }

    .button,
    .input,
    .select {
        border-radius: var(--radius-control);
    }

    .card {
        border-radius: var(--radius-card);
    }

    .dialog {
        border-radius: var(--radius-dialog);
    }

    .badge {
        border-radius: var(--radius-pill);
    }

Токени названі за призначенням, а не лише за числовим розміром.

Це альтернативний підхід до назв `sm`, `md`, `lg`. Обидва підходи можуть бути корисними залежно від масштабу дизайн-системи.

---

# Як вибирати Border Radius

Під час вибору радіуса потрібно враховувати:

1. **Стиль продукту.** Чи має інтерфейс бути строгим, геометричним або м'яким?
2. **Тип компонента.** Чи це кнопка, картка, поле введення, аватар або модальне вікно?
3. **Розмір елемента.** Як радіус виглядає відносно ширини та висоти?
4. **Внутрішні відступи.** Чи достатньо простору біля кутів?
5. **Інші компоненти.** Чи узгоджується форма з рештою інтерфейсу?
6. **Дизайн-система.** Чи належить значення до визначеної шкали?
7. **Вміст.** Чи потрібно обрізати зображення або інші дочірні елементи?
8. **Responsive behavior.** Чи залишається форма доречною на різних екранах?
9. **Доступність.** Чи не погіршує форма зрозумілість або зручність використання компонента?
10. **Послідовність.** Чи має кожне відхилення від стандарту зрозумілу причину?

# Практика UI Design

## Завдання 1 — Порівняння радіусів

Створи чотири картки з однаковим розміром, кольором і вмістом.

Змінюй лише радіус:

    0px
    4px
    12px
    24px

Мета — побачити, як одна властивість впливає на загальний вигляд компонента.

---

## Завдання 2 — Button System

Створи три кнопки:

    Sharp
    Rounded
    Pill

Використай:

    0px
    8px
    999px

Залиш однаковими:

    padding
    font-size
    height
    color

Порівняй лише форму.

---

## Завдання 3 — Component Consistency

Створи набір компонентів:

    Button
    Input
    Select
    Card
    Modal
    Badge

Визнач для них radius tokens.

Наприклад:

    Controls → 8px
    Card     → 12px
    Modal    → 20px
    Badge    → 999px

Перевір, чи виглядають компоненти як частини однієї системи.

---

## Завдання 4 — Nested Radius

Створи картку із зображенням усередині.

Перевір кілька варіантів:

    Card: 16px
    Image: 0px

    Card: 16px
    Image: 8px

    Card: 16px
    Image: 16px

Порівняй результат з урахуванням padding і розташування зображення.

---

## Завдання 5 — Radius Tokens

Створи власну шкалу радіусів у CSS.

    :root {
        --radius-sm: 4px;
        --radius-md: 8px;
        --radius-lg: 12px;
        --radius-xl: 16px;
        --radius-full: 999px;
    }

Використай токени у всіх створених компонентах.

Переконайся, що для однакових типів компонентів застосовуються узгоджені значення.

---

## Завдання 6 — Аналіз реального інтерфейсу

Обери будь-який вебзастосунок і проаналізуй:

- радіуси кнопок;
- радіуси полів введення;
- радіуси карток;
- форму аватарів;
- радіуси модальних вікон;
- використання pill shape;
- повторюваність значень;
- узгодженість компонентів.

Спробуй визначити, чи використовує продукт єдину шкалу радіусів.

Не потрібно точно відтворювати кожне значення. Головне — навчитися помічати закономірності.

# Міні-шпаргалка

## Основна властивість

    border-radius: 12px;

Заокруглює всі кути елемента.

---

## Прямі кути

    border-radius: 0;

---

## Круглий елемент

    .avatar {
        width: 48px;
        height: 48px;
        border-radius: 50%;
    }

Ширина та висота мають бути однаковими для кола.

---

## Pill shape

    border-radius: 999px;

---

## Окремі кути

    border-radius: 16px 16px 4px 4px;

Порядок:

    top-left
    top-right
    bottom-right
    bottom-left

---

## Radius tokens

    :root {
        --radius-sm: 4px;
        --radius-md: 8px;
        --radius-lg: 12px;
        --radius-xl: 16px;
        --radius-full: 999px;
    }

---

## Використання токенів

    .button {
        border-radius: var(--radius-md);
    }

    .card {
        border-radius: var(--radius-lg);
    }

    .badge {
        border-radius: var(--radius-full);
    }

---

## Обрізання вмісту

    .card {
        border-radius: 16px;
        overflow: hidden;
    }

Використовуй `overflow: hidden`, якщо потрібно обрізати вміст по межах контейнера, і перевіряй, чи це не обрізає тіні або інші елементи.

---

## Основні правила

    border-radius
        → заокруглення кутів

    radius scale
        → система значень радіуса

    radius tokens
        → повторно використовувані значення

    consistent radius
        → послідовність між компонентами

    border-radius: 50%
        → коло за однакових ширини та висоти

    border-radius: 999px
        → pill shape

    overflow: hidden
        → обрізання вмісту за межами контейнера

---

# Головне

• Border radius визначає заокруглення кутів елемента.

• У CSS для цього використовується `border-radius`.

• Радіус може бути нульовим, малим, помірним, великим або дуже великим.

• Форма компонента впливає на загальний візуальний стиль інтерфейсу.

• Для кола зазвичай використовують однакові ширину та висоту й `border-radius: 50%`.

• Для pill shape часто використовують `border-radius: 999px`.

• Кнопки, поля введення, картки та модальні вікна можуть мати різні радіуси.

• Відмінності між радіусами повинні бути свідомими та узгодженими.

• Radius scale допомагає організувати значення радіусів.

• Radius tokens спрощують підтримку дизайн-системи.

• Border radius не успадковується автоматично.

• `overflow: hidden` може знадобитися для обрізання вмісту за заокругленими межами контейнера.

• Радіус потрібно розглядати разом із padding, розмірами елемента та розташуванням вмісту.

• Не існує універсального значення радіуса, яке підходить для всіх продуктів.

• Послідовність важливіша за механічне використання однакових значень.

• Основне завдання дизайнера — зробити геометрію компонентів зрозумілою, узгодженою та доречною для конкретного продукту.

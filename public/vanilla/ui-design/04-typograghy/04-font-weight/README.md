# 04. Font Weight — Товщина шрифту в UI-дизайні

## 1. Що таке Font Weight?

**Font Weight (товщина шрифту)** — це характеристика типографіки, яка визначає, наскільки тонкими або товстими виглядають штрихи символів.

У CSS товщина шрифту задається властивістю `font-weight`.

    h1 {
      font-weight: 700;
    }

Це означає, що заголовок використовує варіант шрифту з товщиною `700`, якщо така товщина доступна для підключеної гарнітури.

Font Weight впливає на:
- ✔ Візуальну ієрархію тексту.
- ✔ Помітність заголовків.
- ✔ Відмінність основного тексту від допоміжного.
- ✔ Акцентування важливих елементів.
- ✔ Читабельність тексту в різних умовах.
- ✔ Загальний характер інтерфейсу.
- ✔ Узгодженість типографіки в дизайн-системі.

Наприклад:

    Regular text       — звичайний текст
    Medium text        — трохи виразніший текст
    Bold text          — жирний текст

Товщина шрифту — це не просто декоративна властивість. Вона допомагає користувачеві зрозуміти, які елементи важливіші та на що варто звернути увагу.

---

## 2. Навіщо потрібен Font Weight?

У UI-дизайні товщина шрифту використовується для створення зрозумілої текстової ієрархії.

Основні завдання:

- ✔ Виділяти заголовки.
- ✔ Відокремлювати назви компонентів від їхніх описів.
- ✔ Акцентувати важливі слова та значення.
- ✔ Робити кнопки та навігаційні елементи виразними.
- ✔ Виділяти активні стани інтерфейсу.
- ✔ Допомагати користувачеві швидко сканувати сторінку.
- ✔ Підтримувати візуальну послідовність.
- ✔ Зменшувати потребу у використанні зайвих кольорів та декоративних ефектів.

Приклад картки курсу:

    Основи JavaScript          — 700
    Практичний курс для новачків — 400
    12 уроків · 4 години       — 400
    Продовжити навчання        — 600

Назва курсу привертає увагу завдяки більшій товщині. Опис залишається спокійнішим, а кнопка виділяється достатньо, щоб сприйматися як інтерактивний елемент.

**Головний принцип:** товщина шрифту повинна підкреслювати значення тексту, а не робити весь інтерфейс однаково виразним.

---

## 3. Основні поняття

### 3.1. Font Weight

Властивість CSS, яка визначає товщину шрифту.

    p {
      font-weight: 400;
    }

### 3.2. Font Family

**Font Family** — це гарнітура або сімейство шрифтів, наприклад Arial, Inter чи Roboto.

Різні гарнітури можуть мати різні доступні товщини. Тому `font-weight: 600` не гарантує однакового візуального результату в усіх шрифтах.

### 3.3. Font Style

**Font Style** визначає стиль накреслення, наприклад звичайний або курсивний.

    p {
      font-style: italic;
    }

`font-style` і `font-weight` — різні властивості:

- `font-weight` — товщина штрихів.
- `font-style` — стиль накреслення, наприклад italic.

### 3.4. Typeface Weight

Це конкретний варіант товщини всередині сімейства шрифтів.

Наприклад, одне сімейство може містити:

    Inter Regular
    Inter Medium
    Inter SemiBold
    Inter Bold

Кожен варіант має власну візуальну товщину.

### 3.5. Typography Hierarchy

**Типографічна ієрархія** — це система візуального розрізнення тексту за важливістю.

Вона створюється не лише товщиною, а й:
- Розміром шрифту.
- Кольором.
- Міжрядковим інтервалом.
- Відступами.
- Розташуванням.
- Контрастом із фоном.

### 3.6. Variable Font

**Variable Font** — це шрифт, який може підтримувати безперервний діапазон значень товщини, наприклад від `100` до `900`.

Це дозволяє точніше налаштовувати типографіку, якщо відповідна вісь підтримується шрифтом.

---

## 4. Значення Font Weight у CSS

CSS підтримує числові значення товщини від `1` до `1000`, якщо вони підтримуються шрифтом і браузером.

Найпоширеніші значення:

| Значення | Назва | Типове використання |
|---:|---|---|
| 100 | Thin | Дуже тонкі заголовки або декоративний текст |
| 200 | Extra Light | Легкий декоративний текст |
| 300 | Light | Великі заголовки, легка типографіка |
| 400 | Normal / Regular | Основний текст |
| 500 | Medium | Помірне виділення |
| 600 | Semi Bold | Виразні підзаголовки та кнопки |
| 700 | Bold | Заголовки та сильні акценти |
| 800 | Extra Bold | Дуже виразні заголовки |
| 900 | Black | Максимально виразні акценти |

Ці назви є загальноприйнятими орієнтирами, але конкретна назва й доступність накреслення залежать від шрифту.

### 4.1. Значення `normal` і `bold`

CSS дозволяє використовувати словесні значення:

    p {
      font-weight: normal;
    }

    h1 {
      font-weight: bold;
    }

Зазвичай:

    normal = 400
    bold   = 700

Проте фактичний вигляд залежить від доступних накреслень та правил вибору шрифту браузером.

### 4.2. Чи потрібно використовувати всі значення?

Ні.

Для більшості невеликих інтерфейсів достатньо кількох товщин:

    400 — основний текст
    500 — помірні акценти
    600 — підзаголовки та кнопки
    700 — головні заголовки

У деяких проєктах достатньо `400` і `700`. В інших дизайн-система може використовувати більше варіантів.

Головне — щоб кожне значення мало зрозумілу роль.

---

## 5. Як Font Weight впливає на візуальну ієрархію

Товщина допомагає розрізняти рівні тексту навіть тоді, коли їхній розмір однаковий.

Приклад:

    Назва курсу — 700
    Опис курсу — 400

Інший приклад:

    Назва курсу — 600
    Опис курсу — 400
    Допоміжна інформація — 400

У другому випадку ієрархію можна додатково створити за допомогою розміру та кольору.

### 5.1. Заголовки

Заголовки часто використовують більшу товщину, щоб чітко відрізнятися від основного тексту.

    h1 {
      font-size: 3rem;
      font-weight: 700;
    }

    h2 {
      font-size: 2rem;
      font-weight: 600;
    }

    h3 {
      font-size: 1.5rem;
      font-weight: 600;
    }

Це лише один із можливих варіантів. Великі заголовки іноді добре виглядають і з товщиною `400` або `500`, особливо якщо шрифт має виразний характер.

### 5.2. Основний текст

Основний текст зазвичай використовує звичайну товщину.

    body {
      font-weight: 400;
    }

Це дозволяє читати довгі тексти без надмірної візуальної щільності.

### 5.3. Кнопки

Кнопки часто використовують товщину `500` або `600`.

    .button {
      font-weight: 600;
    }

Вибір залежить від гарнітури, розміру кнопки та загального стилю інтерфейсу.

### 5.4. Допоміжна інформація

Допоміжний текст не обов'язково повинен бути тоншим. Його можна зробити менш помітним за допомогою розміру та кольору.

    .metadata {
      font-size: 0.875rem;
      font-weight: 400;
      color: #666;
    }

Не слід робити допоміжний текст настільки тонким або малоконтрастним, що його важко читати.

---

## 6. Font Weight і Font Size

Товщина та розмір шрифту працюють разом, але вирішують різні завдання.

- `font-size` визначає розмір тексту.
- `font-weight` визначає товщину накреслення.

Приклад:

    .title {
      font-size: 2rem;
      font-weight: 700;
    }

    .subtitle {
      font-size: 1.25rem;
      font-weight: 500;
    }

    .body {
      font-size: 1rem;
      font-weight: 400;
    }

У цьому прикладі ієрархія створюється одночасно розміром і товщиною.

### 6.1. Великий текст не завжди має бути жирним

Приклад:

    .hero-title {
      font-size: clamp(2.5rem, 5vw, 4.5rem);
      font-weight: 400;
    }

Великий розмір уже створює сильний візуальний акцент. Тому звичайна товщина може бути доречною для мінімалістичного дизайну.

### 6.2. Малий текст не завжди має бути тонким

Наприклад, текст кнопки або коротка мітка може використовувати `600`, щоб залишатися помітною.

    .button {
      font-size: 0.875rem;
      font-weight: 600;
    }

Необхідно перевіряти результат на реальному екрані: дрібні накреслення можуть втрачати чіткість, особливо за низького контрасту.

---

## 7. Font Weight і читабельність

Читабельність залежить не лише від товщини шрифту, а й від його гарнітури, розміру, контрасту, інтервалів та умов перегляду.

### 7.1. Занадто тонкий текст

Накреслення `100`, `200` або `300` може виглядати елегантно, але не завжди підходить для основного тексту.

Потенційні проблеми:
- Тонкі штрихи можуть бути погано помітними.
- Текст може втрачати чіткість на певних екранах.
- Низький контраст робить читання ще складнішим.
- Малий розмір посилює проблему.

Тонкі накреслення краще перевіряти на реальному пристрої та використовувати там, де вони не шкодять читабельності.

### 7.2. Занадто жирний текст

Якщо весь текст має `700` або `800`, інтерфейс може виглядати перевантаженим.

Можливі наслідки:
- Зникає різниця між заголовками та основним текстом.
- Сторінку складніше сканувати.
- Великі блоки тексту виглядають щільними.
- Акценти втрачають свою ефективність.

### 7.3. Практичне правило

Для довгого основного тексту часто доречно починати з `400`, а для заголовків і коротких акцентів використовувати `600` або `700`.

Однак це не універсальний стандарт. Деякі гарнітури мають іншу візуальну щільність, тому рішення потрібно перевіряти практично.

## 8. Font Weight у CSS: приклади

### 8.1. Основні текстові ролі

    body {
      font-weight: 400;
    }

    h1 {
      font-weight: 700;
    }

    h2 {
      font-weight: 600;
    }

    .subtitle {
      font-weight: 500;
    }

    .button {
      font-weight: 600;
    }

### 8.2. Використання класів

    .font-regular {
      font-weight: 400;
    }

    .font-medium {
      font-weight: 500;
    }

    .font-semibold {
      font-weight: 600;
    }

    .font-bold {
      font-weight: 700;
    }

Такі класи можуть бути корисними, але не потрібно створювати окремий клас для кожного числа, якщо проєкт цього не потребує.

У більшій дизайн-системі зручніше використовувати семантичні класи або токени, що відповідають ролям тексту.

### 8.3. Семантичні класи

    .page-title {
      font-weight: 700;
    }

    .section-title {
      font-weight: 600;
    }

    .body-text {
      font-weight: 400;
    }

    .button-label {
      font-weight: 600;
    }

Перевага: код описує призначення елемента, а не лише його зовнішній вигляд.

## 9. Доступні товщини шрифту

Важливо розуміти: не кожна гарнітура містить усі можливі товщини.

Наприклад, підключений шрифт може мати лише:

    400 — Regular
    700 — Bold

Якщо написати:

    p {
      font-weight: 500;
    }

браузер може вибрати найближче доступне накреслення відповідно до правил підбору шрифту.

Тому значення `500` не гарантує, що браузер відобразить справжній Medium.

### 9.1. Перевіряй файли шрифту

Якщо використовуєш локальні файли шрифтів, переконайся, що потрібні товщини справді підключені.

Приклад для окремих статичних файлів:

    @font-face {
      font-family: "MyFont";
      src: url("/fonts/my-font-regular.woff2") format("woff2");
      font-weight: 400;
      font-style: normal;
      font-display: swap;
    }

    @font-face {
      font-family: "MyFont";
      src: url("/fonts/my-font-semibold.woff2") format("woff2");
      font-weight: 600;
      font-style: normal;
      font-display: swap;
    }

    @font-face {
      font-family: "MyFont";
      src: url("/fonts/my-font-bold.woff2") format("woff2");
      font-weight: 700;
      font-style: normal;
      font-display: swap;
    }

    body {
      font-family: "MyFont", sans-serif;
      font-weight: 400;
    }

    h1 {
      font-weight: 700;
    }

У цьому прикладі кожне оголошення `@font-face` відповідає окремому файлу зі своєю товщиною.

Назви файлів і шрифтові значення повинні відповідати реальним файлам, які є у проєкті.

### 9.2. Не підмінюй реальні накреслення без потреби

Якщо дизайн використовує `600`, а ти підключив лише `400` і `700`, результат може відрізнятися від макета.

Краще:
- ✔ Підключити потрібні товщини.
- ✔ Або адаптувати дизайн до доступних накреслень.
- ✔ Перевірити фактичне відображення в браузері.

## 10. Variable Fonts і Font Weight

Variable Font може містити вісь товщини `wght`, яка дозволяє використовувати діапазон значень.

Наприклад, шрифт може підтримувати:

    100–900

Тоді можна задавати:

    h1 {
      font-weight: 750;
    }

Таке значення може працювати, якщо воно підтримується конкретним variable font.

### 10.1. Підключення variable font

Приклад:

    @font-face {
      font-family: "MyVariableFont";
      src: url("/fonts/my-variable-font.woff2") format("woff2");
      font-weight: 100 900;
      font-style: normal;
      font-display: swap;
    }

    body {
      font-family: "MyVariableFont", sans-serif;
      font-weight: 400;
    }

    h1 {
      font-weight: 750;
    }

Діапазон `100 900` повідомляє браузеру, що файл підтримує змінну товщину в цьому діапазоні.

Не потрібно вказувати такий діапазон для звичайного статичного файлу, який містить лише одне накреслення.

### 10.2. Переваги variable fonts

- ✔ Можна використовувати багато значень товщини.
- ✔ Можна точніше налаштовувати типографічну ієрархію.
- ✔ Один файл може містити кілька варіантів товщини.
- ✔ Можна плавно змінювати товщину, якщо це доречно.
- ✔ Потенційно можна зменшити кількість окремих файлів шрифту.

Фактична економія залежить від конкретних файлів і способу їх підключення.

### 10.3. Не обов'язково використовувати variable fonts

Для невеликого навчального проєкту звичайних накреслень `400`, `600` і `700` може бути цілком достатньо.

Variable fonts корисні тоді, коли вони справді потрібні дизайну або спрощують роботу з типографічною системою.

## 11. Font Weight у різних компонентах UI

### 11.1. Заголовки сторінок

    .page-title {
      font-size: 2.5rem;
      font-weight: 700;
      line-height: 1.15;
    }

Головний заголовок зазвичай має бути помітним, але його товщина залежить від характеру шрифту та дизайну.

### 11.2. Заголовки секцій

    .section-title {
      font-size: 2rem;
      font-weight: 600;
      line-height: 1.25;
    }

Товщина `600` може допомогти створити другий рівень ієрархії.

### 11.3. Картки

    .card__title {
      font-size: 1.25rem;
      font-weight: 600;
    }

    .card__description {
      font-size: 1rem;
      font-weight: 400;
    }

    .card__meta {
      font-size: 0.875rem;
      font-weight: 400;
    }

### 11.4. Кнопки

    .button {
      font-size: 1rem;
      font-weight: 600;
    }

    .button--secondary {
      font-weight: 500;
    }

Необов'язково робити всі кнопки жирними. Їхню ієрархію можна також передавати кольором, фоном, обведенням та розташуванням.

### 11.5. Форми

    .form-label {
      font-weight: 600;
    }

    .form-input {
      font-weight: 400;
    }

    .form-help {
      font-weight: 400;
    }

    .form-error {
      font-weight: 500;
    }

Помилки потрібно робити зрозумілими не лише через товщину: важливі також текст повідомлення, доступний колірний контраст та відповідний зв'язок із полем.

### 11.6. Навігація

    .nav-link {
      font-weight: 500;
    }

    .nav-link[aria-current="page"] {
      font-weight: 700;
    }

Товщина може допомагати показувати активний пункт, але активний стан бажано позначати й іншими способами, наприклад кольором або індикатором.

---

## 12. Font Weight у дизайн-системі

У дизайн-системі важливо не просто вибрати кілька товщин, а визначити, де саме вони використовуються.

Приклад:

| Токен | Значення | Призначення |
|---|---:|---|
| `--weight-regular` | 400 | Основний текст |
| `--weight-medium` | 500 | Помірні акценти |
| `--weight-semibold` | 600 | Кнопки й підзаголовки |
| `--weight-bold` | 700 | Головні заголовки |

### 12.1. CSS-токени

    :root {
      --weight-regular: 400;
      --weight-medium: 500;
      --weight-semibold: 600;
      --weight-bold: 700;
    }

    body {
      font-weight: var(--weight-regular);
    }

    h1 {
      font-weight: var(--weight-bold);
    }

    h2 {
      font-weight: var(--weight-semibold);
    }

    .button {
      font-weight: var(--weight-semibold);
    }

Переваги:
- ✔ Єдина система товщин.
- ✔ Менше повторень.
- ✔ Зрозумілі правила використання.
- ✔ Зручне оновлення стилів.
- ✔ Простіше підтримувати дизайн у багатьох компонентах.

### 12.2. Не створюй зайві токени

Якщо в проєкті використовуються лише три товщини, не потрібно створювати десять токенів.

Починай із реальних потреб інтерфейсу, а не з бажання охопити всі можливі значення CSS.

## 13. Font Weight і доступність

Товщина шрифту може впливати на те, наскільки легко користувач розрізняє текст, але сама по собі не гарантує доступності.

### 13.1. Контраст важливіший за декоративність

Тонкий текст на світлому фоні може бути важким для читання.

Приклад потенційної проблеми:

    .caption {
      color: #b8b8b8;
      font-weight: 300;
      font-size: 0.75rem;
    }

Такий текст може бути недостатньо помітним залежно від фону та гарнітури.

Рішення:
- Перевірити контраст кольорів.
- За потреби збільшити товщину.
- Не зменшувати текст без необхідності.
- Переконатися, що допоміжна інформація залишається читабельною.

### 13.2. Не покладайся лише на жирність

Якщо повідомлення про помилку позначене лише жирним шрифтом, деякі користувачі можуть не помітити його.

Краще використовувати:
- Зрозумілий текст повідомлення.
- Візуально помітний стиль.
- Достатній контраст.
- Програмний зв'язок із відповідним полем форми, якщо це помилка введення.

### 13.3. Товщина не замінює семантику HTML

Наприклад:

    <strong>Важлива інформація</strong>

Елемент `<strong>` має семантичне значення важливості. Браузер зазвичай відображає його жирним, але його роль не зводиться лише до зовнішнього вигляду.

Для суто візуального виділення можна використовувати CSS, якщо немає семантичної потреби підкреслювати важливість тексту.

## 14. Типові помилки у Font Weight

### Помилка 1. Використання жирного шрифту всюди

Приклад:

    h1,
    h2,
    h3,
    p,
    button,
    span {
      font-weight: 700;
    }

Проблема: усі елементи стають однаково виразними, а ієрархія втрачається.

Краще визначити ролі:

    body {
      font-weight: 400;
    }

    h1 {
      font-weight: 700;
    }

    h2 {
      font-weight: 600;
    }

    .button {
      font-weight: 600;
    }

### Помилка 2. Використання надто тонкого шрифту для основного тексту

Приклад:

    body {
      font-weight: 200;
    }

Тонке накреслення може виглядати красиво в короткому заголовку, але бути незручним для довгого тексту.

Краще починати з `400` і перевіряти реальну гарнітуру.

### Помилка 3. Вважати, що `500` завжди доступний

Якщо шрифт не має накреслення `500`, браузер може використати інший доступний варіант.

Рішення: перевіряти підключені файли та фактичне відображення.

### Помилка 4. Не підключити потрібні файли шрифту

Дизайн може використовувати Medium, SemiBold і Bold, але сайт підключає лише Regular.

У такому разі результат може відрізнятися від макета.

Рішення: підключати лише ті накреслення, які справді потрібні, і правильно описувати їх у `@font-face`.

### Помилка 5. Використовувати багато значень без системи

Наприклад:

    h1 { font-weight: 800; }
    h2 { font-weight: 500; }
    h3 { font-weight: 700; }
    p  { font-weight: 300; }
    a  { font-weight: 900; }

Це не обов'язково технічно неправильно, але без дизайнерської причини такі значення можуть створювати непослідовний інтерфейс.

Рішення: визначити кілька основних товщин і призначити їх типографічним ролям.

### Помилка 6. Використовувати `bold` замість чисел у всіх випадках

`bold` є коректним значенням, але числові значення зручніші, коли дизайн-система використовує кілька рівнів товщини.

    .title {
      font-weight: 700;
    }

    .subtitle {
      font-weight: 600;
    }

### Помилка 7. Плутати `font-weight` і `font-style`

`font-weight` змінює товщину, а `font-style` керує звичайним або курсивним стилем.

    .example {
      font-weight: 700;
      font-style: italic;
    }

Текст у цьому прикладі буде і жирним, і курсивним, якщо шрифт підтримує відповідне накреслення.

### Помилка 8. Ігнорувати особливості конкретного шрифту

Два шрифти з `font-weight: 600` можуть виглядати по-різному.

Рішення: оцінювати товщину в контексті обраної гарнітури, розміру, кольору та фону.

### Помилка 9. Використовувати жирність як єдиний спосіб показати активний стан

Активний пункт меню краще позначати не лише товщиною, а й іншим візуальним індикатором, якщо це потрібно для зрозумілості.

### Помилка 10. Не перевіряти шрифт після завантаження

Якщо вебшрифт не завантажився, браузер може використати резервний шрифт. Його товщини та ширина символів можуть відрізнятися.

Рішення: перевіряти сторінку після завантаження, а також передбачати адекватний резервний шрифт.

## 16. Як вибирати Font Weight для нового інтерфейсу

Практична послідовність:

1. Вибрати гарнітуру, яка підходить для інтерфейсу.
2. Перевірити, які товщини вона підтримує.
3. Визначити ролі тексту: заголовки, основний текст, підписи, кнопки.
4. Вибрати початкову товщину для основного тексту.
5. Визначити товщини для заголовків та акцентів.
6. Перевірити, чи є помітна різниця між рівнями ієрархії.
7. Переконатися, що жирність не використовується надмірно.
8. Перевірити читабельність на різних розмірах екрана.
9. Перевірити контраст і відображення після завантаження шрифту.
10. Зафіксувати повторювані значення в CSS-токенах.

Для початку достатньо такої системи:

    400 — основний текст
    500 — помірні акценти
    600 — підзаголовки та кнопки
    700 — головні заголовки

Якщо певна товщина не потрібна, не додавай її лише заради повноти шкали.

## 17. Мініпроєкт: Font Weight System

Мета — створити просту систему товщин для інтерфейсу навчального застосунку.

### Завдання

Створи сторінку з такими елементами:
- Головний заголовок.
- Заголовок секції.
- Назва картки.
- Основний опис.
- Допоміжна інформація.
- Кнопка.
- Мітка поля форми.

### Крок 1. Визнач товщини

    Regular: 400
    Medium: 500
    SemiBold: 600
    Bold: 700

### Крок 2. Створи токени

    :root {
      --weight-regular: 400;
      --weight-medium: 500;
      --weight-semibold: 600;
      --weight-bold: 700;
    }

### Крок 3. Признач ролі

    h1 {

    }

      font-weight: var(--weight-semibold);
    }

      font-weight: var(--weight-regular);
    }

### Крок 4. Перевір ієрархію

Подивись на сторінку та відповідай на питання:
- Чи помітний головний заголовок?
- Чи відрізняється заголовок секції від основного тексту?
- Чи не виглядає кожен елемент однаково жирним?
- Чи залишається текст зручним для читання?
- Чи достатньо виразні кнопки?

### Крок 5. Спробуй інші значення

Зміни товщину заголовка:

    font-weight: 700;

на:

    font-weight: 500;

Порівняй результат.

Потім поверни `700`, але зменш розмір шрифту. Подивись, як змінюється візуальна ієрархія.

Мета — зрозуміти, як товщина працює разом із розміром, а не ізольовано.

### Крок 6. Перевір доступні накреслення

Якщо використовуєш вебшрифт, переконайся, що він підтримує обрані товщини.

Якщо доступні лише `400` і `700`, спробуй побудувати систему на цих двох значеннях, замість того щоб покладатися на відсутні накреслення.

## 19. Типові питання на співбесіді

### Що таке `font-weight`?

Це CSS-властивість, яка визначає товщину накреслення тексту.

### Які значення `font-weight` використовуються найчастіше?

Найпоширеніші числові значення — `400`, `500`, `600` і `700`. Їхня фактична доступність залежить від шрифту.

### Чим відрізняються `400` і `700`?

`400` зазвичай відповідає звичайному накресленню, а `700` — жирному.

### Чим відрізняються `font-weight` і `font-size`?

`font-weight` визначає товщину штрихів, а `font-size` — розмір шрифту.

### Чим відрізняються `font-weight` і `font-style`?

`font-weight` керує товщиною, а `font-style` — стилем накреслення, наприклад normal або italic.

### Чи можна використовувати `font-weight: 600`, якщо шрифт має лише Regular і Bold?

Так, але браузер може підібрати найближчу доступну товщину. Точний результат залежить від підключеного шрифту та правил вибору накреслення.

### Що таке variable font?

Це шрифт, який може підтримувати змінні осі, наприклад товщину, і дозволяти використовувати діапазон значень в одному файлі.

### Чому не варто робити весь текст жирним?

Тому що візуальна ієрархія стає менш виразною, а сторінка може виглядати перевантаженою.

### Чи робить жирний текст інтерфейс доступнішим?

Не автоматично. Доступність залежить також від розміру, контрасту, гарнітури, структури та інших характеристик тексту.

### Навіщо потрібні токени Font Weight?

Вони забезпечують послідовність і дозволяють централізовано керувати товщинами в дизайн-системі.

Для якісної типографіки важливо:

1. Використовувати товщину відповідно до ролі тексту.
2. Починати з невеликого набору узгоджених значень.
3. Перевіряти, які накреслення підтримує обрана гарнітура.
4. Узгоджувати товщину з розміром, кольором та інтервалами.
5. Не робити весь текст однаково жирним.
6. Не використовувати надто тонкі накреслення там, де потрібна висока читабельність.
7. Створювати CSS-токени для повторюваних значень.
8. Перевіряти результат на реальних екранах.

**Головне правило:** товщина шрифту повинна допомагати користувачеві розуміти структуру інтерфейсу. Кожне значення має бути обґрунтованим і працювати разом з іншими параметрами типографіки.

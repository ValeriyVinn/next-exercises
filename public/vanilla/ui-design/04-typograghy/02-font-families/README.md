# 02. Font Families

Font Families (сімейства шрифтів) — одна з основ типографіки в UI Design. Вибір правильного сімейства шрифтів допомагає створити візуально узгоджений, читабельний і професійний інтерфейс.

Font family визначає загальний дизайн символів, характер тексту та його візуальне сприйняття. Різні сімейства можуть створювати різне враження навіть за однакового розміру, товщини й кольору тексту.

У UI Design font families використовуються для:

- оформлення заголовків і основного тексту;
- створення візуальної ієрархії;
- формування характеру бренду;
- покращення читабельності;
- розмежування типів інформації;
- оформлення навігації, кнопок і форм;
- відображення коду та технічних даних;
- створення єдиної типографічної системи;
- підтримки багатомовних інтерфейсів;
- забезпечення узгодженості дизайну на різних сторінках.

## Що потрібно пам'ятати

• Font family — сімейство шрифтів зі спільним візуальним дизайном.

• Serif — сімейство шрифтів із засічками.

• Sans-serif — сімейство шрифтів без засічок.

• Monospace — категорія шрифтів, у яких символи зазвичай мають однакову ширину.

• Display fonts призначені переважно для великих заголовків і коротких акцентних написів.

• Text fonts оптимізовані для читання тексту, особливо в довших блоках.

• UI fonts використовуються для елементів інтерфейсу: кнопок, меню, форм, таблиць і навігації.

• Brand fonts допомагають сформувати впізнаваний характер бренду.

• Для одного інтерфейсу часто достатньо одного або двох сімейств шрифтів.

• Два шрифти не обов'язково повинні бути максимально різними: важливіше, щоб вони доповнювали один одного.

• Для заголовків можна використовувати виразніший шрифт, а для основного тексту — нейтральніший.

• Не кожен декоративний шрифт підходить для дрібного тексту.

• Вибір сімейства залежить від призначення продукту, аудиторії, мови та умов використання.

• Сімейство шрифтів має підтримувати потрібні символи, зокрема українську кирилицю.

• Font stack забезпечує запасні варіанти, якщо основний шрифт недоступний.

• У дизайн-системі сімейства шрифтів доцільно визначати централізовано.

# Font Family

Font family — сімейство шрифтів зі спільними дизайнерськими характеристиками.

Наприклад:

    Inter
    Roboto
    Open Sans
    Lato
    Merriweather
    Source Sans 3
    Source Serif 4
    IBM Plex Sans
    IBM Plex Mono

У межах сімейства можуть існувати різні накреслення:

    Regular
    Medium
    SemiBold
    Bold
    Italic

Наприклад:

    Inter Regular
    Inter Medium
    Inter Bold
    Inter Italic

Вони належать до одного сімейства, але відрізняються товщиною або стилем.

У CSS сімейство задається через `font-family`.

    body {
        font-family: "Inter", sans-serif;
    }

Тут:

    "Inter"    → конкретне сімейство
    sans-serif → запасна загальна категорія

---

# Typeface vs Font Family

Ці поняття тісно пов'язані.

**Typeface** — дизайн набору символів.

**Font family** — сімейство пов'язаних шрифтових накреслень, що мають спільний дизайн.

Спрощено:

    Typeface → візуальний дизайн літер
    Font family → сімейство пов'язаних накреслень

У повсякденній роботі веброзробника та UI-дизайнера ці терміни часто використовуються майже як синоніми.

Для практичної роботи достатньо розуміти, що `font-family` у CSS задає сімейство шрифту, яке браузер має використовувати для відображення тексту.

# Основні категорії Font Families

У CSS існують загальні категорії шрифтів, які називаються generic font families.

Основні категорії:

    serif
    sans-serif
    monospace
    cursive
    fantasy

Також є системні категорії:

    system-ui
    ui-serif
    ui-sans-serif
    ui-monospace
    ui-rounded

Generic font family не визначає один конкретний файл шрифту. Браузер вибирає доступний шрифт, який відповідає цій категорії.

# Serif

Serif — категорія шрифтів із засічками.

Засічки — невеликі завершальні елементи штрихів літер.

Приклади:

    Georgia
    Times New Roman
    Merriweather
    Source Serif 4
    Lora

Візуальні характеристики:

- помітні завершальні елементи літер;
- часто асоціюються з книжковою типографікою;
- можуть створювати традиційне або редакційне враження;
- можуть добре підходити для статей і довгих текстів.

Типові сфери використання:

    online magazines
    editorial websites
    books
    educational articles
    literary websites
    formal publications

Приклад:

    body {
        font-family: Georgia, serif;
    }

## Serif у заголовках

Serif може створювати виразний контраст із нейтральним інтерфейсом.

    h1 {
        font-family: Georgia, serif;
    }

    body {
        font-family: Arial, sans-serif;
    }

Це поєднання може підійти для освітнього сайту, блогу або редакційного проєкту.

Важливо: serif не означає автоматично кращу читабельність або гіршу придатність для екранів. Результат залежить від конкретного шрифту, розміру, контрасту й інтервалів.

---

# Sans-serif

Sans-serif — категорія шрифтів без засічок.

Приклади:

    Arial
    Helvetica
    Inter
    Roboto
    Open Sans
    Lato
    Source Sans 3
    IBM Plex Sans

Візуальні характеристики:

- відсутність засічок;
- часто нейтральний і сучасний вигляд;
- широкий вибір стилів;
- придатність для багатьох типів інтерфейсів.

Типові сфери використання:

    web applications
    mobile applications
    dashboards
    navigation
    forms
    buttons
    product interfaces
    educational platforms

Приклад:

    body {
        font-family: "Inter", sans-serif;
    }

Sans-serif часто є зручним початковим вибором для UI, оскільки багато сімейств цієї категорії добре підходять для різних розмірів тексту.

Проте конкретний шрифт потрібно оцінювати в контексті реального інтерфейсу.

---

# Monospace

Monospace — категорія шрифтів, у яких символи зазвичай мають однакову ширину.

Приклади:

    Consolas
    Courier New
    JetBrains Mono
    IBM Plex Mono
    Source Code Pro

Типові сфери використання:

    source code
    terminal
    code editor
    technical documentation
    identifiers
    tabular data
    developer tools

Приклад:

    code,
    pre {
        font-family: "JetBrains Mono", monospace;
    }

Monospace допомагає вирівнювати символи в коді та деяких технічних представленнях.

Для звичайних довгих текстів monospace часто менш компактний за пропорційні шрифти.

---

# Cursive

Cursive — загальна категорія шрифтів, які імітують рукописний або каліграфічний стиль.

Приклад:

    .signature {
        font-family: cursive;
    }

Можливі сценарії використання:

    signatures
    invitations
    decorative headings
    short visual accents

У звичайному UI cursive краще використовувати обережно.

Не варто застосовувати декоративний рукописний шрифт для довгих текстів, дрібних підписів або важливих інструкцій, якщо це погіршує читабельність.

---

# Fantasy

Fantasy — загальна категорія декоративних шрифтів.

Приклад:

    .game-title {
        font-family: fantasy;
    }

Може використовуватися для:

    game interfaces
    entertainment websites
    themed projects
    decorative headings

Конкретний вигляд залежить від браузера та доступних шрифтів.

Для звичайних бізнесових інтерфейсів fantasy зазвичай не є основним вибором для body text.

---

# System UI Fonts

System UI fonts — системні шрифти, які використовуються операційною системою для інтерфейсів.

У CSS:

    body {
        font-family: system-ui, sans-serif;
    }

Переваги:

- зазвичай не потрібно завантажувати окремий файл шрифту;
- швидке початкове відображення;
- природна інтеграція з платформою;
- знайомий користувачеві вигляд.

Недоліки:

- зовнішній вигляд може відрізнятися між операційними системами;
- типографічний стиль складніше повністю контролювати;
- метрики можуть відрізнятися між платформами.

System UI fonts часто підходять для застосунків, де важливі простота, швидкість і нативне відчуття інтерфейсу.

---

# UI Sans-serif

`ui-sans-serif` — загальна CSS-категорія шрифтів без засічок, призначених для інтерфейсного використання.

Приклад:

    body {
        font-family: ui-sans-serif, sans-serif;
    }

Це не конкретний шрифт. Браузер використовує доступний варіант, який відповідає цій категорії.

Схожим чином працюють:

    ui-serif
    ui-monospace
    ui-rounded

Ці категорії можна використовувати, коли потрібен відповідний загальний тип шрифту без прив'язки до конкретного сімейства.

---

# Text Fonts

Text fonts — шрифти, призначені для читання тексту.

Вони можуть використовуватися для:

    paragraphs
    articles
    documentation
    descriptions
    educational content
    long-form text

Для text fonts важливі:

- читабельність у невеликих розмірах;
- розрізнення схожих символів;
- комфортна форма літер;
- достатня підтримка потрібних мов;
- передбачувана поведінка в абзацах;
- гармонійна взаємодія з line-height і шириною рядка.

Приклад:

    body {
        font-family: "Open Sans", sans-serif;
        font-size: 1rem;
        line-height: 1.6;
    }

Це лише приклад налаштування. Придатність конкретного шрифту потрібно перевіряти на реальному тексті.

---

# Display Fonts

Display fonts — шрифти, які особливо добре працюють у великих розмірах або коротких текстових акцентах.

Типові сценарії:

    hero headings
    landing page titles
    campaign headlines
    promotional banners
    brand statements
    decorative titles

Приклад:

    h1 {
        font-family: "Playfair Display", serif;
    }

    body {
        font-family: "Inter", sans-serif;
    }

Display font може мати виразні форми літер, незвичні пропорції або декоративні елементи.

Проте такий шрифт не обов'язково підходить для:

- довгих абзаців;
- дрібного тексту;
- форм;
- навігації;
- щільних таблиць.

Важливо оцінювати не лише дизайн заголовка, а й його читабельність на мобільному пристрої.

---

# Body Font

Body font — шрифт основного тексту інтерфейсу.

Зазвичай використовується для:

    paragraphs
    descriptions
    article text
    helper text
    general content

Приклад:

    body {
        font-family: "Inter", sans-serif;
    }

Під час вибору body font звертай увагу на:

- комфорт читання;
- форму малих літер;
- x-height;
- підтримку кирилиці;
- читабельність у невеликих розмірах;
- ширину тексту;
- доступні накреслення.

Для освітніх сайтів і платформ body font особливо важливий, оскільки користувачі можуть читати великі обсяги тексту.

---

# Heading Font

Heading font — шрифт, який використовується для заголовків.

Він може збігатися з body font або бути окремим сімейством.

Один шрифт для всього інтерфейсу:

    body {
        font-family: "Inter", sans-serif;
    }

    h1,
    h2,
    h3 {
        font-family: "Inter", sans-serif;
    }

Окремий шрифт для заголовків:

    body {
        font-family: "Open Sans", sans-serif;
    }

    h1,
    h2,
    h3 {
        font-family: "Merriweather", serif;
    }

Heading font допомагає створити візуальну ієрархію та характер продукту.

Але ієрархію потрібно формувати не лише через сімейство шрифту, а й через:

    font-size
    font-weight
    line-height
    letter-spacing
    spacing
    color

---

# UI Font

UI font — шрифт, який використовується для елементів інтерфейсу.

Приклади елементів:

    buttons
    navigation
    labels
    input fields
    tabs
    menus
    tooltips
    table headers
    status badges

Для UI font важливі:

- чіткі форми символів;
- читабельність у невеликих розмірах;
- достатня кількість накреслень;
- підтримка потрібних мов;
- стабільні метрики;
- передбачувана ширина тексту.

Приклад:

    body {
        font-family: "Inter", sans-serif;
    }

    button,
    input,
    select,
    textarea {
        font: inherit;
    }

`font: inherit` допомагає елементам форм успадковувати типографічні налаштування від батьківського елемента.

Це зменшує ймовірність того, що кнопки й поля введення матимуть випадкові системні шрифти.

---

# Brand Font

Brand font — шрифт або сімейство шрифтів, яке використовується для формування візуальної ідентичності бренду.

Може застосовуватися для:

    logo
    brand headings
    marketing pages
    promotional materials
    product interface

У деяких проєктах бренд використовує одне сімейство для всього тексту. В інших — окремий шрифт для заголовків і нейтральний для основного тексту.

Важливо, щоб брендова типографіка не погіршувала зручність користування.

Для UI потрібно знайти баланс між:

    brand identity
    readability
    accessibility
    performance
    consistency

---

# Editorial Fonts

Editorial fonts — шрифти, які використовуються в редакційних проєктах: статтях, журналах, блогах і довгих матеріалах.

Часто зустрічаються комбінації:

    serif headings + sans-serif body
    sans-serif headings + serif body
    serif headings + serif body
    sans-serif headings + sans-serif body

Вибір залежить від характеру видання.

Наприклад, для освітнього сайту можна використати:

    h1,
    h2 {
        font-family: Georgia, serif;
    }

    body {
        font-family: "Open Sans", sans-serif;
    }

Така комбінація створює відмінність між заголовками й основним текстом.

Проте це не універсальне правило: обидва сімейства можуть бути однаковими, якщо цього потребує дизайн.

---

# Один шрифт чи кілька?

Для більшості UI-проєктів достатньо одного або двох сімейств шрифтів.

## Варіант 1 — одне сімейство

    body {
        font-family: "Inter", sans-serif;
    }

    h1,
    h2,
    h3,
    button,
    input {
        font-family: inherit;
    }

Переваги:

- візуальна узгодженість;
- простіша типографічна система;
- менше шрифтових ресурсів;
- простіше підтримувати дизайн;
- легше створювати дизайн-токени.

Цей підхід добре підходить для:

    dashboards
    SaaS applications
    admin panels
    educational platforms
    forms
    productivity tools

## Варіант 2 — два сімейства

    body {
        font-family: "Inter", sans-serif;
    }

    h1,
    h2,
    h3 {
        font-family: "Merriweather", serif;
    }

Переваги:

- виразніші заголовки;
- більший візуальний контраст;
- можливість сформувати характер бренду;
- чіткіше розділення типів контенту.

Такий підхід може підійти для:

    editorial websites
    blogs
    educational websites
    institutional websites
    landing pages

## Варіант 3 — три сімейства

Наприклад:

    body → Inter
    headings → Merriweather
    code → JetBrains Mono

CSS:

    body {
        font-family: "Inter", sans-serif;
    }

    h1,
    h2,
    h3 {
        font-family: "Merriweather", serif;
    }

    code,
    pre {
        font-family: "JetBrains Mono", monospace;
    }

Це може бути доречним для документації, навчальних платформ або технічних продуктів.

Однак кожне додаткове сімейство має виправдовувати свою роль.

# Font Pairing

Font pairing — поєднання двох або більше сімейств шрифтів в одному дизайні.

Мета — створити гармонійний інтерфейс із чіткою візуальною ієрархією.

Наприклад:

    headings → Merriweather
    body → Open Sans

Або:

    headings → Inter
    body → Inter

Font pairing не обов'язково означає використання різних сімейств. Поєднання одного сімейства з різними розмірами та товщинами також може бути ефективним.

## Основні принципи Font Pairing

### 1. Спільний характер

Шрифти мають відповідати загальному стилю продукту.

Наприклад, для академічного сайту можна вибрати стримані шрифти, а для ігрового проєкту — виразніші.

### 2. Контраст

Шрифти повинні достатньо відрізнятися, якщо їхні ролі мають бути візуально різними.

Наприклад:

    serif headings
    sans-serif body

Але надмірний контраст може порушити цілісність інтерфейсу.

### 3. Читабельність

Основний текст має залишатися зручним для читання.

Не варто вибирати складний декоративний шрифт лише заради контрасту.

### 4. Узгоджені пропорції

Порівнюй, як шрифти виглядають за реального розміру, товщини та міжрядкового інтервалу.

### 5. Мовна підтримка

Перевіряй, чи обидва сімейства коректно відображають українську кирилицю.

# Приклади Font Pairing

## Приклад 1 — нейтральний UI

    headings → Inter
    body → Inter
    code → JetBrains Mono

CSS:

    body {
        font-family: "Inter", sans-serif;
    }

    code,
    pre {
        font-family: "JetBrains Mono", monospace;
    }

Підходить для:

    dashboards
    admin panels
    SaaS
    developer tools

---

## Приклад 2 — редакційний стиль

    headings → Merriweather
    body → Open Sans

CSS:

    h1,
    h2,
    h3 {
        font-family: "Merriweather", serif;
    }

    body {
        font-family: "Open Sans", sans-serif;
    }

Може підійти для:

    blogs
    educational articles
    online magazines
    editorial websites

---

## Приклад 3 — мінімалістичний сайт

    headings → Inter
    body → Inter

Контраст створюється не через сімейства, а через розмір і товщину.

    h1 {
        font-size: 2.5rem;
        font-weight: 700;
    }

    p {
        font-size: 1rem;
        font-weight: 400;
        line-height: 1.6;
    }

Підходить для багатьох типів вебзастосунків.

---

## Приклад 4 — освітній сайт

    headings → Source Serif 4
    body → Source Sans 3

Може поєднувати книжковий характер заголовків із нейтральним основним текстом.

Підходить для:

    online courses
    learning platforms
    educational articles
    digital libraries

## Приклад 5 — технічна документація

    headings → Inter
    body → Inter

CSS:

    body {

Може бути зручним для документації, де звичайний текст і код мають чітко відрізнятися.

# Font Compatibility

Font compatibility — сумісність шрифтів у межах одного інтерфейсу.

Вона охоплює:

- візуальну гармонію;
- сумісність пропорцій;
- підтримку мов;
- доступність потрібних накреслень;
- читабельність у реальних розмірах;
- передбачуваність перенесення тексту.

Навіть якщо два шрифти виглядають добре окремо, разом вони можуть створювати неузгоджений результат.

Потрібно перевіряти їх на реальному контенті:

    headings
    paragraphs
    navigation
    buttons
    labels
    numbers
    tables
    code

---

# Font Metrics та сумісність сімейств

Різні сімейства можуть мати різні метрики.

Наприклад, за однакового `font-size` вони можуть відрізнятися:

- висотою малих літер;
- шириною тексту;
- висотою рядка;
- формою цифр;
- довжиною заголовків;
- переносами рядків.

Приклад:

    h1 {
        font-family: "Inter", sans-serif;
        font-size: 2.5rem;
    }

Якщо замінити Inter на інший шрифт, заголовок може стати ширшим або вужчим.

Це може вплинути на:

    line wrapping
    component height
    alignment
    responsive layout

Тому зміну шрифту потрібно перевіряти на всіх основних розмірах екрана.

---

# Font Fallback

Font fallback — використання запасного шрифту, якщо основний недоступний або не містить потрібного символу.

Приклад:

    body {
        font-family:
            "Inter",
            "Segoe UI",
            Arial,
            sans-serif;
    }

Порядок:

    Inter
      ↓ unavailable
    Segoe UI
      ↓ unavailable
    Arial
      ↓ unavailable
    sans-serif

Fallback важливий для:

- стабільного відображення тексту;
- роботи без доступу до зовнішніх ресурсів;
- підтримки різних операційних систем;
- відображення символів, відсутніх в основному шрифті.

Для українського інтерфейсу важливо перевірити, чи fallback коректно відображає:

    Ґ ґ
    Є є
    І і
    Ї ї

Fallback може використовуватися не лише для всього тексту, а й для окремих символів.

---

# Font Stack

Font stack — список сімейств шрифтів, які браузер перевіряє послідовно.

Приклад:

    body {
        font-family:
            "Inter",
            "Segoe UI",
            Arial,
            sans-serif;
    }

Для заголовків:

    h1,
    h2,
    h3 {
        font-family:
            "Merriweather",
            Georgia,
            serif;
    }

Для коду:

    code,
    pre {
        font-family:
            "JetBrains Mono",
            Consolas,
            monospace;
    }

Основні правила:

- Спочатку вказуй бажане сімейство.
- Додавай осмислені альтернативи.
- Завершуй стек відповідною generic font family.
- Перевіряй, як виглядає текст, коли основний шрифт недоступний.
- Не припускай, що однакові назви шрифтів гарантують ідентичний вигляд на всіх платформах.

# Font Families у Design System

У дизайн-системі сімейства шрифтів варто визначати централізовано.

Наприклад:

    Typography
    ├── Font families
    │   ├── Primary
    │   ├── Heading
    │   └── Monospace
    ├── Font sizes
    ├── Font weights
    ├── Line heights
    └── Letter spacing

Для CSS можна використовувати custom properties.

    :root {
        --font-primary: "Inter", sans-serif;
        --font-heading: "Merriweather", serif;
        --font-mono: "JetBrains Mono", monospace;
    }

Використання:

    body {
        font-family: var(--font-primary);
    }

    h1,
    h2,
    h3 {
        font-family: var(--font-heading);
    }

    code,
    pre {
        font-family: var(--font-mono);
    }

Переваги:

- однакові правила на всіх сторінках;
- простіша зміна шрифтів;
- менше дублювання CSS;
- зрозуміла структура типографіки;
- зручніше підтримувати дизайн-систему.

Якщо проєкт використовує лише одне сімейство, не потрібно створювати додаткові токени для неіснуючих ролей.

# Font Families у реальному UI

## Dashboard

Можливий підхід:

    primary font → Inter
    code font → JetBrains Mono

Причини:

- нейтральний вигляд;
- читабельність таблиць і форм;
- чіткі підписи;
- зручне відображення технічних значень.

## Освітня платформа

Можливий підхід:

    headings → Source Serif 4
    body → Source Sans 3

Причини:

- виразні заголовки;
- зручне читання навчальних матеріалів;
- розмежування заголовків і основного тексту.

## Церковний або культурний сайт

Можливий підхід:

    headings → serif
    body → sans-serif

Таке поєднання може створити стриманий редакційний характер.

Водночас шрифти потрібно перевіряти на українській кирилиці, довгих заголовках і мобільних екранах.

## Landing Page

Можливий підхід:

    hero heading → display font
    body → sans-serif

Важливо, щоб виразний заголовок не погіршував читабельність і не створював проблем із перенесенням рядків.

## Developer Tool

Можливий підхід:

    interface → sans-serif
    code → monospace

Так користувач може швидко розрізняти звичайні підписи та фрагменти коду.

# Практичні приклади CSS

## Приклад 1 — один шрифт для всього інтерфейсу

    :root {
        --font-primary: "Inter", sans-serif;
    }

    body {
        font-family: var(--font-primary);
    }

    button,
    input,
    select,
    textarea {
        font: inherit;
    }

Це простий і послідовний варіант для багатьох застосунків.

---

## Приклад 2 — окремий шрифт для заголовків

    :root {
        --font-body: "Open Sans", sans-serif;
        --font-heading: "Merriweather", serif;
    }

    body {
        font-family: var(--font-body);
    }

    h1,
    h2,
    h3 {
        font-family: var(--font-heading);
    }

---

## Приклад 3 — три ролі шрифтів

    :root {
        --font-body: "Inter", sans-serif;
        --font-heading: "Merriweather", serif;
        --font-code: "JetBrains Mono", monospace;
    }

    body {
        font-family: var(--font-body);
    }

    h1,
    h2,
    h3 {
        font-family: var(--font-heading);
    }

    code,
    pre {
        font-family: var(--font-code);
    }

---

## Приклад 4 — системний UI

    :root {
        --font-ui: system-ui, sans-serif;
    }

    body {
        font-family: var(--font-ui);
    }

Це рішення не потребує окремого вебшрифту для основного тексту.

---

## Приклад 5 — fallback для заголовків

    h1,
    h2,
    h3 {
        font-family:
            "Merriweather",
            Georgia,
            serif;
    }

Якщо Merriweather недоступний, браузер може використати Georgia, а потім інший доступний serif.

- Яке сімейство найзручніше для основного тексту?
- Як змінюється ширина однакового тексту?

# Типові помилки

## Помилка 1 — надто багато сімейств

    body {
        font-family: Arial, sans-serif;
    }

    h1 {
        font-family: Georgia, serif;
    }

    h2 {
        font-family: Verdana, sans-serif;
    }

    h3 {
        font-family: "Courier New", monospace;
    }

    button {
        font-family: Tahoma, sans-serif;
    }

Кожен елемент використовує інше сімейство без зрозумілої системи.

Краще визначити чіткі ролі:

    body → primary font
    headings → heading font
    code → monospace font

---

## Помилка 2 — display font для всього тексту

Декоративний шрифт може добре виглядати в заголовку, але погано працювати в довгих абзацах.

Використовуй display font відповідно до його призначення.

---

## Помилка 3 — відсутність fallback

    body {
        font-family: "Inter";
    }

Краще:

    body {
        font-family: "Inter", sans-serif;
    }

---

## Помилка 4 — поєднання шрифтів без перевірки

Два популярні шрифти не обов'язково добре працюватимуть разом.

Перевіряй:

    proportions
    visual character
    readability
    font metrics
    Cyrillic support

---

## Помилка 5 — ігнорування кирилиці

Шрифт може добре виглядати англійською, але мати проблеми з українськими літерами.

Тестуй:

    Ґ ґ
    Є є
    І і
    Ї ї

---

## Помилка 6 — створення ієрархії лише через сімейства

Не потрібно використовувати різний шрифт для кожного рівня заголовків.

Часто достатньо одного сімейства з різними значеннями:

    font-size
    font-weight
    line-height
    letter-spacing

---

## Помилка 7 — забагато шрифтових файлів

Кожне додаткове сімейство або накреслення може збільшувати обсяг ресурсів, які потрібно завантажити.

Використовуй лише ті сімейства й накреслення, які справді потрібні.

---

## Помилка 8 — неправильний вибір шрифту для UI

Декоративний або надто вузький шрифт може ускладнювати читання кнопок, підписів і полів введення.

Для UI важливо перевіряти текст у реальних розмірах, а не лише в заголовках.

# Міні-шпаргалка

## Основні категорії

    serif       → із засічками
    sans-serif  → без засічок
    monospace   → однакова ширина символів
    cursive     → рукописний стиль
    fantasy     → декоративний стиль

## Основні ролі

    body font    → основний текст
    heading font → заголовки
    display font → великі акцентні написи
    UI font      → елементи інтерфейсу
    code font    → код і технічні дані
    brand font   → візуальна ідентичність бренду

## Font stack

    body {
        font-family:
            "Inter",
            Arial,
            sans-serif;
    }

## Один шрифт

    body {
        font-family: "Inter", sans-serif;
    }

    h1 {
        font-weight: 700;
    }

    p {
        font-weight: 400;
    }

## Два шрифти

    body {
        font-family: "Open Sans", sans-serif;
    }

    h1,
    h2 {
        font-family: "Merriweather", serif;
    }

## Три ролі

    body → Inter
    headings → Merriweather
    code → JetBrains Mono

## Основні правила

    body text → читабельність
    headings → ієрархія
    code → monospace
    fallback → резервний шрифт
    design system → централізовані font tokens

# Головне

• Font family — це сімейство шрифтів зі спільним візуальним дизайном.

• Serif часто асоціюється з книжковою та редакційною типографікою, а sans-serif широко використовується в сучасних інтерфейсах.

• Monospace корисний для коду та технічних даних.

• Display fonts призначені насамперед для великих заголовків і коротких акцентів.

• Body font потрібно вибирати насамперед з урахуванням читабельності.

• UI font має добре працювати в кнопках, формах, навігації та невеликих текстових елементах.

• Одне сімейство шрифтів часто є достатнім для створення професійного інтерфейсу.

• Друге сімейство варто додавати, якщо воно створює зрозумілу візуальну відмінність або підтримує характер бренду.

• Font pairing — це не просто поєднання красивих шрифтів. Це баланс між контрастом, гармонією та читабельністю.

• Font stack забезпечує запасні варіанти для різних браузерів і систем.

• Шрифти потрібно перевіряти на українській кирилиці, реальних заголовках, абзацах, формах і таблицях.

• У дизайн-системі доцільно централізовано визначати сімейства через CSS custom properties.

• Кількість сімейств і файлів варто обмежувати потребами проєкту.

• Основна послідовність вибору сімейств:

    1. Визначити характер і призначення продукту.
    2. Вибрати основне сімейство.
    3. Перевірити читабельність і підтримку мов.
    4. Визначити, чи потрібен окремий шрифт для заголовків.
    5. За потреби вибрати monospace для коду.
    6. Налаштувати font stack і fallback.
    7. Перевірити реальний вигляд інтерфейсу.
    8. Закріпити вибрані сімейства в дизайн-системі.

• Хороша типографічна система не потребує великої кількості шрифтів. Вона потребує обґрунтованого вибору, чітких ролей і послідовного використання.

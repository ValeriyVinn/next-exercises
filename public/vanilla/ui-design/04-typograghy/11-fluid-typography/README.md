# 11. Fluid Typography — Гнучка типографіка

## 1. Що таке Fluid Typography?

**Fluid Typography (гнучка типографіка)** — це підхід до оформлення тексту, за якого розмір шрифту плавно змінюється залежно від ширини viewport або іншого доступного простору.

Замість того щоб задавати лише один розмір шрифту або різко перемикати його за допомогою медіазапитів, можна визначити мінімальне, бажане та максимальне значення.

Наприклад, заголовок може поступово збільшуватися на ширших екранах, але не ставати надто великим на моніторі й не зменшуватися до нечитабельного розміру на смартфоні.

У CSS для цього часто використовують функцію `clamp()`.

    h1 {
      font-size: clamp(2rem, 5vw, 4rem);
    }

Тут:

- `2rem` — мінімальний розмір;
- `5vw` — бажаний розмір, залежний від ширини viewport;
- `4rem` — максимальний розмір.

Браузер обчислює бажане значення, але обмежує його мінімумом і максимумом.

**Головна ідея:** текст адаптується до доступного простору плавно, без необхідності задавати окремий розмір для кожної ширини екрана.

---

## 2. Навіщо потрібна Fluid Typography?

✔ Робить заголовки адаптивними.

✔ Допомагає підтримувати пропорції типографіки на різних екранах.

✔ Зменшує кількість медіазапитів для налаштування розмірів тексту.

✔ Допомагає створювати гнучкі дизайн-системи.

✔ Дає змогу плавно масштабувати заголовки та інші текстові елементи.

✔ Допомагає узгодити розміри тексту з адаптивною композицією сторінки.

✔ Полегшує підтримку єдиної типографічної системи.

### Де використовується?

- Заголовки на посадкових сторінках.
- Hero-секції.
- Заголовки статей.
- Сторінки портфоліо.
- Освітні вебзастосунки.
- Блоги та журнали.
- Інтернет-магазини.
- Адаптивні дизайн-системи.
- Великі рекламні заголовки.
- Інтерфейси, які повинні працювати на різних розмірах viewport.

### Приклад без Fluid Typography

    h1 {
      font-size: 48px;
    }

Такий заголовок матиме однаковий заданий розмір на вузькому й широкому екранах, якщо інші правила не змінюють його.

На смартфоні він може займати забагато місця.

### Приклад із Fluid Typography

    h1 {
      font-size: clamp(2rem, 5vw, 4rem);
    }

Розмір заголовка змінюється плавно в межах визначеного діапазону.

Водночас Fluid Typography не означає, що кожен текст на сторінці обов'язково повинен змінюватися залежно від ширини екрана. Для звичайного тексту фіксований відносний розмір може бути цілком доречним.

## 3. Основні поняття

### 3.1. Viewport

**Viewport** — видима область вебсторінки у браузері.

Ширина viewport впливає на те, скільки тексту поміщається в рядку та як розташовуються елементи інтерфейсу.

Для Fluid Typography часто використовують одиницю `vw`.

    h1 {
      font-size: 5vw;
    }

`5vw` дорівнює 5% ширини viewport.

Наприклад, якщо ширина viewport становить 1000 CSS-пікселів, то `5vw` дорівнює 50 CSS-пікселям.

Але використовувати `vw` без обмежень не завжди добре: на дуже вузькому екрані текст може стати надто малим, а на дуже широкому — надто великим.

### 3.2. Relative Units — відносні одиниці

Для гнучкої типографіки використовують різні CSS-одиниці.

| Одиниця | Що означає | Типове застосування |
|---|---|---|
| `px` | CSS-пікселі | Точні розміри, окремі елементи |
| `rem` | Відносно розміру шрифту кореневого елемента | Основні типографічні значення |
| `em` | Відносно розміру шрифту відповідного контексту | Локальне масштабування |
| `vw` | 1% ширини viewport | Плавне масштабування від ширини вікна |
| `vh` | 1% висоти viewport | Рідше для типографіки |
| `vmin` | 1% меншого виміру viewport | Спеціальні адаптивні випадки |
| `vmax` | 1% більшого виміру viewport | Спеціальні адаптивні випадки |

Для більшості звичайних типографічних систем зручно використовувати `rem` як мінімальне й максимальне значення, а `vw` — як частину формули плавного масштабування.

### 3.3. `rem`

`rem` — одиниця, яка залежить від обчисленого розміру шрифту кореневого елемента, зазвичай `html`.

    html {
      font-size: 100%;
    }

    body {
      font-size: 1rem;
    }

Якщо стандартний розмір шрифту браузера становить 16 CSS-пікселів, то `1rem` зазвичай дорівнює 16 CSS-пікселям.

Проте не варто вважати, що це значення завжди незмінне: користувач або стилі сторінки можуть змінювати базовий розмір.

### 3.4. `vw`

`vw` означає відсоток ширини viewport.

    h1 {
      font-size: 5vw;
    }

Якщо ширина viewport змінюється, значення `5vw` також змінюється.

Перевага:
- плавна залежність від ширини екрана.

Недоліки:
- текст може стати надто великим;
- текст може стати надто малим;
- масштабування може не відповідати реальній потребі;
- значення залежить від ширини viewport, а не безпосередньо від ширини текстового контейнера.

Тому для багатьох заголовків `vw` краще використовувати всередині `clamp()`.

### 3.5. `clamp()`

`clamp()` — CSS-функція, яка обмежує значення заданим мінімумом і максимумом.

Синтаксис:

    clamp(мінімум, бажане-значення, максимум)

Приклад:

    h1 {
      font-size: clamp(2rem, 5vw, 4rem);
    }

Аргументи:

- перший — нижня межа;
- другий — значення, яке браузер намагається використати;
- третій — верхня межа.

Функція повертає значення, яке не менше за мінімум і не більше за максимум, за умови коректного порядку меж.

### 3.6. Minimum, Preferred, Maximum

Fluid Typography часто ґрунтується на трьох значеннях.

**Minimum** — найменший допустимий розмір.

**Preferred** — бажаний розмір, який змінюється залежно від умов.

**Maximum** — найбільший допустимий розмір.

    h1 {
      font-size: clamp(2rem, 5vw, 4rem);
    }

У цьому прикладі:
- мінімум — `2rem`;
- бажане значення — `5vw`;
- максимум — `4rem`.

Такий підхід дає змогу контролювати поведінку тексту на різних екранах.

### 3.7. Fluid Scale — гнучка типографічна шкала

**Fluid Scale** — набір типографічних розмірів, які плавно змінюються залежно від viewport або інших визначених умов.

Наприклад:
- основний текст;
- дрібний текст;
- підзаголовок;
- заголовок секції;
- головний заголовок.

У дизайн-системі для кожної ролі можна визначити окремий діапазон.

Важливо, щоб розміри залишалися візуально узгодженими й не руйнували ієрархію.

## 4. Як працює `clamp()`

### 4.1. Базовий приклад

    h1 {
      font-size: clamp(2rem, 5vw, 4rem);
    }

Уявімо, що стандартний розмір `1rem` дорівнює 16px.

Тоді:
- `2rem` = 32px;
- `4rem` = 64px.

Бажане значення `5vw` залежить від ширини viewport.

| Ширина viewport | `5vw` | Результат `clamp()` |
|---:|---:|---:|
| 320px | 16px | 32px |
| 768px | 38.4px | 38.4px |
| 1024px | 51.2px | 51.2px |
| 1440px | 72px | 64px |

У цьому прикладі заголовок:
- не стає меншим за 32px;
- плавно збільшується, поки бажане значення перебуває в межах;
- не стає більшим за 64px.

Значення в таблиці наведені для ілюстрації та припускають базовий розмір `1rem = 16px`.

### 4.2. Чому не використовувати лише `vw`?

    /* Без обмежень */
    h1 {
      font-size: 5vw;
    }

На дуже вузькому екрані значення може бути занадто малим, а на дуже широкому — надмірно великим.

Краще:

    h1 {
      font-size: clamp(2rem, 5vw, 4rem);
    }

Тепер розмір має контрольовані межі.

### 4.3. Чому не використовувати лише `rem`?

    h1 {
      font-size: 3rem;
    }

Такий розмір передбачуваний і може бути цілком доречним.

Однак він не змінюється плавно залежно від ширини viewport.

Якщо дизайн потребує плавного масштабування, можна використати `clamp()`.

### 4.4. Коли краще використати медіазапити?

Fluid Typography не замінює медіазапити в усіх ситуаціях.

Медіазапити можуть бути кращими, якщо:
- заголовок має принципово іншу композицію на мобільному;
- змінюється розташування елементів;
- потрібно перемкнутися між кількома чітко визначеними стилями;
- плавне масштабування не дає бажаного результату.

    h1 {
      font-size: 2rem;
    }

    @media (min-width: 48rem) {
      h1 {
        font-size: 3rem;
      }
    }

Це дискретний підхід: розмір змінюється після досягнення визначеної ширини.

`clamp()` натомість забезпечує плавний перехід між мінімумом і максимумом.

## 5. Розрахунок Fluid Typography

Іноді потрібно, щоб розмір шрифту плавно змінювався між двома конкретними ширинами viewport.

Наприклад:
- на ширині 320px шрифт має бути 32px;
- на ширині 1280px шрифт має бути 64px.

Для цього можна розрахувати лінійну формулу.

### 5.1. Загальна формула

Бажаний розмір можна описати так:

    font-size = a + b × viewport-width

У CSS це часто записують через `calc()` і `vw`.

    font-size: calc(коефіцієнт + коефіцієнт-vw);

Щоб отримати формулу, потрібно знати:
- мінімальну ширину viewport;
- максимальну ширину viewport;
- мінімальний розмір шрифту;
- максимальний розмір шрифту.

### 5.2. Приклад розрахунку

Потрібно масштабувати заголовок:
- від 32px на ширині 320px;
- до 64px на ширині 1280px.

Спочатку обчислюємо різницю розмірів шрифту:

    64 - 32 = 32px

Потім різницю ширини viewport:

    1280 - 320 = 960px

Обчислюємо зміну розміру на один піксель ширини:

    32 / 960 = 0.033333...

Переводимо коефіцієнт у `vw`:

    0.033333... × 100 = 3.3333vw

Тепер знаходимо базову частину формули.

На ширині 320px бажане значення має бути 32px:

    32 - (320 × 0.033333...) = 21.333...

Отже, приблизна формула:

    font-size: calc(21.333px + 3.333vw);

Щоб обмежити розмір заданим діапазоном:

    h1 {
      font-size: clamp(
        32px,
        calc(21.333px + 3.333vw),
        64px
      );
    }

Тепер:
- нижче визначеного мінімуму розмір залишатиметься 32px;
- у проміжному діапазоні змінюватиметься плавно;
- вище визначеного максимуму залишатиметься 64px.

Це приклад математичного підходу. Для реального інтерфейсу важливо перевіряти не лише формулу, а й те, як заголовок виглядає з конкретним шрифтом.

### 5.3. Коли не потрібно рахувати вручну?

Для багатьох простих випадків достатньо:

    h1 {
      font-size: clamp(2rem, 5vw, 4rem);
    }

Ручний розрахунок корисний, коли потрібно точно задати початкову та кінцеву точки масштабування.

## 6. Fluid Typography для різних текстових ролей

Не всі елементи повинні масштабуватися однаково.

### 6.1. Головний заголовок

Головний заголовок часто потребує найбільшого діапазону масштабування.

    h1 {
      font-size: clamp(2rem, 5vw, 4.5rem);
      line-height: 1.1;
    }

Значення `line-height: 1.1` наведене як приклад для великого заголовка. Перевіряй його разом із конкретним шрифтом і перенесенням рядків.

### 6.2. Заголовок секції

    h2 {
      font-size: clamp(1.5rem, 3vw, 2.5rem);
      line-height: 1.25;
    }

Заголовок секції може масштабуватися менш інтенсивно, ніж головний заголовок.

### 6.3. Підзаголовок

    h3 {
      font-size: clamp(1.25rem, 2vw, 1.75rem);
      line-height: 1.35;
    }

Для невеликих заголовків достатньо помірного діапазону.

### 6.4. Основний текст

Основний текст не завжди потребує значного масштабування.

    body {
      font-size: clamp(1rem, 0.95rem + 0.2vw, 1.125rem);
      line-height: 1.7;
    }

Це приклад невеликого діапазону між базовим і трохи більшим розміром.

Якщо текст комфортно читається на всіх цільових пристроях за фіксованого значення `1rem`, немає потреби додавати Fluid Typography лише заради самого підходу.

### 6.5. Дрібний текст

    .text-small {
      font-size: 0.875rem;
      line-height: 1.5;
    }

Для підписів і допоміжного тексту можна залишити стабільний розмір.

Не варто автоматично зменшувати текст на мобільному пристрої: маленький екран не означає, що користувачеві потрібен дрібніший текст.

### 6.6. Кнопки

    button {
      font-size: 1rem;
      font-weight: 600;
    }

Для більшості кнопок фіксований відносний розмір є достатнім.

Fluid Typography може бути корисною для великих декоративних кнопок або спеціальних hero-композицій, але зазвичай не потрібна для всіх елементів інтерфейсу.

## 7. Fluid Typography і CSS-змінні

CSS-змінні допомагають централізувати типографічні значення.

### 7.1. Створення типографічної шкали

    :root {
      --font-size-small: 0.875rem;
      --font-size-body: 1rem;
      --font-size-h3: clamp(1.25rem, 2vw, 1.75rem);
      --font-size-h2: clamp(1.5rem, 3vw, 2.5rem);
      --font-size-h1: clamp(2rem, 5vw, 4.5rem);
    }

### 7.2. Використання змінних

    body {
      font-size: var(--font-size-body);
    }

    h1 {
      font-size: var(--font-size-h1);
    }

    h2 {
      font-size: var(--font-size-h2);
    }

    h3 {
      font-size: var(--font-size-h3);
    }

Переваги:
- всі основні значення зберігаються в одному місці;
- легше змінювати дизайн;
- простіше підтримувати однакову типографіку на різних сторінках;
- зручніше документувати дизайн-систему.

### 7.3. Окремі змінні для міжрядкового інтервалу

    :root {
      --line-height-body: 1.7;
      --line-height-heading: 1.2;
    }

    body {
      line-height: var(--line-height-body);
    }

    h1,
    h2,
    h3 {
      line-height: var(--line-height-heading);
    }

Розмір шрифту й міжрядковий інтервал пов'язані, але це різні параметри.

Не потрібно автоматично масштабувати `line-height` тією самою формулою, що й `font-size`. Часто відносного значення достатньо.

## 8. Fluid Typography і адаптивна типографічна шкала

У дизайн-системі типографічні ролі повинні утворювати узгоджену шкалу.

Наприклад:

    :root {
      --text-sm: 0.875rem;
      --text-base: 1rem;
      --text-lg: clamp(1.125rem, 1rem + 0.5vw, 1.375rem);

      --heading-sm: clamp(1.25rem, 1.1rem + 0.8vw, 1.75rem);
      --heading-md: clamp(1.5rem, 1.2rem + 1.5vw, 2.5rem);
      --heading-lg: clamp(2rem, 1.4rem + 3vw, 4rem);
    }

Така шкала створює різні діапазони масштабування для заголовків і основного тексту.

### Що потрібно перевірити?

- Чи залишається помітною різниця між `h1`, `h2` і `h3`?
- Чи не стає основний текст надто великим?
- Чи не надто швидко збільшується головний заголовок?
- Чи узгоджені розміри на смартфоні?
- Чи не займає заголовок надто багато вертикального простору?
- Чи працюють значення з фактичним шрифтом?

Fluid Scale не повинна бути просто набором незалежних формул. Вона має створювати послідовну ієрархію.

## 9. Fluid Typography і читабельність

Гнучкий розмір тексту сам по собі не гарантує зручності читання.

### 9.1. Розмір і ширина рядка

Якщо текст збільшується, рядки стають коротшими, якщо ширина контейнера не змінюється.

Це може змінити висоту текстового блоку.

    .article {
      max-width: 65ch;
      margin-inline: auto;
      padding-inline: 1rem;
    }

    .article-title {
      font-size: clamp(2rem, 5vw, 4rem);
    }

Обмеження ширини допомагає контролювати композицію.

### 9.2. Міжрядковий інтервал

    .article {
      font-size: 1rem;
      line-height: 1.7;
    }

Для довгих абзаців міжрядковий інтервал має велике значення.

Він не повинен ставати надто малим, коли змінюється розмір шрифту.

### 9.3. Довгі заголовки

Заголовок може виглядати добре на широкому екрані, але займати забагато місця на смартфоні.

    h1 {
      max-width: 18ch;
      font-size: clamp(2rem, 5vw, 4rem);
      line-height: 1.1;
    }

Тут:
- `max-width` обмежує ширину заголовка;
- `clamp()` контролює діапазон розміру;
- `line-height` визначає вертикальний ритм.

`18ch` — лише початковий орієнтир. Реальний результат залежить від гарнітури та тексту.

### 9.4. Масштабування браузера

Користувачі можуть збільшувати масштаб сторінки або змінювати налаштування тексту.

Тому важливо перевіряти:
- чи не перекриваються елементи;
- чи не обрізаються заголовки;
- чи залишаються доступними кнопки;
- чи не виникає горизонтальне прокручування сторінки;
- чи зберігається змістова ієрархія.

Не варто покладатися виключно на `vw` для всіх розмірів шрифту, оскільки він безпосередньо залежить від ширини viewport і може недостатньо враховувати потреби користувача.

## 10. Типові помилки

### 10.1. Використання лише `vw`

    /* Потенційна проблема */
    h1 {
      font-size: 5vw;
    }

Без обмежень текст може стати надто малим або надто великим.

Краще:

    h1 {
      font-size: clamp(2rem, 5vw, 4rem);
    }

### 10.2. Надто широкий діапазон масштабування

    h1 {
      font-size: clamp(1rem, 8vw, 6rem);
    }

Такий діапазон може створювати надто велику різницю між вузьким і широким екранами.

Потрібно перевіряти мінімум, бажане значення й максимум у реальному макеті.

### 10.3. Надто вузький діапазон

    h1 {
      font-size: clamp(2rem, 2.1vw, 2.2rem);
    }

Якщо бажане значення рідко виходить за межі, ефект плавного масштабування може бути майже непомітним.

Це не обов'язково помилка: невеликий діапазон може бути саме тим, що потрібно.

### 10.4. Fluid Typography для кожного елемента

Не кожен текст потребує плавного масштабування.

Наприклад:
- основний текст може залишатися `1rem`;
- кнопки можуть використовувати стабільний розмір;
- підписи можуть мати фіксовану типографічну роль;
- великі заголовки можуть масштабуватися плавно.

Використовуй Fluid Typography там, де вона справді покращує адаптацію.

### 10.5. Ігнорування міжрядкового інтервалу

Збільшення шрифту змінює вертикальну композицію.

Якщо `line-height` занадто малий, рядки можуть виглядати стиснутими.

    h1 {
      font-size: clamp(2rem, 5vw, 4rem);
      line-height: 1.1;
    }

    p {
      font-size: 1rem;
      line-height: 1.7;
    }

Для заголовків і основного тексту можуть бути потрібні різні значення.

### 10.6. Ігнорування довжини заголовка

Великий заголовок може виглядати ефектно, але займати занадто багато рядків.

Потрібно перевіряти:
- ширину контейнера;
- кількість рядків;
- довжину слів;
- реальний текст;
- розмір шрифту на мобільних пристроях.

### 10.7. Надмірна залежність від ширини viewport

`vw` реагує на ширину viewport, а не на ширину батьківського контейнера.

Якщо текст знаходиться у вузькій картці на широкому екрані, значення `vw` може збільшити шрифт сильніше, ніж це доречно для самої картки.

Для таких компонентів потрібно перевіряти конкретний контекст. У певних випадках можуть бути корисними контейнерні одиниці, але вони потребують відповідного контейнера.

### 10.8. Відсутність перевірки доступності

Не варто зменшувати текст лише для того, щоб умістити більше контенту на смартфоні.

Краще переглянути:
- ширину контейнера;
- відступи;
- структуру сторінки;
- довжину тексту;
- компонування елементів.

Текст повинен залишатися читабельним і доступним.

## 12. Практичний приклад: Fluid Typography через CSS-змінні

Для проєкту з багатьма сторінками краще централізувати типографічні значення.

### CSS

    :root {
      --font-size-body: 1rem;

      --font-size-h3: clamp(1.25rem, 1.1rem + 0.7vw, 1.75rem);
      --font-size-h2: clamp(1.5rem, 1.2rem + 1.5vw, 2.5rem);
      --font-size-h1: clamp(2rem, 1.4rem + 3vw, 4rem);

      --line-height-body: 1.7;
      --line-height-heading: 1.2;
    }

    body {
      font-size: var(--font-size-body);
      line-height: var(--line-height-body);
    }

    h1 {
      font-size: var(--font-size-h1);
      line-height: 1.1;
    }

    h2 {
      font-size: var(--font-size-h2);
      line-height: var(--line-height-heading);
    }

    h3 {
      font-size: var(--font-size-h3);
      line-height: var(--line-height-heading);
    }

### Переваги

- Розміри тексту зібрані в одному місці.
- Зручно змінювати типографічну шкалу.
- Легше підтримувати послідовність між сторінками.
- Можна повторно використовувати змінні в компонентах.
- Простіше документувати дизайн-систему.

### Важливо

Змінні повинні відповідати реальним потребам проєкту. Не потрібно використовувати Fluid Typography для кожного рівня лише тому, що CSS дозволяє це зробити.

## 13. Fluid Typography і контейнерні одиниці

Зазвичай `vw` залежить від ширини viewport.

Але іноді текст розташований у компоненті, ширина якого значно відрізняється від ширини всього екрана.

Наприклад:
- картка в бічній панелі;
- віджет на інформаційній панелі;
- блок у багатоколонковому макеті;
- компонент у вузькій колонці.

У таких випадках масштабування за шириною viewport може бути неідеальним.

CSS підтримує контейнерні одиниці, зокрема `cqw`, які залежать від ширини контейнера запиту.

### Приклад

    .card-container {
      container-type: inline-size;
    }

    .card-title {
      font-size: clamp(1.25rem, 5cqw, 2rem);
    }

Тут `5cqw` дорівнює 5% ширини відповідного контейнера запиту.

### Що потрібно пам'ятати?

- `vw` залежить від ширини viewport.
- `cqw` залежить від ширини контейнера запиту.
- Для контейнерних одиниць потрібно правильно налаштувати контейнер.
- Потрібно перевірити підтримку браузерами, які важливі для проєкту.
- Контейнерні одиниці не потрібні для кожного заголовка.

Для початкового рівня достатньо добре розуміти `clamp()`, `rem` і `vw`. Контейнерні одиниці можна вивчати після засвоєння базових принципів адаптивної типографіки.

## 14. Практичні вправи

### Вправа 1. Порівняй три способи

Створи три варіанти головного заголовка.

    /* Фіксований розмір */
    .title-fixed {
      font-size: 3rem;
    }

    /* Масштабування без обмежень */
    .title-fluid {
      font-size: 5vw;
    }

    /* Масштабування з обмеженнями */
    .title-clamped {
      font-size: clamp(2rem, 5vw, 4rem);
    }

Перевір усі варіанти на вузькому, середньому та широкому viewport.

Порівняй:
- читабельність;
- кількість рядків;
- вертикальну висоту;
- поведінку на дуже широкому екрані.

**Мета:** зрозуміти, чому плавне масштабування потребує меж.

### Вправа 2. Створи Fluid Scale

Задай розміри для:
- `h1`;
- `h2`;
- `h3`;
- основного тексту;
- допоміжного тексту.

Використай `clamp()` лише для тих ролей, яким справді потрібне плавне масштабування.

Перевір, чи зберігається ієрархія між заголовками.

### Вправа 3. Розрахуй власну формулу

Визнач:
- мінімальну ширину viewport;
- максимальну ширину viewport;
- мінімальний розмір шрифту;
- максимальний розмір шрифту.

Наприклад:

    Мінімальна ширина: 360px
    Максимальна ширина: 1200px
    Мінімальний шрифт: 28px
    Максимальний шрифт: 56px

Обчисли коефіцієнт `vw` та базову частину `calc()`, а потім обмеж результат через `clamp()`.

Перевір результат у браузері.

### Вправа 4. Створи Hero-секцію

Зроби секцію з:
- великим заголовком;
- коротким описом;
- кнопкою;
- фоновим кольором;
- достатніми відступами.

Застосуй Fluid Typography до заголовка й, за потреби, опису.

Перевір, чи не стає секція надто високою на смартфоні.

### Вправа 5. Перевір доступність

Збільш масштаб сторінки та перевір:
- чи не перекриваються елементи;
- чи не обрізаються заголовки;
- чи залишаються доступними кнопки;
- чи не з'являється горизонтальне прокручування всієї сторінки;
- чи зберігається читабельність.

### Вправа 6. Створи типографічні токени

У файлі `typography.css` визнач:

    --font-size-body
    --font-size-h1
    --font-size-h2
    --font-size-h3
    --line-height-body
    --line-height-heading

Використай ці змінні на кількох сторінках або компонентах.

## 15. Що потрібно пам'ятати

- **Fluid Typography** — це плавна зміна розміру тексту залежно від доступного простору.
- `clamp()` задає мінімум, бажане значення та максимум.
- `vw` залежить від ширини viewport.
- `rem` допомагає створювати відносні типографічні значення.
- `clamp()` зазвичай безпечніший за необмежене масштабування через `vw`.
- Не кожен текст потребує Fluid Typography.
- Великі заголовки часто виграють від плавного масштабування.
- Основний текст може залишатися стабільного розміру.
- Розмір шрифту потрібно перевіряти разом із `line-height` і шириною контейнера.
- `max-width` допомагає контролювати довжину рядків.
- Медіазапити залишаються корисними, коли потрібна зміна композиції.
- CSS-змінні спрощують створення типографічної шкали.
- Контейнерні одиниці можуть бути корисними для компонентів, але не завжди потрібні.
- Перевіряй дизайн на різних розмірах viewport і зі збільшеним масштабом.
- Формула, яка математично працює, не обов'язково створює найкращий візуальний результат.
- Головна мета — адаптивність і читабельність, а не використання якомога більшої кількості CSS-функцій.

## 16. Мінішпаргалка

| Завдання | CSS |
|---|---|
| Мінімальний, бажаний і максимальний розмір | `font-size: clamp(2rem, 5vw, 4rem);` |
| Розмір відносно viewport | `font-size: 5vw;` |
| Відносний розмір шрифту | `font-size: 1rem;` |
| Плавний розмір із `calc()` | `font-size: calc(1rem + 2vw);` |
| Обмежити ширину заголовка | `max-width: 18ch;` |
| Встановити міжрядковий інтервал | `line-height: 1.2;` |
| Створити типографічну змінну | `--font-size-h1: clamp(...);` |
| Використати змінну | `font-size: var(--font-size-h1);` |
| Застосувати контейнерну одиницю | `font-size: 5cqw;` |
| Створити дискретну адаптацію | `@media (min-width: 48rem) { ... }` |

### Базовий шаблон

    :root {
      --font-size-body: 1rem;
      --font-size-h1: clamp(2rem, 5vw, 4rem);
      --font-size-h2: clamp(1.5rem, 3vw, 2.5rem);
    }

    body {
      font-size: var(--font-size-body);
      line-height: 1.7;
    }

    h1 {
      font-size: var(--font-size-h1);
      line-height: 1.1;
    }

    h2 {
      font-size: var(--font-size-h2);
      line-height: 1.25;

## Висновок

**Fluid Typography — це спосіб створювати гнучку типографіку, яка адаптується до доступного простору без різких переходів між розмірами.**

Почни з `clamp()`, навчись задавати мінімальний, бажаний і максимальний розмір, а потім застосовуй цей підхід до заголовків і тих текстових ролей, яким справді потрібне масштабування.

Не забувай про ширину контейнера, міжрядковий інтервал, довжину заголовків і доступність. Плавна типографіка повинна працювати разом із композицією сторінки, а не замінювати її.

Головне правило: **масштабуй текст настільки, наскільки це покращує читабельність і зберігає типографічну ієрархію.**

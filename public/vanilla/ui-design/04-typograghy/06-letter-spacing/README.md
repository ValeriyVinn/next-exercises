# 06. Letter Spacing — Міжлітерний інтервал

Міжлітерний інтервал (*letter spacing*) — це відстань між символами тексту, яка впливає на його читабельність, візуальну щільність, ритм і загальне сприйняття інтерфейсу.

У UI-дизайні правильний міжлітерний інтервал допомагає зробити текст охайним, збалансованим і зручним для читання. Він особливо важливий для заголовків, кнопок, навігації, підписів, метаданих і тексту, написаного великими літерами.

**Мета:** навчитися керувати міжлітерним інтервалом, розуміти вплив його значень на текст і використовувати CSS-властивість `letter-spacing` для створення якісної типографіки.

---

## 1. Що таке Letter Spacing

Міжлітерний інтервал визначає додаткову відстань між символами тексту.

Порівняймо три варіанти:

    /* Нормальний інтервал */
    .text-normal {
      letter-spacing: normal;
    }

    /* Збільшений інтервал */
    .text-wide {
      letter-spacing: 0.08em;
    }

    /* Зменшений інтервал */
    .text-tight {
      letter-spacing: -0.03em;
    }

Візуально це можна уявити так:

    Нормальний:     TYPOGRAPHY
    Збільшений:     T Y P O G R A P H Y
    Зменшений:      TYPOGRAPHY (щільніше)

Це схематичне зображення: фактична відстань залежить від шрифту, розміру тексту та заданого значення.

### Для чого використовують letter spacing

- Для покращення вигляду коротких заголовків.
- Для оформлення тексту великими літерами.
- Для розрізнення рівнів заголовків.
- Для створення візуального стилю бренду.
- Для покращення сприйняття коротких підписів.
- Для балансування щільності тексту.

Важливо: збільшення міжлітерного інтервалу не завжди покращує читабельність. Для довгих текстів надмірне розрідження може ускладнювати сприйняття слів.

---

## 2. CSS-властивість letter-spacing

Властивість `letter-spacing` задає додатковий інтервал між символами.

Синтаксис:

    selector {
      letter-spacing: value;
    }

Приклад:

    h1 {
      font-size: 3rem;
      letter-spacing: -0.04em;
    }

У цьому прикладі заголовок має трохи щільніше розташовані символи.

### Основні значення

| Значення | Результат |
|---|---|
| `normal` | Звичайний інтервал, визначений шрифтом |
| `0` | Нульовий додатковий інтервал |
| `1px` | Додаткова відстань у 1 піксель |
| `0.05em` | Додаткова відстань, пропорційна розміру шрифту |
| `-0.02em` | Зменшення інтервалу між символами |

Зверни увагу: `normal` і `0` зазвичай виглядають однаково, але `normal` залишає браузеру стандартне значення інтервалу, визначене шрифтом.

---

## 3. Додатний, нульовий і від'ємний інтервал

### 3.1. Додатний інтервал

Додатне значення збільшує відстань між символами.

    .eyebrow {
      letter-spacing: 0.12em;
    }

Підходить для:

- коротких підписів над заголовками;
- навігаційних елементів;
- написів великими літерами;
- невеликих метаданих;
- окремих декоративних текстових елементів.

Приклад:

    <p class="eyebrow">НАШІ ПОСЛУГИ</p>
    <h1>Створюємо цифрові продукти</h1>

    .eyebrow {
      font-size: 0.75rem;
      font-weight: 700;
      letter-spacing: 0.12em;
      text-transform: uppercase;
    }

Для короткого напису збільшений інтервал може створити відчуття легкості та чіткої структури.

### 3.2. Нульовий інтервал

Нульове значення не додає додаткової відстані між символами.

    .body-text {
      letter-spacing: 0;
    }

Це корисно, коли потрібно явно скинути раніше задане значення.

У більшості випадків для основного тексту достатньо стандартного значення шрифту:

    p {
      letter-spacing: normal;
    }

### 3.3. Від'ємний інтервал

Від'ємне значення зменшує відстань між символами.

    h1 {
      letter-spacing: -0.04em;
    }

Може використовуватися для:

- великих заголовків;
- коротких акцентних написів;
- великих чисел;
- логотипоподібних текстових елементів.

Приклад:

    .hero-title {
      font-size: clamp(2.5rem, 6vw, 5rem);
      font-weight: 800;
      letter-spacing: -0.045em;
      line-height: 1.05;
    }

Надмірно від'ємний інтервал робить текст стиснутим і може спричинити візуальне злиття символів.

**Правило:** від'ємні значення використовуй обережно, особливо для дрібного тексту та шрифтів із вузькими формами символів.

## 4. Одиниці вимірювання

Для `letter-spacing` найчастіше використовують `px`, `em` і `rem`.

### 4.1. Пікселі — px

    .button {
      letter-spacing: 1px;
    }

Переваги:

- значення легко зрозуміти;
- інтервал має фіксований розмір;
- зручно для невеликих, точно налаштованих елементів.

Недолік: фіксована відстань не масштабується пропорційно до розміру шрифту.

Наприклад, `1px` може бути помітним для тексту розміром `12px`, але менш помітним для заголовка розміром `48px`.

### 4.2. Відносна одиниця em

`em` задає інтервал відносно розміру шрифту самого елемента.

    .heading {
      font-size: 2rem;
      letter-spacing: -0.03em;
    }

Якщо обчислений розмір шрифту становить `32px`, то `-0.03em` відповідає приблизно `-0.96px` додаткового інтервалу.

Формула:

    letter-spacing у px = значення em × розмір шрифту у px

Приклади:

    0.05em × 16px = 0.8px
    0.1em × 12px = 1.2px
    -0.04em × 48px = -1.92px

Перевага `em`: інтервал масштабується разом із розміром шрифту.

### 4.3. Одиниця rem

    .navigation {
      letter-spacing: 0.05rem;
    }

`rem` залежить від розміру шрифту кореневого елемента, зазвичай `html`.

Якщо базовий розмір кореневого шрифту дорівнює `16px`, тоді `0.05rem` становить `0.8px`.

Однак для міжлітерного інтервалу `em` часто зручніший, тому що автоматично адаптується до розміру конкретного текстового елемента.

### Що вибрати

| Одиниця | Коли використовувати |
|---|---|
| `px` | Коли потрібна фіксована точність |
| `em` | Коли інтервал має масштабуватися разом із текстом |
| `rem` | Коли потрібна прив'язка до кореневого розміру шрифту |
| `normal` | Коли достатньо стандартного інтервалу |

**Практична рекомендація:** для заголовків і коротких підписів починай із `em`, а для дрібних точкових коригувань можна використовувати `px`.

## 5. Letter Spacing і великі літери

Текст у верхньому регістрі (*uppercase*) часто має кращий вигляд із трохи збільшеним міжлітерним інтервалом.

Приклад:

    .label {
      font-size: 0.75rem;
      font-weight: 700;
      text-transform: uppercase;
      letter-spacing: 0.1em;
    }

HTML:

    <span class="label">Нові можливості</span>

Зверни увагу на три властивості:

- `text-transform: uppercase` переводить літери у верхній регістр.
- `font-weight: 700` робить текст жирнішим.
- `letter-spacing: 0.1em` збільшує інтервал між символами.

Ці властивості вирішують різні завдання, тому не варто плутати їх.

### Чому великі літери потребують уваги

- Великі літери можуть утворювати візуально щільний рядок.
- Додатковий інтервал іноді полегшує розпізнавання короткого напису.
- Занадто широкий інтервал робить слово розірваним.
- Для довгих написів uppercase може бути менш зручним для читання.

Не потрібно автоматично додавати інтервал до кожного напису великими літерами. Оцінюй конкретний шрифт і реальний результат.

---

## 6. Letter Spacing для різних елементів UI

### 6.1. Заголовки

Великі заголовки часто добре виглядають із трохи від'ємним інтервалом.

    h1 {
      font-size: clamp(2.5rem, 6vw, 5rem);
      font-weight: 800;
      letter-spacing: -0.04em;
      line-height: 1.05;
    }

Для заголовків середнього розміру може вистачити стандартного інтервалу:

    h2 {
      font-size: 2rem;
      font-weight: 700;
      letter-spacing: -0.02em;
      line-height: 1.2;
    }

Це лише початкові орієнтири. Не кожному шрифту потрібне від'ємне значення.

### 6.2. Основний текст

Для абзаців зазвичай краще залишати стандартний інтервал.

    p {
      font-size: 1rem;
      line-height: 1.6;
      letter-spacing: normal;
    }

Не додавай великий інтервал до всього основного тексту без конкретної причини.

### 6.3. Кнопки

Для короткого тексту кнопок можна використовувати невелике додатне значення.

    .button {
      font-size: 0.875rem;
      font-weight: 600;
      letter-spacing: 0.02em;
    }

Наприклад:

    <button class="button">Зареєструватися</button>

Якщо текст кнопки довгий, інтервал не повинен погіршувати читання або спричиняти небажане перенесення.

### 6.4. Навігація

    .nav-link {
      font-size: 0.875rem;
      font-weight: 600;
      letter-spacing: 0.01em;
    }

Для навігації важливі насамперед читабельність, зрозумілість і зручність сканування.

### 6.5. Метадані та підписи

    .metadata {
      font-size: 0.75rem;
      font-weight: 600;
      letter-spacing: 0.04em;
      color: #666;
    }

Для маленького тексту не використовуй надто великий інтервал: символи можуть візуально роз'єднуватися.

---

## 7. Letter Spacing у системі типографіки

У дизайн-системі можна створити невеликий набір стандартних значень.

Наприклад:

    :root {
      --tracking-tight: -0.04em;
      --tracking-normal: 0;
      --tracking-wide: 0.04em;
      --tracking-wider: 0.1em;
    }

Використання:

    .hero-title {
      letter-spacing: var(--tracking-tight);
    }

    .body-text {
      letter-spacing: var(--tracking-normal);
    }

    .button {
      letter-spacing: var(--tracking-wide);
    }

    .eyebrow {
      letter-spacing: var(--tracking-wider);
    }

Переваги:

- узгоджена типографіка;
- повторне використання значень;
- швидке налаштування стилю всього сайту;
- простіша підтримка CSS;
- менше випадкових значень у різних компонентах.

Не потрібно створювати багато змінних заради самих змінних. Почни з кількох значень і додавай нові лише за потреби.

## 8. Letter Spacing і адаптивний дизайн

Зміна розміру екрана впливає на розмір заголовків, довжину рядків і загальне сприйняття інтервалу.

Наприклад:

    .hero-title {
      font-size: clamp(2rem, 5vw, 4.5rem);
      letter-spacing: -0.035em;
      line-height: 1.08;
    }

Завдяки `em` інтервал масштабується разом із розміром шрифту.

Якщо потрібне окреме налаштування для вузьких екранів:

    .hero-title {
      font-size: clamp(2rem, 5vw, 4.5rem);
      letter-spacing: -0.035em;
      line-height: 1.08;
    }

    @media (max-width: 480px) {
      .hero-title {
        letter-spacing: -0.02em;
      }
    }

На маленьких екранах можна зробити інтервал менш від'ємним, якщо текст виглядає надто щільним.

Але не додавай медіазапити автоматично. Спочатку перевір, чи адаптація через `em` уже дає потрібний результат.

## 9. Взаємодія з іншими властивостями типографіки

Міжлітерний інтервал не варто налаштовувати ізольовано. Він працює разом з іншими властивостями.

### 9.1. font-size

Розмір шрифту впливає на фактичний розмір інтервалу, особливо коли використовується `em`.

    h1 {
      font-size: 3rem;
      letter-spacing: -0.04em;
    }

### 9.2. font-weight

Жирніший шрифт може виглядати щільніше, але це залежить від гарнітури.

    .heading {
      font-weight: 800;
      letter-spacing: -0.03em;
    }

Не компенсуй кожну зміну жирності автоматичним збільшенням або зменшенням інтервалу. Спочатку перевір результат.

### 9.3. line-height

`line-height` визначає вертикальну відстань між рядками, а `letter-spacing` — додатковий горизонтальний інтервал між символами.

    .title {
      font-size: 3rem;
      line-height: 1.1;
      letter-spacing: -0.035em;
    }

Це різні властивості, які не замінюють одна одну.

### 9.4. font-family

Різні шрифти мають різну ширину символів і різні пропорції.

    .heading {
      font-family: Arial, sans-serif;
      letter-spacing: -0.03em;
    }

    .body {
      font-family: Georgia, serif;
      letter-spacing: normal;
    }

Значення, яке добре виглядає в одному шрифті, може бути невдалим в іншому.

**Висновок:** підбирай інтервал після вибору шрифту, розміру та жирності.

## 10. Типові помилки

### Помилка 1. Надмірне розрідження тексту

    /* Не найкращий варіант для довгого тексту */
    p {
      letter-spacing: 0.15em;
    }

Чому це проблема:

- слова стають візуально розірваними;
- читання може сповільнюватися;
- рядки займають більше місця;
- абзаци виглядають неприродно.

Краще:

    p {
      letter-spacing: normal;
      line-height: 1.6;
    }

### Помилка 2. Надто від'ємне значення

    /* Потенційно проблемне значення */
    h1 {
      letter-spacing: -0.12em;
    }

Чому це проблема:

- символи можуть візуально зливатися;
- форма окремих літер стає менш виразною;
- заголовок може виглядати непропорційно щільним.

Краще почати з меншого від'ємного значення та перевірити результат у браузері.

    h1 {
      letter-spacing: -0.03em;
    }

### Помилка 3. Однакове значення для всіх елементів

    /* Надто узагальнене правило */
    * {
      letter-spacing: 0.05em;
    }

Це може погіршити читабельність абзаців, форм, кнопок і дрібних підписів.

Краще налаштовувати інтервал на рівні типографічних компонентів.

    h1 {
      letter-spacing: -0.03em;
    }

    p {
      letter-spacing: normal;
    }

    .eyebrow {
      letter-spacing: 0.1em;
    }

### Помилка 4. Використання px без урахування розміру шрифту

    .small-text {
      font-size: 0.75rem;
      letter-spacing: 2px;
    }

Для маленького тексту `2px` може бути надто великим значенням.

Краще перевірити відносний інтервал:

    .small-text {
      font-size: 0.75rem;
      letter-spacing: 0.04em;
    }

Це не універсально правильне значення, а лише більш пропорційна початкова точка.

### Помилка 5. Ігнорування реального шрифту

Якщо змінити `font-family`, попереднє значення `letter-spacing` може вже не виглядати добре.

Рішення: після зміни шрифту повторно перевірити заголовки, кнопки, навігацію та підписи.

### Помилка 6. Налаштування лише за скриншотом

Текст може виглядати добре в одному розмірі екрана, але погано — на іншому.

Рішення: перевіряй типографіку в браузері на різних ширинах і з реальним текстовим вмістом.

## 11. Практичний приклад: типографіка картки

HTML:

    <article class="card">
      <p class="card__eyebrow">ОСВІТА</p>

      <h2 class="card__title">
        Вивчай програмування крок за кроком
      </h2>

      <p class="card__description">
        Практичні завдання допоможуть закріпити знання
        та поступово створювати власні застосунки.
      </p>

      <a class="card__link" href="#">
        Дізнатися більше
      </a>
    </article>

CSS:

    .card {
      max-width: 420px;
      padding: 24px;
      border: 1px solid #ddd;
      border-radius: 12px;
      font-family: Arial, sans-serif;
    }

    .card__eyebrow {
      margin: 0 0 12px;
      font-size: 0.75rem;
      font-weight: 700;
      letter-spacing: 0.1em;
      text-transform: uppercase;
      color: #666;
    }

    .card__title {
      margin: 0 0 16px;
      font-size: 1.75rem;
      font-weight: 700;
      line-height: 1.2;
      letter-spacing: -0.025em;
    }

    .card__description {
      margin: 0 0 20px;
      font-size: 1rem;
      line-height: 1.6;
      letter-spacing: normal;
      color: #444;
    }

    .card__link {
      font-size: 0.875rem;
      font-weight: 600;
      letter-spacing: 0.02em;
      color: #155eef;
    }

### Що тут відбувається

- `card__eyebrow` має збільшений інтервал для короткого напису великими літерами.
- `card__title` має трохи від'ємний інтервал, щоб заголовок виглядав компактніше.
- `card__description` використовує стандартний інтервал для комфортного читання.
- `card__link` має невелике додатне значення для акценту.

Це приклад системного підходу: кожен тип тексту отримує значення відповідно до своєї функції.

## 12. Як перевіряти Letter Spacing у браузері

Під час роботи над інтерфейсом можна змінювати `letter-spacing` безпосередньо в DevTools.

Послідовність:

1. Відкрий сторінку у браузері.
2. Відкрий DevTools.
3. Вибери потрібний текстовий елемент.
4. Знайди CSS-властивість `letter-spacing`.
5. Змінюй значення, наприклад від `normal` до `0.05em` або `-0.03em`.
6. Порівняй вигляд тексту з початковим варіантом.
7. Перевір текст на вузькому та широкому екранах.
8. Перенеси вдалі значення у файл CSS.

### Що оцінювати

- Чи легко розпізнаються окремі символи?
- Чи зберігається цілісність слів?
- Чи пасує інтервал до ваги та розміру шрифту?
- Чи не виглядає заголовок надто щільним?
- Чи не займає текст зайвого місця?
- Чи зручно читати його на мобільному екрані?

**Порада:** змінюй одну властивість за раз. Так легше зрозуміти, який саме параметр покращив або погіршив результат.

## 13. Практичні вправи

### Вправа 1. Порівняння інтервалів

Створи три однакові заголовки:

    <h2 class="title title--normal">Digital Products</h2>
    <h2 class="title title--wide">Digital Products</h2>
    <h2 class="title title--tight">Digital Products</h2>

CSS:

    .title {
      font-size: 2rem;
      font-weight: 700;
    }

    .title--normal {
      letter-spacing: normal;
    }

    .title--wide {
      letter-spacing: 0.06em;
    }

    .title--tight {
      letter-spacing: -0.04em;
    }

Завдання:

- Порівняй три варіанти.
- Визнач, який виглядає найкраще для заголовка.
- Перевір, чи зміниться результат з іншим шрифтом.
- Зроби висновок, чому одного універсального значення немає.

### Вправа 2. Оформлення підпису

Створи короткий підпис над заголовком.

    <p class="eyebrow">НАВЧАННЯ ПРОГРАМУВАННЯ</p>
    <h1>Створюй власні застосунки</h1>

Спробуй:

    .eyebrow {
      font-size: 0.75rem;
      font-weight: 700;
      text-transform: uppercase;
      letter-spacing: 0.08em;
    }

Завдання:

- Зміни `letter-spacing` на `0.04em`.
- Зміни його на `0.12em`.
- Порівняй читабельність.
- Перевір, чи не стає підпис занадто довгим на вузькому екрані.

### Вправа 3. Налаштування картки

Використай картку з практичного прикладу.

Завдання:

- Залиши основний текст зі значенням `normal`.
- Підбери інтервал для заголовка.
- Підбери інтервал для кнопки або посилання.
- Перевір картку на мобільному екрані.
- Запиши, чому ти вибрав саме ці значення.

### Вправа 4. Мініексперимент із шрифтами

Використай два різні шрифти для одного заголовка.

Завдання:

- Порівняй ширину тексту.
- Перевір значення `normal`, `-0.02em` і `-0.04em`.
- Визнач, чи однакове значення підходить обом шрифтам.
- Зроби висновок про роль гарнітури у типографіці.

## 14. Що потрібно пам'ятати

✔ `letter-spacing` задає додатковий інтервал між символами.

✔ `normal` використовує стандартний інтервал шрифту.

✔ Додатне значення збільшує інтервал.

✔ Від'ємне значення зменшує інтервал.

✔ `em` зручний для масштабування інтервалу разом із розміром тексту.

✔ Великі літери можуть виглядати краще з трохи збільшеним інтервалом, але це не обов'язкове правило.

✔ Для основного тексту зазвичай достатньо `normal`.

✔ Для великих заголовків іноді доречний невеликий від'ємний інтервал.

✔ Для кнопок і підписів можна використовувати невелике додатне значення.

✔ Значення потрібно підбирати з урахуванням `font-family`, `font-size` і `font-weight`.

✔ Надмірний інтервал може погіршити читабельність.

✔ Після зміни шрифту варто повторно перевірити типографіку.

✔ Результат потрібно оцінювати на реальному тексті та різних розмірах екрана.

## 15. Типові питання на співбесіді

**1. Що таке `letter-spacing`?**

CSS-властивість, яка задає додаткову відстань між символами тексту.

**2. Яке значення збільшує міжлітерний інтервал?**

Додатне значення, наприклад `letter-spacing: 0.05em`.

**3. Що робить від'ємний `letter-spacing`?**

Зменшує відстань між символами, роблячи текст щільнішим.

**4. Чим відрізняються `letter-spacing` і `line-height`?**

`letter-spacing` впливає на горизонтальний інтервал між символами, а `line-height` — на висоту рядка та вертикальне розташування рядків тексту.

**5. Чому для великих заголовків іноді використовують від'ємний інтервал?**

Щоб зробити великі літери візуально компактнішими. Це залежить від конкретного шрифту та дизайну.

**6. Чому для основного тексту часто залишають `letter-spacing: normal`?**

Тому що стандартний інтервал шрифту зазвичай забезпечує природну форму слів і комфортне читання.

**7. Чим відрізняються `px` і `em` у `letter-spacing`?**

`px` задає фіксовану відстань, а `em` масштабується відносно розміру шрифту елемента.

**8. Чи потрібно збільшувати інтервал для кожного тексту у верхньому регістрі?**

Ні. Це поширений дизайнерський прийом, але остаточне рішення залежить від шрифту, розміру та призначення тексту.

**9. Чому не варто задавати великий `letter-spacing` усім елементам через універсальний селектор?**

Тому що заголовки, абзаци, кнопки й дрібні підписи мають різні потреби щодо читабельності.

**10. Як правильно підібрати `letter-spacing`?**

Почати зі стандартного значення, змінювати інтервал невеликими кроками, перевіряти результат із вибраним шрифтом і тестувати на різних розмірах екрана.

- Розумієш, як `em` залежить від розміру шрифту.

- Враховуєш адаптивність і довжину тексту.

- Визначаєш, де типографічний акцент допомагає ієрархії, а де заважає читанню.

- Приймаєш рішення на основі читабельності, функції тексту та візуальної ієрархії, а не лише естетичних уподобань.

## 17. Мінішпаргалка

| Завдання | Приклад |
|---|---|
| Стандартний інтервал | `letter-spacing: normal;` |
| Нульовий додатковий інтервал | `letter-spacing: 0;` |
| Трохи збільшити інтервал | `letter-spacing: 0.03em;` |
| Збільшити інтервал для короткого підпису | `letter-spacing: 0.1em;` |
| Трохи ущільнити заголовок | `letter-spacing: -0.02em;` |
| Ущільнити великий заголовок | `letter-spacing: -0.04em;` |
| Створити змінну | `--tracking-tight: -0.04em;` |

Ці значення — стартові приклади, а не універсальні стандарти. Підбирай їх під конкретний шрифт, розмір і призначення тексту.

## 18. Підсумок

`letter-spacing` — невелика CSS-властивість, яка може помітно змінити характер типографіки.

Для якісного UI важливо:

- використовувати стандартний інтервал як початкову точку;
- збільшувати інтервал лише там, де це допомагає сприйняттю;
- обережно застосовувати від'ємні значення;
- враховувати розмір, жирність і гарнітуру шрифту;
- розрізняти потреби заголовків, кнопок, підписів та основного тексту;
- перевіряти результат у браузері на різних ширинах екрана.

**Головне правило:** правильний міжлітерний інтервал — не той, який помітний сам по собі, а той, який допомагає тексту виглядати цілісно, підтримує візуальну ієрархію та залишається зручним для читання.

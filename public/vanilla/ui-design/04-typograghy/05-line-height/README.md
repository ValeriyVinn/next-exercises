# 05. Line Height — Міжрядковий інтервал у UI-дизайні

## 1. Що таке Line Height?

**Line Height (міжрядковий інтервал)** — це CSS-властивість, яка визначає висоту рядка тексту та впливає на вертикальну відстань між рядками.

У CSS для цього використовується властивість `line-height`.

    p {
      font-size: 16px;
      line-height: 1.5;
    }

У цьому прикладі:
- `font-size: 16px` — розмір шрифту.
- `line-height: 1.5` — висота рядка приблизно дорівнює 1,5 розміру шрифту, тобто 24 px.

    16px × 1.5 = 24px

Line Height впливає на:
- ✔ Читабельність тексту.
- ✔ Візуальну щільність текстових блоків.
- ✔ Комфорт читання довгих статей.
- ✔ Відстань між рядками заголовків.
- ✔ Висоту текстових компонентів.
- ✔ Загальний ритм сторінки.
- ✔ Відчуття простору в інтерфейсі.
- ✔ Адаптивність типографіки.

**Головний принцип:** міжрядковий інтервал повинен допомагати очам легко переходити від одного рядка до наступного.

---

## 2. Навіщо потрібен Line Height?

Навіть добре підібраний шрифт може бути незручним для читання, якщо рядки розташовані надто близько або надто далеко один від одного.

Основні завдання Line Height:

- ✔ Полегшувати читання довгого тексту.
- ✔ Відокремлювати рядки один від одного.
- ✔ Створювати візуальний ритм.
- ✔ Робити заголовки компактними та виразними.
- ✔ Контролювати висоту текстових блоків.
- ✔ Узгоджувати текст із розмірами компонентів.
- ✔ Підтримувати читабельність на різних екранах.
- ✔ Зменшувати візуальну втому під час читання.

Порівняй два варіанти:

    /* Надто щільний текст */
    .text-tight {
      font-size: 16px;
      line-height: 1;
    }

    /* Просторіший текст */
    .text-comfortable {
      font-size: 16px;
      line-height: 1.6;
    }

У першому випадку рядки розташовані щільно. У другому між ними більше вертикального простору.

Для основного тексту другий варіант часто буде комфортнішим, але остаточне значення залежить від гарнітури, довжини рядка та призначення тексту.

---

## 3. Основні поняття

### 3.1. Line Height

Властивість CSS, яка задає висоту рядка тексту.

    p {
      line-height: 1.5;
    }

### 3.2. Font Size

`font-size` визначає розмір шрифту.

    p {
      font-size: 16px;
    }

Line Height та Font Size працюють разом, але виконують різні завдання.

- `font-size` — розмір шрифту.
- `line-height` — висота рядка.

### 3.3. Unitless Line Height

**Unitless Line Height** — це значення `line-height` без одиниці вимірювання.

    p {
      font-size: 16px;
      line-height: 1.5;
    }

Браузер обчислює висоту рядка на основі розміру шрифту елемента.

    16px × 1.5 = 24px

Це один із найзручніших способів задавати міжрядковий інтервал.

### 3.4. Line Box

**Line Box** — це прямокутна область, яка формується для рядка тексту та бере участь у вертикальному компонуванні документа.

`line-height` впливає на висоту цієї області, але фактичне розташування символів залежить також від метрик конкретного шрифту.

### 3.5. Typography Rhythm

**Типографічний ритм** — це узгодженість розмірів тексту, міжрядкових інтервалів та відступів.

Наприклад:

    H1: великий текст, компактний line-height
    H2: середній заголовок, помірний line-height
    Body: основний текст, просторіший line-height
    Caption: невеликий текст, достатній line-height

Так сторінка стає послідовною та зручною для читання.

---

## 4. Значення Line Height у CSS

Властивість `line-height` може приймати різні типи значень.

### 4.1. Число без одиниці

Приклад:

    p {
      font-size: 16px;
      line-height: 1.5;
    }

Обчислення:

    16px × 1.5 = 24px

Переваги:
- ✔ Значення масштабується разом із розміром шрифту.
- ✔ Зручно використовувати в дизайн-системі.
- ✔ Добре працює з адаптивною типографікою.
- ✔ Дозволяє уникати зайвого дублювання значень.

Це рекомендований початковий варіант для більшості текстових стилів.

### 4.2. Пікселі (`px`)

Приклад:

    p {
      font-size: 16px;
      line-height: 24px;
    }

Висота рядка задана безпосередньо.

Переваги:
- ✔ Легко зрозуміти конкретне значення.
- ✔ Зручно для окремих компонентів із точними вимогами.

Недоліки:
- ⚠️ Якщо розмір шрифту зміниться, висота рядка автоматично не масштабуватиметься.
- ⚠️ Можна випадково зробити текст надто щільним після адаптивної зміни розміру.

### 4.3. `em`

Приклад:

    p {
      font-size: 16px;
      line-height: 1.5em;
    }

У цьому прикладі `1.5em` обчислюється як 24 px.

Проте `line-height` з одиницею може успадковуватися як уже обчислене значення, що створює несподівані результати у вкладених елементах.

Наприклад:

    .container {
      font-size: 16px;
      line-height: 1.5em;
    }

    .container h2 {
      font-size: 32px;
    }

У батьківському елементі `1.5em` обчислюється як 24 px. Якщо дочірній елемент успадкує це обчислене значення, воно не обов'язково збільшиться до 48 px.

Тому для більшості типографічних систем зручніше використовувати число без одиниці:

    .container {
      line-height: 1.5;
    }

### 4.4. Відсотки (`%`)

Приклад:

    p {
      font-size: 16px;
      line-height: 150%;
    }

Це задає висоту рядка, що становить 150% від відповідного розміру шрифту.

Однак відсоткове значення обчислюється та успадковується інакше, ніж число без одиниці. Для глобальної типографічної системи unitless-значення часто передбачуваніше.

### 4.5. Значення `normal`

Приклад:

    p {
      line-height: normal;
    }

`normal` дозволяє браузеру вибрати звичайну висоту рядка на основі метрик шрифту та правил відображення.

Це стандартне значення, яке часто працює прийнятно, але не дає дизайнеру точного контролю над вертикальним ритмом.

Для інтерфейсів із визначеною типографічною системою зазвичай зручніше задавати конкретне значення.

---

## 5. Як обчислюється Line Height?

Коли використовується число без одиниці, висота рядка обчислюється множенням `font-size` на `line-height`.

Формула:

    line box height = font-size × line-height

Приклади:

| Font Size | Line Height | Обчислена висота рядка |
|---:|---:|---:|
| 12px | 1.4 | 16.8px |
| 14px | 1.5 | 21px |
| 16px | 1.5 | 24px |
| 18px | 1.6 | 28.8px |
| 24px | 1.3 | 31.2px |
| 32px | 1.2 | 38.4px |
| 48px | 1.1 | 52.8px |

Це приблизні розрахунки висоти рядка, а не гарантована висота видимих символів.

Видимі літери можуть займати меншу частину line box, оскільки кожна гарнітура має власні метрики.

### 5.1. Приклад для основного тексту

    .article {
      font-size: 16px;
      line-height: 1.6;
    }

Обчислення:

    16px × 1.6 = 25.6px

### 5.2. Приклад для заголовка

    h1 {
      font-size: 48px;
      line-height: 1.15;
    }

Обчислення:

    48px × 1.15 = 55.2px

Заголовок має відносно компактний міжрядковий інтервал, що часто доречно для великого тексту.

---

## 6. Як вибирати Line Height для різних типів тексту

Різні текстові елементи мають різні потреби.

### 6.1. Основний текст (Body Text)

Для довгого тексту зазвичай потрібен достатній вертикальний простір.

Початковий варіант:

    body {
      font-size: 16px;
      line-height: 1.6;
    }

Орієнтовний діапазон для експериментів:

    1.4–1.7

Це не універсальне правило. Значення залежить від гарнітури, розміру тексту, ширини колонки та умов читання.

### 6.2. Великі заголовки

Для великих заголовків часто використовують компактніший інтервал.

    h1 {
      font-size: 48px;
      line-height: 1.1;
    }

Орієнтовний діапазон:

    1.0–1.25

Якщо значення занадто мале, рядки заголовка можуть накладатися або виглядати стиснутими.

### 6.3. Підзаголовки

    h2 {
      font-size: 32px;
      line-height: 1.25;
    }

Підзаголовок зазвичай потребує балансу між компактністю та читабельністю.

### 6.4. Допоміжний текст

    .caption {
      font-size: 14px;
      line-height: 1.5;
    }

Навіть невеликий текст повинен мати достатню висоту рядка, особливо якщо він може переноситися на кілька рядків.

### 6.5. Кнопки

    .button {
      font-size: 16px;
      line-height: 1.25;
    }

У кнопках текст зазвичай короткий, тому можна використовувати компактніший інтервал.

Водночас висота кнопки не повинна визначатися лише `line-height`. На неї також впливають вертикальні відступи, межі та мінімальні розміри компонента.

### 6.6. Навігація

    .nav-link {
      font-size: 16px;
      line-height: 1.4;
    }

Якщо назви пунктів меню можуть переноситися на кілька рядків, потрібно перевірити, чи не створює це проблем у компонуванні.

---

## 7. Line Height і читабельність

Читабельність залежить від поєднання кількох параметрів:
- Розміру шрифту.
- Товщини шрифту.
- Міжрядкового інтервалу.
- Довжини рядка.
- Міжлітерного інтервалу.
- Контрасту.
- Гарнітури.
- Структури контенту.

### 7.1. Надто малий Line Height

Приклад:

    .text {
      font-size: 16px;
      line-height: 1;
    }

Висота рядка дорівнює 16 px.

Можливі проблеми:
- Рядки виглядають надто щільними.
- Висхідні та низхідні елементи символів можуть візуально зближуватися.
- Текст важче читати в довгих абзацах.
- За певних умов рядки можуть накладатися.

### 7.2. Надто великий Line Height

Приклад:

    .text {
      font-size: 16px;
      line-height: 2.5;
    }

Висота рядка дорівнює 40 px.

Можливі проблеми:
- Текст виглядає надмірно розрідженим.
- Важче сприймати абзац як цілісний блок.
- Зростає загальна висота сторінки.
- Може порушуватися візуальний ритм.

### 7.3. Знайди баланс

Практичний підхід:

    .article {
      font-size: 1rem;
      line-height: 1.6;
    }

Потім перевір:
- Чи легко переходити від одного рядка до наступного.
- Чи не виглядає текст занадто щільним.
- Чи не розпадається абзац на окремі рядки.
- Чи підходить інтервал для вибраної гарнітури.

---

## 8. Line Height і довжина рядка

Міжрядковий інтервал потрібно оцінювати разом із шириною текстового блоку.

Якщо рядок надто довгий, очам складніше знаходити початок наступного рядка.

Якщо рядок надто короткий, текст може часто переноситися, через що читання сповільнюється.

Приклад:

    .article {
      max-width: 70ch;
      font-size: 1rem;
      line-height: 1.6;
    }

`ch` — одиниця, приблизно пов'язана з шириною символу `0` у поточному шрифті. Вона часто використовується для обмеження ширини текстових блоків.

Значення `70ch` — лише приклад. Потрібно враховувати гарнітуру, мову та тип контенту.

### Практичне правило

Не намагайся виправити надто довгі рядки лише збільшенням `line-height`.

Для читабельності потрібно узгодити:
- Ширину текстового контейнера.
- Розмір шрифту.
- Міжрядковий інтервал.
- Відступи між абзацами.

---

## 9. Line Height і абзаци

Міжрядковий інтервал визначає відстань між рядками всередині абзацу.

Відстань між абзацами зазвичай контролюють через `margin` або інші правила компонування.

Це різні речі.

### 9.1. Line Height усередині абзацу

    p {
      line-height: 1.6;
    }

### 9.2. Відступ між абзацами

    p {
      margin-block: 0 1rem;
    }

### 9.3. Разом

    .article p {
      font-size: 1rem;
      line-height: 1.6;
      margin-block: 0 1rem;
    }

У цьому прикладі:
- `line-height` створює вертикальний простір між рядками.
- `margin-block` створює простір після абзацу.

Не потрібно збільшувати `line-height` лише для того, щоб віддалити один абзац від іншого.

---

## 10. Line Height і заголовки з кількома рядками

Великі заголовки часто займають два або більше рядків.

Приклад:

    Створюй власні
    JavaScript-застосунки

Якщо міжрядковий інтервал надто великий, заголовок може займати забагато вертикального простору.

Якщо надто малий — рядки можуть виглядати стиснутими.

Приклад CSS:

    .hero-title {
      font-size: clamp(2.5rem, 5vw, 4.5rem);
      line-height: 1.1;
      max-width: 12ch;
    }

Тут:
- `clamp()` обмежує адаптивний розмір шрифту.
- `line-height` робить великий заголовок компактнішим.
- `max-width` обмежує ширину заголовка.

### Що перевіряти?

- Чи не накладаються рядки.
- Чи зберігається читабельність.
- Чи не виглядає заголовок надто щільним.
- Чи правильно переноситься текст на вузьких екранах.
- Чи не перекриває заголовок інші елементи.

---

## 11. Line Height у адаптивному дизайні

Адаптивність стосується не лише `font-size`, а й міжрядкового інтервалу.

Якщо розмір шрифту змінюється, відносний `line-height` автоматично масштабується разом із ним.

Приклад:

    h1 {
      font-size: clamp(2rem, 4vw, 3.5rem);
      line-height: 1.15;
    }

Тут не потрібно окремо обчислювати висоту рядка для кожного розміру екрана.

### 11.1. Media Queries

Іноді на різних екранах потрібні різні значення.

    .hero-title {
      font-size: 3.5rem;
      line-height: 1.1;
    }

    @media (max-width: 600px) {
      .hero-title {
        font-size: 2.25rem;
        line-height: 1.2;
      }
    }

У цьому випадку на вузьких екранах заголовок стає меншим, а відносний міжрядковий інтервал трохи збільшується.

Це лише приклад. Не кожен заголовок потребує окремого медіазапиту для `line-height`.

### 11.2. Не зменшуй інтервал автоматично на мобільному

Мобільний екран не означає, що міжрядковий інтервал повинен бути меншим.

Для основного тексту достатній інтервал залишається важливим на будь-якому пристрої.

Рішення потрібно приймати з урахуванням:
- Розміру шрифту.
- Ширини колонки.
- Довжини рядків.
- Особливостей гарнітури.
- Типу контенту.

---

## 12. Line Height і доступність

Міжрядковий інтервал впливає на зручність читання, особливо для довгого контенту.

### 12.1. Рекомендації WCAG

У WCAG 2.2 критерій 1.4.12 Text Spacing визначає вимоги до того, щоб контент залишався доступним, коли користувач змінює текстові інтервали.

Серед контрольних значень:
- Висота рядка — щонайменше 1.5 розміру шрифту.
- Інтервал після абзаців — щонайменше 2 розміри шрифту.
- Міжлітерний інтервал — щонайменше 0.12 розміру шрифту.
- Інтервал між словами — щонайменше 0.16 розміру шрифту.

Ці значення є умовами перевірки для відповідного критерію доступності, а не вимогою встановлювати саме такі значення для кожного елемента в початковому дизайні.

Важливо, щоб після застосування цих налаштувань користувачем не втрачалися контент або функціональність.

### 12.2. Не обрізай текст за фіксованою висотою

Проблемний приклад:

    .description {
      height: 48px;
      line-height: 24px;
      overflow: hidden;
    }

Якщо текст збільшиться або перенесеться на додаткові рядки, частина інформації може стати недоступною.

Краще дозволяти текстовому блоку зростати, якщо дизайн не вимагає іншої поведінки.

### 12.3. Перевір масштабування

Після збільшення тексту перевір:
- ✔ Чи не накладаються рядки.
- ✔ Чи не обрізається текст.
- ✔ Чи не перекриваються компоненти.
- ✔ Чи залишаються видимими повідомлення та інструкції.
- ✔ Чи можна користуватися кнопками й формами.
- ✔ Чи зберігається логічний порядок читання.

## 14. Line Height і дизайн-система

У дизайн-системі можна визначити узгоджені значення `line-height` для різних типографічних ролей.

Приклад:

| Токен | Значення | Призначення |
|---|---:|---|
| `--leading-tight` | 1.1 | Великі заголовки |
| `--leading-heading` | 1.25 | Заголовки секцій |
| `--leading-normal` | 1.5 | Загальний текст |
| `--leading-relaxed` | 1.7 | Довгі тексти |

Це лише приклад. Значення потрібно узгоджувати з реальною гарнітурою та контентом.

### 14.1. CSS-токени

    :root {
      --leading-tight: 1.1;
      --leading-heading: 1.25;
      --leading-normal: 1.5;
      --leading-relaxed: 1.7;
    }

    h1 {
      line-height: var(--leading-tight);
    }

    h2,
    h3 {
      line-height: var(--leading-heading);
    }

    body {
      line-height: var(--leading-normal);
    }

    .article {
      line-height: var(--leading-relaxed);
    }

### 14.2. Чому токени корисні?

- ✔ Допомагають підтримувати послідовність.
- ✔ Зменшують кількість випадкових значень.
- ✔ Спрощують глобальні зміни.
- ✔ Допомагають узгоджувати дизайн і код.
- ✔ Дозволяють швидко налаштовувати типографіку.

### 14.3. Не потрібно створювати надто багато токенів

Якщо в невеликому проєкті достатньо трьох значень, не потрібно створювати десять.

Краще мати невелику систему, у якій кожне значення має конкретне призначення.

## 15. Типові помилки у Line Height

### Помилка 1. Використовувати однаковий інтервал для всього

Приклад:

    h1,
    h2,
    p,
    small {
      line-height: 1.5;
    }

Це технічно допустимо, але не завжди забезпечує найкращий результат.

Великі заголовки часто потребують компактнішого інтервалу, ніж довгий основний текст.

Краще:

    h1 {
      line-height: 1.1;
    }

    h2 {
      line-height: 1.25;
    }

    p {
      line-height: 1.6;
    }

### Помилка 2. Занадто малий інтервал у довгому тексті

    p {
      line-height: 1;
    }

Текст може виглядати стиснутим і бути незручним для читання.

Краще почати з більшого значення та перевірити його на реальному контенті.

### Помилка 3. Занадто великий інтервал у заголовках

    h1 {
      font-size: 48px;
      line-height: 2;
    }

Висота рядка буде приблизно 96 px. Для звичайного заголовка це може створити надмірні вертикальні проміжки.

### Помилка 4. Плутати Line Height і Margin

`line-height` впливає на висоту рядків усередині текстового елемента.

`margin` створює зовнішній простір навколо елемента.

Не варто використовувати `line-height` для керування відстанню між окремими абзацами.

### Помилка 5. Використовувати `em` без розуміння успадкування

Значення `line-height: 1.5em` обчислюється з урахуванням розміру шрифту, після чого може успадковуватися як обчислена довжина.

Для загальних текстових стилів часто простіше:

    body {
      line-height: 1.5;
    }

### Помилка 6. Задати фіксовану висоту текстового блока

    .text {
      height: 60px;
      overflow: hidden;
    }

Якщо текст зміниться або користувач збільшить шрифт, частина вмісту може бути обрізана.

Не задавай фіксовану висоту текстовому блоку без конкретної потреби та перевірки різних станів.

### Помилка 7. Ігнорувати довжину рядка

Навіть правильний `line-height` не компенсує надто довгі рядки.

Рішення: налаштувати ширину контейнера разом із розміром шрифту та міжрядковим інтервалом.

### Помилка 8. Змінювати Line Height лише заради компактності

Надмірно щільний текст може дозволити вмістити більше інформації на екрані, але погіршити читабельність.

Компактність повинна бути збалансована з потребами користувача.

### Помилка 9. Не перевіряти перенесення заголовків

Заголовок може виглядати добре в один рядок, але погано після перенесення.

Перевіряй багаторядкові заголовки на різних ширинах viewport.

### Помилка 10. Не тестувати збільшення тексту

Якщо макет працює лише з початковими значеннями, інтерфейс може втрачати читабельність після масштабування.

Перевіряй, чи не обрізаються рядки та чи можуть текстові блоки збільшувати висоту.

## 19. Типові питання на співбесіді

### Що таке `line-height`?

Це CSS-властивість, яка задає висоту рядка тексту та впливає на вертикальний простір між рядками.

### Чим відрізняються `font-size` і `line-height`?

`font-size` визначає розмір шрифту, а `line-height` — висоту рядка.

### Як обчислюється `line-height: 1.5`?

Якщо розмір шрифту становить 16 px, висота рядка приблизно дорівнює:

    16px × 1.5 = 24px

### Чому unitless Line Height часто зручніший?

Він масштабується разом із розміром шрифту та зазвичай краще працює зі спадкуванням у вкладених елементах.

### Чим `line-height` відрізняється від `margin`?

`line-height` впливає на висоту рядків усередині текстового елемента, а `margin` створює зовнішній простір навколо елемента.

### Який Line Height використовувати для основного тексту?

`1.5–1.7` може бути хорошою початковою точкою для експериментів, але значення залежить від гарнітури, розміру, ширини рядка та контенту.

### Чому заголовки часто мають менший Line Height?

Великі заголовки зазвичай краще виглядають із компактнішим міжрядковим інтервалом, який допомагає зберігати цілісність заголовка.

### Чому не варто задавати фіксовану висоту текстовому блоку?

Текст може переноситися на додаткові рядки або збільшуватися. Фіксована висота може призвести до обрізання контенту.

### Як Line Height пов'язаний із доступністю?

Достатній інтервал може полегшувати читання. Важливо також, щоб користувач міг змінювати текстові інтервали без втрати контенту та функціональності.

### Для чого потрібні токени Line Height?

Вони допомагають створити узгоджену систему міжрядкових інтервалів у всьому застосунку.

**Line Height — це важливий інструмент керування читабельністю, вертикальним ритмом і візуальною структурою тексту.**

Для якісної типографіки важливо:

1. Узгоджувати `line-height` із `font-size`.
2. Використовувати unitless-значення для передбачуваного масштабування.
3. Застосовувати компактніший інтервал для великих заголовків, якщо це покращує вигляд.
4. Забезпечувати достатній простір між рядками основного тексту.
5. Не плутати міжрядковий інтервал із відступами між абзацами.
6. Враховувати ширину текстового контейнера.
7. Не обрізати текст через жорстко задану висоту.
8. Перевіряти адаптивність і доступність.

**Головне правило:** хороший Line Height не привертає до себе уваги — він допомагає читати текст природно, без зайвих зусиль.

# 01. Fonts

Fonts (шрифти) — це основа типографіки в UI Design. Вони визначають, як текст виглядає, наскільки легко його читати та яке враження створює інтерфейс.

У UI Design шрифти використовуються для:

- відображення заголовків і основного тексту;
- формування візуального стилю інтерфейсу;
- створення ієрархії інформації;
- покращення читабельності;
- передавання характеру бренду;
- забезпечення доступності тексту;
- підтримки різних мов і систем письма;
- адаптації інтерфейсу до різних пристроїв.

Основні поняття, пов'язані зі шрифтами:

### Що потрібно пам'ятати

• Font — шрифт, який використовується для відображення тексту.

• Typeface — дизайн набору символів із певними візуальними характеристиками.

• Font family — сімейство шрифтів із пов'язаними стилями та накресленнями.

• Font size визначає розмір тексту.

• Font weight визначає товщину накреслення символів.

• Font style описує стиль накреслення, наприклад normal або italic.

• Serif — шрифти із засічками.

• Sans-serif — шрифти без засічок.

• Monospace — шрифти, у яких символи зазвичай займають однакову ширину.

• System font — шрифт, доступний у системі користувача.

• Web font — шрифт, який вебсторінка може завантажувати з файлу.

• Fallback font — запасний шрифт, який браузер використовує, якщо основний недоступний або не містить потрібного символу.

• Font stack — список шрифтів, які браузер перевіряє послідовно.

• Variable font може містити багато значень товщини та інших параметрів в одному файлі.

• Static font зазвичай містить окреме зафіксоване накреслення, наприклад Regular або Bold.

• WOFF2 — сучасний формат вебшрифтів із хорошим стисненням.

• Font licensing визначає, як дозволено використовувати шрифт.

• Не кожен шрифт містить символи всіх мов.

• Для українського інтерфейсу потрібно перевіряти підтримку кирилиці, зокрема українських літер.

• Гарний шрифт не обов'язково є читабельним для будь-якого розміру та будь-якого контексту.

• Вибір шрифту залежить від призначення інтерфейсу, аудиторії, читабельності та візуального стилю.

# Font

Font — конкретне накреслення шрифту, яке використовується для відображення символів.

Наприклад:

    Arial Regular
    Arial Bold
    Roboto Regular
    Roboto Bold
    Roboto Italic

Ці варіанти мають спільний дизайн у межах відповідних сімейств, але можуть відрізнятися товщиною або стилем.

У веброзробці поняття font часто використовується ширше — як загальна назва шрифту.

Наприклад, у CSS:

    body {
        font-family: Arial, sans-serif;
    }

Тут ми задаємо браузеру бажане сімейство шрифтів.

---

# Typeface

Typeface — візуальний дизайн набору символів.

Він визначає, як виглядають:

    letters
    numbers
    punctuation
    symbols
    diacritical marks

Наприклад, два typeface можуть мати однаковий текст, але зовсім різний вигляд.

    This is a heading.

Один варіант може бути геометричним і сучасним, інший — традиційним і книжковим.

Typeface впливає на:

- характер інтерфейсу;
- сприйняття бренду;
- читабельність;
- візуальну ієрархію;
- щільність тексту;
- загальне враження від дизайну.

### Font vs Typeface

У повсякденній роботі ці слова часто використовуються як синоніми.

Спрощено:

    Typeface → дизайн літер
    Font     → конкретне шрифтове накреслення або файл

У сучасних цифрових інструментах значення термінів може залежати від контексту.

# Font Family

Font family — сімейство шрифтів зі спільним дизайном.

Наприклад:

    Roboto
    Inter
    Open Sans
    Lato
    Merriweather
    Source Sans 3

У межах одного сімейства можуть бути різні накреслення:

    Regular
    Medium
    SemiBold
    Bold
    Italic

Наприклад:

    Inter Regular
    Inter Medium
    Inter SemiBold
    Inter Bold

Вони мають спільний візуальний характер, але відрізняються товщиною.

У CSS:

    body {
        font-family: "Inter", sans-serif;
    }

Назва сімейства береться в лапки, якщо містить пробіли або для кращої однозначності.

Наприклад:

    body {
        font-family: "Open Sans", sans-serif;
    }

# Основні категорії шрифтів

У CSS існують п'ять загальних категорій шрифтів:

    serif
    sans-serif
    monospace
    cursive
    fantasy

Це generic font families — загальні категорії, які браузер може зіставити з доступними шрифтами.

---

## Serif

Serif — шрифти із засічками.

Засічки — невеликі завершальні елементи штрихів літер.

Приклади:

    Georgia
    Times New Roman
    Merriweather
    Source Serif 4

Типові асоціації:

- традиційність;
- редакційний стиль;
- книжкова типографіка;
- академічність;
- формальність.

Де можуть використовуватися:

    editorial websites
    online magazines
    articles
    books
    educational platforms
    landing pages

Приклад:

    body {
        font-family: Georgia, serif;
    }

Serif не означає автоматично кращу читабельність або гіршу придатність для екранів.

Результат залежить від конкретного шрифту, розміру, інтервалів і якості відображення.

---

## Sans-serif

Sans-serif — шрифти без засічок.

Приклади:

    Arial
    Helvetica
    Inter
    Roboto
    Open Sans
    Lato
    Source Sans 3

Типові асоціації:

- сучасність;
- простота;
- нейтральність;
- технологічність;
- мінімалізм.

Де можуть використовуватися:

    dashboards
    web applications
    mobile interfaces
    navigation
    forms
    buttons
    product interfaces

Приклад:

    body {
        font-family: Arial, sans-serif;
    }

Sans-serif часто є зручним вибором для інтерфейсів, але не є універсально найкращим рішенням.

---

## Monospace

Monospace — шрифт, у якому символи зазвичай мають однакову ширину.

Приклади:

    Consolas
    Courier New
    JetBrains Mono
    IBM Plex Mono

Де використовуються:

    source code
    terminal interfaces
    code editors
    technical data
    identifiers
    tabular-like text

Приклад:

    code {
        font-family: "JetBrains Mono", monospace;
    }

Monospace допомагає вирівнювати символи в коді та технічних представленнях.

Для великих обсягів звичайного тексту такий шрифт не завжди є найзручнішим.

---

## Cursive

Cursive — категорія шрифтів, які імітують рукописний або каліграфічний стиль.

Приклад:

    .signature {
        font-family: cursive;
    }

Може використовуватися для:

    decorative headings
    signatures
    invitations
    short visual accents

У звичайному UI cursive варто використовувати обережно.

Не слід застосовувати його для довгих текстів, важливих інструкцій або дрібних елементів керування, якщо це погіршує читабельність.

---

## Fantasy

Fantasy — категорія декоративних шрифтів із виразним стилем.

Може використовуватися для:

    game interfaces
    themed websites
    decorative headings
    entertainment projects

Приклад:

    .game-title {
        font-family: fantasy;
    }

Конкретний результат залежить від доступних шрифтів у системі користувача.

Тому generic family не гарантує однакового вигляду на всіх пристроях.

---

# Generic Font Families

Generic font family — загальна категорія шрифтів.

Основні категорії:

    serif
    sans-serif
    monospace
    cursive
    fantasy
    system-ui
    ui-serif
    ui-sans-serif
    ui-monospace
    ui-rounded

Приклад:

    body {
        font-family: "Inter", sans-serif;
    }

Тут:

    "Inter"   → конкретне сімейство
    sans-serif → запасна загальна категорія

Якщо Inter недоступний, браузер спробує підібрати доступний sans-serif.

Для сучасних інтерфейсів також можна використовувати системні категорії:

    body {
        font-family: system-ui, sans-serif;
    }

`system-ui` дозволяє використовувати системний UI-шрифт операційної системи.

Це може зменшити потребу завантажувати окремий шрифт.

# Font Style

Font style — стиль накреслення шрифту.

У CSS найчастіше використовуються:

    normal
    italic
    oblique

Приклад:

    .text {
        font-style: normal;
    }

Курсив:

    .quote {
        font-style: italic;
    }

Похиле накреслення:

    .emphasis {
        font-style: oblique;
    }

Різниця:

    normal  → звичайне накреслення
    italic  → курсивне накреслення
    oblique → похиле накреслення

Italic може мати окремий дизайн літер, а oblique зазвичай представляє похилий варіант основного накреслення.

Фактичний результат залежить від наявних у шрифті накреслень і можливостей браузера.

---

# Font Weight

Font weight — товщина накреслення символів.

Поширені значення:

    100 → Thin
    200 → Extra Light
    300 → Light
    400 → Regular
    500 → Medium
    600 → SemiBold
    700 → Bold
    800 → ExtraBold
    900 → Black

Приклад:

    h1 {
        font-weight: 700;
    }

    p {
        font-weight: 400;
    }

Не кожен шрифт підтримує всі значення.

Якщо потрібне накреслення відсутнє, браузер може використати найближче доступне.

# Font Size

Font size — розмір тексту.

У CSS:

    body {
        font-size: 16px;
    }

Можна використовувати різні одиниці:

    px
    rem
    em
    %

Приклад:

    body {
        font-size: 1rem;
    }

    h1 {
        font-size: 2.5rem;
    }

Розмір тексту впливає на:

- читабельність;
- візуальну ієрархію;
- висоту блоків;
- щільність інформації;
- адаптивність інтерфейсу.

Для основного тексту часто використовують розмір близько 16–18 CSS px, але конкретне значення залежить від шрифту, аудиторії та контексту.

# Font Metrics

Font metrics — характеристики шрифту, які визначають розташування та розміри символів відносно базової лінії.

Основні поняття:

    baseline
    ascent
    descent
    line gap
    cap height
    x-height

## Baseline

Baseline — базова лінія, на якій розташовується основна частина символів.

Спрощено:

    letters
       ↓
    baseline

У звичайному тексті багато символів візуально спираються на цю лінію.

## Ascent

Ascent — відстань від baseline до верхньої межі основної зони символів відповідно до метрик шрифту.

## Descent

Descent — відстань від baseline до нижньої зони символів.

Наприклад, літери:

    g
    j
    p
    q
    y

можуть мати частини, які опускаються нижче baseline.

## Cap Height

Cap height — висота великих літер відносно baseline.

Наприклад:

    H
    E
    A

## X-height

X-height — висота малих літер без верхніх і нижніх виносних елементів.

Наприклад, висота літери:

    x

є типовим орієнтиром для цієї метрики.

X-height впливає на те, як великим або компактним здається текст за однакового значення font-size.

Два шрифти з однаковим CSS font-size можуть виглядати по-різному через відмінності у font metrics.

# Glyph

Glyph — конкретне графічне представлення символу або його форми у шрифті.

Наприклад, шрифт може містити гліфи для:

    A
    B
    a
    b
    0
    1
    ?
    !
    Ґ
    Є
    І
    Ї

Гліфи можуть також представляти лігатури або альтернативні форми символів.

Важливо розрізняти:

    Character → символ у тексті
    Glyph     → графічна форма, якою цей символ відображається

Один символ може мати різні гліфи залежно від шрифту та контексту.

Наприклад, деякі шрифти підтримують лігатури, у яких кілька літер відображаються як єдина графічна форма.

---

# Character та Unicode

Character — символ тексту.

Unicode — стандарт, який визначає кодові точки для символів різних систем письма.

Для українського тексту особливо важливо, щоб шрифт підтримував кирилицю.

Українські літери, які потрібно перевіряти:

    Ґ ґ
    Є є
    І і
    Ї ї

Приклад тестового рядка:

    Ґанок, ґудзик, Європа, Україна, Київ, їжак.

Якщо шрифт не має потрібного гліфа, браузер може використати інший шрифт для відповідного символу.

Це називається font fallback.

Через це окремі символи іноді виглядають інакше, ніж решта тексту.

---

# Font Coverage

Font coverage — набір символів, які підтримує шрифт.

Шрифт може підтримувати:

    Latin
    Cyrillic
    Greek
    Arabic
    Hebrew
    CJK
    mathematical symbols
    currency symbols
    punctuation

Підтримка певної писемності не означає, що шрифт містить абсолютно всі символи цієї писемності.

Для українського UI потрібно перевіряти:

- українську кирилицю;
- цифри;
- розділові знаки;
- лапки;
- тире;
- спеціальні символи;
- валютні символи, якщо вони використовуються.

Тестовий текст:

    Ґанок, ґудзик, Європа, Україна, Київ, їжак.
    «Типографіка» — важлива частина UI Design.
    Ціна: 1 299,99 ₴.

Перевіряй не лише англомовний демонстраційний текст, а й реальні тексти свого інтерфейсу.

# Static Fonts

Static font — файл шрифту з фіксованими параметрами накреслення.

Наприклад:

    Inter-Regular.woff2
    Inter-Medium.woff2
    Inter-SemiBold.woff2
    Inter-Bold.woff2

Кожен файл може відповідати окремому значенню font-weight.

Приклад підключення через CSS:

    @font-face {
        font-family: "MyFont";
        src: url("/fonts/my-font-regular.woff2") format("woff2");
        font-weight: 400;
        font-style: normal;
        font-display: swap;
    }

    @font-face {
        font-family: "MyFont";
        src: url("/fonts/my-font-bold.woff2") format("woff2");
        font-weight: 700;
        font-style: normal;
        font-display: swap;
    }

Тут ми описуємо два окремі накреслення.

Важливо, щоб значення `font-weight` відповідало реальному файлу.

---

# Variable Fonts

Variable font — шрифт, який може містити неперервний діапазон значень певних параметрів.

Наприклад:

    font-weight: 100–900

Замість кількох окремих файлів можна використовувати один variable font, який підтримує діапазон товщини.

Приклад:

    @font-face {
        font-family: "MyVariableFont";
        src: url("/fonts/my-variable-font.woff2") format("woff2");
        font-weight: 100 900;
        font-style: normal;
        font-display: swap;
    }

Використання:

    h1 {
        font-family: "MyVariableFont", sans-serif;
        font-weight: 750;
    }

Variable fonts можуть підтримувати різні осі:

    wght → weight
    wdth → width
    opsz → optical size
    slnt → slant
    ital → italic

Не кожен variable font підтримує всі ці осі.

Переваги:

- гнучке налаштування накреслення;
- менша кількість файлів у деяких сценаріях;
- можливість плавної зміни товщини;
- більше свободи для адаптивної типографіки.

Водночас variable font не завжди автоматично менший за всі статичні файли разом. Результат залежить від конкретного шрифту та способу його використання.

---

# Web Fonts

Web font — шрифт, який вебсторінка завантажує з файлу.

Він може бути розміщений:

    locally in the project
    on a font hosting service
    on a CDN

Наприклад, локальна структура:

    public/
    └── fonts/
        ├── inter-regular.woff2
        └── inter-bold.woff2

Підключення:

    @font-face {
        font-family: "Inter";
        src: url("/fonts/inter-regular.woff2") format("woff2");
        font-weight: 400;
        font-style: normal;
        font-display: swap;
    }

    body {
        font-family: "Inter", sans-serif;
    }

Web fonts дають змогу використовувати конкретний шрифт незалежно від того, чи встановлений він у користувача.

Але для цього необхідно враховувати:

- розмір файлів;
- час завантаження;
- ліцензію;
- підтримку потрібних символів;
- поведінку під час завантаження;
- можливі зміни макета.

---

# System Fonts

System font — системний шрифт операційної системи.

Приклад:

    body {
        font-family: system-ui, sans-serif;
    }

Переваги:

- зазвичай не потрібно завантажувати окремий файл;
- швидкий початковий рендеринг;
- знайомий користувачеві вигляд;
- можливе узгодження з нативними інтерфейсами операційної системи.

Недоліки:

- вигляд може відрізнятися між операційними системами;
- типографічний стиль менш контрольований;
- метрики можуть бути різними на різних пристроях.

System fonts добре підходять для багатьох інтерфейсів, але вибір залежить від дизайн-системи та вимог проєкту.

---

# Fallback Fonts

Fallback font — запасний шрифт, який браузер використовує, якщо попередній варіант недоступний або не має потрібного символу.

Приклад:

    body {
        font-family:
            "Inter",
            "Segoe UI",
            Arial,
            sans-serif;
    }

Браузер намагатиметься використати шрифти у визначеному порядку.

Спрощено:

    Inter
      ↓ unavailable
    Segoe UI
      ↓ unavailable
    Arial
      ↓ unavailable
    sans-serif
      ↓
    browser selects an available font

Fallback потрібен, тому що:

- вебшрифт може не завантажитися;
- шрифт може бути відсутнім;
- потрібний символ може не підтримуватися;
- мережа може бути недоступною.

Не варто залишати вебсторінку залежною лише від одного конкретного шрифту.

---

# Font Stack

Font stack — послідовність шрифтів, задана у CSS.

Приклад:

    body {
        font-family:
            "Inter",
            "Segoe UI",
            Arial,
            sans-serif;
    }

Структура:

    preferred font
        ↓
    alternative font
        ↓
    another fallback
        ↓
    generic family

Для системного UI:

    body {
        font-family:
            system-ui,
            -apple-system,
            BlinkMacSystemFont,
            "Segoe UI",
            sans-serif;
    }

Такий стек використовує системні шрифти на різних платформах, де вони доступні.

Важливо:

• Шрифти у стеку повинні відповідати призначенню інтерфейсу.

• Потрібно перевіряти кирилицю.

• Не слід додавати багато випадкових шрифтів без причини.

• Останній елемент зазвичай має бути generic font family.

• Fallback може змінювати ширину тексту, тому після його спрацювання макет може відрізнятися.

---

# Font Formats

Основні формати шрифтових файлів:

    WOFF2
    WOFF
    TTF
    OTF

## WOFF2

WOFF2 — сучасний формат вебшрифтів із ефективним стисненням.

Часто є хорошим вибором для вебпроєктів.

    font.woff2

## WOFF

WOFF — формат вебшрифтів, який передував WOFF2.

Може використовуватися для сумісності з певними середовищами.

    font.woff

## TTF

TTF — TrueType Font.

Поширений формат шрифтових файлів.

    font.ttf

## OTF

OTF — OpenType Font.

Підтримує можливості OpenType, які можуть використовуватися для типографічних функцій.

    font.otf

Для вебпроєктів часто віддають перевагу WOFF2, якщо він доступний і підтримується цільовими браузерами.

---

# OpenType

OpenType — формат шрифтів і набір типографічних можливостей.

Залежно від конкретного шрифту він може підтримувати:

    ligatures
    kerning
    alternate glyphs
    small caps
    stylistic sets
    numeral styles

Наприклад, деякі шрифти можуть автоматично замінювати певні комбінації літер на лігатури.

Інші можуть містити альтернативні форми символів або спеціальні варіанти цифр.

Не кожен шрифт підтримує всі можливості OpenType.

На початковому етапі достатньо знати, що шрифтовий файл може містити не лише базові форми символів, а й додаткові типографічні функції.

---

# Font Loading

Font loading — процес завантаження шрифту браузером.

Спрощено:

    browser requests page
        ↓
    browser reads CSS
        ↓
    browser discovers font
        ↓
    browser loads font file
        ↓
    browser renders text

Залежно від налаштувань браузер може спочатку показати текст запасним шрифтом, а потім замінити його завантаженим.

Це може спричинити зміну ширини тексту або висоти блоків.

Наприклад:

    fallback font
        ↓
    web font loads
        ↓
    text metrics change
        ↓
    layout may shift

Тому завантаження шрифтів потрібно враховувати під час проєктування UI.

---

# font-display

Властивість `font-display` у правилі `@font-face` визначає поведінку тексту під час завантаження вебшрифту.

Приклад:

    @font-face {
        font-family: "Inter";
        src: url("/fonts/inter-regular.woff2") format("woff2");
        font-weight: 400;
        font-style: normal;
        font-display: swap;
    }

Основні значення:

    auto
    block
    swap
    fallback
    optional

## swap

    font-display: swap;

Дозволяє показувати запасний шрифт, а після завантаження замінити його вебшрифтом.

Часто є практичним вибором для текстового контенту.

## block

    font-display: block;

Може приховувати текст на короткий початковий період очікування шрифту.

Тривалість і подальша поведінка визначаються правилами браузера.

## fallback

    font-display: fallback;

Використовує короткий період очікування та обмежене вікно для заміни запасного шрифту.

## optional

    font-display: optional;

Дозволяє браузеру вирішувати, чи використовувати завантажений шрифт у поточному сценарії, зважаючи на умови завантаження.

Для більшості початкових вебпроєктів варто знати насамперед:

    font-display: swap;

Але остаточний вибір залежить від вимог до продуктивності та візуальної стабільності.

---

# Font Rendering

Font rendering — процес перетворення текстових символів на видимі графічні форми.

На результат можуть впливати:

- операційна система;
- браузер;
- шрифтовий файл;
- роздільна здатність екрана;
- масштабування;
- параметри відображення;
- властивості CSS.

Один і той самий шрифт може трохи відрізнятися за виглядом на різних пристроях.

Тому UI потрібно перевіряти не лише в дизайнерському редакторі, а й у браузері.

---

# Readability vs Legibility

Ці поняття пов'язані, але мають різні значення.

## Legibility

Legibility — наскільки легко розрізняти окремі символи.

Наприклад:

    a
    e
    o

Якщо форми літер дуже схожі, їх може бути складніше розрізняти.

На legibility впливають:

- форма символів;
- товщина штрихів;
- розмір;
- контраст;
- відстань між символами;
- якість відображення.

## Readability

Readability — наскільки легко читати текст як послідовність слів, речень і абзаців.

На readability впливають:

- довжина рядка;
- line-height;
- розмір тексту;
- відстань між абзацами;
- структура контенту;
- контраст;
- вибір шрифту.

Спрощено:

    Legibility → легко розрізнити символи
    Readability → легко читати текст

Обидва поняття важливі для UI Design.

# Вибір шрифту для UI

Під час вибору шрифту потрібно враховувати призначення продукту.

## Web Application

Для вебзастосунку часто важливі:

    readability
    neutral appearance
    clear characters
    consistent metrics
    Cyrillic support

Приклад:

    body {
        font-family: "Inter", sans-serif;
    }

## Educational Website

Для освітнього сайту важливі:

    comfortable reading
    clear headings
    readable body text
    support for long articles

Можна використовувати sans-serif або serif залежно від характеру проєкту.

## Dashboard

Для dashboard важливі:

    compact text
    clear labels
    readable numbers
    consistent alignment

Для більшості тексту можна використовувати sans-serif, а для технічних значень — monospace, якщо це покращує сприйняття.

## Editorial Website

Для статей і журналів можна використовувати:

    serif headings
    sans-serif body text

Але можливі й інші комбінації.

## Developer Tool

Для коду та технічних даних може бути доречним:

    sans-serif → interface
    monospace  → source code

# Типові помилки під час вибору шрифтів

❌ Вибирати шрифт лише за зовнішнім виглядом.

Шрифт може бути красивим, але незручним для довгих текстів або малих розмірів.

---

❌ Не перевіряти українську кирилицю.

Деякі шрифти можуть не містити всіх необхідних українських літер.

---

❌ Використовувати декоративний шрифт для всього інтерфейсу.

Декоративні шрифти можуть погіршувати читабельність навігації, форм і довгих текстів.

---

❌ Використовувати надто багато сімейств шрифтів.

Це може зробити інтерфейс візуально неузгодженим і збільшити витрати на завантаження шрифтів.

---

❌ Завантажувати багато накреслень без потреби.

Якщо інтерфейс використовує лише Regular і Bold, немає сенсу автоматично завантажувати всі доступні накреслення.

---

❌ Не задавати fallback.

    body {
        font-family: "Inter";
    }

Краще:

    body {
        font-family: "Inter", sans-serif;
    }

---

❌ Не враховувати метрики fallback-шрифту.

Якщо запасний шрифт має іншу ширину символів, текст може переноситися інакше.

---

❌ Не враховувати ліцензію.

Не кожен шрифт дозволено використовувати в комерційних продуктах або самостійно розміщувати на сервері.

---

❌ Завантажувати шрифт без потреби.

Системний шрифт може бути достатнім для конкретного проєкту.

---

❌ Не перевіряти шрифт у реальному інтерфейсі.

Тестуй заголовки, абзаци, кнопки, поля введення, цифри та довгі українські слова.

---

# Практичні приклади

## Приклад 1 — базовий font stack

    body {
        font-family:
            "Inter",
            "Segoe UI",
            Arial,
            sans-serif;
    }

Першим використовується Inter, якщо він доступний.

Якщо ні — браузер переходить до наступних варіантів.

---

## Приклад 2 — системний шрифт

    body {
        font-family: system-ui, sans-serif;
    }

Підходить для інтерфейсів, де важливі простота та мінімальна залежність від зовнішніх файлів.

---

## Приклад 3 — окремий шрифт для коду

    body {
        font-family: "Inter", sans-serif;
    }

    code,
    pre {
        font-family: "JetBrains Mono", monospace;
    }

Основний текст використовує sans-serif, а код — monospace.

---

## Приклад 4 — локальний вебшрифт

    @font-face {
        font-family: "MyFont";
        src: url("/fonts/my-font-regular.woff2") format("woff2");
        font-weight: 400;
        font-style: normal;
        font-display: swap;
    }

    body {
        font-family: "MyFont", sans-serif;
    }

Файл шрифту завантажується з папки `public/fonts`, якщо проєкт обслуговує цю папку за шляхом `/fonts`.

---

## Приклад 5 — Regular і Bold

    @font-face {
        font-family: "MyFont";
        src: url("/fonts/my-font-regular.woff2") format("woff2");
        font-weight: 400;
        font-style: normal;
        font-display: swap;
    }

    @font-face {
        font-family: "MyFont";
        src: url("/fonts/my-font-bold.woff2") format("woff2");
        font-weight: 700;
        font-style: normal;
        font-display: swap;
    }

    body {
        font-family: "MyFont", sans-serif;
        font-weight: 400;
    }

    h1 {
        font-weight: 700;
    }

Браузер зможе використовувати відповідні файли для звичайного тексту та заголовка.

---

## Приклад 6 — variable font

    @font-face {
        font-family: "MyVariableFont";
        src: url("/fonts/my-variable-font.woff2") format("woff2");
        font-weight: 100 900;
        font-style: normal;
        font-display: swap;
    }

    body {
        font-family: "MyVariableFont", sans-serif;
        font-weight: 400;
    }

    h1 {
        font-weight: 750;
    }

Діапазон `100 900` повідомляє браузеру, що файл підтримує цей діапазон ваги.

---

## Приклад 7 — перевірка кирилиці

    const sampleText =
        "Ґанок, ґудзик, Європа, Україна, Київ, їжак.";

Текст можна вставити в тестову сторінку, щоб перевірити, як шрифт відображає українські символи.

# Типові помилки в CSS

## Помилка 1 — відсутній fallback

    body {
        font-family: "Inter";
    }

Краще:

    body {
        font-family: "Inter", sans-serif;
    }

---

## Помилка 2 — неправильна назва сімейства

    body {
        font-family: Inter Display, sans-serif;
    }

Якщо назва містить пробіли, використовуй лапки:

    body {
        font-family: "Inter Display", sans-serif;
    }

---

## Помилка 3 — неправильний діапазон variable font

    @font-face {
        font-family: "MyFont";
        src: url("/fonts/my-font.woff2") format("woff2");
        font-weight: 400;
    }

Якщо файл підтримує variable weight від 100 до 900, діапазон потрібно описати відповідно:

    @font-face {
        font-family: "MyFont";
        src: url("/fonts/my-font.woff2") format("woff2");
        font-weight: 100 900;
    }

Це правило потрібно застосовувати лише тоді, коли файл справді підтримує відповідний діапазон.

---

## Помилка 4 — використання відсутнього накреслення

    h1 {
        font-weight: 800;
    }

Якщо підключений статичний шрифт має лише Regular і Bold, браузер не обов'язково матиме справжнє накреслення 800.

Потрібно перевірити, які ваги реально доступні.

---

## Помилка 5 — неправильний шлях до файлу

    src: url("/fonts/inter.woff2");

Якщо файл фактично знаходиться в іншому місці, шрифт не завантажиться.

Перевіряй:

    file location
    URL path
    browser Network tab
    browser Console

## Browser DevTools

- яке значення `font-weight` використовується;

# Font Licensing

Font licensing — ліцензія, яка визначає дозволені способи використання шрифту.

Потрібно перевіряти:

- чи дозволене комерційне використання;
- чи можна розміщувати файл на власному сервері;
- чи дозволено модифікувати шрифт;
- чи є вимоги щодо зазначення авторства;
- чи дозволене вбудовування у програмне забезпечення;
- які умови поширення файлів.

Навіть безкоштовний для завантаження шрифт не обов'язково дозволено використовувати будь-яким способом.

Перед використанням у реальному продукті перевіряй конкретну ліцензію.

# Міні-шпаргалка

## Font categories

    serif       → шрифти із засічками
    sans-serif  → шрифти без засічок
    monospace   → однакова ширина символів
    cursive     → рукописний стиль
    fantasy     → декоративний стиль

---

## Font family

    body {
        font-family: "Inter", sans-serif;
    }

    preferred font → fallback family

---

## System font

    body {
        font-family: system-ui, sans-serif;
    }

Використовує системний UI-шрифт.

---

## Font weight

    400 → Regular
    500 → Medium
    600 → SemiBold
    700 → Bold

Це поширені відповідності, але доступні накреслення залежать від шрифту.

---

## Font style

    font-style: normal;
    font-style: italic;
    font-style: oblique;

---

## Web font

    @font-face {
        font-family: "MyFont";
        src: url("/fonts/my-font.woff2") format("woff2");
        font-weight: 400;
        font-style: normal;
        font-display: swap;
    }

---

## Variable font

    @font-face {
        font-family: "MyVariableFont";
        src: url("/fonts/my-variable-font.woff2") format("woff2");
        font-weight: 100 900;
    }

Використовуй діапазон, який реально підтримує файл.

---

## Font metrics

    baseline  → базова лінія
    ascent    → верхня зона метрик
    descent   → нижня зона метрик
    cap height → висота великих літер
    x-height  → висота основної зони малих літер

---

## Character vs Glyph

    Character → символ тексту
    Glyph     → графічне представлення символу

---

## Readability vs Legibility

    Readability → наскільки легко читати текст
    Legibility  → наскільки легко розрізняти символи

---

## Font loading

    CSS
      ↓
    font request
      ↓
    font file
      ↓
    text rendering

---

## Основні правила

    body text → читабельність
    headings  → виразна ієрархія
    code      → monospace
    fallback  → резервний варіант
    WOFF2     → поширений сучасний вебформат
    system-ui → системний UI-шрифт
    variable  → змінні параметри накреслення

# Головне

• Шрифт — один із ключових інструментів візуальної комунікації в UI Design.

• Вибір шрифту впливає на характер інтерфейсу, читабельність і сприйняття бренду.

• Typeface описує дизайн літер, а font у сучасному контексті може означати конкретне накреслення або шрифтовий ресурс.

• Serif, sans-serif і monospace — три важливі категорії шрифтів для практичної роботи.

• System fonts можуть бути хорошим рішенням, коли потрібні простота та мінімальна кількість зовнішніх ресурсів.

• Web fonts дозволяють використовувати конкретні сімейства шрифтів незалежно від того, чи встановлені вони в користувача.

• Font stack забезпечує запасні варіанти, якщо основний шрифт недоступний.

• Під час вибору шрифту необхідно перевіряти підтримку української кирилиці.

• Static fonts зазвичай містять окремі фіксовані накреслення, а variable fonts можуть підтримувати діапазони параметрів.

• WOFF2 — поширений формат для вебшрифтів.

• `@font-face` дозволяє підключати шрифтові файли.

• `font-display` допомагає визначити поведінку тексту під час завантаження вебшрифту.

• Font metrics впливають на те, як текст виглядає та скільки місця він займає.

• Legibility відповідає за розрізнення символів, а readability — за комфорт читання тексту.

• Не потрібно завантажувати всі можливі накреслення, якщо вони не використовуються в інтерфейсі.

• Потрібно перевіряти ліцензію шрифту перед використанням у проєкті.

• Шрифт слід оцінювати в реальному інтерфейсі, а не лише за демонстраційним заголовком.

• Для якісної типографіки важливі не тільки шрифти, а й розмір, товщина, міжрядковий інтервал, ширина рядка та ієрархія.

• Основна послідовність роботи зі шрифтами:

    1. Визначити призначення інтерфейсу.
    2. Вибрати відповідне сімейство шрифтів.
    3. Перевірити підтримку потрібних символів.
    4. Визначити необхідні накреслення.
    5. Підключити шрифт або вибрати системний.
    6. Налаштувати fallback.
    7. Перевірити завантаження та відображення.
    8. Оцінити читабельність на різних пристроях.

• Правильний вибір шрифту — це баланс між естетикою, читабельністю, доступністю, продуктивністю та потребами конкретного продукту.

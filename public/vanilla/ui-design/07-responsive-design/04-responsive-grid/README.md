# 04. Responsive Grid — Адаптивні сітки

## 1. Що таке Responsive Grid?

**Responsive Grid (адаптивна сітка)** — це спосіб організації елементів вебсторінки в рядки та колонки, які пристосовуються до доступного простору.

Адаптивна сітка допомагає розміщувати картки, зображення, текстові блоки та інші компоненти так, щоб інтерфейс залишався зручним на смартфонах, планшетах, ноутбуках і великих моніторах.

Наприклад, каталог товарів може мати:

- одну колонку на вузькому екрані;
- дві колонки на планшеті;
- три або чотири колонки на широкому екрані.

Але кількість колонок не обов'язково потрібно задавати окремо для кожного пристрою. CSS Grid дозволяє створювати сітки, які автоматично підлаштовуються до ширини контейнера.

    .grid {
      display: grid;
      grid-template-columns: repeat(
        auto-fit,
        minmax(240px, 1fr)
      );
      gap: 1rem;
    }

У цьому прикладі браузер автоматично визначає, скільки колонок можна розмістити в контейнері, зважаючи на доступний простір і мінімальну ширину треку.

**Головна ідея:** адаптивна сітка повинна організовувати контент відповідно до доступного простору, зберігаючи читабельність і зрозумілу структуру.

---

## 2. Навіщо потрібні адаптивні сітки?

Без адаптивної сітки елементи можуть:

- ставати надто вузькими;
- виходити за межі контейнера;
- утворювати незручні довгі рядки;
- залишати надто багато порожнього простору;
- порушувати візуальну ієрархію;
- вимагати горизонтального прокручування.

Responsive Grid допомагає:

- ✔ розміщувати елементи в упорядкованих колонках і рядках;
- ✔ автоматично змінювати кількість колонок;
- ✔ створювати каталоги, галереї, картки та панелі;
- ✔ контролювати мінімальну й максимальну ширину елементів;
- ✔ підтримувати однакові проміжки;
- ✔ зменшувати кількість необхідних медіазапитів;
- ✔ поєднувати гнучкість макета з передбачуваною структурою.

Адаптивна сітка — це не лише зміна кількості колонок. Вона також може змінювати пропорції, порядок і розташування блоків залежно від потреб інтерфейсу.

---

## 3. Responsive Grid і CSS Grid

**CSS Grid** — це технологія CSS для створення двовимірних макетів.

Вона дозволяє працювати одночасно з:

- рядками;
- колонками;
- проміжками;
- розмірами треків;
- розташуванням елементів;
- областями сітки.

**Responsive Grid** — це підхід до проєктування адаптивних сіток, який може використовувати CSS Grid, Flexbox або інші засоби CSS.

На практиці CSS Grid часто є найзручнішим інструментом для адаптивних сіток карток і складних двовимірних макетів.

### Приклад простої сітки

    .grid {
      display: grid;
      grid-template-columns: 1fr 1fr;
      gap: 1rem;
    }

Цей код створює дві колонки однакової частки доступного простору.

Однак сам по собі він не гарантує, що дві колонки залишатимуться зручними на дуже вузькому екрані. Для цього потрібно передбачити адаптивну поведінку.

---

## 4. Основні поняття CSS Grid

### 4.1. Grid container

**Grid container** — елемент, для якого встановлено `display: grid` або `display: inline-grid`.

    .cards {
      display: grid;
    }

Його безпосередні дочірні елементи стають grid items.

### 4.2. Grid items

**Grid items** — безпосередні дочірні елементи Grid-контейнера.

    .cards {
      display: grid;
      grid-template-columns: repeat(3, 1fr);
    }

    .card {
      padding: 1rem;
    }

Якщо всередині `.cards` розміщено шість карток, браузер розташовуватиме їх у створених колонках і рядках.

Важливо: елементи всередині самої картки не стають grid items зовнішньої сітки автоматично. Для цього потрібна окрема сітка або інший механізм компонування.

### 4.3. Grid tracks

**Grid track** — рядок або колонка сітки.

Наприклад:

    .grid {
      display: grid;
      grid-template-columns: 200px 1fr;
      grid-template-rows: auto auto;
    }

Тут створено дві колонки та задано два явні рядки.

Якщо елементів більше, ніж місць у явно визначених рядках, браузер може створювати додаткові неявні рядки.

### 4.4. Grid lines

**Grid lines** — лінії, що розділяють рядки та колонки.

Вони можуть використовуватися для розміщення елементів на конкретних ділянках сітки.

    .featured {
      grid-column: 1 / 3;
    }

Цей елемент починається на першій вертикальній лінії та закінчується на третій, займаючи дві колонки, якщо така структура існує.

### 4.5. Grid cells

**Grid cell** — окрема комірка, утворена перетином рядка та колонки.

### 4.6. Grid area

**Grid area** — область сітки, яка може охоплювати одну або декілька комірок.

Це корисно для макетів сторінки з header, sidebar, main і footer.

## 5. Одиниці та функції для адаптивних сіток

Для Responsive Grid особливо важливі:

- `fr`;
- `%`;
- `min-content`;
- `max-content`;
- `minmax()`;
- `repeat()`;
- `auto-fit`;
- `auto-fill`.

### 5.1. Одиниця `fr`

`fr` означає частку вільного простору Grid-контейнера.

    .grid {
      display: grid;
      grid-template-columns: 1fr 1fr;
      gap: 1rem;
    }

Дві колонки отримують однакові частки вільного простору після врахування проміжків та інших обмежень.

Інший приклад:

    .grid {
      display: grid;
      grid-template-columns: 1fr 2fr;
      gap: 1rem;
    }

Друга колонка отримує вдвічі більшу частку вільного простору, ніж перша, якщо інші обмеження не впливають на розрахунок.

`1fr` не означає фіксовану ширину. Значення змінюється залежно від доступного простору.

### 5.2. Відсотки в Grid

    .grid {
      display: grid;
      grid-template-columns: 30% 70%;
    }

Колонки задаються відносно розміру Grid-контейнера.

Проте потрібно враховувати проміжки. Дві колонки по `50%` разом із додатковим `gap` можуть перевищити доступну ширину.

Для більшості гнучких сіток часто зручніше використовувати `fr`.

### 5.3. `min-content`

`min-content` — мінімальний розмір треку, який дозволяє вмісту стискатися відповідно до його мінімальних вимог.

    .grid {
      display: grid;
      grid-template-columns: min-content 1fr;
    }

Це може бути корисно для невеликих елементів, але довгі нерозривні слова або URL можуть впливати на результат.

### 5.4. `max-content`

`max-content` — розмір, потрібний вмісту за умови, що він не переноситься без необхідності.

    .grid {
      display: grid;
      grid-template-columns: max-content 1fr;
    }

Потрібно використовувати обережно: довгий текст може вимагати більше простору, ніж доступно на вузькому екрані.

### 5.5. `minmax()`

`minmax()` задає мінімальний і максимальний розмір треку.

    .grid {
      display: grid;
      grid-template-columns: minmax(200px, 1fr) 2fr;
    }

Перша колонка має мінімальну ширину `200px`, а її максимальний розмір може збільшуватися до доступної частки простору.

Якщо весь контейнер стає вужчим за суму мінімальних вимог колонок, може знадобитися інша структура макета.

### 5.6. `repeat()`

`repeat()` дозволяє повторювати визначення треків.

    .grid {
      display: grid;
      grid-template-columns: repeat(3, 1fr);
    }

Це еквівалентно трьом однаковим колонкам:

    .grid {
      display: grid;
      grid-template-columns: 1fr 1fr 1fr;
    }

`repeat()` особливо корисний у поєднанні з автоматичним розміщенням.

## 6. Статична та адаптивна кількість колонок

### 6.1. Статична кількість колонок

    .grid {
      display: grid;
      grid-template-columns: repeat(3, 1fr);
      gap: 1rem;
    }

Цей макет завжди визначає три колонки.

Переваги:

- зрозуміла структура;
- передбачуваний розподіл;
- простий контроль композиції.

Недоліки:

- колонки можуть стати надто вузькими;
- на мобільному екрані часто потрібні додаткові медіазапити;
- довгий вміст може спричиняти переповнення.

### 6.2. Зміна колонок через медіазапити

    .grid {
      display: grid;
      grid-template-columns: 1fr;
      gap: 1rem;
    }

    @media (min-width: 600px) {
      .grid {
        grid-template-columns: repeat(2, 1fr);
      }
    }

    @media (min-width: 900px) {
      .grid {
        grid-template-columns: repeat(3, 1fr);
      }
    }

Цей підхід забезпечує контроль над кількістю колонок на різних ширинах.

Він підходить, якщо потрібна конкретна композиція, але точки перелому потрібно вибирати за поведінкою контенту, а не лише за назвами пристроїв.

### 6.3. Автоматична кількість колонок

    .grid {
      display: grid;
      grid-template-columns: repeat(
        auto-fit,
        minmax(240px, 1fr)
      );
      gap: 1rem;
    }

Браузер автоматично визначає кількість колонок, які можуть поміститися в контейнері з урахуванням мінімальної ширини треку.

Такий варіант часто дозволяє обійтися без медіазапитів для зміни кількості колонок.

---

## 7. Різниця між `auto-fit` і `auto-fill`

Обидва значення використовуються в автоматичному повторенні треків:

    repeat(auto-fit, ...)
    repeat(auto-fill, ...)

Вони дозволяють браузеру визначати кількість колонок залежно від доступного простору.

### 7.1. `auto-fit`

`auto-fit` дозволяє згорнути порожні повторені треки після розміщення елементів. Завдяки цьому наявні елементи можуть займати більше простору.

    .grid {
      display: grid;
      grid-template-columns: repeat(
        auto-fit,
        minmax(220px, 1fr)
      );
      gap: 1rem;
    }

Це часто зручно для каталогів, у яких картки повинні рівномірно розтягуватися.

### 7.2. `auto-fill`

`auto-fill` намагається зберігати всі треки, які поміщаються в контейнері, навіть якщо деякі з них залишаються порожніми.

    .grid {
      display: grid;
      grid-template-columns: repeat(
        auto-fill,
        minmax(220px, 1fr)
      );
      gap: 1rem;
    }

Це може бути корисним, коли важливо зберегти структуру сітки та порожні місця.

### 7.3. Що вибрати?

Для типового каталогу карток почни з `auto-fit`.

Якщо потрібно, щоб порожні позиції в сітці зберігалися, перевір `auto-fill`.

Важливо: результат залежить від ширини контейнера, кількості елементів, мінімального розміру треків та інших обмежень.

## 8. Формула адаптивної сітки

Один із найкорисніших шаблонів:

    .grid {
      display: grid;
      grid-template-columns: repeat(
        auto-fit,
        minmax(min(100%, 250px), 1fr)
      );
      gap: 1.5rem;
    }

Розглянемо кожну частину.

### `display: grid`

Створює Grid-контейнер.

### `repeat(auto-fit, ...)`

Автоматично повторює стільки колонок, скільки дозволяє доступний простір.

### `minmax(..., 1fr)`

Задає мінімальний і максимальний розмір колонки.

### `min(100%, 250px)`

Вибирає менше значення між `100%` доступної ширини та `250px`.

Це допомагає уникнути ситуації, коли мінімальна ширина колонки перевищує ширину дуже вузького контейнера.

### `gap: 1.5rem`

Задає однаковий проміжок між рядками та колонками.

**Коли використовувати цей шаблон?**

- каталоги;
- галереї;
- картки статей;
- списки навчальних матеріалів;
- блоки рекомендацій;
- картки послуг.

Цей шаблон є відправною точкою, а не універсальним рішенням для всіх макетів.

## 9. Responsive Grid із фіксованою мінімальною шириною

Іноді потрібно, щоб картки не ставали меншими за певний розмір.

    .cards {
      display: grid;
      grid-template-columns: repeat(
        auto-fit,
        minmax(280px, 1fr)
      );
      gap: 1.5rem;
    }

У цьому випадку кожна колонка має мінімальний розмір `280px`.

Але якщо контейнер стає вужчим за `280px`, сітка може переповнювати доступний простір.

Для більшої надійності на дуже вузьких екранах можна використати:

    .cards {
      display: grid;
      grid-template-columns: repeat(
        auto-fit,
        minmax(min(100%, 280px), 1fr)
      );
      gap: 1.5rem;
    }

Тепер мінімальна ширина треку не перевищуватиме доступну ширину контейнера.

### Важливе правило

Якщо потрібно гарантувати, що колонка не буде ширшою за контейнер, перевіряй не лише `minmax()`, а й ширину самого контейнера, його відступи та мінімальні розміри вмісту.

## 10. Responsive Grid для різних типів макетів

### 10.1. Сітка карток

    .cards {
      display: grid;
      grid-template-columns: repeat(
        auto-fit,
        minmax(min(100%, 240px), 1fr)
      );
      gap: 1rem;
    }

Підходить для каталогів, списків статей і навчальних матеріалів.

### 10.2. Дві колонки з різними пропорціями

    .content-layout {
      display: grid;
      grid-template-columns: 1fr 2fr;
      gap: 2rem;
    }

Одна колонка займає меншу частку простору, інша — більшу.

Для вузьких екранів може знадобитися перехід до однієї колонки.

    @media (max-width: 700px) {
      .content-layout {
        grid-template-columns: 1fr;
      }
    }

### 10.3. Основний контент і бічна панель

    .page-layout {
      display: grid;
      grid-template-columns: 16rem minmax(0, 1fr);
      gap: 2rem;
    }

`16rem` задає бажану ширину бічної панелі, а `minmax(0, 1fr)` дозволяє основному контенту займати залишок простору.

На вузькому екрані:

    @media (max-width: 750px) {
      .page-layout {
        grid-template-columns: 1fr;
      }
    }

Тепер контент і бічна панель розташовуються вертикально.

### 10.4. Галерея з різними розмірами елементів

    .gallery {
      display: grid;
      grid-template-columns: repeat(4, 1fr);
      gap: 0.75rem;
    }

    .gallery__item--wide {
      grid-column: span 2;
    }

    .gallery__item--tall {
      grid-row: span 2;
    }

Це дозволяє створювати складнішу композицію.

Однак для такого макета потрібно додатково перевіряти поведінку на вузьких екранах. Іноді окремі елементи повинні перестати займати кілька колонок.

    @media (max-width: 600px) {
      .gallery {
        grid-template-columns: repeat(2, minmax(0, 1fr));
      }

      .gallery__item--wide {
        grid-column: auto;
      }
    }

### 10.5. Макет сторінки через `grid-template-areas`

    .page {
      display: grid;
      grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
      grid-template-columns: 16rem minmax(0, 1fr);
      gap: 1rem;
    }

    .header {
      grid-area: header;
    }

    .sidebar {
      grid-area: sidebar;
    }

    .main {
      grid-area: main;
    }

    .footer {
      grid-area: footer;
    }

Для вузького екрана:

    @media (max-width: 750px) {
      .page {
        grid-template-areas:
          "header"
          "main"
          "sidebar"
          "footer";
        grid-template-columns: minmax(0, 1fr);
      }
    }

`grid-template-areas` дозволяє наочно описати структуру сторінки та змінювати розташування областей.

Проте CSS-перестановка не змінює порядок елементів у DOM. Переконайся, що порядок читання та клавіатурної навігації залишається логічним.

## 11. `minmax(0, 1fr)` і проблема переповнення

Поширена ситуація: Grid-колонка має `1fr`, але її вміст не дозволяє їй достатньо звузитися.

Наприклад:

    .layout {
      display: grid;
      grid-template-columns: 250px 1fr;
      gap: 1rem;
    }

У другій колонці може бути довгий URL, таблиця або інший елемент із великим мінімальним розміром.

У результаті вміст може виходити за межі макета.

У багатьох випадках допомагає:

    .layout {
      display: grid;
      grid-template-columns: 250px minmax(0, 1fr);
      gap: 1rem;
    }

`minmax(0, 1fr)` дозволяє треку мати нульову мінімальну ширину, замість того щоб покладатися на мінімальний розмір вмісту.

Для самого елемента також може знадобитися:

    .main {
      min-width: 0;
    }

А для довгих нерозривних рядків:

    .text {
      overflow-wrap: anywhere;
    }

Не застосовуй ці властивості механічно до всіх елементів. Спочатку визнач, що саме спричиняє переповнення.

## 12. Проміжки між елементами: `gap`

`gap` задає відстань між рядками та колонками.

    .grid {
      display: grid;
      grid-template-columns: repeat(3, 1fr);
      gap: 1.5rem;
    }

Можна задавати окремі значення:

    .grid {
      display: grid;
      row-gap: 2rem;
      column-gap: 1rem;
    }

Або використовувати короткий запис:

    .grid {
      gap: 2rem 1rem;
    }

У короткому записі перше значення відповідає проміжку між рядками, друге — між колонками.

Для адаптивних сіток `gap` зазвичай зручніший за додавання `margin` до кожної картки.

Переваги:

- відсутні зайві зовнішні відступи останніх елементів;
- простіше контролювати відстані;
- легше підтримувати єдину систему інтервалів;
- простіше змінювати щільність сітки.

### Плавна зміна проміжків

    .grid {
      gap: clamp(0.75rem, 2vw, 1.5rem);
    }

Проміжки плавно змінюються в межах заданих значень.

Але не завжди потрібно робити `gap` гумовим. У багатьох інтерфейсах сталі значення з дизайн-системи дають передбачуваніший результат.

## 13. Адаптивна ширина контейнера

Адаптивна сітка залежить від доступного простору свого контейнера.

Тому важливо правильно налаштувати зовнішній контейнер.

    *,
    *::before,
    *::after {
      box-sizing: border-box;
    }

    .container {
      width: min(100% - 2rem, 1200px);
      margin-inline: auto;
    }

    .grid {
      display: grid;
      grid-template-columns: repeat(
        auto-fit,
        minmax(min(100%, 240px), 1fr)
      );
      gap: 1.5rem;
    }

У цьому прикладі:

- контейнер займає доступну ширину за вирахуванням горизонтальних відступів;
- максимальна ширина контейнера обмежена `1200px`;
- сітка автоматично визначає кількість колонок;
- колонки не мають бути вужчими за `240px`, якщо доступний простір це дозволяє;
- на дуже вузькому контейнері мінімум колонки зменшується до доступної ширини.

Такий підхід допомагає створювати адаптивні макети без великої кількості медіазапитів.

## 14. Responsive Grid і медіазапити

Автоматичне розміщення не завжди достатнє.

Іноді потрібно змінити саму композицію, а не лише кількість колонок.

Наприклад:

- на широкому екрані — картки у три колонки;
- на середньому — у дві;
- на вузькому — одна колонка.

Це можна реалізувати за допомогою медіазапитів.

    .cards {
      display: grid;
      grid-template-columns: 1fr;
      gap: 1rem;
    }

    @media (min-width: 600px) {
      .cards {
        grid-template-columns: repeat(2, minmax(0, 1fr));
      }
    }

    @media (min-width: 900px) {
      .cards {
        grid-template-columns: repeat(3, minmax(0, 1fr));
      }
    }

Точки перелому `600px` і `900px` наведені як приклад.

Їх потрібно обирати на основі:

- мінімальної зручної ширини картки;
- довжини тексту;
- кількості колонок;
- доступності кнопок;
- характеру контенту;
- загальної композиції.

### Коли вибирати автоматичну сітку?

Використовуй `auto-fit` і `minmax()`, коли кількість колонок може змінюватися плавно залежно від ширини контейнера.

### Коли вибирати медіазапити?

Використовуй медіазапити, коли потрібно заздалегідь визначити конкретну структуру або змінити поведінку інтерфейсу.

Ці підходи можна комбінувати.

## 15. Адаптивні сітки для зображень

Галереї та каталоги часто використовують CSS Grid.

### 15.1. Проста адаптивна галерея

    .gallery {
      display: grid;
      grid-template-columns: repeat(
        auto-fit,
        minmax(min(100%, 200px), 1fr)
      );
      gap: 1rem;
    }

    .gallery img {
      display: block;
      width: 100%;
      aspect-ratio: 4 / 3;
      object-fit: cover;
    }

У цьому прикладі:

- кількість колонок змінюється автоматично;
- зображення займають ширину своїх колонок;
- пропорції всіх зображень однакові;
- `object-fit: cover` заповнює область, обрізаючи зайву частину зображення.

### 15.2. Зображення без обрізання

    .product-image {
      width: 100%;
      aspect-ratio: 1;
      object-fit: contain;
    }

Це підходить для товарів, логотипів, схем та інших зображень, які важливо показувати повністю.

### 15.3. Різна висота елементів

Якщо картки містять зображення з різними пропорціями, вони можуть мати різну висоту.

Для регулярної сітки можна задати однакове співвідношення сторін. Для художньої галереї, навпаки, різна висота може бути частиною композиції.

Вибирай спосіб відповідно до призначення сторінки.

## 16. Responsive Grid для карток із текстом

Картка може містити:

- зображення;
- заголовок;
- опис;
- кнопку;
- додаткові метадані.

Важливо, щоб довший текст не руйнував сітку.

    .cards {
      display: grid;
      grid-template-columns: repeat(
        auto-fit,
        minmax(min(100%, 260px), 1fr)
      );
      gap: 1.25rem;
    }

    .card {
      display: flex;
      flex-direction: column;
      min-width: 0;
      padding: 1rem;
      border: 1px solid #ddd;
      border-radius: 0.75rem;
    }

    .card__title {
      overflow-wrap: anywhere;
    }

    .card__description {
      overflow-wrap: anywhere;
    }

    .card__button {
      align-self: flex-start;
      margin-top: auto;
    }

Тут зовнішня сітка відповідає за розташування карток, а Flexbox усередині картки — за розташування її вмісту.

`margin-top: auto` може розміщувати кнопку внизу картки, якщо картки мають достатню висоту та відповідну структуру.

Не потрібно задавати всім карткам жорстку висоту лише для вирівнювання кнопок. Спочатку перевір, чи можна досягти потрібного результату гнучким компонуванням.

6. `gap` контролює відстань між картками.
7. `aspect-ratio` підтримує однакові пропорції зображень.
8. Flexbox організовує вміст усередині картки.
9. `clamp()` плавно змінює розмір заголовка та відступи.
10. Довгий текст може переноситися, не руйнуючи структуру.

Цей приклад не потребує медіазапитів лише для зміни кількості колонок.

## 18. Типові помилки під час створення Responsive Grid

### Помилка 1. Фіксовані колонки без перевірки вузьких екранів

    .grid {
      display: grid;
      grid-template-columns: repeat(4, 1fr);
    }

На вузькому екрані чотири колонки можуть стати надто вузькими.

Рішення: використовуй адаптивну кількість колонок або змінюй структуру за допомогою медіазапитів.

### Помилка 2. Мінімальна ширина більша за контейнер

    .grid {
      grid-template-columns: repeat(
        auto-fit,
        minmax(280px, 1fr)
      );
    }

Якщо контейнер вужчий за `280px`, може з'явитися горизонтальне переповнення.

Краще:

    .grid {
      grid-template-columns: repeat(
        auto-fit,
        minmax(min(100%, 280px), 1fr)
      );
    }

### Помилка 3. Неправильний розрахунок відсоткових колонок

    .grid {
      grid-template-columns: 50% 50%;
      gap: 1rem;
    }

Сума ширин колонок уже дорівнює ширині контейнера, тому додатковий `gap` може спричинити переповнення.

Краще:

    .grid {
      grid-template-columns: repeat(2, minmax(0, 1fr));
      gap: 1rem;
    }

### Помилка 4. Довгий текст розширює колонку

    .grid {
      grid-template-columns: 250px 1fr;
    }

Якщо друга колонка містить довгий нерозривний рядок, він може впливати на мінімальний розмір треку.

Краще перевірити:

    .grid {
      grid-template-columns: 250px minmax(0, 1fr);
    }

    .grid-item {
      min-width: 0;
      overflow-wrap: anywhere;
    }

Властивості потрібно застосовувати до елементів, які справді спричиняють проблему.

### Помилка 5. Використання Grid для кожного елемента

Grid не потрібно застосовувати скрізь.

Для звичайного текстового потоку часто достатньо стандартного блокового розташування.

Для ряду кнопок або елементів навігації може бути зручнішим Flexbox.

Вибирай інструмент відповідно до структури.

### Помилка 6. Надто багато медіазапитів

Якщо сітка може автоматично змінювати кількість колонок, немає потреби створювати медіазапит для кожного пристрою.

Використовуй медіазапити, коли необхідно змінити композицію або поведінку.

### Помилка 7. Однакова сітка для всіх типів контенту

Картки товарів, фотографії, статті та панелі можуть мати різні вимоги до ширини.

Для кожного типу контенту визначай:

- мінімальну зручну ширину;
- бажану кількість колонок;
- максимальну ширину;
- необхідні пропорції;
- характер тексту;
- поведінку на вузьких екранах.

### Помилка 8. Перевірка тільки на стандартних розмірах

Макет може працювати на `390px` і `768px`, але ламатися на ширині між ними.

Змінюй ширину viewport поступово, щоб помітити момент, коли сітка перестає працювати.

## 19. Responsive Grid і доступність

Адаптивна сітка повинна підтримувати не лише візуальну структуру, а й зручність користування.

### 19.1. Логічний порядок вмісту

CSS Grid може візуально переміщувати елементи, але порядок DOM залишається важливим для:

- читачів екрана;
- клавіатурної навігації;
- послідовного читання;
- розуміння структури сторінки.

Не змінюй порядок елементів лише заради зовнішнього вигляду, якщо це робить взаємодію незрозумілою.

### 19.2. Достатній простір для тексту

Не створюй надто вузькі колонки, у яких текст перетворюється на довгі стовпчики з частими переносами.

Якщо контент не поміщається, краще зменшити кількість колонок.

### 19.3. Довгі заголовки

Перевіряй, як картки поводяться з довшими заголовками, адресами, URL і перекладами.

    .card__title {
      overflow-wrap: anywhere;
    }

Це допомагає запобігати горизонтальному переповненню через довгі нерозривні слова.

### 19.4. Збільшення масштабу

Перевіряй сітку при збільшенні масштабу сторінки.

Вона повинна дозволяти контенту змінювати розміри без обрізання важливих елементів.

### 19.5. Не приховуй важливий контент без причини

Якщо на вузькому екрані картки не поміщаються, не варто автоматично приховувати частину з них.

Краще змінити кількість колонок або структуру макета.

## 20. Як тестувати адаптивну сітку

Після створення сітки потрібно перевірити її на різних ширинах viewport.

### Перевір такі параметри

- ✔ Чи змінюється кількість колонок у потрібний момент?
- ✔ Чи зберігається комфортна ширина карток?
- ✔ Чи не з'являється горизонтальне прокручування?
- ✔ Чи не виходить текст за межі карток?
- ✔ Чи зберігаються проміжки між елементами?
- ✔ Чи правильно масштабується зображення?
- ✔ Чи не стає контейнер надто широким?
- ✔ Чи працює сітка з різною кількістю елементів?
- ✔ Чи коректно виглядає останній неповний ряд?
- ✔ Чи не порушується порядок читання?

### Практична послідовність

1. Відкрий сторінку в браузері.
2. Увімкни DevTools.
3. Перейди в режим адаптивного перегляду.
4. Перевір ширину `320px`.
5. Перевір ширину близько `390px`.
6. Перевір ширину планшета.
7. Перевір звичайний ноутбук.
8. Перевір широкий монітор.
9. Поступово змінюй ширину viewport.
10. Перевір короткий і довгий текст.
11. Перевір сітку з однією, двома, трьома та багатьма картками.
12. Перевір збільшення масштабу сторінки.

Ці розміри є прикладами тестування, а не обов'язковими точками перелому для кожного проєкту.

### Пошук горизонтального переповнення

Для тимчасової діагностики можна виконати в консолі браузера:

    [...document.querySelectorAll("*")].filter((element) => {
      const rect = element.getBoundingClientRect();

      return (
        rect.left < 0 ||
        rect.right > document.documentElement.clientWidth
      );
    });

Цей код знаходить елементи, чиї межі виходять за горизонтальні межі viewport.

Не кожен результат означає помилку. Наприклад, галерея з навмисним горизонтальним прокручуванням може використовувати такий дизайн свідомо.

## 21. Практичний алгоритм створення Responsive Grid

### Крок 1. Визнач структуру контенту

З'ясуй, що потрібно розмістити:

- картки;
- зображення;
- статті;
- блоки з інформацією;
- основний контент і бічну панель;
- секції сторінки.

### Крок 2. Визнач контейнер

    .container {
      width: min(100% - 2rem, 1200px);
      margin-inline: auto;
    }

Контейнер має адаптуватися до viewport і водночас мати розумну максимальну ширину.

### Крок 3. Визнач мінімальну зручну ширину елемента

Наприклад, картці може бути потрібно близько `240px`, щоб комфортно відображати зображення, заголовок і опис.

Це лише початкове значення. Перевір його на реальному вмісті.

### Крок 4. Вибери спосіб побудови сітки

Для автоматичного розміщення карток:

    .cards {
      display: grid;
      grid-template-columns: repeat(
        auto-fit,
        minmax(min(100%, 240px), 1fr)
      );
      gap: 1.5rem;
    }

Для конкретної кількості колонок:

    .cards {
      display: grid;
      grid-template-columns: repeat(3, minmax(0, 1fr));
      gap: 1.5rem;
    }

### Крок 5. Додай адаптивну поведінку

Якщо структура повинна змінюватися, додай медіазапити.

    @media (max-width: 700px) {
      .content-layout {
        grid-template-columns: 1fr;
      }
    }

### Крок 6. Перевір розміри вмісту

Особливо зверни увагу на:

- довгі заголовки;
- зображення;
- кнопки;
- таблиці;
- довгі URL;
- картки з різною кількістю тексту.

### Крок 7. Перевір крайні випадки

Тестуй макет із малою кількістю елементів, неповним останнім рядом і дуже вузьким контейнером.

### Крок 8. Перевір доступність

Переконайся, що порядок читання залишається логічним, текст не обрізається, а інтерактивні елементи залишаються доступними.

## 22. Що потрібно запам'ятати

✔ Responsive Grid — це адаптивне розміщення елементів у рядках і колонках.

✔ CSS Grid — основний інструмент для побудови двовимірних сіток.

✔ `display: grid` створює Grid-контейнер.

✔ Безпосередні дочірні елементи Grid-контейнера стають grid items.

✔ `grid-template-columns` визначає структуру колонок.

✔ `fr` задає частки вільного простору.

✔ `repeat()` дозволяє повторювати визначення треків.

✔ `minmax()` задає мінімальний і максимальний розмір треку.

✔ `auto-fit` дозволяє автоматично розміщувати доступну кількість колонок і згортати порожні треки.

✔ `auto-fill` зберігає треки, які поміщаються в контейнері, навіть якщо деякі залишаються порожніми.

✔ `gap` задає проміжки між рядками та колонками.

✔ `minmax(min(100%, 240px), 1fr)` допомагає створювати гнучкі колонки, які не перевищують доступну ширину контейнера.

✔ `minmax(0, 1fr)` часто допомагає уникати переповнення через мінімальні розміри вмісту.

✔ Адаптивна сітка може працювати без медіазапитів, якщо достатньо автоматичного розміщення.

✔ Медіазапити потрібні, коли змінюється структура або поведінка макета.

✔ Flexbox і Grid можуть використовуватися разом.

✔ Зображення часто потребують `width: 100%`, `aspect-ratio` та `object-fit`.

✔ Потрібно перевіряти не лише ширину viewport, а й реальний вміст.

✔ Правильна адаптивна сітка зберігає читабельність, пропорції та логічну структуру.

## 23. Мінішпаргалка

### Дві рівні колонки

    .grid {
      display: grid;
      grid-template-columns: repeat(2, minmax(0, 1fr));
      gap: 1rem;
    }

### Три рівні колонки

    .grid {
      display: grid;
      grid-template-columns: repeat(3, minmax(0, 1fr));
      gap: 1rem;
    }

### Адаптивні картки

    .grid {
      display: grid;
      grid-template-columns: repeat(
        auto-fit,
        minmax(min(100%, 240px), 1fr)
      );
      gap: 1.5rem;
    }

### Автоматична сітка з фіксованим мінімумом

    .grid {
      display: grid;
      grid-template-columns: repeat(
        auto-fit,
        minmax(250px, 1fr)
      );
      gap: 1rem;
    }

Використовуй цей варіант, коли контейнер гарантовано достатньо широкий. Для дуже вузьких контейнерів розглянь `minmax(min(100%, 250px), 1fr)`.

### Основний контент і бічна панель

    .layout {
      display: grid;
      grid-template-columns: 16rem minmax(0, 1fr);
      gap: 2rem;
    }

### Перехід до однієї колонки

    @media (max-width: 750px) {
      .layout {
        grid-template-columns: 1fr;
      }
    }

### Різні проміжки між рядками та колонками

    .grid {
      display: grid;
      row-gap: 2rem;
      column-gap: 1rem;
    }

### Сітка сторінки

    .page {
      display: grid;
      grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
      grid-template-columns: 16rem minmax(0, 1fr);
      gap: 1rem;
    }

### Адаптивна галерея

    .gallery {
      display: grid;
      grid-template-columns: repeat(
        auto-fit,
        minmax(min(100%, 200px), 1fr)
      );
      gap: 1rem;
    }

    .gallery img {
      display: block;
      width: 100%;
      aspect-ratio: 4 / 3;
      object-fit: cover;
    }

### Захист від переповнення

    .grid {
      grid-template-columns: minmax(0, 1fr);
    }

    .grid-item {
      min-width: 0;
      overflow-wrap: anywhere;
    }

### Центрований контейнер

    .container {
      width: min(100% - 2rem, 1200px);
      margin-inline: auto;
    }

## 25. Практичні завдання

### Завдання 1. Дві колонки

Створи Grid-контейнер із двома однаковими колонками.

Вимоги:

- використовуй `display: grid`;
- використай `grid-template-columns`;
- додай `gap`;
- перевір, як змінюється ширина колонок.

### Завдання 2. Три колонки

Створи сітку з трьома колонками однакової частки.

Перевір її з різною кількістю карток.

### Завдання 3. Адаптивний каталог

Створи сітку з шести карток.

Вимоги:

- мінімальна бажана ширина картки — `240px`;
- максимальна ширина контейнера — `1200px`;
- однакові проміжки;
- автоматична кількість колонок;
- відсутність горизонтального переповнення.

Спробуй `auto-fit`, `minmax()` і `min()`.

### Завдання 4. `auto-fit` проти `auto-fill`

Створи дві однакові сітки:

- перша використовує `auto-fit`;
- друга використовує `auto-fill`.

Залиш у кожній лише дві картки та збільш ширину контейнера.

Порівняй, як змінюється розподіл простору.

### Завдання 5. Основний контент і бічна панель

Створи макет із двома колонками:

- бічна панель;
- основний контент.

На вузькому екрані макет повинен переходити до однієї колонки.

### Завдання 6. Галерея зображень

Створи галерею з восьми зображень.

Вимоги:

- адаптивна кількість колонок;
- однакові проміжки;
- співвідношення сторін `4 / 3`;
- зображення заповнюють свої області;
- відсутнє горизонтальне переповнення.

### Завдання 7. Довгий текст

Додай до однієї картки дуже довгий заголовок або URL.

Перевір, чи впливає він на ширину колонки.

Спробуй використати:

    .card {
      min-width: 0;
      overflow-wrap: anywhere;
    }

За потреби перевір також визначення колонок через `minmax(0, 1fr)`.

### Завдання 8. Складна композиція

Створи макет із:

- header;
- sidebar;
- main;
- footer.

Використай `grid-template-areas`.

На вузькому екрані зміни розташування областей, зберігаючи логічний порядок читання.

### Завдання 9. Мініпроєкт — навчальний каталог

Створи адаптивну сторінку каталогу навчальних матеріалів.

Реалізуй:

- контейнер із максимальною шириною;
- адаптивну сітку карток;
- автоматичну кількість колонок;
- зображення однакових пропорцій;
- заголовки та описи;
- кнопки або посилання;
- узгоджені відступи;
- підтримку довгого тексту;
- перевірку на вузьких і широких екранах.

Спочатку спробуй реалізувати сітку за допомогою `auto-fit` і `minmax()`. Додавай медіазапити лише тоді, коли автоматичної поведінки недостатньо.

## 26. Рівні опанування теми

### Core — базовий рівень

Ти повинен уміти:

- пояснити призначення Responsive Grid;
- створити Grid-контейнер;
- визначати колонки через `grid-template-columns`;
- використовувати `fr`;
- додавати проміжки через `gap`;
- створювати сітку з двох або трьох колонок;
- розуміти різницю між фіксованою та адаптивною кількістю колонок.

### Junior — практичний рівень

Ти повинен уміти:

- створювати адаптивні сітки через `repeat()`, `minmax()` і `auto-fit`;
- розуміти різницю між `auto-fit` та `auto-fill`;
- комбінувати Grid із медіазапитами;
- створювати макети з основним контентом і бічною панеллю;
- використовувати `grid-template-areas`;
- уникати горизонтального переповнення;
- створювати адаптивні галереї;
- тестувати сітку з різною кількістю елементів.

### Middle — поглиблений рівень

Ти повинен уміти:

- проєктувати складні двовимірні макети;
- вибирати між автоматичним розміщенням і контрольованими точками перелому;
- працювати з `min-content`, `max-content` та `minmax()`;
- враховувати довгий і динамічний вміст;
- поєднувати Grid і Flexbox у компонентах;
- підтримувати читабельність та доступність;
- створювати гнучкі сітки для різних типів контенту.

### Senior — системний рівень

Ти повинен уміти:

- проєктувати систему адаптивних сіток для всього продукту;
- визначати узгоджені контейнери та проміжки;
- створювати композиції для різних інформаційних потреб;
- обирати між CSS Grid, Flexbox і Container Queries;
- оцінювати вплив зміни структури на доступність;
- створювати макети, які працюють із різною кількістю та довжиною контенту;
- підтримувати передбачувану поведінку інтерфейсу на нестандартних ширинах.

## 27. Головний принцип Responsive Grid

**Не намагайся вмістити однакову кількість колонок у кожен екран. Проєктуй сітку так, щоб елементи зберігали зручні розміри та логічну структуру.**

Використовуй `auto-fit` і `minmax()` для автоматичного розміщення карток. Використовуй медіазапити, коли потрібно змінити композицію. Застосовуй обмеження ширини, щоб контент не ставав надто широким або вузьким.

Хороша адаптивна сітка не просто змінює кількість колонок — вона допомагає зберігати читабельність, візуальну ієрархію та зручність користування на різних екранах.
